    1.0 综述的角色与边界#

    在进入正式 motivation 之前，先用一节明确本综述的角色与边界。本综述不试图替代任一子领域的深度专著——wildfire 资源最完整的是 Vahedi Nat. Rev. EE 2025；FDIA detection 最聚焦的是 Frontiers Smart Grids 2024；GFM IBR 最规范的是 UNIFI Consortium 文档；equity & metric 最权威的是 PNNL 2023。本综述的位置在这些专著与文档之上：它不重新做子领域内部的方法对比，而是把它们的方法接口暴露出来，让读者能在子领域间走动。

    边界划定如下：

    • 在范围内：2022–2026 期间 ML / optimization 方法服务于电网 anticipate / absorb / adapt / restore 四阶段，覆盖 weather / cyber / compound 三类 disruption。
    • 不在范围内：（i）市场设计与电力批发市场——除非作为指标外部性短暂提及；（ii）单纯硬件可靠性建模（绝缘老化、变压器寿命预测）；（iii）量子计算 / 神经形态计算等前沿计算架构对电力系统优化的影响——窗口外；（iv）电力公司组织行为与监管经济学的非技术研究——除非作为术语锚或政策机制证据短暂提及。
    • 暂搁置：DER / VPP / 多能源耦合的"非 HILP 下日常运行"——这些在韧性框架下进入只作为 §11 的 testbed 元素，而非独立章节。

    电力系统正处于三股压力的交会：（i）气候非平稳性使灾害统计漂移而不再可用历史频次外推，（ii）数字化攻击面随 IT/OT 融合与 DER 接入持续扩张，（iii）逆变器主导的低惯量电网在 HILP（High-Impact, Low-Probability）扰动下展现出与传统同步机系统不同的暂态行为。Vahedi, S.; Zhao, J.; Pierre, B.; Lei, F.; Anagnostou, E. et al.     2. Vocabulary Discipline — Reliability vs Robustness vs Resilience vs Recoverability vs Security vs Cyber-Security#

    文献的最大单一失败模式不是数学错误，而是术语滑动。本节按 phase0a §4 强制如下区分，全文不破例。

    • Reliability（可靠性）：长期统计意义下的服务充足性，通常排除 major event days (MEDs)（IEEE 1366-2012 的 2.5β day-level 规则；阈值 \(T_{\text{MED}} = \exp(\bar{\alpha} + 2.5\sigma_\alpha)\)，其中 \(\alpha_d = \ln(\text{SAIDI}_d)\) 在 trailing 五年非零 daily SAIDI 上的均值与标准差）。注意 MED 是日级阈值过滤，而不是 event 级——整个日历日 SAIDI 超过 \(T_{\text{MED}}\) 即被剔除（即可能跨多个 events，也可能一个 event 跨多日各自独立判定）。标准指标家族 SAIDI / SAIFI / CAIDI 服务于 reliability。它是"蓝天 (blue-sky)"性能指标。归口 NERC TPL / IEEE 1366。
    • Resilience（韧性）：在 HILP 事件下 anticipate–absorb–adapt–restore 四阶段的综合能力。没有行业范围的单一量化标准。常以"韧性梯形"\(R(t)\) 曲线呈现。DOE/IEEE 2020 是当下最广泛被引的术语 anchor。
    • Robustness（鲁棒性）：resilience 的子属性，表征承受冲击而不丧失服务的能力。"灰天 (gray-sky)" 硬化措施（埋地化、覆盖导体、植被管理）归属此属性。
    • Recoverability / Restoration（可恢复性）：resilience 的另一子属性，表征事件后服务的恢复速度与质量。\(\tau_{\text{rec}}\) 与 \(\int R(t)\,dt\) 是其主要量度。
    • Security（NERC 意义上的"安全"）：实时面向 credible contingencies 的充足性（N-1, N-1-1），与 cyber-security 不同。本综述出现"security"时一律给出限定语境。
    • Cyber-security：网络层的机密性 / 完整性 / 可用性。与 resilience 的接口是：完整性攻击（FDIA）和可用性攻击（DoS、勒索软件）耦合到物理层时影响 absorb / adapt 阶段。
    • Vulnerability / Fragility：fragility = 给定 hazard 强度下组件失效的条件概率；vulnerability = 系统级条件损失。
    • Hardening（硬化）：电容性 ex-ante 投资（埋地化、植被管理、覆盖导体）以提升 robustness。
    • HILP event：High-Impact, Low-Probability，覆盖极端天气与协调式网络攻击的操作性伞概念。HILP 不是 NERC 官方术语——它源自 DOE/IEEE 2020 framework，与 NERC TPL-001-5 的 deterministic "Category P0–P7" contingency 框架是不同本体；IEEE 1366 MED 2.5β 规则在 day-classification level 工作，被 statistically 校准为 reliability time-series 稳定性需要，而非作为 HILP filter 设计。
    • Compound event：多 hazard 的同时或时序耦合（如热浪叠加 cyber attack）；IPCC AR6 气候文献中的第一类概念，正被电网研究引入。

    这一字典的政治含义在 phase0b Thread A 中已点明，并被 §12 metric-and-regulation 段进一步展开：SAIDI 在 IEEE 1366 MED 2.5β rule 下机械性排除 major event days，这使 HILP 段的社区间不公平在 reliability 指标体系内不可见。换言之，"reliability 指标好、resilience 指标差"在制度上是可能的，且与监管 ownership 直接挂钩（谁来归口 resilience？SAIDI 由州 PUC 管，但 HILP 期间的恢复责任并不在同一个 ownership 边界内）。LBNL 评估（Eto et al. 2016；LaCommare et al. 2024）[作者待 verify]给出没有 general-purpose MED 替代法在跨 utility 的年间 SAIDI 方差意义上一致优于 2.5β——utility-specific calibration 可能局部更好，但作为标准化 day-classification rule，2.5β 是当前 corpus 中没有 dominator 的方案。换言之，MED day-exclusion 不是 SAIDI 的 bug，而是其稳定性的统计要求。这把"修补 SAIDI 让它覆盖 HILP"这一选项关掉了，倒逼一条平行 metric 路径——这是 §9 与 §12 的规范性结论的统计基础。

    从 practitioner-vs-research 视角看：业内（utility planners、PUC staff）默认 SAIDI/SAIFI 是"已被 MED 净化"的 reliability 数字，而学术 resilience 文献的 curve-area / \(\tau_{\text{rec}}\) / EENS 数字是 MED 之外的另一套指标——两套都对各自的统计假设是正确的，但若不显式互译就会在政策辩论里互相牙签插针。本综述在 §6–§11 引用任何 utility-side 数字时都会标注它在 MED 维度上的可见性。

    2.1 术语滑动的三种典型情境与本综述纠正#

    在本综述执笔过程中识别出三类最常见的术语滑动模式——它们都不是偶然的笔误，而是 corpus 中的系统性问题。明确列出有助于读者在阅读本综述以外的文献时识别同类滑动。

    滑动 α：以 "resilience" 标签包装 "reliability" 工作。这种滑动最常见于 utility-supplied case studies——分析的事件被排除在 SAIDI 计算之外（即定义上不是 reliability 事件），论文却用 reliability 词汇与方法处理它。结果是：声称的"resilience 提升"在 reliability metric 上不可见、在 resilience metric 上未量化。本综述严格按事件性质而非作者用词归类——HILP 段的工作一律归 resilience，blue-sky 段的工作一律归 reliability，跨段工作显式标注。

    滑动 β：把 "robustness" 当作 "resilience" 的同义词。robustness 是 resilience 的子属性（withstand without service loss），不包含 recovery。一篇 hardening optimization 论文证明在某个 hazard 强度下负荷削减为零，是 robustness 结论；要成为 resilience 结论需要进一步证明在更高强度下 \(\tau_{\text{rec}}\) 与 \(\mathcal{R}\) 也可接受。本综述按这一区分组织 §6 的 absorb 与 restore 两阶段。

    滑动 γ：把 "security" 在两种意义间无声切换。NERC 意义下的 security 是 N-1 / N-1-1 在实时调度中的充足性；信息层 cyber-security 是 CIA 三元组。两者在同一语段中被切换的最常见后果是：cyber-physical 论文把"提升 N-1 充足性"伪装成"提升 cyber-security"，反之亦然。本综述任何出现 "security" 的句子都附限定语境。

    2.2 vocabulary discipline 作为综述的"硬骨架"#

    把 §2 写成强制性骨架而非软建议有两条工程理由。理由一：当下游 reader 引用本综述某段时，§2 的术语锚使该段在不同 reader 的术语习惯下保持单义——这是综述被作为 cross-reference 工具使用的必要条件。理由二：当 §11 案例研究讨论 multi-objective Pareto 时，目标函数的每一维都必须对应一个单义的现象——否则 Pareto front 的解释被术语滑动污染。综述把 §2 视为这两条工程理由的硬骨架，并据此拒绝在主体章节中"轻松地"使用术语近义词。

    2.3 与 DOE/IEEE 2020 / NERC RISC 2025 的术语对齐#

    3.1.1 关于 notation 的两条工程注释#

    notation 的设计有两条值得说明的工程选择。第一，\(p^{\text{fail}}\) 同时把 \(\mathbf{H}_t\) 与 \(\mathbf{u}_t\) 写入参数列表——这是 DDU 区分的语法标记。当某一段文献只让 \(\mathbf{H}_t\) 出现而 \(\mathbf{u}_t\) 不出现时，意味着该段是 exogenous fragility 范式；当两者都出现且 \(\mathbf{u}_t\) 项非零时，是 DDU 范式。这种用 notation 显式标记范式的写法在综述全文使用，使读者在阅读章节时能从公式直接判断方法学归属。

    第二，\(\mathcal{P}_{\text{amb}}\) 单独列于 \(\mathcal{U}_{\text{robust}}\) 之外——这是为了把 distributionally robust 与 classical robust 区分。两者数学结构不同：classical robust 在 hazard 强度的有界集合上做 worst-case；distributionally robust 在 hazard 强度的概率分布集合上做 worst-case。综述在 §11 使用 \(\mathcal{P}_{\text{amb}}\) 而非 \(\mathcal{U}_{\text{robust}}\)，是有意把 ambiguity 装置选择为分布级别——这是 B12 distributionally robust DAD 与 climate fragility 预测对象之间的形式接口要求。读者若读 §11 时把 \(\mathcal{P}_{\text{amb}}\) 误解为 \(\mathcal{U}_{\text{robust}}\)，会丢失分布鲁棒的关键 structural advantage。

    4. Methods Spine I — Decision-Dependent Uncertainty as a First-Class Formal Device#

    4.1 形式化与 taxonomy#

    直觉前置（赌博类比）。设想 PSPS 决策：加州 PG&E 在大风火险天预报发出后，主动切断高风险输电线——理由是合闸通电的线路在大风下弧光对干燥植被的点火概率会显著升高。换言之，操作员的决策（合不合闸）直接改变了 hazard 概率分布，而不是单方面接受 hazard。把这种情形类比为赌博：经典两阶段 stochastic programming 假设"先抛骰子（抽样 \(\boldsymbol{\xi} \sim \mathbb{P}\)），再决策"——SAA 一致性证明依赖"骰子的分布不被我的决策改变"。但 PSPS 的决策（合不合闸）直接改变骰子的概率分布，相当于"我的下注改变了下一次掷骰的赔率"——赌场会立刻反对，SAA 证明的核心图景被破坏。下面把这一直觉形式化。

    DDU 是指不确定分布（或其可观测性）对决策变量内生的随机/鲁棒优化情形。形式上，给定一阶决策 \(\mathbf{u}_t\)，hazard fragility 写作 \(p_{ij}^{\text{fail}}(\mathbf{H}_t, \mathbf{u}_t)\) 而不是 \(p_{ij}^{\text{fail}}(\mathbf{H}_t)\)。这看似细枝末节，却破坏经典两阶段 stochastic programming 的 SAA（sample average approximation）一致性证明：样本生成器依赖于一阶决策，sampling 与 optimization 不再可分。

    Yin et al. (IET Renewable Power Generation 2024, DOI 10.1049/rpg2.13082) [作者待 verify]给出 DDU 在电力系统中的最近一篇 review，并把 DDU 分为两类：

    • distribution-DDU：\(\mathbf{u}_t\) 改变 \(\mathbf{H}_t\) 或 \(p^{\text{fail}}\) 的概率分布本身（即 \(\mathbb{P}(\mathbf{H}_t \mid \mathbf{u}_t)\) 对 \(\mathbf{u}_t\) 内生）。野火/PSPS 是典型——给线路通电直接抬高其点火概率。
    • information-revelation-DDU：\(\mathbf{u}_t\) 改变可观测信号或观测时机，从而改变后续阶段可获得的信息结构（即 filtration \(\mathcal{F}_t(\mathbf{u}_{<t})\) 对 \(\mathbf{u}_{<t}\) 内生；POMDP 语言下即 observation kernel \(o_t \sim O(\cdot \mid \mathbf{x}_t, \mathbf{u}_{<t})\) 对 \(\mathbf{u}_{<t}\) 依赖）。野火监控加密、PMU placement、巡线无人机部署等都是此类，但 PSPS corpus 没有任何论文显式形式化它。

    跨域注：information-revelation-DDU 在数学上是 POMDP active-sensing with action-dependent observation kernel 的电力实例，与决策论中 EVPI / EVSI (Howard 1966 onwards) 同源。Power-systems venue 的 gap 是 application（特别是叠加 endogenous observation cost + irreversible safety-critical commitment + climate-non-stationary observation noise 这三层），而不是机器本身缺失；§12.1 把它作为 sharp seam 时建议读者从 POMDP active-sensing 文献借机器。

(Energy Conversion and Economics 2025, DOI 10.1049/enc2.70010)[作者待 verify] 是 robust 分支的 DDU review——adjustable RO 在有 recourse 的 PSPS（火险消退后重新合闸）上是天然形式，但在所有 W1 PSPS 论文中没有一篇显式使用 adjustable-RO 形式化，这是 §4.3 列出的 sharp seam。

    4.2 PSPS 作为 canonical instance#

    W1 文献是把 DDU 写到环境转移核里的现存最干净一群。四篇方法学代表如下：

    • arXiv:2303.07558（2023）[作者待 verify]——两阶段输电拓扑切换 MILP，线路失效概率随线路 power flow 升高（弧诱发点火）。这是 W1 corpus 中最干净的 distribution-DDU exemplar，被后续 ADP / RL 工作引为参照点。
    • arXiv:2604.06692（2025/26）[作者待 verify]——MDP/ADP 框架，post-decision states 让 Bellman 递归在 DDU 下保持可处理。模型基方法的代表。
    • arXiv:2604.26150（2025/26）[作者待 verify]——PPO RL 在 feeder 级 PSPS 环境上训练，环境转移把点火概率作为天气协变量与合闸状态的函数；声称对 Park (2024)、Eaton (2025)、Palisades (2025) 风格 fire-weather 漂移有 OOD 鲁棒性。模型无关方法的代表。arXiv ID 与作者待二次 verify；任何对 Eaton/Palisades 火灾事后报告的引用须独立 cross-check 公用事业事件报告。
    • arXiv:2403.09903（2024）[作者待 verify]——野火韧性 UC，把火险作为约束修饰子（de-rate / 预先削负）而非 DDU；W1 与 W3 之间的过渡形态，反过来强化 DDU 是结构性而非普适性特征。

    Caveat C1（按 phase0d §6 强制）。W1 corpus 在方法上清晰分裂为 RL/ADP 路线（[W1-c]/[W1-d]）与 DDU-MILP 路线（[W1-e]），两条线的工具集、guarantee 类型、与算力 profile 都不同。本综述不把"野火文献"叙述为已收敛：前者偏 model-free policy learning，需 simulation 充分覆盖 OOD；后者偏 explicit reformulation，需 DDU 重新表达为 mixed-integer constraint。哪条是长期赢家未决。

    4.3 DDU 在 PSPS 之外的迁移：proactive cyber isolation 与 pre-emptive load curtailment#

    DDU 不应被理解为野火特异性。本综述把以下三类决策识别为同一 DDU 模式的实例：

    1. PSPS（野火）：合闸 → 抬高点火概率。distribution-DDU。
    2. Proactive cyber isolation：把可疑子网从 SCADA 主干隔离 → 改变攻击者的可达集与攻击成本，从而改变后续被攻击的概率分布。distribution-DDU，但 cyber-side 文献从未用 DDU 词汇表写下来——Thread A 的 DDU 词汇表是恰当 loan word。
    3. Pre-emptive load curtailment（热浪期间）：主动削负 → 降低线路温度与垂度 → 改变后续过载脱扣概率分布。distribution-DDU。

    把这三者并列的实质后果是：合规于 phase0d Thread A 的 DDU 形式化可以重用到 cyber-physical compound 模型——这正是 §11 案例研究的形式入口。

    Caveat C4（按 phase0d §6 强制）。Information-revelation DDU 在 PSPS 中至今未被形式化，尽管"在 commit de-energization 之前先布无人机/红外/气象站"这个 operational 实践正是 information-revelation DDU 的教科书定义。[D-a]/[D-c] 有完整 formal machinery，PSPS corpus 没有一篇套上去。这是综述识别出的最尖锐 unwritten 对象之一，§12 把它列入开放前沿。

    跨域 anchor —— POMDP / Howard EVPI / active-sensing 的连续性。Information-revelation DDU 不是 corpus 发明的新对象——它在数学结构上是 POMDP with action-dependent observation kernel 的电力实例，与决策论 60 年传统连续：

    • Howard EVPI / EVSI lineage（1966 onwards）：Howard 的 information value 框架给出"在 sequencing of decisions 下，关于某未来随机变量的 perfect information 的 expected value"——PSPS 问句"commit de-energization 前是否值得部署无人机"恰是 EVSI (Expected Value of Sample Information) 的教科书实例，但带一道附加 wrinkle：sample acquisition 本身是 decision variable（无人机部署有成本），即 EVSI with endogenous sample cost。
    • POMDP active-sensing（Kaelbling, Littman, Cassandra 1998 onwards）：information-revelation DDU 在 POMDP 语言下即 observation kernel \(O(o_t \mid \mathbf{x}_t, \mathbf{u}_{<t})\) 对 \(\mathbf{u}_{<t}\) 内生——这是 active-sensing / active-perception 在 POMDP 文献中的 standard 形式。现代 deep-RL 版本（DeepMind sensor-placement 工作、robotics active SLAM）给出可计算 surrogate。
    • Contextual bandit with side-observations / purchase-information variant（Mannor & Shamir 2011 系 graph-feedback bandits）：pre-emptive observation deployment 是带成本的 information-purchase 决策。

    Boundary condition。"PSPS corpus 没有一篇套上去"在 power-systems venue 是事实，但它不意味着 machinery 缺失——machinery 在 POMDP / EVPI / active-sensing 三族文献中成熟。Power-systems 的 gap 是 application + 三层 wrinkle 的叠加：(i) endogenous observation cost（部署有成本）；(ii) irreversible safety-critical commitment（点火后无法 un-de-energize）；(iii) climate-non-stationary observation noise（观测核本身随气候漂移）。三层独立成熟，叠加是综述识别的形式空白。

    §12.1 第 1 条 sharp seam 是这一跨域 anchor 的具体邀请：建议读者从 POMDP active-sensing 文献借机器（belief-state formulation、forward search、Monte-Carlo tree search on POMDP），并把上述三层 wrinkle 作为 power-specific contribution。综述不引入这些 cross-domain 工作进入 reference list——它们作为概念锚出现，让读者识别 PSPS-side 工作的形式位置而非定位综述外的 in-corpus citation。

    4.4 W2 的"无 native DDU"事实——必须明说#

    Caveat C2（按 phase0d §6 强制）。台风/飓风的路径对电网状态外生：合闸或不合闸不会改变 storm track。W2 corpus（Li/Huang/Luo et al. 2025；[W2-b] IET 2024；[W2-c] arXiv:2601.21371；[W2-d] EAAI 2024；[W2-e] ASCE-ASME J.     请勿把这件事倒推：不要把 information-revelation DDU 反向证据化为"W2 也是 DDU"。W2 的方法学事实是 fragility 对决策外生，相应方法是经典两阶段 stochastic / robust optimization；DDU 一节论及 W2 时只用来反证"DDU 是结构性而非普适性"。

    4.5 W2 的 verified 锚——Li, Huang, Luo et al. 2025#

    W2 唯一在本综述中以完整作者表引用的工作是 Li, S.; Huang, Z.; Luo, J. et al.     4.6 DDU 与两阶段 stochastic programming 的形式不兼容性#

    为何 DDU 必须被作为第一类装置而不仅是"另一种不确定性"？关键在于经典两阶段 stochastic programming 假定样本生成器与决策序无关：先抽样 \(\boldsymbol{\xi} \sim \mathbb{P}\)，再在样本上最优化第二阶段决策；样本平均近似（SAA）的一致性证明依赖于这种独立性。一旦概率测度 \(\mathbb{P}\) 本身依赖于第一阶段决策 \(\mathbf{u}_t\)——记为 \(\mathbb{P}(\cdot \mid \mathbf{u}_t)\)——抽样与最优化之间出现反馈环：不同的 \(\mathbf{u}_t\) 候选生成不同的样本族，"在固定样本上比较候选"这一 SAA 的基本图景被破坏。

    应对路线有四条：（i）显式重表达——把 \(\mathbb{P}(\cdot \mid \mathbf{u}_t)\) 离散化为有限多个 \((\mathbf{u}_t, \boldsymbol{\xi})\) 组合并以二元指示器写入约束（[W1-e] 类做法）；（ii）MDP / ADP——把 DDU 编码进转移核 \(T(\mathbf{x}_t, \mathbf{u}_t, \mathbf{x}_{t+1})\)，用 post-decision states 保持 Bellman 递归可处理（[W1-d]）；（iii）model-free RL——把环境当黑箱，由策略学习 \(\pi_\theta\) 在交互中适应 DDU 反馈（[W1-c]）；（iv）adjustable robust optimization——把决策序与不确定揭示交错，写为多阶段 RO（[D-c] 评述但 W1 未应用）。本综述把这四条路线作为读者在面对 DDU 时的可选择形式列出，并明示哪条路线对何种 hazard 子树最 natural。

    值得强调的一条 corpus-level 观察：[D-c] 把 adjustable RO 评述为 DDU 在有 recourse 设置下的天然形式，但 PSPS corpus 没有一篇论文显式使用 adjustable-RO 形式。这是一条 unwritten bridge——把 [D-c] 的形式装置搬到 [W1-c]/[W1-d]/[W1-e] 的应用层是低悬果实的 methods paper。

    4.6.1 模型基与模型无关 DDU 方法的工程对比#

    [W1-d]（MDP/ADP，模型基）与 [W1-c]（PPO RL，模型无关）作为 W1 DDU 处理的两条代表性路线，工程性质有系统差异。MDP/ADP 路线需要显式建模转移核——点火概率作为合闸状态与气象协变量的函数必须以参数化形式写出；好处是策略可解释、收敛证明可承担、政策制定者审计友好；缺点是当转移核错配时性能下降严重，且对高维气象协变量的离散化是 hard problem。RL 路线相反：把环境当黑箱学习，对模型错配较鲁棒；缺点是 OOD 行为不可证、对训练分布的依赖与 fire-weather 漂移交互产生 silent failure。

    实际选择应按操作时间尺度与监管审计要求而非"哪个更现代"决定：planning-stage（年度 hardening 决策）偏向 MDP/ADP，因为审计与可解释性优先；operational-stage（小时级 PSPS 决策）可能偏向 RL，因为模型错配与协变量数量过大。综述把这一选择呈现为用例驱动而非方法学竞争——这与 phase0c-A C1 caveat 一致。

    4.7 DDU 作为综述的统一切片#

    把 DDU 提升为第一类装置的好处在于：综述六轴立方的 methodology 轴与 disruption 轴之间出现一条可识别的对角切片——DDU 切片。该切片同时贯穿 weather（W1 PSPS）与 cyber（proactive isolation）与 compound（§11 案例）。读者可以沿这条切片纵向阅读综述：§4 学到形式；§6.1 在 W1 中看到 distribution-DDU 的 worked example；§7.3 看到 DDU 在 cyber 中的词汇借用；§9.5 看到 information-revelation DDU 在 restoration sequencing 中的潜在引申；§11 看到 DDU 在 compound 中的双层叠加。综述的"DDU first-class"主张因此不止是一个分类宣告，而是一条贯穿全文的纵向阅读路径。

    5. Methods Spine II — Physics-Informed ML Fragility Surrogates#

    5.1 The hybrid template#

    术语约束（按 §2）：本节"fragility surrogate"指的是per-element 条件失效概率 \(p_{ij}^{\text{fail}}\) 的代理，而不是 vulnerability（系统级条件损失）的代理。两者通过 rollup 算子（OPF / DC 潮流 / cascading simulator）联立——本综述在使用 "fragility" 时仅指元件级，使用 "vulnerability" 时指系统级；§11 的 \(Q_0\) 是 fragility-forecast level（per-element），\(\mathcal{P}_{\text{amb}}\) 是 fragility-forecast quality ambiguity，二者均不混入 vulnerability 语义。

    phase0b Thread D 总结了 2024–2025 期间出现的一个事实上的模板：结构物理基座 + ML 残差 + 协变量加权 + 场景化简。模板的复合形式可形式化为：

    \[ p_{ij}^{\text{fail}}(\mathbf{H}_t; \mathbf{z}_{ij}) = \sigma\!\left(\beta \cdot g^{\text{phys}}(\mathbf{H}_t; \theta^{\text{phys}}_{ij}) + h^{\text{ML}}_\phi(\mathbf{H}_t, \mathbf{z}_{ij})\right) \]

    其中 \(g^{\text{phys}}\) 是结构基座（杆塔/导线承载方程的失效指标），\(h^{\text{ML}}_\phi\) 是 ML 残差（CNN / GBDT on covariates \(\mathbf{z}_{ij}\) = 导体年龄 / 植被指数 / 土壤湿度），\(\sigma\) 是 logistic clip（应对 §5.2 EAAI 2024 bounded-output failure mode）。\(\beta\) 控制物理基座权重。

    • 结构物理基座：杆塔/导线/绝缘子的承载方程（风载 + 冰载 + 热致弛度），给出 \(p_{ij}^{\text{fail,phys}}(\mathbf{H}_t)\)。
    • ML 残差：在 \(p^{\text{fail,phys}}\) 不能解释的剩余方差上拟合协变量（导体年龄、植被指数、土壤湿度、用户密度），得 \(\delta p^{\text{fail,ML}}\)。
    • 协变量加权：把 reliability-era 的 risk priors（pole class, span length, exposure）转化为 ML 输入特征的样本权重。
    • 场景化简：用 surrogate-based importance sampling 把 \(|\mathcal{S}|\) 从 \(10^5\) 量级缩到 \(10^2\) 而保留分位匹配。

    [W2-e] ASCE-ASME J. Risk 2024 (DOI 10.1061/AJRUA6.RUENG-1171)[作者待 verify] 是该模板的最干净 worked example：物理基座是杆塔/导线风承载，data-driven 部分是历史台风轨迹下的协变量校准。[W2-d] EAAI 2024 (DOI 10.1016/j.engappai.2024.108056)[作者待 verify] 是该模板的 review，并明确指出三种失败模式（详见 §5.2）。

    5.2 Failure modes per EAAI 2024#

    EAAI 2024 review 系统总结纯 ML fragility 模型的三类失败：

    1. Bounded-output 违反：神经网络在风速分布尾部输出非 \([0,1]\) 的失效概率，必须显式 logistic-clip 或 isotonic 校准。
    2. Wind extrapolation：风速在训练分布外，纯 ML 性能崩塌；这正是物理基座必须承担的部分——结构方程在外推区间仍有物理意义。
    3. Geographic transfer：在 Florida 训练的 outage 模型不能直接搬到 Texas（植被、土壤、构件年龄分布不同）。这是综述识别"shared physics-ML fragility benchmark"为开放前沿（phase0c Thread A S5）的实证根据。

    5.3 W1 的 anchor —— Vahedi et al. TPWRS 2025#

    Wildfire 侧的 worked example 是 Vahedi, S.; Zhao, J.; Pierre, B. J.; Wang, B.; Yusuf, J. "Probabilistic Resilience-Oriented Assessment Approach for Transmission Networks Under Wildfires," IEEE Transactions on Power Systems, accepted 2025, DOI 10.1109/TPWRS.2025.3599431。它把 fire-spread + thermal-derate 耦合模型作为物理基座，给出线路条件失效概率，再用合成 IEEE 输电 testbed + 加州野火 footprint 做契约式 contingency 模拟。fragility 在该论文中是 \(\mathbf{H}_t\) 的函数、不依赖于 \(\mathbf{u}_t\)，即 exogenous fragility——与 §4 DDU 形成对照。本综述把 [W1-b] 当作 exogenous-fragility paradigm 在 W1 中的代表，与 §4 DDU-aware 工作并列展示该 corpus 的方法学分裂。

    WIREs Climate Change 2025（Karagiannakis et al., DOI 10.1002/wcc.930）[第一作者 Karagiannakis 经搜索片段确认；其余作者待 verify] 提供 cross-hazard fragility-modeling 的 meta 评述，是综述以survey 而非定量来源身份引用 W3 ice/heat 段的依据。

    5.3.1 物理-ML 模板在三种 hazard 中的差异化形态#

    把同一个模板在三种 hazard 中放置，呈现的是三种不同的工作划分：

    • W1 wildfire：物理基座是 fire-spread + 热致弛度耦合，ML 残差承担植被状态、燃料含水率、历史点火空间相关的协变量加权；典型 metric 是 fire-induced 条件失效概率 \(p^{\text{ig}}\)。这一形态在 Vahedi TPWRS 2025 中可见。
    • W2 hurricane：物理基座是杆塔/导线/绝缘子的风载结构方程（与传统结构工程 fragility 谱系一致），ML 残差承担土壤湿度、植被指数、构件年龄分布等。这一形态在 [W2-e] ASCE-ASME 2024 中可见。
    • W3 ice/heat：物理基座是冰载结构方程（ice）或 ampacity-temperature 方程（heat），ML 残差几乎没有写入文献——这是 §6.5 提到的"方法迁移尚未开始"。

    把三种形态并列展示有助于读者识别 portable subroutines：协变量加权、isotonic 校准、surrogate-based importance sampling 这三件子程序在三种 hazard 下结构相同；变的是物理基座方程。综述据此识别"物理-ML 工具箱"作为可发布的 community infrastructure（与 phase0c-A S5 的 shared benchmark 主张呼应）。

    5.4 W3：assessment-heavy, optimization-light#

    Caveat C3（按 phase0d §6 强制）。W3（ice / heat）是 weather 三个子树中评估侧重、优化侧轻的一个。corpus 由 [W3-a] RESS 2023 ice storm 概率评估（DOI 10.1016/j.ress.2022.108990 待二次 verify）[作者待 verify]、Karagiannakis 2025 WIREs fragility review、IRENA 2025 政策评估、Appl. Energy 2023 compound paper 承担。纯 optimization 角度的论文在 W3 中实质性缺席——除复合事件外。本综述在 §6 中不为 W3 over-promise method coverage。

    W3 corpus 的结构性观察有两条：

    1. 冰与热都产生 coincident 供应去额定 + 需求飙升：冰 → 机械线路失效 + 取暖负荷峰；热 → 热致去额定 + 制冷负荷峰。双边 coincidence 不被单一 hazard fragility 曲线捕获——这是 phase0c Thread A S4 列为 sharp seam 的"joint coincidence fragility"对象（失效概率 = 资产应力 × 需求应力的联合曲面）。
    2. W3 是与 compound-event 边界最软的子树：heatwave + cyber 的 §11 案例研究在 W3 与 I2 都合理。本综述把它放在 §11，§6 只引用 [W3-d] 作为指向。

    IRENA 2025（"Climate-proofing power infrastructure"，"Quality infrastructure for renewables facing extreme weather"）作为机构 anchor 在本节出现两次：（i）2021 Pacific Northwest heat-dome 电缆熔化事件作为热致去额定的代表性事件，（ii）冷链耦合（gas-electricity coupling 在 cold snap 期间的同步失效）。IRENA "电力 = 终端能源 52% by 2050" 数字应引到 IRENA 自家 scenario 文档（不是下游 summary）——按 phase0d §6 C5。

    Anchor：B5. IEEE/CAA J. Automatica Sinica 2024 remote SE cybersecurity review[作者待 verify]；B6. Applied Energy 2025 attack-resilient SE 动态时空冗余重构[作者待 verify]；B7.     形式工具。Fawzi–Tabuada–Diggavi (IEEE TAC 2014) heritage 在 SE 侧贡献核心定理：在最多 \(s\) 个 sensor 被攻击下的可证 resilient state estimation 当且仅当 系统是 \(2s\)-sparse observable——即对任意 \(S \subseteq [p]\), \(|S| = 2s\)，在 \([p] \setminus S\) 上限制的子系统仍可观测。"\(\ge 2s+1\) redundancy" 是 linear sensor model 下的充分冗余 rule-of-thumb；\(2s\)-sparse observability 是 necessary-and-sufficient 的组合特征。该结果在 B5 的 review 中作为 mature 理论被列为低风险引用。下游"secure-by-design PMU placement"应用应逐个 trace，而非整体地引用为 consensus。

    Detection 与 control 的 information-flow。本综述把 C1 与 C2 当作单一信息流：detection 产生 belief state；resilient control 在此 belief 上做 worst-case 决策。B5–B8 是分析骨干，B1–B3 是 data-driven appendix。§4.3 的 DDU loan word 在此特别有用——proactive cyber isolation 是 distribution-DDU，但 C2 corpus 没有这个词汇。

    Resilient ≠ robust（B7 review 模糊）。B7 把 resilient control（可证攻击下性能）与 robust control（可证有界扰动下性能）混用，本综述按 §2 术语纪律拆开，不沿用 B7 的混合表述。

    Seam to §11。\(2s\)-sparse observability 给出 secure SE 在 §11 operator inner level 的 worst-case 性能 bound；但 bound 在 compound stress（FDIA setpoints + thermal de-rate）下是否仍成立未被验证——见 §7.3 S3 HIL gap。

    7.4 cyber 文献的术语滑动与本综述纠正#

    cyber 子领域是 §2 术语纪律最频繁失守的一段。文献中出现的滑动主要有三类：

    滑动一：把"resilience"等同于"detection accuracy"。许多 FDIA 检测论文以"提升 resilience"做卖点，但其 metric 实质是 detector 的 F1 / FPR。本综述按 §2 纪律把它们重新归类为 cyber-security 工具（confidentiality / integrity / availability 的 integrity 通道），其在 resilience 框架中的位置是 anticipate 阶段的辅助信号源——并非 resilience 本身。这一重新归类不否认这些工作的方法学贡献，仅否认它们直接在 \(R(t)\) 上的可证收益。

    滑动二：把"resilient control"等同于"robust control"。B7 review 把两者并列处理而不加区分；B8 一类 \(H_\infty\)-style worst-case bounds 经常在论文标题上写"resilient"但在数学上做的是有界扰动下的鲁棒控制（不是攻击下的可证性能）。本综述按 §2 区分：resilient control = 在 modeled adversary 集合下的可证性能；robust control = 有界扰动下的可证性能。两者形式互不蕴含，且评测时序不同（resilient 需要 adversarial training / adaptive attacker；robust 只需 worst-case 扰动）。

    滑动三：把"security"在 NERC 意义（实时 N-1 / N-1-1）与 cyber-security 意义（信息层 CIA）之间无声切换。这种滑动在跨学科论文（power + control + computer security 联合作者）尤其频繁。本综述任何出现"security"的句子都会显式给出限定语境。

    把这三类滑动暴露在术语层面而非埋在叙事中，是本综述对 cyber 子领域的一项术语贡献——不增加任何新方法，但让现存方法的可比性大幅提升。

    7.4.1 cyber 文献缺失的一类基础工作：threat-model standardization#

    在 weather 子领域，hazard 强度场（风速、温度、湿度、FWI）有相对公认的物理量，跨论文比较至少在量纲与定义上一致。cyber 子领域没有对应的 standardization：FDIA 论文常以"unobservable"或"stealthy"描述攻击，但每篇定义不同；DoS 论文常以"丢包率"或"链路中断"描述攻击但 protocol assumption 各异；勒索软件论文（学术侧）几乎没有 corpus-level 共同 threat model。这种威胁模型 standardization 缺失与 §7.1 detection accuracy 不可比性的根源同一：没有共同对象就没有公平比较。

    本综述识别 threat-model standardization 为 cyber 子领域的基础设施级开放问题——它不在 §12.1 五条最锋利前沿中只是因为它优先级低于 RobustBench-analog（RobustBench 隐含一个共同 threat model），但若 community 投入此基础工作回报会很大。这一观察与综述其它前沿并列呈现而不作为推荐工作，留给读者自行判断优先级。

    7.5 detection-control 信息流的形式接口#

    把 §7.1 与 §7.2 当作单一信息流，意味着 detector 输出在 control 层有明确的形式接口。最简洁的接口是 belief state：detector 输出后验概率 \(b_t = \Pr(\text{attack present} \mid \text{measurements}_{\le t})\)；resilient controller 在 \(b_t\) 上做 worst-case 决策——这把 C1 与 C2 的 corpus 在数学上接到一起。

    实操上接口面临两个困难：校准 — detector 的 F1 / FPR 在 testbed 之间不可比，因此 \(b_t\) 的校准是 controller 设计的隐含前提；adversarial reliability — adaptive attacker 会针对 \(b_t\) 优化攻击 vector，使 detector 输出系统性偏置，这是 S2 caveat 的 controller-side 影响。结论是：对 detection 的 adversarial-evaluation 缺席不仅是 detection 论文自身的缺陷，更直接传染到 resilient controller 的安全声明。这是综述把 S2 放在 §12 而非 §7 局部 caveat 的理由。

    8.7 跨域 anchor —— systemic risk、percolation 与 threshold cascades#

    复合事件 corpus 在数学结构上与两个成熟邻近领域同构，但电力 corpus 至今未导入它们的 closed-form 结果。本节作为跨域 anchor显式呈现这一同构，让读者把 \(\Pr[\text{cascade}\ge k]\) 与 §11 attacker 的目标重新置于 percolation phase-transition framing 之中。

    (a) Systemic risk in finance（contagion / cascade lineage）。Eisenberg–Noe (2001) clearing-vector 模型把银行间负债网络的 default propagation 写为 fixed-point 方程；其图结构 + 节点状态向量 + clearing 算子 + 触发扰动的数学骨架与电网级联同构。Acemoglu, Ozdaglar, Tahbaz-Salehi (2015) 给出网络结构 → contagion phase transition 的 "robust-yet-fragile vs fragile-yet-robust" 相变结果——这正是 §10 GFM cascading 的相变问句，但电力 corpus 未以此形式提问。Battiston et al. (2012) DebtRank 给出 contagion network 上的 node-level systemic-risk 中心性测度，其电网对应物（node-level resilience contribution）在 §9 Pareto vector 四维之外。

    (b) Network percolation theory。Newman / Watts / Strogatz 系（2000s）给出随机网络上的 percolation threshold 与巨连通分量的形成/消解；§3.1 notation 已引入 \(\Phi\) 作为渗流阶参数，但未把它与 percolation phase transition 的 closed-form 结果连接。Watts (2002 PNAS) "global cascades on random networks" 的 threshold-cascade 动力学在结构上正是 relay-cascade。Granovetter (1978) threshold model 是 cascade-on-network 框架的原始来源——继电保护级联在 Granovetter 意义下是 threshold dynamics（每个元件在 local stress 超阈值时失效，阈值在元件间异构分布）。

    (c) 跨域 anchor 的实质后果（对 §11 与 §12 的 reframe）。把 \(\Pr[\text{cascade}\ge k]\) 重新框为 percolation order parameter——sub-critical regime 下 mean-field approximation 有效（SAIDI / EENS / \(\tau_{\text{rec}}\) 工作），super-critical regime 下尾事件主导（\(\Pr[\text{cascade}\ge k]\) 工作）。§11 attacker 的目标因此可以重写为"把网络推到 super-critical regime"，而非泛指 LoadShed maximization——这给 attacker 的 fragility-forecast object 一个自然 target（percolation threshold）而非 generic load-shed 标量。\(\mathcal{P}_{\text{amb}}\) 大小 → defender 优势曲线（§11.5）自然对应 sub-/super-critical 相图在 \((\mathcal{B}_{\text{harden}}, \epsilon)\) 空间的相变线。综述把这一 reframe 作为 §11 + §12 的跨域阅读路径列出，不引入新 in-corpus citation——上述四组工作（Eisenberg-Noe / Acemoglu / Battiston / Newman-Watts / Granovetter）作为概念锚出现，不进入综述 reference list。

    9.1 为什么三个子线索必须融合#

    GFM dynamics、restoration sequencing、与 metric-and-equity 看似不相关——它们分别落在 phase 0a 的 transversal cross-cut、I3、与 Thread A。但它们在 (phase, layer, metric) 空间共定位：phase = restore，layer = distribution-with-DER，metric = MED-excluded。换言之，post-HILP restoration 阶段恰好是 GFM 行为最关键、SAIDI 机械性盲视、与社区间不公平最大的运行段。三者作为单一 thread 处理，把三个独立 open problem 转换为一个 operational research question。

    具体来说，GFM-rich 配电馈线从 battery + PV 微电网 black-start 的行为与同步机馈线自上而下从 bulk 系统恢复质性不同；恢复轨迹依赖于继承自同步机分析的级联仿真器不捕获的逆变器动态；而谁先恢复的问题在 SAIDI 维度上不可见——因为整个事件被 IEEE 1366 MED 规则排除。

    Anchor：[11] PNNL 2023 / Springer Curr. Sustain./Renew. Energy Rep.     9.4 MED 排除的结构性后果 —— [LBNL] + [11] + Thread A 的共同论点#

    按 §2：LBNL 评估（Eto et al. 2016；LaCommare et al. 2024）[作者待 verify] 建立没有 general-purpose MED 替代法在跨 utility 的年间 SAIDI 方差意义上一致优于 2.5β——utility-specific calibration 局部可能更好，但作为标准化 day-classification rule，2.5β 至今没有 dominator。MED day-exclusion 是 SAIDI 稳定性的统计要求，不是 bug。

    直接后果：equity-weighted resilience 不能作为 SAIDI 的 patch——它必须是平行 metric。PNNL 2023 主张 Pareto front 而非单 scalar；NERC RISC 2025 把 resilience 与 reliability 并列但分别测度——这与 PNNL 2023 立场一致，但没有任何 regulator 采纳标准化 Pareto vector（NERC RISC 2025 / CPUC / PUCT 均未）。

    这是 regulatory-design seam（C-γ）——本综述把它作为 §12 的规范性结论之一：推荐小型固定 Pareto vector (EENS, equity-EENS, \(\tau_{\text{rec}}\), \(\Pr[\text{cascade}\ge k]\)) 而非单一标量。

    Worked example（hypothetical）让"SAIDI 看不见 vs equity-EENS 看得见"具体化。设某市经历一次 5 天 HILP 飓风事件，整体触发 IEEE 1366 MED 2.5β 阈值，事件中所涉日历日被排除在该年 SAIDI 计算之外。事件中劣势社区 A（10% 人口、SVI percentile 90）累计停电 96 小时，富裕社区 B（30% 人口、SVI percentile 20）累计停电 12 小时。结果：该年 SAIDI 不变（major event days 排除），从 reliability 视角看不出任何不平等；equity-EENS 一项即把社区 A 的负荷 × 时长 × 劣势权重 \(w_A \approx 0.9\) 与社区 B 的 \(w_B \approx 0.2\) 共同写入指标家族，可以直接进入 DOE BIL Justice40 "≥ 40% benefits 流向劣势社区"的可裁决报送。SAIDI 不是"算错了"，是它的统计稳定性要求让它结构性地与 HILP equity 不兼容——这正是 §12.2 推荐 Pareto vector 的政策机制。

    规范性结论的备选空间（domain-expert / deep-diver review 共同提示的扩展）。Parallel-metric 是 §12.2 推荐路径，但不是唯一选项。至少另有三族 regulatory-design 选择：(I) conditional reporting——保留 SAIDI 但要求 utilities 单独报告 MED-excluded sub-series，最小改动；(II) distributional reporting——以 customer-hours-out 分布（含每客户上限阈值）替代单 scalar SAIDI，把 tail 显式化到客户层而非系统层，与 Justice40 自然契合；(III) capability-based reporting——参 Sen / Nussbaum capabilities 传统，直接报告中断的具体服务（冷藏、透析、通信、取暖）而非网络指标。本综述选择 parallel-metric 路径主要因 (a) utility-side 数据基础设施兼容、(b) 与 PNNL 2023 学术 anchor 兼容、(c) 渐进式监管成本最低；但 conditional / distributional / capability-based 三族在政策机制 ROI 上不必然次于 parallel-metric，本综述把它们作为开放 design space 并列呈现而非否定。

    这就是 §12 metric 推荐（小型固定 Pareto vector）的形式正向理由：没有 fixed vector，restoration MILP 多目标维度无对接界面；有了，restoration 设计与 equity 政策之间存在显式合同。

    UNIFI V3 规定 GFM IBR 在电压/频率扰动下的行为，但conformance envelope 隐含 bluesky-cyber + benign-thermal。compound stress（热致 BESS 去额定 + setpoints 被 FDIA 操纵）超出 specification 范围。这是 §11 案例研究在 GFM 约束上的具体形式——\(\mathcal{F}_{\text{UNIFI}}\) 在 compound 下未定义。本综述识别这是公开 spec 边界与 §11 case study 的硬接触面，§12 列入开放前沿。

    9.7 restoration 文献为何在 compound 与 equity 维度上欠覆盖#

    把 §9.2 与 §9.3 并读，浮现的是 restoration corpus 的两条系统偏向：目标函数偏向与约束语言偏向。目标函数偏向 = 文献绝大多数把"累计恢复负荷"或"恢复时间"作为单标量目标——这反映 OR 传统而非 resilience 政治传统；equity 维度作为加权项的引入需要决策者选定权重，许多论文回避此选择。约束语言偏向 = 文献几乎不写 GFM 动态约束（\(\mathcal{F}_{\text{UNIFI}}\)），因为可行性集合是 MILP-friendly 的电气/操作约束族，UNIFI 风格的暂态包络是动态可行性而非静态可行性，写入 MILP 需要额外的离散化与近似。两条偏向叠加的结果是：restoration corpus 的"成熟"是OR 意义下的成熟，而不是 resilience-and-equity 意义下的成熟。

    本综述识别该偏向并据此组织 §9.5 与 §9.6：把 multi-objective Pareto 框架（Seam C-β）作为对目标函数偏向的对策，把 \(\mathcal{F}_{\text{UNIFI}}\) 作为约束的对策。两个对策的实操困难也明示：Pareto 多目标使 MILP 解空间膨胀，需要 \(\varepsilon\)-约束法或权重扫描；GFM 动态可行性需要 ROM (reduced-order model) 才能进入 MILP——这两条都是 §12 列出的开放前沿的具体子任务。

    9.7.1 dynamic microgrid formation 在 restoration 中的关键角色#

    把 dynamic microgrid 单列一节是因为它在 phase0c-C [6]–[10] 的几条工作中已成为 novelty 集中点。其形式是：在 outage 之后，配电网被分割为若干 islands，每个 island 内部包含若干 GFM 资源（BESS、PV+逆变器、可调度发电）作为黑启动源；MILP 在 island 形态上决策切换序列与负荷优先级。与传统"自上而下从 bulk 系统恢复"对比，dynamic microgrid 的优点是不依赖 bulk 系统的可用性——在级联范围大、bulk 长时间不可用的 HILP 段尤其关键。

    但 dynamic microgrid 形式在文献中的成熟度有限：（i）大多数论文（[8] arXiv:2510.02495 是代表）证明 MILP 求解可行但忽略 GFM 暂态可行性——即把 \(\mathcal{F}_{\text{UNIFI}}\) 隐含为 trivially 满足，这在低 SCR、高 IBR 占比下不成立；（ii）大多数论文在 8500-node 上 scale 仍未稳定；（iii）equity 维度的引入几乎不存在。这三条直接对应 §9.5（Seam C-β）、§9.6（Seam C-δ）、§9.8（政治经济学）的开放方向——dynamic microgrid 形式是 §11 案例研究在 restore 阶段的具体决策对象。

    9.8 equity 与 reliability metric 的政治经济学注释#

    phase0b Thread A 的"political stakes"在 §2 与 §9.4 已分别从术语与统计角度建立。值得补一段政治经济学的注释：SAIDI 的稳定性需求 = 监管时间序列的可比性需求——若 SAIDI 把 major event days 计入，年度 SAIDI 会被一两次大事件主导，跨年比较失去意义，PUC 难以据此做费率裁决。换言之 SAIDI 的 MED 排除是为了让监管对"日常服务质量"的可裁决性成立。问题在于：HILP 段的服务质量也是真实的服务质量，且 disproportionately 落在劣势社区。本综述据此把 equity-weighted resilience 的政策需要解读为：不是更换 SAIDI，而是补一条平行通道专门服务 HILP 段。这与 PNNL 2023 的 Pareto 前沿主张在政策机制上一致，且与 DOE BIL Justice40 的 ≥ 40% benefits 强制性结合后形成可裁决的报送指标。这就是 §12.2 推荐小型固定 Pareto vector 的政治经济学骨架。

    10.0 GFM 词汇最小集（onboarding）#

    本章 vocabulary 密度高，对非控制 / 非电力电子背景读者门槛大；先给最小必要词汇 onboarding，再进入 UNIFI / Heliyon / arXiv 参考。

    • GFM (Grid-Forming) inverter：以电压相量为内部参考的逆变器，可独立"形成"电压（类比同步机的电势源行为）；能在 islanded / black-start 模式下工作。
    • GFL (Grid-Following) inverter：以电网电压相量为锁相参考的逆变器（类比电流源），需要预先存在的电压才能工作。绝大多数传统光伏与风机用 GFL。
    • IBR (Inverter-Based Resource)：广义的逆变器接入资源，含 GFM 与 GFL。
    • droop control：把功率偏差线性映射到频率/电压偏差，模拟同步机调速器/调压器行为。
    • VSM (Virtual Synchronous Machine)：在 droop 上叠加虚拟惯量项，模拟同步机惯性响应。
    • VOC (Virtual Oscillator Control)：用非线性振荡器实现同步，2020 之后受关注的 GFM 替代族。
    • RoCoF (Rate of Change of Frequency)：频率变化率（Hz/s）。低惯量（高 IBR 占比）系统 RoCoF 高，HILP 段大扰动时易触发保护脱扣。bulk-system 指标。
    • frequency nadir：扰动后频率最低点。bulk-system 指标。
    • voltage recovery time：故障穿越后电压恢复至额定范围的时间。local PCC（point-of-common-coupling）指标。三者必须在不同时空尺度上分别报告，不可聚合为单 "GFM resilience score"。
    • SCR (Short-Circuit Ratio)：电网在某点的强度指标。低 SCR = 弱电网，GFM 控制力在低 SCR 下受限。
    • ROM (Reduced-Order Model)：把 GFM 的高频暂态（cycle 至秒级）简化到决策层 MILP（小时至天级）可吞下的低阶模型。两个时间尺度差两个数量级——这是 §10.4 公式必须经 ROM projection 的根因。
    • GFM/GFL hybrid：按 IEEE 2800-2022 / UNIFI V3 分类 GFM 与 GFL 互斥；"hybrid" 通常指mode-switching capability（dual-mode inverter 在不同 SCR 下切换运行模式），不是两种模式同时启用。
    • \(\mathcal{F}_{\text{UNIFI}}\)（贯穿 §10–§11）：UNIFI V3 规定的 GFM IBR 动态可行轨迹包络——电压相量、电流注入、故障穿越在受扰下的行为必须满足该集合。注意它是关于轨迹的可行性（动态）而非"允许的当前状态"（静态），与 MILP 通常处理的"每时刻一组线性 inequality"不同；进入 MILP 必须经 ROM projection \(\pi_{\text{decision}}(\mathcal{F}_{\text{UNIFI}}^{\text{ROM}})\)（详 §10.4）。

    无此 onboarding，读者读 §10.2 droop / VSM / virtual oscillator 时直接卡住。本节是综述对非领域读者的硬骨架词汇。

    10.0.1 为何 GFM 是"横切"而非"子领域"#

    phase0a 初稿曾把 GFM 列为 W1/W2/W3 之外的第四子树，但 phase0b 与 phase0c 扫描一致地把它降格为横切。理由有三层。第一层（电气）：GFM 行为不是某一类 hazard 的属性，而是某一类资源的属性——它在任何 hazard 下都以同一种方式参与（提供电压相量、电流注入、过流限制、故障穿越）。把它列为 hazard 子树是 ontology 错位。第二层（建模）：GFM 暂态时间尺度（cycle 级到秒级）与 fragility / restoration 决策时间尺度（小时到天）之间存在两个数量级以上的差距，要把 GFM 引入决策模型必须以 ROM 形式介入——即 \(\mathcal{F}_{\text{UNIFI}}\) 这种可行性集合形式而非 ODE 形式。这天然把 GFM 推向"约束语言"而非"决策对象"。第三层（empirical）：在 phase0c 三 thread 扫描中没有任何 single paper 把 GFM 当成研究主体的同时把 hazard 模型化为现实 fragility——GFM 论文要么把 hazard 抽象为单一扰动（控制论文），要么把 GFM 抽象为同步机等效（fragility 论文）。这一 corpus 现实让"GFM 子领域"的写法不仅 ontology 错位，且没有 corpus 支撑。

    综上，本综述把 GFM 作为 §10 横切章——既不抢 W1/W2/W3 的方法主线，也不被埋为附录脚注；它出现在 restoration MILP 的可行性约束、cascading 仿真器的参数集、与 §11 的 Seam C-δ 中。读者在进入 §10.1 之前先消化"为什么这章这样组织"，是 pedagogy 的硬骨架前置。

    10.0.2 GFM / GFL 控制原理（intro 层概念框架）#

    在进入 UNIFI V3 normative anchor 之前，先建立 GFM / GFL 控制层的概念框架。GFL（grid-following）逆变器以电网电压相量为 PLL（phase-locked loop）锁相参考，输出可控电流注入；其稳态行为类似受控电流源，需要预先存在的电网电压相量才能运作，在 islanded 模式下无法独立成网。GFM（grid-forming）逆变器内部维持电压相量基准（droop / VSM / VOC 三族控制实现），输出端等效为受控电压源；在 islanded 模式与 black-start 模式下可独立形成电网。

    三族 GFM 控制原理的简短对比：(i) droop control 把 \(P\)-\(f\) 与 \(Q\)-\(V\) 偏差线性映射为相角速度与电压幅值偏差，模拟同步机调速器 / 调压器的稳态行为；(ii) VSM (Virtual Synchronous Machine) 在 droop 上叠加虚拟惯量与阻尼，模拟同步机摆动方程的暂态行为；(iii) VOC (Virtual Oscillator Control) 用非线性振荡器（Liénard / Andronov-Hopf 振荡器族）实现同步，2020 之后受关注，结构上避开 droop 的 small-signal 假设。三族在稳态行为上等价，在暂态与故障穿越下分歧明显——HILP 段对 VSM / VOC 类的虚拟惯量响应更敏感。

    GFM / GFL 互斥按 IEEE 2800-2022 / UNIFI V3 分类；"hybrid" 通常指 mode-switching capability（dual-mode inverter 在不同 SCR / event 状态下切换模式），不是两种模式同时启用。在 §10.2 SciRep 2025 hybrid GFM 工作中，"hybrid" 即指此 mode-switching 语义。

    10.0.3 UNIFI V3 conformance 的形式角色#

    UNIFI Consortium "Specifications for Grid-Forming Inverter-Based Resources, Version 3" 是 NREL / DOE 联合 normative anchor。其 conformance 范围有两层：(i) power-system 层——GFM IBR 在 fault ride-through、voltage support、frequency response 等 grid-side 行为的最低要求；(ii) inverter functional 层——constant internal voltage phasor、0–5 cycle disturbance response 等 device-side 要求。V3 (2026) 与 V2 (2024) 在若干 clause 上不稳定，本综述任何 UNIFI 引用都带版本号——"the UNIFI spec" 这种泛称会过几个月失效。

    UNIFI V3 的形式角色是把 GFM IBR 的轨迹级动态可行性写为可验证 envelope \(\mathcal{F}_{\text{UNIFI}}\)——它是关于轨迹而非"当前状态"的可行性集合，进入决策层 MILP 前必须经 ROM projection（详 §10.0.5 / §10.4）。UNIFI 是 single-inverter conformance spec；当多台 conformant inverters 在低 SCR、高 IBR 占比馈线上联立时，联合可行集不是各自可行集的交——这就是 §10.6 Seam C-ε 把 "\(\mathcal{F}_{\text{UNIFI}}\) 非空性"提升为开放前沿的原因（cross-domain anchor：small-signal stability of multi-inverter systems，Kundur 传统延伸到 IBR）。

    10.0.4 Cascading dynamics 与 GFM 的耦合#

    GFM 进入 cascading 仿真器的角色不在"被级联"——而在改变级联本身的动力学。传统级联仿真（DC potential / AC OPF post-contingency / 线性化保护误动作模型）继承同步机 inertia 假设：扰动后频率/电压响应由 swing equation 与 governor dynamics 主导。GFM-rich 馈线在 islanded 或弱联结条件下，inertia 由虚拟惯量项与 droop 增益参数化，cascade 时序与 size 分布质性不同：(i) RoCoF 显著高于同步机系统，protection settings 在 inherited threshold 下易触发；(ii) voltage recovery time 在 local PCC 上由 inverter current 限制而非系统阻尼；(iii) 在多 GFM inverter 互动下出现 sub-synchronous resonance 与 control-loop interaction，cascade 路径可能进入同步机模型无法捕获的模式。

    跨域结构性观察：cascading-on-network 文献（Watts 2002 PNAS / Newman-Watts threshold cascades / Granovetter threshold models）给出 threshold-dynamics phase transition 的 closed-form 相图——GFM-rich 馈线的级联是 threshold dynamics 的电力实例（每个 inverter 在 local stress 超 \(\mathcal{F}_{\text{UNIFI}}\) envelope 时退出），但 threshold 由 UNIFI conformance 而非 generic homogeneous 阈值定义。这是 §8.7 跨域 anchor 在 §10 章节的具体化。

    10.0.5 ROM / MILP 耦合的形式入口#

    GFM 暂态时间尺度（cycle 级到秒级）与 restoration MILP 决策时间尺度（小时到天）之间存在两个数量级以上的差距——这是 §10.4 公式必须经 ROM projection \(\pi_{\text{decision}}(\mathcal{F}_{\text{UNIFI}}^{\text{ROM}})\) 的根因。ROM (Reduced-Order Model) 把 GFM 状态空间的高频暂态压缩到 MILP 可吞下的低阶模型；两条主要路径：(a) Galerkin / balanced truncation 给出可证内/外近似；(b) 数据驱动 surrogate 给出概率近似但缺保守性保证。

    ROM-MILP 耦合的控制论 robust 视角（cross-domain anchor）：在 GFM 联合可行集非空的条件下（§10.6 Seam C-ε 假设成立），ROM projection 的保守性（内近似）相当于 small-signal stability margin 的下界估计——把 multi-inverter 系统的稳定性 margin 引入 MILP 决策层。这是 small-signal stability of multi-inverter systems（Hatziargyriou / Milano / Dorfler 系延伸）的电力 MILP 实例。综述据此把 §10.4 的 \(\pi_{\text{decision}}(\mathcal{F}_{\text{UNIFI}}^{\text{ROM}})\) 读为 small-signal stability margin 的 MILP-friendly surrogate，而非纯工程压缩。

    §10.0.2–§10.0.5 构成 GFM intro 章节的完整概念骨架；§10.1–§10.6 是其具体 corpus + 引用 + open seam 展开。

    10.4 横切论点 —— GFM 进入每个 restoration MILP 与每个 cascading 仿真器#

    GFM 行为进入每个 restoration MILP作为可行性约束。表面上的写法是：

    \[ \text{feasibility} = \text{(MILP-feasible)} \cap \pi_{\text{decision}}\!\left(\mathcal{F}_{\text{UNIFI}}^{\text{ROM}}\right) \]

    需要解释 ROM projection 的必要性：\(\mathcal{F}_{\text{UNIFI}}\) 是 ODE/transient level 的动态可行轨迹集（cycle 至秒级的电压相量、电流注入、过流限制、fault ride-through 行为），其判定需要 ODE 仿真或 Lyapunov 函数；而 MILP-feasible 是 mixed-integer 离散静态可行集（小时-天级的二进制切换 + 线性/二阶锥电气约束）。两者ontology 不一致，不能直接作集合交。well-defined 的写法是先把 \(\mathcal{F}_{\text{UNIFI}}\) project 到 MILP 决策变量空间——即对每个 \((\mathbf{u}_t)\) 候选，判定是否存在 transient trajectory 满足 UNIFI clauses——这是 ROM (reduced-order model) + sampled feasibility 路径；或把 UNIFI 条件 surrogate 化为静态代理约束（如 SCR 下限、IBR-to-load ratio 上限、virtual-impedance interference margin）。

    \(\pi_{\text{decision}}(\mathcal{F}_{\text{UNIFI}}^{\text{ROM}})\) 的 caveat：投影是 \(\mathcal{F}_{\text{UNIFI}}\) 的内近似（保守）还是外近似（乐观）取决于 ROM 选择与采样密度，这是 §12.1 第 3 条开放前沿的具体子任务。直觉：\(\mathcal{F}_{\text{UNIFI}}\) 不是"允许的当前状态集"而是"允许的暂态行为轨迹集"——要求在故障 + 切换 + 黑启动过程中，GFM 输出在每个 cycle（5–100 ms 级）都满足 UNIFI V3 包络。把它放入 MILP（小时-天级）决策需要 ROM 把"轨迹可行性"压缩为"决策点的若干代数约束"。这一压缩本身是 open 子问题。

    任何忽略 \(\pi_{\text{decision}}(\mathcal{F}_{\text{UNIFI}}^{\text{ROM}})\) 的 restoration MILP 在 inverter-rich 馈线上给出形式可行但物理不可行的方案。

    Seam C-α（phase0c Thread C 列出，本综述沿用）：GFM-aware cascading + restoration co-simulation 不存在。percolation / DRL-for-cascading 文献（RESS 2024 RL-for-cascading[作者待 verify]、Frontiers Energy Research 2023 NREL cyber-physical-cascade review[作者待 verify]）仍以同步机 inertia 假设；UNIFI / NREL GFM 线止于 single-feeder dynamics。没有 scanned 工作把（i）HILP cascade 真实 fragility、（ii）UNIFI V3 GFM 暂态包络、（iii）动态微电网 restoration MILP 端到端串联起来。这是 phase0a OP-#5 与 phase 0b Thread E 的 operationalization，本综述把它列为方法学邀请，§11 案例研究是其单 hazard × restore × T+D × equity-weighted 的可处理版本。

    10.4.1 ROM projection 的实操选择（短）#

    10.6 Seam C-ε（开放）—— 在 compound stress 下 \(\mathcal{F}_{\text{UNIFI}}\) 何时非空？#

    §9.6 与 §10.4 把 \(\mathcal{F}_{\text{UNIFI}}\) 作为可行性约束使用，隐含假设它在所讨论场景下非空。但在何种 compound stress 下 \(\mathcal{F}_{\text{UNIFI}}\) 才非空本身是一个未解决的 control-theoretic 鲁棒性问题：UNIFI V3 是 single-inverter conformance specification，当多台 UNIFI-conformant inverters 在 HILP 馈线上联立（低 SCR、高 IBR 占比、FDIA 操纵 setpoints、热致 BESS 去额定），联合可行集不是各自可行集的交——它受 inter-inverter coupling（sub-synchronous resonance、control-loop interaction、virtual-impedance interference）约束。

    这是 robust control of networked control systems 谱系下的问题——packet drops / delays / quantization 在 distributed control 中的鲁棒性（Hespanha 2007 survey 谱系），small-signal stability of multi-inverter systems（Kundur 传统延伸到 IBR），passivity-based control under disturbance（van der Schaft, Ortega 谱系）。Power-systems venue 至今未把 "\(\mathcal{F}_{\text{UNIFI}}\) 非空条件" 提升为独立研究对象，§11 案例研究假设 \(\mathcal{F}_{\text{UNIFI}} \neq \emptyset\) 作为 modeling assumption；违反此假设本身是一个 finding。本综述识别这是 Seam C-α 之前的先验问题：若 \(\mathcal{F}_{\text{UNIFI}}\) 在某 compound regime 下空，则 §9 / §11 的所有 GFM 可行性约束在该 regime ill-posed。综述把它作为 Seam C-ε 提升为开放前沿，与 §12.1 第 3 条并列但 logically prior。

    \(\mathcal{F}_{\text{UNIFI}}\) 非空性作为 small-signal stability of multi-inverter systems 的先验。具体地，"在 HILP 馈线上 \(\mathcal{F}_{\text{UNIFI}} \neq \emptyset\) " 等价于以下 control-theoretic 命题：存在一组 admissible inverter setpoints（功率、电压、droop 增益、虚拟惯量参数）使得 (a) 每台 inverter 在 single-unit conformance 测试下满足 UNIFI V3 envelope，(b) 联合多台 inverter 在 sub-synchronous / control-loop 相互作用下小信号稳定（特征根全部位于左半平面，或在 nonlinear 视角下满足 Lyapunov dissipation）。这是 Kundur (1994) "Power System Stability and Control" 单机模型延伸到 multi-IBR 的直接形式，但 HILP 段引入三层非平凡扰动：

    1. adversarial FDIA setpoints——attacker 在 \(\mathcal{P}_{\text{amb}}\) 内最坏 perturb 控制 setpoints；
    2. thermal-induced 参数漂移——热致 BESS 容量与逆变器开关频率 / 损耗特性的去额定；
    3. 拓扑切换瞬态——restoration MILP 决策的 breaker 开合在 cycle 级触发 control-loop transient。

    在此三层扰动下，\(\mathcal{F}_{\text{UNIFI}}\) 非空性是 robust small-signal stability margin 问题——小信号稳定 margin 是否足以吸收三层扰动的 worst-case 复合。这是 networked control systems robustness（Hespanha, Naghshtabrizi, Xu 2007）与 passivity-based control（van der Schaft / Ortega）的电力 multi-inverter 实例；现有 small-signal stability 文献（Hatziargyriou, Milano, Dorfler 系 IBR-extended Kundur 传统）给出 single-feeder 静态 worst-case bound，但 multi-feeder × HILP × adversarial 的联合 robust stability 是未完成研究对象。

    对 §11 的具体含义：§11 testbed 在第一次实现时应显式 verify \(\mathcal{F}_{\text{UNIFI}} \neq \emptyset\) 在所选 compound scenario 下成立——若不成立，testbed 在该 scenario 下退化为 ill-posed，结果应作为 negative finding 报告（Seam C-ε 的实证存在性证据）。这是综述把 Seam C-ε 提升为与 Seam C-α 并列前沿的具体可操作判据。综述据此把 \(\mathcal{F}_{\text{UNIFI}}\) 在 §11 的可行性预检作为 testbed 标准 protocol 的第一步，而非 modeling assumption 隐含通过。

    11. Case Study — Compound DAD with a Climate-Fragility-Bearing Attacker#

    本综述的两条规范性贡献之一（另一为 §12 的 Pareto vector）。本案例研究是 phase0d §7 三条 convergences 的汇聚点，也是 phase0b 立方中 (compound × restore × T+D+ICT × equity-weighted × field-validated) empty cell 的方法学进攻方向。

    该案例在 phase0d brief 中以 "§5 case study" 引用，进入主体后正式编号为 §11；旧编号仅在 phase0d 上游 brief 中保留。

    11.1 形式化目标#

    命名 anchor（D-A-O vs 传统 D-A-D）。Cyber-physical 文献中 tri-level DAD 的常见命名是 Defender-Attacker-Defender，第三层 "Defender" 实际是 operator（运行层），并非另一个 planner。本综述把第三层显式命名为 operator 而非 "defender"，避免读者把 outer 与 innermost 混淆为同一 actor——综述简称该结构为 D-A-O（Defender / Attacker / Operator）。

    三层时间尺度与信息流动（Stackelberg-style sequential）。三层不是同时决策；按以下顺序展开：

    1. Outer defender（规划层，年度时间尺度）：选择 hardening 资本分配 \(\mathbf{y} \in \mathcal{Y}(\mathcal{B}_{\text{harden}})\)（线路埋地、覆盖导体、变电站冗余、BESS 容量、cyber 防御预算），公开承诺。
    2. Inner attacker（运行层，事件期间小时-天）：观察 \(\mathbf{y}\) 后选择 cyber 攻击向量 \(\mathbf{a} \in \mathcal{A}(\mathbf{y})\) 与攻击 timing \(t^a\)，目标是最大化预期负荷削减。
    3. Innermost operator（运行层，实时分-秒）：观察 \((\mathbf{y}, \mathbf{a}, t^a)\) 与 \(\mathbf{H}_t\) 后选择 \(\mathbf{u}_t\)（包括 PSPS 风格 pre-emptive curtailment、proactive cyber isolation、restoration 排序），目标是最小化预期负荷削减与 equity-EENS 的 Pareto 凸组合。

    tri-level Stackelberg 决策图（ASCII）：

    读法：三层不是同时决策——按 annual → event → real-time 时间尺度依次展开。outer defender 的 sensor 部署是 Bayesian persuasion (Kamenica-Gentzkow 2011) of attacker posterior；inner attacker 的 \(\mathcal{P}_{\text{amb}}\) 是 Bayesian-Stackelberg attacker type space（Conitzer-Sandholm 2006；Tambe ARMOR / IRIS 谱系）；innermost operator 的 \(\mathbf{u}_t\) 与 \(p^{\text{fail}}\) 构成 DDU closed-loop。

    关键一致性约束：在 D-A-O 序下 attacker 决策时未知 realized \(\mathbf{u}_t\)（operator 在后 react），attacker 内层求解的对象应以 operator 的 commit-ahead policy \(\pi^{\text{op}}\) 为参数而非 realized \(\mathbf{u}_t\)：

    \[ \max_{\mathbf{a}, t^a} \min_{Q \in \mathcal{P}_{\text{amb}}} \mathbb{E}_{Q,\,\pi^{\text{op}}}\!\left[\,\text{LoadShed}(\mathbf{a}, t^a; \pi^{\text{op}})\,\right] \]

    其中 \(\pi^{\text{op}}\) 是 operator rolling-horizon commit-ahead policy。Single-shot 假设：attacker 不与 fragility 实时更新交互（即 attacker 在 \(t^a\) 之前固定 \((\mathbf{a}, t^a)\)，不在事件演化中重选）；完整动态 closed-loop（attacker 实时调整）超出本综述范围。

    attacker 的关键创新装置——也是 corpus 现存所有 DAD 论文都没有的——是它装备一个概率气候 fragility 预测 \(\hat{p}^{\text{fail}}(\mathbf{H}_t, \mathbf{u}_t)\)，且 ambiguity set \(\mathcal{P}_{\text{amb}}\) 是对预测质量而非 hazard 强度：

    \[ \mathcal{P}_{\text{amb}} = \{Q : W_1(Q, Q_0) \le \epsilon\}, \]

    其中 \(Q_0\) 是 baseline fragility 预测（例如 NOAA HRRR 风/温场上的物理-ML surrogate），\(W_1\) 是 Wasserstein-1 距离（ground metric 取 \(L_1\) on fragility 概率空间），\(\epsilon\) 是 forecast-quality 容差由 surrogate cross-validation residual 谱给出。

    为何 Wasserstein-1 而非 KL：(i) KL ill-defined at fragility 边界——当 \(Q_0\) 在 fragility \(\{0,1\}\) 处有 mass（PSPS de-energized line 失效概率 = 0；已失效线 fragility = 1），\(d_{\text{KL}}(Q\|Q_0)\to\infty\)，对 HILP 尾事件 ambiguity 量化不对称；(ii) Wasserstein-1 与 cross-validation residual 物理意义匹配——residual 在概率空间上的 mass transport 是 forecast-quality 的自然度量；(iii) inner-max reformulation 与 tri-level 兼容——Mohajerin Esfahani & Kuhn (Math. Program. 2018) 给出 Wasserstein DRO 在 piecewise-affine loss 下的 finite convex reformulation。综述据此锁定 Wasserstein-1，不并列 KL。

    \(\epsilon\) 的直觉：想象 attacker 拿到一份 NOAA HRRR 风速场 + 一个物理-ML fragility surrogate \(Q_0\)（给出 48 小时内每个变电站每条线路的失效概率）。attacker 不完全相信这份预报，所以在 \(Q_0\) 周围一个 Wasserstein 半径 \(\epsilon\) 的球内挑对自己最有利的 \(Q\)——也就是 worst-case-for-defender 的 fragility 分布。\(\epsilon\) 大 = attacker 对预报不信任 = 难以指挥 attacker timing 抓到精确脆弱时刻；\(\epsilon\) 小 = forecast 精准 = attacker 可挑 timing。§11.5 的期望产出之一就是 \(\epsilon \to\) defender 优势曲线——这是综述给该案例提出的具体可量化指标。

    与 corpus 上游脚手架的对齐：该形式把 phase 0c Thread B B12 的 distributionally robust 脚手架（ambiguity 在 repair time 上）替换 ambiguity 对象为 fragility forecast quality，并把 phase 0c Thread B B13 的 substation-detail tri-level 脚手架加上 climate 维度。\(\mathcal{A}(\mathbf{y})\) 的结构按 B13 继承：attack vector = subset of compromisable substations × subset of attack types {物理短路, relay 误操作, relay 恶意操作} × timing \(t^a\)。

    跨域定位（Bayesian Stackelberg game with type uncertainty）：该案例结构上是 Bayesian Stackelberg game with type uncertainty over the follower's information——game-theory 中已有 20 年传统，与电力 corpus 三处对接：

    • Bayesian Stackelberg lineage（Conitzer & Sandholm 2006；Paruchuri et al. 2008 ARMOR / IRIS；Tambe USC security-games 传统）：leader（defender）在已知 follower（attacker）持有 uncertain type 的条件下 commit 策略，其中 type 索引 information sets。ARMOR / IRIS 已部署到 LAX 机场 / US 联邦空中警官等 real-world security 应用。在本案例中：Wasserstein ambiguity \(\mathcal{P}_{\text{amb}}\) 即 attacker 的 type space——attacker 持有的 fragility forecast 质量是不同 type；defender outer-layer hardening 是 Bayesian Stackelberg 中 leader 的 commit-ahead 策略；inner attacker 在 worst-case-over-types 下 maximize payoff 即 DR DAD 的 robust-Bayesian-Stackelberg 形式。

    • Bayesian persuasion / information design（Kamenica & Gentzkow 2011 AER）：defender 的 information choices（sensor 部署、PMU placement、公开发布 climate forecast 的精度）shape attacker 的 posterior over hazard——information-revelation DDU 在 defender 一侧即 Bayesian persuasion 在 attacker 一侧。在本案例中：defender 部署传感与无人机改变 attacker 可获 fragility 信号的 posterior（§11.2 information-revelation 通道在 game-theoretic 视角下的 dual 解读）；DOE / 公用事业是否公开 climate-forecast precision 本身是 Bayesian persuasion 决策——隐式 reveal posterior 给 attacker 是 §11 defender 的隐含 information design 选择。

    • Mechanism design under partial commitment（Myerson 1981 onwards；算法机制设计文献）：regulator（隐式 outer-outer layer，§11 不显式建模）选择 utility 的 incentive scheme——即 §12.2 的 Pareto-vector metric 选择本身是 mechanism design over the utility's incentives。Utility 持有关于自身电网 fragility 的 asymmetric information；regulator 通过 metric 选择从 utility 报送中提取的信息决定 utility 的 optimal hardening response。

    Power-systems 贡献的具体 instantiation：climate-fragility 作为 attacker type；\(\mathcal{F}_{\text{UNIFI}}\) 作为 physical-feasibility constraint（multi-inverter robust control 视角下 GFM 联合可行集非空性，§10.6 Seam C-ε）；equity-EENS 作为 regulator-imposed 目标分量。这三件 power-specific 物在 game-theoretic 文献中被抽象掉——综述把它们重新接入 Bayesian Stackelberg 框架的工作是 follow-on 论文的方法学入口。

    实质后果（borrow machinery, don't re-invent）：game-theoretic anchor 给 §11 案例提供 (i) existence of equilibrium 结果（mixed strategy Bayesian Nash 在 finite type space 下可保证）；(ii) complexity bounds（计算 Bayesian Stackelberg 在 multiple-types 下为 NP-hard，Conitzer-Sandholm 2006）；(iii) regret analysis 工具（online learning under adaptive attacker，Hannan / Blackwell 系 → no-regret learning）。综述把这一 game-theoretic 定位作为读者借机器的入口，而不为案例自身重做 game-theoretic 分析——案例的 power-systems 贡献是 instantiation 而非 game-theory 创新。这与综述"bridge document"的整体定位（§12.4 final positioning）一致。

    Knightian / DMDU caveat：本案例假设 climate fragility 分布在 ambiguity set 内存在且 \(W_1\) 可定义；当深度气候非平稳性（AMOC slowdown、megafire-megadrought 反馈、tipping point）使条件分布本身存疑时，DMDU / RDM / info-gap framing 是替代选项。本综述把这一边界条件归入 §12 开放前沿（regimes outside 综述 framing）。

    11.2 DDU 内嵌（双层耦合的形式表达）#

    operator 的 \(\mathbf{u}_t\) 通过两条 DDU 通道作用回内层：

    • distribution-DDU：PSPS 风格 de-energization 直接降低 \(\hat{p}^{\text{fail}}\)（点火通道）；proactive cyber isolation 改变 attacker 的可达集（cyber 通道）；
    • information-revelation-DDU：传感与无人机布置改变 operator 在 landfall / heatwave 期间可观测的 hazard 信号。本案例首次在 PSPS-style 设置中显式形式化 information-revelation DDU（phase0c Thread A Caveat C4 / S1 列出的 sharpest unwritten seam）；在 game-theoretic 视角下，defender 的 sensor 部署是 Bayesian persuasion of attacker posterior（详 §11.1 跨域定位）。

    attacker 的 timing \(t^a\) 对 \(\hat{p}^{\text{fail}}\) 内生——这是 phase 0c Thread B S1 的核心closed-loop：attacker timing → operator action → fragility distribution → operator action → attacker payoff。tri-level scaffold + DDU 形式化让这个固定点 well-posed。

    双层 DDU 耦合的显式形式（避免被误读为隐喻）。设 attacker 决策 \((\mathbf{a}, t^a)\)、operator commit-ahead policy \(\pi^{\text{op}}\)（产出实时 \(\mathbf{u}_t\)）、hazard 现实 \(\mathbf{H}_t\)，两层 DDU 关系：

    • operator-side DDU：\(p^{\text{fail}}_{ij}(\mathbf{H}_t, \mathbf{u}_t)\) — \(\mathbf{u}_t\)（PSPS、proactive isolation、pre-emptive curtailment）改变失效概率分布；
    • attacker-side DDU：\(p^{\text{cyber-success}}(\mathbf{a}, \pi^{\text{op}}, \hat{p}^{\text{fail}})\) — attacker 攻击成功率依赖 operator commit-ahead policy（决定 attack surface）与 attacker 持有的 fragility 预测（决定 timing 价值）。

    两层耦合通过 inner attacker 的目标函数 \(\mathbb{E}_{Q,\pi^{\text{op}}}[\text{LoadShed}(\mathbf{a}, t^a, \pi^{\text{op}}, \mathbf{H}_t)]\) 在 worst-case \(Q \in \mathcal{P}_{\text{amb}}\) 下联立——这是 phase0c-B S1 与 phase0c-A S2 的形式合流。Well-posedness 通过 (i) D-A-O 决策序的固定 Stackelberg ordering、(ii) DDU 在两层中分别 single-shot（attacker 不与 fragility 实时更新交互）保证。

    12.2 Metric 推荐 —— 小型固定 Pareto vector#

    按 §2 + §9 的形式前提：SAIDI 在 IEEE 1366 MED 2.5β rule 下机械性排除 major event days，且 LBNL 评估证明 MED day-exclusion 是 SAIDI 稳定性的统计要求——因此 equity-weighted resilience 必须是平行 metric，不能作为 SAIDI 的 patch。

    推荐：报告小型固定 Pareto vector

    \[ \boxed{\;\bigl(\,\text{EENS},\;\text{EENS}_{\text{eq}},\;\tau_{\text{rec}},\;\Pr[\text{cascade}\ge k]\,\bigr)\;} \]

    而非单一 scalar。理由四条：

    • 不可比性收敛：四维允许 utility / region / hazard 之间在同一坐标系下比较，避免 utility-specific scorecard 的 N-vs-N 不可比。
    • regulatory hook：DOE BIL Justice40（≥ 40% benefits 流向劣势社区）需要 equity-EENS 这一类量化通道；纯 SAIDI 不提供此通道。
    • 政治公平：把 equity-EENS 作为指标家族的显式列而非"附录"，迫使 regulator 在年度报送中正面表达该维度。
    • tail-risk 显式：\(\Pr[\text{cascade}\ge k]\) 是 HILP / compound corpus 的天然 metric，与 curve-area 互补；EENS 是积分量，\(\Pr[\text{cascade}\ge k]\) 是尾分布量。

    Caveat：这是研究 + 监管联合推荐，不是已被任何 regulator 采纳的标准。NERC RISC 2025、CPUC、PUCT 等当前都未采纳。本综述的位置是 PNNL 2023 的方向性主张的具体化（小型固定 vector，标准化后可报送）+ LBNL MED 评估的统计后果（不能 patch SAIDI，必须并行）。

    12.2.1 Pareto vector 的四维选择理由的详细展开#

    为何是 EENS、equity-EENS、\(\tau_{\text{rec}}\)、\(\Pr[\text{cascade}\ge k]\) 而不是其他四维？综述给出形式与政策两方面的理由。

    形式理由。前两维是积分量与积分量的公平加权——它们捕获事件期间的总体能量损失与其分布不公平；\(\tau_{\text{rec}}\) 是时间矩量——它捕获恢复速度；\(\Pr[\text{cascade}\ge k]\) 是尾分布量——它捕获 HILP / compound 段的"灾难性失败"概率。这四个数学性质（积分、加权积分、时间矩量、尾分布）是 \(R(t)\) 曲线的信息完备子集——单 scalar 无论是 curve area 还是 \(\tau_{\text{rec}}\) 都丢失其余三维的信息。

    政策理由。第一维 EENS 与现有 utility 报送传统兼容（与 SAIDI 在结构上同源）；第二维 equity-EENS 与 DOE BIL Justice40 兼容（提供 ≥ 40% benefits 流向劣势社区的可裁决量化通道）；第三维 \(\tau_{\text{rec}}\) 是 utility-side restoration 工程的传统 KPI（与 mutual-assistance crew dispatch 决策直接挂钩）；第四维 \(\Pr[\text{cascade}\ge k]\) 与 NERC TPL 失效层级思维同源（N-k contingency 是 \(k\) 在 reliability 段的 deterministic 版本，\(\Pr[\text{cascade}\ge k]\) 是其 HILP 段的概率推广）。四维各与一条已存在的监管/工程传统对齐，便于在不重建监管的前提下被采纳。

    为何不是五维或三维。综述考虑过加入 economy-wide $ loss (CGE) 作为第五维但拒绝——CGE 数字依赖一次 specific 校准（如 B9 的 NYISO Long Island + 一次 CGE 校准），跨 utility / region 不可比；如要进入指标家族，应作为附加可选维度而非核心 vector。综述也考虑过把 equity-EENS 移除以保持三维的简约——但这会让 DOE BIL Justice40 失去量化通道，违反 §9.8 的政治经济学论点。故选择四维。

    Heritage —— equity-EENS 与 Sen capabilities approach 的 40 年谱系。equity-EENS 不是综述发明的 ad-hoc 指标——它是 Amartya Sen Commodities and Capabilities (1985)、Sen Inequality Reexamined (1992)、Nussbaum Women and Human Development (2000) 的 capability approach 在电力可达性维度上的具体化。Capability approach 的核心论点是：福利衡量不应停留在 resource（资源量）或 utility（主观效用）层面，应抵达 capability（可行 functioning 的可能性空间）层面——即"个体能否实现 X"而非"个体拥有多少 Y"。把这一框架投射到电力：

    • resource 层：MWh 供电量（EENS 的传统读法）；
    • utility 层：customer-minutes-out（SAIDI 的传统读法）；
    • capability 层：因停电而无法实现的具体 functioning——冷藏（食物 / 药品）、透析、通信（紧急救援呼叫）、取暖 / 制冷（避免热致 / 冷致死亡）、移动（电动轮椅充电）。

    equity-EENS 把 capability 层的不平等通过社区劣势权重 \(w_n\) 代理回 resource 层，使指标与 utility-side 数据基础设施兼容——这是一种实用妥协：理想是直接报告 capability deprivation，工程现实是 capability 数据难以采集，故以社区劣势 SVI / EJScreen 作为 capability deprivation 的 proxy。综述据此把 equity-EENS 视为 Sen-Nussbaum 谱系的operational 折中，而非脱离哲学传统的孤立技术对象。

    DOE BIL Justice40 的政策对应：Justice40 "≥ 40% benefits 流向劣势社区"机制本身是 Sen-style capability threshold policy——它不要求事先证明 capability 损失，而要求政策投资的结果分布在 capability deprivation 维度上达到最低占比。这种 threshold-rule 机制在 Nussbaum 2000 给出的 "central capabilities list" 框架下有直接 lineage：每项 capability 设最低阈值，政策合规判定基于 threshold satisfaction 而非 capability optimization。equity-EENS 因此既是技术指标，也是政策 mechanism design 的 measurable hook。

    12.2.2 MED → inequity 的 regulatory-design alternative space（四族对策）#

    §9.4 与 §12.2 已论证 SAIDI 不可 patch，equity-weighted resilience 必须以 parallel metric 实现。但 parallel-metric 是 regulatory-design 空间中的一个选项；至少另有三族（按 §9.4 备选空间已 setup）值得显式枚举为 follow-on 政策研究路径：

    Family 机制 political-economic implication 与 capability approach 的关系
    I. Parallel metric（本综述推荐） 报告 SAIDI（blue-sky reliability）+ 平行 Pareto vector（HILP resilience） regulator 学两套尺度；equity advocates 在两个 arena 工作；utility-side 数据基础设施兼容 proxy via \(w_n\)；capability 不直接出现
    II. Conditional reporting 保留 SAIDI，要求 utility 单独报送 MED-excluded sub-series 与对应 sub-metric 最小报送基础设施改动；equity advocates 可直接挑战 MED-bucket sub-series；保留 SAIDI 统计稳定性 proxy via sub-series；与 I 同层但更最小化
    III. Distributional reporting 把 SAIDI 单 scalar 替换为 customer-hours-out distribution，含每客户上限阈值（如年内任一 customer ≤ X 小时，按 SVI 加权） 强制 utility 在 customer-level 面对 tail outcomes；Justice40 自然落地为 capability threshold 直接接近 capability 视角——customer-level tail 是 capability deprivation 的可量化代理
    IV. Capability-based reporting 不报告网络指标，直接报告社区无法访问的具体 service：冷藏、透析、通信、取暖 与 Sen-Nussbaum 框架最直接对齐；但数据采集成本高、跨 utility 标准化难 capability 本身作为指标——理论最纯，工程最难

    为何本综述推荐 Family I 而非 II/III/IV：选择基于渐进式监管成本与 utility-side 数据基础设施兼容性，而非政策机制 ROI 上的优越。具体理由：(a) Family I 与 PNNL 2023 学术 anchor 直接兼容；(b) 与 NERC RISC 2025 "并列分别测度" 立场一致；(c) 实施成本低于 III/IV。但若 regulator 选择 II / III / IV，本综述的形式工具（DDU、\(\mathcal{F}_{\text{UNIFI}}\)、\(\mathcal{P}_{\text{amb}}\)、Pareto front analysis）仍可复用——只需把 metric 替换为对应 family 的指标对象。综述识别四族 design space 的存在，本身是规范性贡献的一部分，避免下游把 §12.2 的 parallel-metric 推荐误读为"唯一正确指标"。

    Sen capabilities heritage 在四族中的递进：从 Family I（proxy via weights）→ II（proxy via sub-series）→ III（customer-level tail，接近 capability）→ IV（capability 本身作为指标），是 Sen-Nussbaum 框架在监管 metric 上的完整 spectrum。综述把这一 spectrum 呈现为 follow-on 政策研究纲领——任一 family 的具体化都对应一篇政策机制论文，且四 family 之间形式比较是 mechanism-design 研究对象。

    12.5 综述的最终定位 —— "Bridge" 而非 "Gap" Document#

    综述在 phase0d 初稿与 revised draft 中的定位是 "ML + optimization for power-grid resilience, 2022–2026, with three normative claims"——这一定位正确但 under-positioned。经 deep-diver / domain-expert / pedagogy / fact-check / style 五 review 的共同提示，综述在 panel revision 中升级为以下定位：

    本综述是 power-grid resilience 作为 mature adjacent literatures 的 late arrival 的 bridge document——POMDPs、Bayesian Stackelberg security games、network percolation theory、systemic risk in finance、Sen capability ethics 都在过去 20–60 年中给出了与电力级联 / 决策依赖不确定性 / 公平加权指标 / GFM 多机稳定性 同构的形式机器；power-systems 的贡献是这些抽象机器在具体物理可行性约束（GFM 动态、hazard 物理、UNIFI conformance、grid topology）下的具体 instantiation。

    这一 bridge 定位有两条具体优势：

    (a) 降低跨学科协作的 activation energy。follow-on 工作不需要"发明"新方法学——POMDP active-sensing (§4.3 跨域 anchor)、Bayesian Stackelberg security games (§11.1 跨域定位)、percolation phase transition (§8.7 跨域 anchor)、Sen capability approach (§12.2.1 heritage)、small-signal stability of multi-inverter systems (§10.6 control-theoretic prior) 都是 mature machinery，power-systems 的工作是把它们与具体物理约束接入。综述显式列出这些 adjacent literatures，让 follow-on 论文的方法学来源可识别、可借用。

    (b) Bridge document 的引用寿命比 gap document 长。"Gap"会被填上——一旦填上，gap document 的引用价值衰减；"bridge"则不会，因为 bridge 是连接两个永久存在的领域。本综述把 §4 / §8 / §10 / §11 / §12 的形式机器分别 anchor 到 POMDP / percolation / control-robustness / Bayesian Stackelberg / Sen capability 五个 mature 邻近文献——这五个 anchor 在 power-grid resilience 文献被"填满"之后仍然存在，让综述作为 cross-reference 工具的耐久性提高。

    对作者群体的具体后果：综述把 power-grid resilience 的 contribution 重新表达为 "提供给 adjacent literatures 的物理可行性约束"——hazard 物理、UNIFI conformance、grid topology、equity 政策机制。这一表达让 POMDP / security-game / percolation / control / capability 五领域的研究者能直接看到"在我自己领域中加一条 power-physics 约束会得到什么"，反之 power-systems 研究者能直接看到"把 X 邻近文献的机器搬过来要解决哪几条 wrinkle"。综述据此把自身定位从结果展示转为对话邀请——这是 panel revision 在 §12.5 落点的最终规范性主张。
