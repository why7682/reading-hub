    Variational Inequalities for Machine Learning: GAN, RLHF, and Multi-Agent RL#

    Phase 1 Draft · 2026-05-17 · Topic threads A (algorithmic) / B (game-theoretic ML applications) / C (structural & implicit interfaces)

    §1 引言与三轴攻击#

    1.1 论点陈述#

    本综述持以下立场：在（深度）参数空间上任何非保守 (non-conservative) 的梯度场都天然是变分不等式 (Variational Inequality, VI) 的研究对象，而不是单目标最优化的研究对象；并且现代机器学习中三类非保守性来自结构、而非来自噪声扰动的训练范式——鞍点式 GAN 训练、Nash 均衡式多智能体强化学习 (MARL)、Stackelberg / 双层 RLHF——共享同一套算子论 (operator-theoretic) 骨架：

    1. 单调性层级 (monotonicity hierarchy)：strongly monotone \(\Rightarrow\) monotone \(\Rightarrow\) weak-Minty / cohypomonotone \(\Rightarrow\) Minty \(\Rightarrow\) general；
    2. 末次迭代 (last-iterate) 算法机制：proximal-point 为父节点，派生出 Extragradient (EG)、Optimistic Gradient Descent Ascent (OGDA)、Mirror-Prox 三系，加上 Halpern anchoring 作为正交加速；
    3. 通过该不动点的隐式微分 (implicit differentiation) 演算：KKT 层、Deep Equilibrium (DEQ)、iMAML adjoint。

    文献已将这三大应用领域分裂成相互独立的子社区——GAN-VI 一脉、MARL-Nash 一脉、Stackelberg-RLHF 簇——彼此之间几乎不引用、不互译。填补这一裂缝是本综述的主要贡献；附带的结构性发现是：Thread C（隐式层 / differentiable optimization 文献）正是被忽视的结构桥梁。Caveat：potential games (Monderer–Shapley 1996) 是 conservative 的退化情形，VI machinery 在这类问题上 unnecessary——本综述聚焦的是 skew-symmetric component 非可忽略 的 structurally non-conservative 训练范式。

    轴 内涵 Donor thread

    (ii) 博弈型 ML 应用 GAN（鞍点 VI）/ MARL（Nash VI）/ RLHF（Stackelberg / 双层 VI） B

    1.3 与既有综述的差别#

    最相近的两份 ML 端综述（Razaviyayn et al., IEEE SPM 37(5), 2020；以及一些非单调极小极大教程）只覆盖轴 (i)+(ii) 的一个子片，且使用最优化语言而非 VI 语言。运筹学端的 Facchinei & Pang (2003) 经典著作覆盖轴 (i) 极完整，但写作早于深度学习浪潮，因此完全没有触碰轴 (iii)。本综述独有的合并视角是：把 Thread C（隐式层）作为 Thread A 与 Thread B 之间的"结构桥"，从而让 RLHF 的 Stackelberg 矫正项与 iMAML adjoint 在数学上被识别为同一对象（§7、§10.3, stitch S-BC1）。

    1.3.2 Helmholtz 拷问：non-conservative 梯度场与 potential games#

    Deep-diver review 在 "core thesis under a Helmholtz lens" 中提出一个值得正面回应的问题："非保守梯度场"作为切入口是否在数学上严格？Helmholtz decomposition 把 \(\mathbb{R}^n\) 上任意光滑向量场 \(F\) 分解为 conservative + solenoidal 两部分：\(F = \nabla \psi + \mathbf{H}\)，其中 \(\nabla \psi\) 是某标量势的梯度（curl-free, conservative）、\(\mathbf{H}\) 是 divergence-free 旋量分量（"涡度"分量）。GAN / MARL / RLHF 的 \(F\) 是否都有非零 \(\mathbf{H}\) 分量？

    回答 1：Potential games (Monderer & Shapley 1996, Games and Economic Behavior 14:124–143) 是退化情形。\(n\) 玩家博弈称为 potential game 当存在 \(\Psi: \prod_i \Delta(A_i) \to \mathbb{R}\) 使 \(\nabla_{\pi_i} V_i = \nabla_{\pi_i} \Psi\ \forall i\)——此时 \(F = \nabla \Psi\) 严格 conservative，\(\mathbf{H} = 0\)，VI machinery unnecessary：标准梯度下降在 \(\Psi\) 上即收敛到 Nash。Monderer–Shapley 1996 给出 potential games 的几个等价刻画（exact potential / weighted potential / ordinal potential 等）；congestion games（Rosenthal 1973）是 potential games 的经典子类。本综述聚焦的 GAN / 一般-sum MARL / Stackelberg-RLHF 都不是 potential games——其 \(\mathbf{H}\) 分量非零，这正是 VI 框架不可替代的原因。\(n=2\) 零和 总是 potential（取 \(\Psi = V_1 = -V_2\)），但联合训练动力学 \(F = (\nabla_x L, -\nabla_y L)\) 不是任何 \(\Psi\) 的梯度（除非 \(L\) 退化）——这是 GAN 联合训练 \(\mathbf{H} \neq 0\) 的具体来源。

    回答 2：单调性层级是 Helmholtz 谱的有结构对应。粗略对应（精确语义见 §2.2 / §4）： - Conservative + convex \(\Psi\) ⇒ \(F\) 严格单调（Baillon–Haddad 即给出 \(F = \nabla \Psi\) 凸 \(\Rightarrow\) co-coercive，§4.2）。 - Conservative + non-convex \(\Psi\) ⇒ \(F\) 可能非单调，但仍然 curl-free——这是单目标非凸优化的范畴（DPO 的 single-objective likelihood 即此情形，详 §11.4）。 - Non-conservative ⇒ \(\mathbf{H} \neq 0\) ⇒ 单调性层级才有 non-trivial 区分。"strongly monotone" 时旋量分量被对称部分主导（§2.1.5 强单调玩具例子）；"monotone Lip" 时旋量分量与对称部分量级相当（双线性 bilinear 经典例子）；"weak-Minty / cohypomon."时旋量分量超出但仍有限度可控；"general"时旋量分量任意大。

    回答 3：DPO 是 anti-VI 证据吗？这是 deep-diver review 在 §8 Bitter Lesson 拷问中提出的尖锐问题。DPO 把 RLHF closed-form 化简为单目标 KL-regularized likelihood loss——外表上是 conservative single-objective optimization，绕过 Stackelberg/bilevel 结构。但 §11.4 open problem (iv) 主张 DPO 与 STA-RLHF 在 some limit 下严格等价；如果该等价成立，DPO 其实是 hidden Stackelberg-VI 的 closed-form reduction，而非反例——它把 \(\mathbf{H}\) 分量通过 KL 正则 化简为 conservative 等价。Helmholtz lens 下，DPO 不是反对 VI 而是 VI 在特殊偏好-似然结构下的可解析归约。

    1.4 为什么是"非保守梯度场" 这一切入口#

    为什么"非保守梯度场" 是组织三类训练范式的合适切入口？给定一个标量损失 \(\mathcal{L}(\mathbf{x})\)，它的梯度场 \(\nabla \mathcal{L}\) 是保守的（curl-free）——任何闭合迭代回路上的累积梯度为零，于是梯度下降不存在"绕圈"病态。GAN 联合训练 \((\theta, \phi)\) 的"梯度"\(F = (\nabla_\theta V, -\nabla_\phi V)\)不是任何标量的梯度（生成器与判别器目标符号相反），其 Jacobian \(\partial F\) 通常有非零反对称分量，于是产生 spiraling 与 limit-cycle 病态——这是 GAN 训练实证中常见的 mode collapse / oscillation 的算子论根源。MARL 的多智能体 \(F_i = \nabla_{\pi_i} V_i\) 在 general-sum 设定下亦非任何 potential 的梯度；RLHF 的 outer loss 在 follower-best-response substitution 后失去 conservative 性质，因为 \(\phi^*(\theta)\) 经 IFT 引入的隐式依赖项也是非对称的。三类训练范式在"梯度场不是 conservative"这一同种数学事实下汇合，而 VI 框架正是处理 non-conservative 算子的最自然的形式语言。Facchinei & Pang (2003) 经典著作把 VI 与互补问题 (Complementarity Problems) 视为运筹学不动点理论的统一坐标系；本综述把它移植到 ML 训练。

    2.1.5 几何直觉：为什么需要 VI（2D toy example）#

    VI 框架的"一切起点"可以由一个 2D 的玩具例子说明。考虑双线性算子 \(F(x,y) = (y, -x)\) 与对应的 saddle-point objective \(L(x,y) = xy\)（零和、双线性、bilinear）。这是 minimax 教学中最经典的 sanity-check。

    vanilla GDA (gradient descent-ascent) 迭代 $\(\mathbf{x}_{k+1} = \mathbf{x}_k - \eta F(\mathbf{x}_k), \qquad F(\mathbf{x}_k) = (y_k, -x_k).\)$ 代入 \((x_{k+1}, y_{k+1}) = (x_k - \eta y_k,\ y_k + \eta x_k)\)。此线性递推矩阵特征值为 \(1 \pm i\eta\)，模 \(= \sqrt{1+\eta^2} > 1\)，即对任意正步长，GDA 在原点（唯一鞍点）附近螺旋发散。这是 GAN/MARL 训练里"loss 不收敛而是绕圈"现象的最干净缩影。

    EG (Korpelevich) 的几何修正：超前一步 \(\mathbf{x}_{k+1/2} = \mathbf{x}_k - \eta F(\mathbf{x}_k)\)，然后用前瞻点的算子值更新 \(\mathbf{x}_{k+1} = \mathbf{x}_k - \eta F(\mathbf{x}_{k+1/2})\)。在双线性问题上代入计算得 \((x_{k+1}, y_{k+1}) = ((1-\eta^2) x_k - \eta y_k,\ \eta x_k + (1-\eta^2) y_k)\)，特征值 \((1-\eta^2) \pm i\eta\)，模 \(= \sqrt{(1-\eta^2)^2 + \eta^2} = \sqrt{1 - \eta^2 + \eta^4}\)。在 \(\eta \in (0, 1)\) 范围内严格 < 1，于是 EG 在双线性问题上线性收敛——这是 §3 算法谱系的"种子"几何事实。

    与可保守梯度场的对照：把 \(F\) 换成保守的 \(F_{\text{cons}}(x,y) = (x, y) = \nabla(\frac{1}{2}(x^2+y^2))\)（标量势 \(\frac{1}{2}\|\mathbf{x}\|^2\) 的梯度），同样的 GDA 迭代变为 \(\mathbf{x}_{k+1} = (1-\eta)\mathbf{x}_k\)，模 \(|1-\eta| < 1\)，线性收敛到原点——保守场上 GDA 永远不会螺旋。\(F\) 的反对称分量 (Jacobian \(\partial F\) 的反对称部分，2D 例子里就是旋转矩阵 \(\begin{pmatrix}0&1\\-1&0\end{pmatrix}\)) 是 GDA 失效的算子论根因，也是 VI 框架要处理的对象。

    强单调 vs 非单调对照：把 \(F\) 换成 \(F_{\mu}(x,y) = (\mu x + y, -x + \mu y)\)（\(\mu > 0\)）——此 \(F_\mu\) 是 \(\mu\)-强单调（验证：\(\langle F_\mu(\mathbf{x}), \mathbf{x}\rangle = \mu(x^2+y^2)\)），其 Jacobian = \(\begin{pmatrix}\mu&1\\-1&\mu\end{pmatrix}\) 的反对称部分仍非零但已被对称强单调部分主导。GDA 迭代矩阵特征值 \(1 - \eta\mu \pm i\eta\)，模 \(= \sqrt{(1-\eta\mu)^2 + \eta^2}\)；只要 \(\eta < 2\mu/(1+\mu^2)\)，模 < 1——GDA 直接线性收敛，不需 EG/OGDA 修正。这是 §2.2 表中 "strongly monotone" 行只列"线性 \(\exp(-ck)\)"而不需 lookahead/anchoring 的几何根因。

    weak-Minty / cohypomon. 在 \(x^*\) 处 \(\langle F(x), x-x^*\rangle \geq -\rho\|F(x)\|^2\)（同义词：cohypomonotone in modern usage；严格意义见 §4.3 caveat） 某些 NC-C GAN；某些 Markov 博弈 EG+ \(O(1/K)\) on \(\|F\|^2\)（Diakonikolas–Daskalakis–Jordan AISTATS 2021；EG+ 稳定要求 \(\rho<1/(2L)\)，详 §3.2）

    general 无任何上述条件 一般 NC-NC；典型 RLHF outer loss 通常困难性下界

    下文每章都将其讨论的算法 / 应用锚定在该层级的某一行；这构成了三轴攻击在 Y 轴的对齐机制。

    单调性层级并非 ML 文献的本土概念，源自 1960–1970s 的 Stampacchia / Hartman / Browder 单调算子理论（Stampacchia 1964, C. R. Acad. Sci. Paris；Hartman & Stampacchia 1966, Acta Math.；Kinderlehrer & Stampacchia 1980 SIAM Classics）。Konnov (2007, Equilibrium Models and Variational Inequalities, Elsevier) 与 Facchinei & Pang (2003) 给出了 ML 兴起之前的现代综合处理。本综述把这一层级机械式地搬到 ML 文献头顶，作为 algorithm × application 对齐的元数据。Phase 0a 的 scoping 工作显示，ML 文献几乎没有任何一处显式使用这套层级语言——这正是综述能填的最大语义缺口之一。

    2.3 Co-coercivity 作为桥梁#

    强单调与单调之间还有一类重要的中间结构 co-coercivity：\(\langle F(x)-F(y), x-y\rangle \geq \beta\|F(x)-F(y)\|^2\)。它是 strong monotonicity 在算子范数侧的"对偶"，并且是 Gorbunov, Loizou & Gidel (AISTATS 2022, arXiv:2110.04261) 用以建立 EG 末次率 \(O(1/K)\) on \(\|F\|^2\) 的核心结构性桥梁。该论文的标题副词 "Connections With Cocoercivity" 明确点出了这条桥；本文 §3、§4 将该结构反复调用。

    Mirror-Prox（Nemirovski 2004）的 Bregman 推广：把投影换为 Bregman projection \(\arg\min_{y\in K}\{\eta\langle F(\mathbf{x}_k), y\rangle + D_\psi(y, \mathbf{x}_k)\}\)，\(D_\psi(y, x) = \psi(y) - \psi(x) - \langle\nabla\psi(x), y-x\rangle\) 是 Bregman 散度（\(\psi\) 是 mirror map，乘积单纯形上常取 \(\psi=\sum_i x_i \log x_i\) 即负熵，对应 entropic mirror map）。显式两步： $\(\mathbf{x}_{k+1/2} = \arg\min_{y\in K}\Big\{\eta \langle F(\mathbf{x}_k), y\rangle + D_\psi(y, \mathbf{x}_k)\Big\},\)$ $\(\mathbf{x}_{k+1} = \arg\min_{y\in K}\Big\{\eta \langle F(\mathbf{x}_{k+1/2}), y\rangle + D_\psi(y, \mathbf{x}_k)\Big\}.\)$ 单调 + Lip 下 ergodic gap \(O(1/T)\)。Bregman 几何的实战意义：当 \(K = \prod_i \Delta(A_i)\) 是乘积单纯形（§6 MARL 策略空间），负熵 mirror map 把欧氏投影换成 multiplicative-weight 更新，避免边界投影的退化——这是 zero-sum Markov 博弈在策略空间使用 Mirror-Prox 而非欧氏 EG 的根因（参见 §6.2 Daskalakis–Foster–Golowich 的 mirror-descent 处理）。

    Halpern anchoring（Halpern 1967）的显式公式：基础 Halpern 迭代针对压缩算子 \(T\)（不动点 \(z^* = T(z^*)\)），引入锚点 \(\mathbf{x}_0\) 与权重序列 \(\beta_k \in (0,1)\)： $\(\mathbf{x}_{k+1} = \beta_k \mathbf{x}_0 + (1-\beta_k)\, T(\mathbf{x}_k),\)$ \(\beta_k = 1/(k+2)\) 是经典选择。Halpern + EG 即 EAG (Yoon–Ryu 2021)：把上式中的 \(T(\mathbf{x}_k)\) 换成 EG 一步迭代，得 $\(\mathbf{x}_{k+1} = \beta_k \mathbf{x}_0 + (1-\beta_k)\, \big[\mathbf{x}_k - \eta F(\mathbf{x}_k - \eta F(\mathbf{x}_k))\big].\)$ 几何含义：每步以 \(\beta_k\) 权重把迭代往初始锚点 \(\mathbf{x}_0\) 拉一把；这"锚点引力" 是非加速→加速的几何来源（与 Nesterov 加速对单目标凸优化的 momentum 平行——Nesterov momentum 拉向历史平均，Halpern anchoring 拉向初始点）。Yoon–Ryu 2021 证明 EAG 在单调 + Lip 下末次率 \(O(1/k^2)\) on \(\|F\|^2\)，且与 lower bound 匹配——这是当前一阶 VI 算法在单调设定下的紧最优率。

    Korpelevich 1976 (EG, Èkonomika i Matematicheskie Metody, FC-2). 经典 extragradient 迭代 $\(\mathbf{x}_{k+1/2} = \Pi_K(\mathbf{x}_k - \eta F(\mathbf{x}_k)), \qquad \mathbf{x}_{k+1} = \Pi_K(\mathbf{x}_k - \eta F(\mathbf{x}_{k+1/2})),\)$ 其引入"超前一步" (lookahead) 修正非保守梯度场的旋转分量。原文俄文未直接获取，本文遵循 FC-2 约定通过 Gorbunov–Loizou–Gidel 2022 引言二手引证。

    Nemirovski 2004 Mirror-Prox (SIAM J. Optim. 15(1), DOI 10.1137/S1052623403425629). 把 EG 推广到 Bregman 几何下的 mirror 映射，给出在单调 + Lip 条件下 ergodic gap 的 \(O(1/T)\) 率。Mirror-Prox 是后续所有非欧 VI 算法（含 Mirror-Descent-on-policy 在 MARL 中的复用）的母板。

    Optimism 的来源（FC-14）. 在 VI 一侧 "optimism / extrapolation" 概念可上溯到 Popov 1980 (Math.     Mokhtari–Ozdaglar–Pattathil (AISTATS 2020, arXiv:1901.08511). 谱系上的"统一时刻"：proximal-point method (PPM) 隐式 \(\mathbf{x}_{k+1} = \Pi_K(\mathbf{x}_k - \eta F(\mathbf{x}_{k+1}))\) 在 strongly mon + Lip 下线性收敛 (rate \(\propto \kappa\))；EG 与 OGDA 是 PPM 的两种一阶近似——分别用 \(F(\mathbf{x}_{k+1/2})\) 或 \(2F(\mathbf{x}_k) - F(\mathbf{x}_{k-1})\) 替代隐式项——给出相同 order 的复杂度但 contraction 常数不同（非"完全等价"）。该统一视角是后续末次迭代分析的几何基础。

    Gorbunov–Loizou–Gidel (AISTATS 2022, arXiv:2110.04261) 与 Gorbunov–Taylor–Gidel (NeurIPS 2022, arXiv:2205.08446)（FC-1, CRIT）. 二者是两篇不同的论文，必须分开引用：前者关于 EG，论文标题为 "Extragradient Method: \(O(1/K)\) Last-Iterate Convergence for Monotone Variational Inequalities and Connections With Cocoercivity"；后者关于 OGDA / PEG，标题为 "Last-Iterate Convergence of Optimistic Gradient Method for Monotone Variational Inequalities"。算法族不同（EG vs OGDA-style），中间作者不同（Loizou vs Taylor），会议不同（AISTATS vs NeurIPS），但末次率均为 \(O(1/K)\) on \(\|F\|^2\)。phase 0b §3 在 thread A 之前曾把两者合并引用，这是错误的——本文遵循 FC-1 的硬约束分述。

    Yoon–Ryu 2021 EAG (ICML 2021, PMLR 139:12098–12109, arXiv:2102.07922). 把 Halpern anchoring（每步以固定权重往初始点拉回）叠加在 EG 上，得到 EAG 算法，将末次率从 \(O(1/K)\) 提升到 \(O(1/k^2)\) on \(\|F\|^2\)，并证明此率紧 (tight)。EAG 是当前单调 + Lip 设定下的最优一阶 known rate；它的几何含义是"加速由锚点提供"，与 Nesterov 加速对单目标凸优化的角色平行。

    Cai–Oikonomou–Zheng (NeurIPS 2022, arXiv:2204.09228)（FC-10）. 给出约束单调 VI 下 EG/OGDA 末次的紧率 \(O(1/\sqrt{T})\) on gap function。注意此处的收敛对象是 gap 而非 \(\|F\|^2\)（FC-13），二者并不能直接相比；并且 FC-10 强调不可凭 NeurIPS 2022 proceedings hash 区分 Cai–Oikonomou–Zheng 与 Gorbunov–Taylor–Gidel——必须通过 arXiv ID + 标题识别。

    3.2.1 谱系上的横向 pattern#

    把上述节点按"加速机制"重新排序，可以看到三条相对独立的提速路径：

    1. lookahead / extrapolation：Korpelevich EG → Nemirovski Mirror-Prox → OGDA → Mokhtari–Ozdaglar–Pattathil 统一证明——加速来自"先看一步" 的内梯度。
    2. anchoring：Yoon–Ryu EAG → 任意 Halpern 类算法——加速来自 "保留对初始点的引力"。EAG 在单调 + Lip 设定下证明 \(O(1/k^2)\) on \(\|F\|^2\) 是目前一阶算法所能达到的紧上界——证毕来自对应的下界匹配工作（同 paper 的 Theorem 4）。
    3. variance reduction：Alacaoglu–Malitsky 把 SVRG/SARAH 风格控制变量引入 EG——加速对象是 stochastic finite-sum 复杂度，正交于 (1)(2)。

    这三条路径的正交性意味着它们原则上可以组合：lookahead + anchoring (Halpern-EG) 已在 EAG 中实现；lookahead + VR (VR-EG) 已在 Alacaoglu–Malitsky 中实现；但 anchoring + VR（Halpern-VR-EG）以及 lookahead + anchoring + VR（Halpern-VR-EAG）目前仍然是空白——这是 §11.7 中 seam A-5 的具体所指。

    3.2.2 单调性外的算法#

    EG+ (Diakonikolas–Daskalakis–Jordan AISTATS 2021)、polynomial-time Minty (Anagnostides–Farina–Sandholm–Zhang 2025)、BC-SEG+ (Pethick et al. 2023) 三者共同把算法谱系从"严格单调"区域推向"结构性非单调"区域，覆盖单调性层级 lookup table 的 weak-Minty 与 Minty 两行。值得注意的是：(a) 多项式时间 Minty 结果至今没有任何 ML 应用 paper 引用——它的覆盖区域（存在 Minty 解的非单调 VI）原则上覆盖某类 RLHF outer-loss 与 general-sum MARL，但二者社区尚未识别该 reduction；(b) BC-SEG+ 已被部分 RLHF 实证文献作为"稳定 stochastic EG" 的理论参考，但未在 RLHF 收敛保证中显式调用。这些是本综述 §11 与 §10 stitch 反复指认的 "translation 缺口"。

    3.2.3 为什么 last-iterate 重要：deploy regime vs game-theoretic regime#

    §3 的算法谱系反复强调"末次率" (last-iterate) 而非"ergodic / averaged 率"，这是 ML 训练范式相对运筹学经典 VI 文献的一个重要 emphasis shift。差异的根因在于"算法输出怎么被使用" 这一应用层事实，可以按三种 regime 区分：

    Regime 1：deploy 单个 model（GAN / RLHF / monDEQ / iMAML 等）。训练结束后 deploy 的是最终参数 \(\theta_K\) 或最后一个 checkpoint，不是训练全程参数的平均 \(\bar\theta_K = \frac{1}{K}\sum_k \theta_k\)。即使理论给出 ergodic gap \(O(1/T)\) 收敛，对实际部署的 \(\theta_K\) 没有直接保证——双线性 bilinear 例子里 vanilla GDA 的 \(\bar\theta_K\) 可以收敛但 \(\theta_K\) 仍螺旋（Daskalakis et al. 2018 引言例子）。这是 GAN / RLHF / DEQ / iMAML 训练所有 paper 关注末次率的最直接 ML 理由。

    Regime 2：game-theoretic equilibrium 概念需要 averaging。在 game theory 经典框架里，Coarse Correlated Equilibrium (CCE) 与 Hannan consistency / no-regret 收敛都是关于经验平均策略 \(\bar\pi_K\) 的——双方使用 no-regret 算法（如 OGDA、Hedge）时 \(\bar\pi_K\) 收敛到 CCE，但个体策略 \(\pi_K\) 可以永远绕圈（Bailey & Piliouras 2018 显示 zero-sum game 上 multiplicative weight update 的迭代点遍布整个单纯形而不收敛）。这正是为什么经典博弈论文献把 ergodic / averaged 收敛视为天然对象——CCE 与 no-regret 是定义在历史平均上的概念。运筹学 VI 经典文献（Nemirovski Mirror-Prox 等）继承这一传统给出 ergodic gap \(O(1/T)\) 是恰当的。

    Regime 3：control / safe-RL / online deployment。模型在每一步都被部署 (online), 历史均值不是可访问对象。这里末次率与"任意一步策略都要好" 是同义的，等价于 Regime 1 的部署需求。

    Deep learning practice 的 alignment：现代 GAN / RLHF / multi-agent training 与 monDEQ / iMAML 训练几乎全部落在 Regime 1（"deploy 最后一个 checkpoint"），因此 §3 强调末次率与 §10 stitch S-AB1 把 thread A 末次定理 portable 到 GAN/MARL/RLHF 训练稳定性，是与 deep learning practice 直接对齐的——而非 operator-theory 选择 fashionable。反向：MARL 文献里如果应用关心的是 CCE convergence 而非个体 deploy（如 mechanism-design 风格的 multi-agent learning），ergodic 框架仍然合用。这一 regime 区分对 §6 MARL 章节的"目标对象选择" 有直接意义：Daskalakis–Foster–Golowich 2020 关心 Nash（individual, 等价 Regime 1），而 CCE 类研究关心 Regime 2——本综述聚焦 Regime 1 是因为它对应 deploy-a-policy 的工程主流。

    §4 单调性重审：从强单调到 weak-Minty / cohypomonotone#

    4.1 为什么需要单独一节#

    §2.2 的 lookup table 把单调性层级摆成了一个线性谱：strong → mon → weak-Minty → Minty → general。但这是一种简化。真实的层级是有"宽度"的——同一行内部存在多种不等价的精化结构（co-coercivity、\(\mu\)-strongly monotone-on-subset、structured non-monotone with hidden Minty）。本节做一次算子论精校，给后续 §5–§7 在锚定算法到应用时提供更精细的语义。

    4.2 强单调与 co-coercivity 的对偶#

    标准事实（Bauschke–Combettes 2017, Prop. 4.11 / Thm. 18.15）：(a) \(\beta\)-co-coercive \(\Rightarrow\) monotone \(+\ 1/\beta\)-Lipschitz；(b) \(F=\nabla f\) for \(L\)-smooth convex \(f\) \(\Leftrightarrow\) \((1/L)\)-co-coercive（Baillon–Haddad）；(c) \(\mu\)-strongly monotone \(+\ L\)-Lipschitz \(\Rightarrow \mu/L^2\)-co-coercive。但 monotone \(+\ L\)-Lipschitz 一般不蕴含 co-coercive——反例为双线性算子 \(F(x,y)=(y,-x)\)（1-Lip、单调，但 \(\langle F(x)-F(y),x-y\rangle=0\) 而 \(\|F(x)-F(y)\|^2>0\)，\(\beta=0\)）。co-coercivity 因此是介于 "monotone+Lip" 与 "strongly monotone" 之间的独立结构条件，不是 strong-monotonicity 的对偶。该结构是 Gorbunov–Loizou–Gidel (AISTATS 2022) 推导 EG 末次率的核心：EG 一次迭代后的"effective"算子展现 co-coercivity 模式，于是末次 \(\|F(\mathbf{x}_k)\|^2\) 可推理成"半"单目标凸优化的 \(\|\nabla f\|^2\) 衰减。这条桥也解释 Mokhtari–Ozdaglar–Pattathil (AISTATS 2020) 统一视角对 EG 与 OGDA 同时奏效。

    4.3 Combettes–Pennanen 2004 cohypomonotone 祖先#

    Combettes & Pennanen ("Proximal Methods for Cohypomonotone Operators," SIAM J. Control Optim. 43(2): 731–742, 2004) 给出了 cohypomonotone 算子在 proximal-point 算法下的渐近收敛——这是远在 ML 兴起之前对 weak-Minty 区域的算子论奠基。Diakonikolas–Daskalakis–Jordan (AISTATS 2021) 的 EG+ 可视为该祖先在 EG 框架下的有限速率版（\(O(1/K)\) on \(\|F\|^2\) 而非仅渐近）。Phase 0b 在归并 thread 时未充分突出这一历史延续，本文 §4 通过显式追溯 Combettes–Pennanen → Diakonikolas–Daskalakis–Jordan → Pethick et al. (stochastic) 的家谱，把 ML 文献的"非单调突破"放回它的运筹学根基。

    4.4 收敛对象再辨析 (FC-13 reprise)#

    不同 thread 之间最常被混淆的是收敛对象而非速率：

    • 平方算子范数 \(\|F(\mathbf{x}_k)\|^2\)：Yoon–Ryu (EAG, ICML 2021)、Gorbunov–Loizou–Gidel (AISTATS 2022)、Gorbunov–Taylor–Gidel (NeurIPS 2022)、Diakonikolas–Daskalakis–Jordan (AISTATS 2021)、Pethick et al. (2023, BC-SEG+) 均使用此对象。
    • Gap function \(\sup_{y \in K} \langle F(y), x - y\rangle\)：Mirror-Prox 原 paper、Cai–Oikonomou–Zheng (NeurIPS 2022) 使用此对象。
    • 迭代点距离 \(\|\mathbf{x}_k - \mathbf{x}^*\|\)：强单调设定下的常用对象。

    三者在一般条件下不可互译。"EAG 击败 EG" 与 "Cai–Oikonomou–Zheng 是 EG 的紧率" 这两句话在没有显式翻译的情况下不是同一时空的命题——前者比较的是 \(\|F\|^2\) rate，后者比较的是约束 gap rate。后续 §5–§9 在每次引用末次率结论时必须显示标注收敛对象（"on \(\|F\|^2\)" 或 "on gap"），这是本综述编辑规范。

    4.6 RLHF 与单调性层级的"溢出"#

    Stackelberg-RLHF（§7）的 outer-loss 在一般情况下既不单调也不在 Minty 范围——它的算子是经过 follower-stationarity 代入后的复合梯度，常常表现出局部 hidden monotonicity 但全局是 general 类型的 NC-NC。Razaviyayn et al. (IEEE SPM 37(5), 2020) 在 NC-NC 综述中已经识别到这一困难性等级；本综述的视角是：这种"溢出"恰恰是 thread C（隐式微分）能介入的接口——即使外层 VI 没有可证明的单调性，只要内层（follower）保持强单调，iMAML adjoint 的反向传播仍然 well-posed（§8, §10 stitch S-BC1）。

    §5 鞍点 VI = GAN 训练#

    5.1 GAN 训练的鞍点形式#

    最经典的 GAN 训练目标（Goodfellow et al. 2014 给出）是 $\(\min_\theta \max_\phi V(\theta, \phi) = \mathbb{E}_{x \sim p_{\text{data}}}[\log D_\phi(x)] + \mathbb{E}_{z \sim p_z}[\log(1 - D_\phi(G_\theta(z)))].\)$ 对应 VI 算子是 \(F = (\nabla_\theta V, -\nabla_\phi V)\)。在判别器最优 \(\phi = \phi^*(\theta)\) 处，沿 \(\theta\) 方向的有效更新就是著名的 Jensen–Shannon 散度梯度——但是联合训练时该最优条件不成立，\(F\) 在 \((\theta, \phi)\) 联合空间内通常是非保守的（旋转分量非零），于是单纯梯度下降-上升 (GDA) 会出现震荡或环绕。

    5.2 Gidel et al. ICLR 2019：VI 词汇入侵 GAN#

    Gidel, Berard, Vignoud, Vincent & Lacoste-Julien ("A Variational Inequality Perspective on GANs," ICLR 2019, arXiv:1802.10551) 第一次把 VI 词汇系统性地引入 GAN 训练。该论文的核心贡献是：

    1. 把 EG / 外推方法替代 vanilla GDA，给出在局部单调 + Lip 假设下的 ergodic 收敛保证；
    2. 在 stochastic 设定下提出 stochastic-extrapolation gradient 算法；
    3. 在 CIFAR-10 上实验展示训练稳定性的实证改进。

    Gidel et al. 是矩阵中 fill-gap = low 的"founder"——它本身已经做了大量统一工作；但仅限于鞍点 / GAN 这一应用面，未触及 MARL（§6）与 Stackelberg-RLHF（§7），这是本综述与之的衔接点。

    5.3 Daskalakis–Ilyas–Syrgkanis–Zeng ICLR 2018：optimism#

    Daskalakis, Ilyas, Syrgkanis & Zeng ("Training GANs with Optimism," ICLR 2018, arXiv:1711.00141) 把 Rakhlin–Sridharan 的 optimistic FTRL（在线学习侧的 optimism）移植到 GAN 训练。OGDA 在双线性鞍点上实现了 last-iterate 收敛，而 vanilla GDA 在同样的双线性零和博弈上有发散螺旋。FC-14 严格警示：optimism 概念本身并非该文发明，应归功于 Chiang et al. 2012 / Rakhlin & Sridharan 2013。

    5.4 Mescheder–Geiger–Nowozin ICML 2018：局部 Jacobian 分析#

    Mescheder, Geiger & Nowozin ("Which Training Methods for GANs do actually Converge?" ICML 2018, arXiv:1801.04406) 通过 GAN 联合动力学在均衡点附近的 Jacobian 谱分析，给出了"哪种方法局部稳定"的清晰答案：consensus optimization、gradient penalty、instance noise 在局部稳定，但都付出额外计算或正则化代价。该工作不是 VI 框架下完成的，但其结论可以在 VI 词汇下重述为"\(F\) 在均衡点的局部线性化是否落入单调或 cohypomonotone 区域"——这是本综述把 Thread B 局部稳定性叙事翻译到 Thread A 单调性层级的关键桥。独立 substantive 例证：Mescheder et al. §3 的 Figure 3 给出 vanilla GAN 在 toy Dirac-GAN (\(p_{\text{data}}=\delta_0\), generator output \(G_\theta(z)=\theta\)) 上 Jacobian 谱纯虚 ⇒ 局部 marginally stable but 非渐近稳定——这恰是 §2.1.5 双线性 \(F=(y,-x)\) 玩具例子的高维化身；本综述 §4.5 weak-Minty 行的"局部单调但全局非"现象在该 Dirac-GAN 设定下即可显式数值再现。

    5.5 Lin–Jin–Jordan ICML 2020：NC-C 复杂度天花板#

    Lin, Jin & Jordan ("On Gradient Descent Ascent for Nonconvex-Concave Minimax Problems," ICML 2020, arXiv:1906.00331) 在 NC-C（非凸-凹）设定下给出 GDA 复杂度 \(O(\varepsilon^{-6})\)、双循环 GDmax 复杂度 \(O(\varepsilon^{-3})\) 等结果。这些是 GAN/AT (adversarial training) 设定下的复杂度天花板——但作者完全没有使用 VI 词汇，全程在 minimax / optimization 词汇中。这是矩阵 fill-gap = high 的代表性条目。本综述的整合视角：Lin–Jin–Jordan 的 NC-C 复杂度结果对应到本文 §2.2 单调性层级里的"general" 行，但其证明结构是 hidden monotonicity（生成器内部循环可视为单调修正过的子问题），可以在 VI 单调性层级里得到一个更精细的位置。独立 substantive 例证：Lin–Jin–Jordan §4 Theorem 4.4 的 \(O(\varepsilon^{-6})\) rate 是关于 \(\nabla \Phi(\mathbf{x}) = \nabla_x \max_y f(x,y)\) 的 \(\varepsilon\)-stationary point——即 outer-min 在 concave inner-max envelope 上的 gradient norm。把这一对象译入本综述 §2.1 记号：\(\|\nabla \Phi\| \to \|F_{\text{effective}}\|\)，其中 \(F_{\text{effective}}\) 是 §7.1 Stackelberg formulation 在 follower-best-response substitution 后的 effective leader gradient。这条 explicit identification 表明 Lin–Jin–Jordan 的 NC-C 结果与本综述 §7 Stackelberg formulation 形式相同而仅记号体系不同——是 §10 stitch S-AB1 在 application 层的内部证据之一。

    5.8 GAN 训练的实证 / 理论 gap#

    GAN 在 §3.3 矩阵的 Thread B GAN 行 ([13]、[14]、[12]) 中，fill-gap 评分从 low (Gidel et al. 2019) 到 high (Lin–Jin–Jordan 2020)。差异的来源是收敛保证的边界与 GAN 实证设定边界的不匹配：

    • Gidel et al. 的 EG 保证依赖于在均衡点附近的局部 monotonicity assumption，而 GAN 真实联合空间在生成器深度模型下远非全局单调；
    • Mescheder et al. 的局部 Jacobian 分析只保证局部 asymptotic stability，不给出 finite-rate 末次率；
    • Lin–Jin–Jordan 的 NC-C \(O(\varepsilon^{-6})\) 复杂度针对stationarity 而非真实 Nash equilibrium。

    本综述视角：把这三种局部 / 全局 / stationary 保证按单调性层级 lookup table 对齐——它们分别处理三个不同的算子论层级（mon local / hidden mon / NC-C），共同覆盖 GAN 训练动力学的一部分，但仍留下大量空白——特别是大规模 GAN（StyleGAN-2、扩散对抗式训练）的全局 last-iterate 行为，目前没有任何 thread A 末次定理覆盖。这是 §10 stitch S-AB1 在 GAN 端落入"实证为主，无理论"区域的根因。

    5.9 与对抗训练 (Adversarial Training, AT) 的紧邻关系#

    对抗训练 (Madry et al. ICLR 2018，仅作为背景陈述，不进入本综述独立引用名单) 通过 inner-max + outer-min 构造 robust classifier，是 §5 鞍点 VI 的另一应用面（Razaviyayn et al. 2020 综述显式覆盖）。本综述选择不深入 AT，仅注明：AT 与 GAN 在算子论结构上几乎相同（Lin–Jin–Jordan 在 §5.5 同时覆盖 GAN 与 AT），但 AT 的 inner maximization 通常被简化为 projected gradient ascent (PGD)，于是 inner loop 不到达 follower stationarity——这使 AT 落出标准 VI 框架而进入"approximate Stackelberg" 区域，与 §7 RLHF 反而更接近。该观察是本综述提供的另一条"未写论文" 线索：AT 的 PGD inner loop ↔ RLHF 的 myopic reward modeling ↔ STA-RLHF 的 IFT-adjoint 三者形成一条 hierarchy，对应不同程度的 follower-rationality 假设。

    §6 Nash VI = 多智能体强化学习#

    6.1 多智能体强化学习的博弈论形式#

    考虑 \(n\) 个智能体，每个智能体 \(i\) 在策略 \(\pi_i\) 下追求自己的累积回报 \(V_i(\pi_1, \ldots, \pi_n)\)。Nash 均衡是 $\(V_i(\pi_i^*, \pi_{-i}^*) \ge V_i(\pi_i, \pi_{-i}^*) \quad \forall \pi_i, \forall i.\)$ 对应 VI 算子是 \(F_i(\boldsymbol{\pi}) = \nabla_{\pi_i} V_i\) 在乘积单纯形 \(K = \prod_i \Delta(A_i)\) 上的拼接。该问题与 §5 鞍点的本质区别在于：不再是零和（除非 \(n=2\) 且 \(V_1+V_2=0\)），因此一般情况下 \(F\) 既不来自任何标量势函数，也不一定满足单调性。

    6.2 Daskalakis–Foster–Golowich NeurIPS 2020：独立策略梯度#

    Daskalakis, Foster & Golowich ("Independent Policy Gradient Methods for Competitive RL," NeurIPS 2020, arXiv:2101.04233) 在零和 Markov 博弈中给出独立策略梯度（每个智能体只用自己的回报与策略梯度，不知道对手 model 与策略）能在有限样本内逼近 Nash 的结果。该工作的算子论解读是：零和 Markov 博弈在策略空间内部的有效算子 \(F\) 是单调的（沿乘积单纯形受 Bregman 几何修正），于是 thread A 的单调-VI 末次率可以借助 mirror-descent / OGDA 类似工具被移植过来。

    6.3 Wei–Lee–Zhang–Luo COLT 2021：去中心化 OGDA#

    Wei, Lee, Zhang & Luo ("Last-iterate Convergence of Decentralized OGDA in Infinite-horizon Competitive Markov Games," COLT 2021 (<venue verify in Phase 1>, FC-11)) 把 OGDA 适配到去中心化 Markov 博弈，证明在零和 infinite-horizon 设定下末次迭代收敛到 Nash——这是 thread A 单调 VI 末次率向 MARL 一侧的最强可迁移点。

    6.4 VI-MARL 预印本（arXiv:2410.07976, FC-8）：一般和 MARL 的 weak-Minty 代理#

    最近的 VI-MARL 预印本（arXiv:2410.07976，作者列表按 FC-8 不在本文枚举）把 EG 风格更新搭配 MADDPG 架构，在 general-sum MARL 上实证逼近 Nash gap。该工作的关键贡献是认识到 general-sum MARL 落出零和单调区域，需要 weak-Minty / cohypomonotone 代理条件（§4.5），并通过 EG+ 风格的稳定步在实证上观察到 Nash-gap 收敛。这是矩阵中最高 fill-gap 的 MARL 行——本综述 §10 stitch S-AB1 / S-AC1 把其位置放回 thread A 的非单调前沿。

    6.5 与博弈论的可计算性下界#

    PPAD 复杂度类对 general Nash 计算给出可计算性下界（Daskalakis–Goldberg–Papadimitriou 2009 SIAM J. Comp., 不在本综述独立引用名单中——仅作为 §6 背景陈述）：一般 Nash 计算属于 PPAD-complete，因此不能期望多项式时间在一般情形精确求解。本综述视角下，"PPAD 困难"对应于本文 §2.2 lookup table 的 general 行；任何 MARL 算法收敛保证都必然伴随单调性层级上的额外假设（zero-sum / weak-Minty / Minty 等）。

    6.9 从 symmetric Nash 到 hierarchical Stackelberg：概念桥#

    §6 处理的 Nash 均衡是对称的——所有智能体地位平等、同时行动、各自优化自己的 \(V_i\)。§7 处理的 Stackelberg 均衡是层级的——leader 先承诺策略，follower 看到后再最优响应。两者在 game-theoretic ML 应用里互不可替代但又结构相邻，本节给出概念桥。

    对称 Nash 的算子论形式：\(F(\boldsymbol{\pi}) = (\nabla_{\pi_1} V_1, \dots, \nabla_{\pi_n} V_n)\)，VI 解 \(\boldsymbol{\pi}^*\) 满足 \(\langle F(\boldsymbol{\pi}^*), \boldsymbol{\pi} - \boldsymbol{\pi}^*\rangle \geq 0\)。所有玩家在同一时间尺度。

    Stackelberg 的算子论形式：leader 的 effective gradient 是沿 follower-best-response 的全导数（§7.1） $\(F_{\text{Stackelberg}}(\theta) = \frac{d}{d\theta}\mathcal{L}_{\text{outer}}(\theta, \phi^*(\theta)) = \partial_\theta \mathcal{L}_{\text{outer}} + \left(\frac{\partial \phi^*}{\partial \theta}\right)^\top \partial_\phi \mathcal{L}_{\text{outer}}.\)$ 对比 Nash：Nash 的 \(F\) 是各 player 偏梯度的简单 concatenation；Stackelberg 的 \(F\) 把 follower 的隐式依赖通过 IFT 折叠进 leader 的全导数。

    两个 limit 的退化： - 若 leader 与 follower 在 zero-sum + simultaneous 设定下——即 \(\mathcal{L}_{\text{outer}}(\theta, \phi) = -\mathcal{L}_{\text{inner}}(\phi; \theta)\) 且双方同时更新——Stackelberg 退化为 symmetric Nash on 2-player zero-sum game，全导数中的 parameter-steering term 消失（因为 \(\phi^*(\theta)\) 在 simultaneous 下不被 leader 感知）。这是 GAN（§5）作为"Stackelberg 但忽略 follower steering" 的简化情形。 - 若 leader-follower 在 sequential + general-sum 设定下——RLHF / iMAML 的标准设定——parameter-steering term 不为零，且对应 IFT-adjoint。这是 §7 / §8.5 / §10.3 stitch S-BC1 关注的核心结构。

    为何 §6 → §7 是渐进的：把 §6 的 simultaneous Nash 视为"零层级 Stackelberg"（leader 与 follower 同时存在，无承诺），\(\to\) §7 的 hierarchical Stackelberg 加上 commitment + IFT-adjoint 是显式承认 follower 智能体性 (rationality) 的精化。两者在 conservative 梯度场上等价（potential games），但在 non-conservative 场上结构差异显著——后者正是本综述聚焦的 GAN / MARL / RLHF 共有特征。这一桥也是 §10 stitch S-AB1 与 S-BC1 在 application 层的具体过渡：S-AB1 在 §6 端把 Nash 算法对接 Thread A 末次率，S-BC1 在 §7 端把 Stackelberg 全导数对接 Thread C iMAML adjoint。

    §7 Stackelberg / 双层 VI = RLHF#

    7.0 IFT primer（前置：理解 Stackelberg 与隐式微分需要的一段直觉）#

    §7.1 与 §8.1 都会反复调用 Implicit Function Theorem (IFT) 来处理 bilevel 结构与 implicit-layer 反向传播。本节先用 1 段直觉 + 1 段公式做 stand-alone primer，避免读者在 §7.1 直接撞上 follower-best-response 代入的"全导数"代数。

    直觉：考虑一个变量 \(\phi\) 是 \(\theta\) 的隐函数——\(\phi\) 不是 \(\theta\) 的显式函数，而是通过满足某个稳定性条件 \(\Phi(\phi, \theta) = 0\) 隐式地依赖 \(\theta\)（典型场景：\(\phi^*(\theta) = \arg\min_\phi \mathcal{L}(\phi; \theta)\) 满足一阶条件 \(\nabla_\phi \mathcal{L}(\phi^*; \theta) = 0\)）。我们想要的是 \(d\phi^*/d\theta\)——参数 \(\theta\) 微调时，最优 \(\phi^*\) 怎么跟着变。不展开内层迭代过程的前提下，IFT 给出闭式答案。

    公式：对 \(\Phi(\phi^*(\theta), \theta) = 0\) 两边对 \(\theta\) 全微分，链式法则给 $\(\frac{\partial \Phi}{\partial \phi}\Big|_{\phi^*(\theta)}\!\cdot \frac{d\phi^*}{d\theta} + \frac{\partial \Phi}{\partial \theta}\Big|_{\phi^*(\theta)} = 0.\)$ 若 \(\partial \Phi/\partial \phi\) 在 \(\phi^*(\theta)\) 处可逆（即内层 problem 在 \(\phi^*\) 处有非退化 Hessian / 强单调 Jacobian），则 $\(\boxed{\;\frac{d\phi^*}{d\theta} = -\left(\frac{\partial \Phi}{\partial \phi}\right)^{-1}\frac{\partial \Phi}{\partial \theta}\;}\)$ 这就是 IFT-adjoint 的 master formula。well-posedness 的真正负担在 \(\partial \Phi/\partial \phi\) 可逆——内层强单调或 Hessian 正定是足够条件，非单调或退化 Hessian 让 IFT 后向 ill-posed（这是 §8 / §10 stitch S-AC1 / §11.5 open problem (v) 的算子论根因）。

    实战形态：在 RLHF（§7.1）里 \(\Phi_{\text{inner}}(\phi; \theta) = \nabla_\phi \mathcal{L}_{\text{inner}}(\phi; \theta, \mathcal{D}_{\text{pref}})\) 是 reward model stationarity；在 iMAML（§8.5）里 \(\Phi_\tau(\phi; \theta) = \nabla_\phi \mathcal{L}_\tau^{\text{inner}}\) 是 task-adapted 参数 stationarity；在 OptNet / cvxpylayers（§8.2 / §8.4）里 \(\Phi\) 是 QP / 凸 cone-program 的 KKT 系统。§7.8 与 §10.3 stitch S-BC1 的核心观察是：这三处的 \(\partial \Phi/\partial \phi\) 与 \(\partial \Phi/\partial \theta\) 在不同社区写法不同但数学相同，IFT 反向公式逐字对应。

    7.1 RLHF 的 Stackelberg 形式#

    标准 RLHF 训练分两步：先训练奖励模型 \(r_\phi\) 拟合人类偏好对，再以 \(r_\phi\) 为信号通过 PPO/DPO 优化策略 \(\pi_\theta\)。myopic 实现把 \(\phi\) 视为不可微的外部常数，于是策略梯度退化成单目标策略优化。Stackelberg / 双层 VI 视角则把 RLHF 显式建模为 $\(\min_\theta \mathcal{L}_{\text{outer}}(\theta, \phi^*(\theta)) \quad \text{s.t.}\quad \phi^*(\theta) = \arg\min_\phi \mathcal{L}_{\text{inner}}(\phi; \theta, \mathcal{D}_{\text{pref}}),\)$ 其中 inner 捕获"奖励模型对当前策略生成数据的拟合"，outer 最小化"在 follower-best-response 下的策略损失"。符号约定：\(\partial_\theta\) 表示偏导（hold \(\phi\) fixed），\(d/d\theta\,(\cdot)|_{\phi=\phi^*(\theta)}\) 表示沿隐函数的全导数。Stackelberg-VI 算子是沿 \(\phi^*(\theta)\) 的全导数： $\(F(\theta) = \frac{d}{d\theta}\mathcal{L}_{\text{outer}}(\theta, \phi^*(\theta)) = \underbrace{\partial_\theta \mathcal{L}_{\text{outer}}}_{\text{myopic 项}} + \underbrace{\left(\frac{\partial \phi^*}{\partial \theta}\right)^\top \partial_\phi \mathcal{L}_{\text{outer}}}_{\text{parameter-steering term}},\)$ 其中 \(\partial \phi^*/\partial \theta\) 通过 IFT 代入（见 §8.1）。myopic RLHF 用 \(\partial_\theta \mathcal{L}_{\text{outer}}\) 作为更新方向；STA-RLHF 用全导数，差出 parameter-steering term。

    7.1.1 Stackelberg formulation 的四个隐藏假设#

    §7.1 的 bilevel 写法 \(\min_\theta \mathcal{L}_{\text{outer}}(\theta, \phi^*(\theta))\) 看似干净，但至少四个假设被默认成立而文献鲜有逐条 caveat——逐一列出，对 §7.2–§7.10 与 §11.4 open problem 的范围理解很重要：

    1. Commitment / Berge upper-semicontinuity：Stackelberg 经典模型（von Stackelberg 1934；现代博弈理论梳理见 Berge 1963 Topological Spaces 的 maximum theorem）假定 leader 能够先承诺策略 \(\theta\) 且承诺对 follower 可信。在 RLHF 工程实践中此假设默认成立（reward model \(\phi\) 在数据上的拟合是 follower 对 leader policy \(\theta\) 的最优响应），但若 follower 也有自主优化轮换（如 iterative RLHF 多轮交替），commitment 退化为 fixed-point game 而非 hierarchical Stackelberg——这是 alignment-collapse (arXiv:2605.04266) 现象的博弈论根因之一。Berge maximum theorem 要求 follower-best-response correspondence \(\phi^*(\theta)\) upper-semicontinuous，对应内层最优化问题在 \(\theta\) 连续变动下解集不"突然消失"。

    2. Unique follower response：\(\phi^*(\theta) = \arg\min_\phi \mathcal{L}_{\text{inner}}\) 默认是单点集 (singleton)，但 reward model 训练在偏好数据有限的实践中常存在多个等价 \(\phi\) 解释同一偏好集（model identifiability gap）。多解情况下 outer-loss 沿 \(\phi^*\) 全导数不再 well-defined；需要 follower-selection 规则（lex-min、entropy-max、proximal regularizer 等）作为额外结构——iMAML（§8.5）正是通过 proximal 正则化强制 follower-response 单点。STA-RLHF (Makar-Limanov et al. 2024) 默认 leader-strong-cvx 推出 follower 单点；SLHF (arXiv:2512.16626) 在 bilevel VI 框架下处理多解但需要额外稳定性假设。

    3. Observability：leader 必须能 observe follower 的实际响应 \(\phi^*\)，否则 IFT 后向无法计算。RLHF 实践里 reward model 训练完成后参数显式可见，此假设成立；但若 follower 是 black-box（如外部 prompt-based reward judging），observability 不再 hold，bilevel 退化为 bandit-style optimization。

    4. IFT well-posedness / KKT-LICQ：IFT 反向 \(\partial \phi^*/\partial \theta = -(\partial \Phi/\partial \phi)^{-1}(\partial \Phi/\partial \theta)\) 要求 \(\partial \Phi/\partial \phi\) 可逆，等价地内层 KKT 系统满足 LICQ (Linear Independence Constraint Qualification) 与 SOSC (Second-Order Sufficient Condition)。在 RLHF reward model 是无约束 logistic regression-like 训练时通常成立（Hessian 正定 a.s. 在数据非退化下），但non-convex 内层 (deep reward model with non-convex loss) 让 KKT-LICQ 退化——这是 §10 stitch S-AC1 / §11.5 open problem (v) 在 RLHF 端的具体呈现。

    四条 caveat 与 §7.10 alignment-collapse 的因果关系：alignment-collapse 现象同时违反 (1) commitment（iterative 多轮替换 = follower 也主动优化）与 (4) IFT well-posedness（reward model 在分布漂移后 KKT 解集退化）；arXiv:2605.04266 的"foresighted PO" 修正可以读作"在 (1) 失效的情况下用 anticipation 重建近似 commitment"。

    7.5 \(\Psi\)-PO / IPO：implicit-VI 的解算#

    Azar, Rowland, Piot, Guo, Calandriello, Valko & Munos ("A General Theoretical Paradigm to Understand Learning from Human Preferences," AISTATS 2024, arXiv:2310.12036) 提出 \(\Psi\)-PO 框架——把 DPO 视为 \(\Psi\)-PO 的一个特例，并提出 IPO 变体避免 DPO 的过拟合问题。本综述的关键观察：\(\Psi\)-PO / IPO 实际上是把 Stackelberg outer-loss 的 closed-form 解析解直接写出来——它等价于一种 implicit-VI solver，把 Stackelberg 双层 VI 通过对 inner 问题的偏好-似然结构求出 \(\phi^*(\theta)\) 的闭式而得到 reduction。这条等价性目前未在 Azar et al. 或后续文献中显式陈述；本综述 §7 / §11 将其作为 open seam 显式提出（详见 §11 open problem (iv)）。独立 substantive 例证：Azar et al. §3 Proposition 1 给出 DPO 的 closed-form policy 推导依赖一个关键步骤——将 reward function \(r_\phi\) 解析地表达为 KL-regularized RLHF objective 的 Lagrangian 解：\(r_\phi(\mathbf{x}, \mathbf{y}) = \beta \log(\pi_\theta(\mathbf{y}|\mathbf{x})/\pi_{\text{ref}}(\mathbf{y}|\mathbf{x})) + Z(\mathbf{x})\)。该步骤的算子论含义：把 RLHF 的 inner problem (reward modeling under preference data) 与 outer problem (KL-regularized policy optimization) 通过 Bradley-Terry likelihood 显式 collapsed 到 single-objective——即把 §7.0 IFT primer 的 \(\phi^*(\theta) = \arg\min_\phi \mathcal{L}_{\text{inner}}\) 解析消去 \(\phi\)。这是 §11.4 open problem (iv) "DPO \(\equiv\) STA-RLHF in some limit" 的具体数学 anchor——等价性的极限是 Bradley-Terry preference + KL-only 正则，DPO closed-form 在此极限下严格等于 STA-RLHF 的 parameter-steering term reduced to zero（因为 \(\phi^*\) 已被解析消去，IFT-adjoint 项化为零）。

    7.9 RLHF 的算子论 vs 工程实践的差距#

    工业 RLHF 训练（OpenAI / Anthropic / Google 系实践，仅作为背景陈述，不进入独立引用名单）几乎全部使用 myopic 实现：先冻结 reward model \(\phi\)，再用 PPO 优化 \(\theta\)。STA-RLHF / SLHF 在工作流意义上要求联合优化 \((\theta, \phi)\) 并通过 IFT 传递 outer 信号到 inner——但是工业 RLHF 训练规模下，IFT 的内层线性方程 \((\partial \Phi_{\text{inner}} / \partial \phi)^{-1}\) 对应 reward model 全参数的 Hessian-vector solve，目前没有 scalable 实现。这是 §11 open problem 之外的一个工程 frontier：是否存在 low-rank / sketching / Krylov 的 IFT-adjoint 近似让 STA-RLHF 在 70B-class reward model 下 actionable？iMAML 社区已有部分相关工作（CG-based adjoint, neumann-series approximation），但移植到 RLHF 规模未见 paper——这本身是 §10 stitch S-BC1 桥具体化后的工程方向。

    7.10 Alignment-collapse 与 foresighted PO#

    Alignment-collapse 预印本 (arXiv:2605.04266, FC-8) 识别 iterative RLHF 训练几轮后会"反向漂移" 到原始无对齐分布，并提出 foresighted PO 修正。该预印本本身在 abstract 中已经把"alignment collapse"归因于"standard iterative RLHF drops the steering term entirely"——即 steering-drop ⇒ alignment-collapse 的因果是其原创解读，本综述沿用。本综述算子论解读：alignment collapse 是 myopic RLHF 丢弃 parameter-steering term 后的累积误差——每轮的 \(\theta\) 更新基于"固定 \(\phi\)" 假设，但 \(\phi\) 实际随训练数据分布漂移，迭代多轮后误差累积超过 KL 正则化的拉回半径。foresighted PO 通过近似 STA-RLHF 的 parameter-steering term 抑制漂移；本综述独有贡献仍在 §10.3 stitch S-BC1 的 iMAML ↔ STA-RLHF 桥（arXiv:2605.04266 未涉及 iMAML lineage）。

    §8 通过 VI 不动点的隐式微分#

    8.1 隐式层范式#

    Thread C 的核心范式是：将一个 fixed-point / KKT system / VI 的解 \(\mathbf{z}^*(\theta)\) 视为参数 \(\theta\) 的可微函数，用 Implicit Function Theorem (IFT) 在不展开前向求解过程的前提下计算反向梯度（§7.0 IFT primer 给出 stand-alone 推导）： $\(\frac{\partial \mathbf{z}^*}{\partial \theta} = -\left(\frac{\partial \Phi}{\partial \mathbf{z}}\right)^{-1}\frac{\partial \Phi}{\partial \theta}, \qquad \Phi(\mathbf{z}^*, \theta) = 0.\)$ 一行推导（§7.0 重复）：\(\Phi(\mathbf{z}^*(\theta), \theta) = 0\) 两边对 \(\theta\) 全微分，链式法则 + 假设 \(\partial\Phi/\partial\mathbf{z}\) 可逆即得上式。当 \(\partial \Phi / \partial \mathbf{z}\) 严格可逆——典型情况是 \(F = \Phi\) 满足强单调条件，逆矩阵的存在性与谱条件自然成立——这一框架给出 well-posed 后向且 \(O(n^3)\) 的反向算力。

    Unroll vs IFT 三行对比（differentiable optimization 的两条反向路径）：

    维度 Unroll (展开前向迭代) IFT (隐式反向)
    反向通过 把前向 \(K\) 步迭代视为深 \(K\) 层网络，autodiff 逐层反传 仅在 \(\mathbf{z}^*\) 处解一次线性系统 \((\partial\Phi/\partial\mathbf{z})^{-1} v\)
    内存 \(O(K)\)（必须保存所有中间状态） \(O(1)\)（只需 \(\mathbf{z}^*\) 与一次线性系统）
    算力 前向 \(O(K\cdot c_F)\) + 反向 \(O(K \cdot c_F)\) 前向 \(O(K \cdot c_F)\) + 反向 \(O(n^3)\)（dense Schur）或 \(O(n \cdot c_F \cdot k_{CG})\)（CG / Krylov）

    其中 \(c_F\) 是单次 \(F\) 评估代价，\(k_{CG}\) 是 conjugate gradient 迭代数。关键 trade-off：Unroll 在前向迭代少 (\(K\) 小) 时反向便宜；IFT 在前向需要多步收敛 (\(K\) 大) 或前向算法不可微（如 Anderson 加速、Broyden 拟 Newton）时反向便宜。DEQ 选 IFT 路径正是因为前向 Broyden 不易展开。本综述 §10.3 stitch S-BC1 的 actionable consequence——把 iMAML 的 CG-based IFT-adjoint 工程实践移植到 STA-RLHF——本质是在 RLHF reward model 大规模 (\(n \gtrsim 10^9\) parameters) 设定下选 IFT 而非 unroll。

    8.2 OptNet (Amos & Kolter, ICML 2017, arXiv:1703.00443)#

    OptNet 把 strongly convex QP 嵌入神经网络层，前向通过 primal-dual 内点法求解，反向通过对 KKT 系统的隐式微分。这是矩阵中 fill-gap = low 的"founder"——它一举建立了 differentiable optimization 范式。OptNet 的 KKT 系统由构造 strongly monotone（QP 的 Hessian 正定 + 等式约束矩阵满秩），因此 IFT 反向 well-posed。

    8.3 DEQ 与 monDEQ#

    DEQ (Bai, Kolter & Koltun, NeurIPS 2019 Spotlight, arXiv:1909.01377)：把无限深度 weight-tied 网络重定义为算子 \(T_\theta(\mathbf{z}) = f_\theta(\mathbf{z}, \mathbf{x})\) 的不动点 \(\mathbf{z}^* = T_\theta(\mathbf{z}^*)\)。前向用 Broyden / Anderson 加速；反向通过 IFT。但 DEQ 不假设 \(T_\theta\) 任何单调或压缩条件——存在性与稳定性靠实证。

    monDEQ (Winston & Kolter, NeurIPS 2020, arXiv:2006.08591)：通过参数化（投影到 monotone operator 集合内）强制 \(T_\theta\) 是 strongly monotone，从而前向用 forward-backward / Peaceman-Rachford 分裂迭代有保证的线性收敛；反向 IFT 严格 well-posed。显式参数化：monDEQ 把权重矩阵 \(W\) 写成 \(W = I - A^\top A - B\) 形式，其中 \(A \in \mathbb{R}^{r\times n}\) 自由（\(r\) 控制 rank）、\(B\) 反对称（\(B = -B^\top\)，由上三角自由参数化）。该构造保证 \(I - W = A^\top A + B\) 的对称部分 \(A^\top A \succeq 0\)，进一步通过 spectral normalization 控制 \(\|A^\top A\|_2 \leq 1 - m\)（\(m > 0\) 是 monotonicity margin），从而 \(T_\theta(\mathbf{z}) = \sigma(W\mathbf{z} + U\mathbf{x} + b)\) 在 ReLU-class 激活下满足 \(m\)-strongly monotone。该参数化是 Thread C "通过参数空间约束 强制算子论结构"的 paradigmatic 案例——它把"前向算子单调" 从"训练时希望"变成"参数空间内禀"。

    MDEQ (Bai, Koltun & Kolter, NeurIPS 2020, proceedings hash 3812f9a59b634c2a9c574610eaba5bed, arXiv ID <verify>, FC-5)：多尺度 DEQ，把分辨率金字塔嵌入单个不动点。

    8.4 cvxpylayers 与 JaxOpt：通用工具#

    cvxpylayers (Agrawal, Amos, Barratt, Boyd, Busseti, Diamond & Kolter, NeurIPS 2019, arXiv:1910.12430)：把任意 disciplined parametrized programming (DPP) 凸问题封装为可微分层，反向通过 cone-program canonical form 的 IFT。

    JaxOpt (Blondel, Berthet, Cuturi, Frostig, Hoyer, Llinares-López, Pedregosa & Vert, NeurIPS 2022, arXiv:2105.15183)：通用模块化 implicit differentiation 库，把"前向求解器 + IFT 后向"做成 autodiff 友好的 transformation。

    8.5 iMAML：把 implicit-grad 用于双层学习#

    Rajeswaran, Finn, Kakade & Levine ("Meta-Learning with Implicit Gradients" iMAML, NeurIPS 2019, arXiv:1909.04630) 把 IFT-adjoint 用于 meta-learning：inner task-adaptation 是带 proximal 正则项的 strongly convex 子问题，通过 IFT 计算 meta-参数对 task-adapted 参数的导数。该 adjoint 公式与 §7.8 中 STA-RLHF parameter-steering term 形式完全一致——这是 §10 stitch S-BC1 的核心。

    8.6 DC3 与 game-as-layer#

    DC3 (Donti, Rolnick & Kolter, ICLR 2021, arXiv:2104.12225 <verify>, FC-6)：处理非凸硬约束（典型 AC-OPF）的端到端学习方法——通过 completion + correction 把非凸约束 enforced via unrolled corrector layer。该工作的非凸性正是 §10 stitch S-Cgrid 的接口（详见 §10）。

    Game-as-layer / symplectic-gradient-adjustment line (ICML 2018, arXiv:1802.05642, FC-7)：关键 FC-7 警示：本文不写具体作者枚举（phase 0c-C 草稿曾误写"Liu et al."，本文遵循 FC-7 改为 "the symplectic-gradient-adjustment line (ICML 2018, arXiv:1802.05642)"）。该工作把博弈均衡视为可微分层，与本综述 §6 的 Nash-VI 视角天然对接。

    §9 随机 VI 与深度学习实践#

    9.1 stochastic VI 的核心挑战#

    VI 算子的随机预言机 \(\hat F(\mathbf{x}, \xi) \approx F(\mathbf{x})\) 存在偏差与方差。与单目标随机优化的关键差别在于：EG / OGDA 在确定性设定下的额外迭代 \(F(\mathbf{x}_{k+1/2})\) 在随机设定下需要独立样本，否则会引入 EG 步骤间的 spurious 相关性。这是 Gidel et al. 2019 在 GAN 训练侧识别的实际问题。

    9.2 Alacaoglu–Malitsky 2021：variance reduction for VI#

    Alacaoglu & Malitsky ("Stochastic Variance Reduction for Variational Inequalities," arXiv:2102.08352, journal <verify>, FC-4) 把 finite-sum variance reduction（SVRG/SARAH 风格）适配到 EG，给出与 single-objective VR-optim 同阶的复杂度。这是 stochastic VI 在 mon + finite-sum 设定下的强结果。

    估计量形式：考虑 finite-sum \(F(\mathbf{x}) = \frac{1}{n}\sum_{i=1}^n F_i(\mathbf{x})\)（\(n\) 是 sample size，e.g. dataset 大小）。SVRG-EG 的 VR 估计量是 $\(\hat F^{\text{VR}}(\mathbf{x}_k) = F_{i_k}(\mathbf{x}_k) - F_{i_k}(\tilde{\mathbf{x}}) + F(\tilde{\mathbf{x}}),\)$ 其中 \(i_k \sim \text{Uniform}(\{1,\dots,n\})\) 是单次随机索引、\(\tilde{\mathbf{x}}\) 是 snapshot 点（每 \(\sim n\) 步更新一次并预计算全梯度 \(F(\tilde{\mathbf{x}})\)）。该估计量满足 \(\mathbb{E}[\hat F^{\text{VR}}(\mathbf{x}_k)] = F(\mathbf{x}_k)\) 且方差 \(\propto \|\mathbf{x}_k - \tilde{\mathbf{x}}\|^2\)（snapshot 接近当前迭代时方差 → 0）。把 EG 的两步 \(F\) 评估全部用 \(\hat F^{\text{VR}}\) 替换即得 VR-EG，匹配单目标 SVRG 在 \(\mu\)-strongly monotone 设定下的 \(\tilde O((n + \kappa^2)\log(1/\varepsilon))\) 复杂度。该构造的关键技术点是 EG 两步使用相互独立 sample 以保证 lookahead 修正项的无偏性（§9.6 实现细节）。

    9.3 Pethick et al. 2023 BC-SEG+：bias-corrected stochastic weak-Minty#

    Pethick et al. (2023, arXiv:2302.09029, OpenReview ejR4E1jaH9k, FC-3) 提出 BC-SEG+ ——把 EG+ (Diakonikolas–Daskalakis–Jordan AISTATS 2021) 推广到随机 weak-Minty 设定，无需扩大 batch 即可保持稳定。末次复杂度 \(O(\varepsilon^{-4})\)。这是当前 stochastic 非单调 VI 最强的算法工具。

    9.4 RLHF 实践与 heavy-tailed noise gap#

    RLHF 在工业实践中观察到偏好梯度具有 heavy-tailed 噪声分布——这超出了上述 finite-variance VI 假设。目前没有 stochastic VI 理论处理 heavy-tailed noise，这是 §11 open problem (iii) 的核心 gap。该 gap 同时跨 thread A（算法侧）与 thread B（RLHF 应用侧）——是矩阵中 weak-Minty 行与 RLHF 行未来的天然交汇。

    9.5 §9 小结#

    算法 设定 单调性 复杂度
    朴素 SEG（Gidel et al. 2019 baseline） stoch mon Lip \(\varepsilon^{-2}\)（不稳）
    VR-EG (Alacaoglu–Malitsky 2021) finite-sum stoch mon Lip matches VR-opt
    BC-SEG+ (Pethick et al. 2023) stoch weak-Minty weak-Minty last \(\varepsilon^{-4}\)
    RLHF practice heavy-tailed stoch 未确定 gap——无理论

    9.6 独立样本与 EG 的随机适配#

    stochastic EG 的细节实现陷阱：EG 的两步使用 \(F(\mathbf{x}_k)\) 与 \(F(\mathbf{x}_{k+1/2})\)；如果对同一 mini-batch 使用，则两步的随机噪声相关，会破坏 ergodic 收敛分析。Gidel et al. (ICLR 2019) 的 stochastic-extrapolation 处理是对每一步使用独立 mini-batch；Alacaoglu–Malitsky (2021) 在 VR 框架下用 control-variate 把相关性显式抹掉。BC-SEG+ (Pethick et al. 2023) 进一步把 bias-correction 项嵌入算法以在 weak-Minty 设定下不依赖大 batch。这条实现 detail 在 ML 工程社区常被忽略，是 stochastic VI 在工业实施中常见的"为什么 paper 算法不 reproduce" 根因之一。

    9.7 与单目标 stochastic 优化的本质差别#

    在单目标 stochastic 优化里，\(\mathbb{E}[\hat g] = \nabla f\) 是 unbiased 已足够给出 \(O(1/\sqrt{T})\) 收敛。在 stochastic VI 里，unbiased 还不够——EG 需要在两步使用独立样本以保证 lookahead 修正项不污染原始预言机方向。这是 stochastic VI 的 "extra requirement"，也是 §11.3 heavy-tailed open problem 的微观起点。

    10.1 Stitch S-AB1 (last-iterate ↔ training stability) — Thread A 末次率 ↔ GAN/MARL/RLHF 训练稳定性#

    Thread A 在 2020–2022 完成的末次迭代浪潮（Mokhtari–Ozdaglar–Pattathil AISTATS 2020 unification；Gorbunov–Loizou–Gidel AISTATS 2022 EG \(O(1/K)\)；Gorbunov–Taylor–Gidel NeurIPS 2022 OGDA \(O(1/K)\) on \(\|F\|^2\)；Yoon–Ryu ICML 2021 EAG \(O(1/k^2)\) tight；Cai–Oikonomou–Zheng NeurIPS 2022 constrained \(O(1/\sqrt{T})\) on gap）是在算子论抽象层面发展的。Thread B 的 GAN（Gidel et al. 2019、Mescheder et al. 2018）与 MARL（Daskalakis–Foster–Golowich 2020、Wei et al.     10.2 Stitch S-AC1 (non-mon ↔ implicit-layer ill-posedness) — Thread A 非单调前沿 ↔ Thread C 隐式层 ill-posedness#

    Diakonikolas–Daskalakis–Jordan EG+（AISTATS 2021）与 Anagnostides–Farina–Sandholm–Zhang 多项式时间 Minty（2025）把算法前沿推进到 weak-Minty / Minty 区。Thread C 的所有 well-posed 锚点（OptNet、monDEQ、cvxpylayers、iMAML）全部假设内层算子强单调——这正是后向 IFT 解线性方程 \((\partial \Phi / \partial \mathbf{z})^{-1}\) 良态的根因。vanilla DEQ 与 MDEQ 放弃强单调，只能在实证层面 survive。

    stitch：把 Thread A 的算法可计算性危机（非单调 VI 一般不可解）与 Thread C 的反向传播 well-posedness 危机（非单调前向算子 ⇒ Jacobian 可能奇异 ⇒ IFT 后向 ill-posed）识别为 structurally coupled 危机——二者皆源于"解处缺少正定线性化"，但严格意义上不是同一定理（可能 \(F\) non-monotone 但解处 \(\partial F\) 仍非奇异，反之亦可）。Phase 1 §11 open problem (v) 把它列为 cross-thread 优先问题。

    具体 ill-posedness 例子（implicit-layer 一侧）：考虑 vanilla DEQ \(\mathbf{z}^* = \tanh(W\mathbf{z}^* + U\mathbf{x} + b)\)，前向算子 \(T_W(\mathbf{z}) = \tanh(W\mathbf{z} + \cdots)\) 的 Jacobian 在 \(\mathbf{z}^*\) 处为 \(\text{diag}(\text{sech}^2(W\mathbf{z}^*+\cdots)) \cdot W\)。若 \(W\) 的奇异值有任何 \(\sigma_i(W) > 1/\min_j \text{sech}^2(\cdot)_j\)，则 \(I - \partial T/\partial \mathbf{z}\) 可能奇异——IFT 后向需要 \((I - W\,\text{diag})^{-1}\) 而该矩阵接近奇异 ⇒ 反向梯度数值爆炸。这是 monDEQ 的强单调参数化（§8.3 explicit form \(W = I - A^\top A - B\)）专门 prevent 的病态。vanilla DEQ 在 NLP 实践中通过 Anderson 加速 + spectral normalization 的 best-effort 工程化绕过此问题，但没有定理保证 well-posedness——遇到对抗输入或分布漂移时 IFT 反向可以剧烈 fail（典型现象：训练后期 loss 突然爆炸或 NaN）。Thread A 一侧的对应是 weak-Minty \(\rho \geq 1/(2L)\) 区域——EG+ stability 边界之外，没有任何一阶算法收敛保证；二者共有"解处 \(\partial F\) 退化导致算法 / 后向 fail" 的同型病态。

    值得分述的反例边界：(a) \(F\) 在全局非单调但解处 \(\partial F\) 仍正定（"locally well-conditioned non-monotone"）——这时 Thread A EG+ 算法可能 fail 但 Thread C IFT 后向仍 well-posed，二者解耦；(b) \(F\) 在全局单调但解处 \(\partial F\) 退化（"monotone but singular at solution"，e.g. 二次约束鞍点的退化 KKT）——Thread A 算法仍收敛但 Thread C IFT 后向 ill-posed，二者反向解耦。S-AC1 因此是统计相关但不是同一定理——这一精修使 §11.5 open problem (v) 的具体 formulation 必须区分上述两类反例边界，而不是合并为单一"非单调隐式层" 问题。

    10.3 Stitch S-BC1 — Stackelberg-RLHF ↔ iMAML adjoint（最 defensible 原创贡献）#

    这是本综述最有原创性的 cross-thread 观察，专门给一节。Phase 0c-C Seam C4 与 Phase 0d §8 都明确指认了它，此处展开：

    事实 1：iMAML（Rajeswaran et al. NeurIPS 2019, arXiv:1909.04630）解决的对象是 $\(\min_\theta \sum_{\tau} \mathcal{L}_\tau\left(\phi_\tau^*(\theta)\right), \quad \phi_\tau^*(\theta) = \arg\min_\phi \mathcal{L}_\tau^{\text{inner}}(\phi; \theta).\)$ 在 iMAML setting 下 outer loss \(\mathcal{L}_\tau(\phi_\tau^*)\) 不直接含 \(\theta\)（只通过 \(\phi_\tau^*\) 间接依赖），所以全梯度等于 indirect / IFT-adjoint term： $\(\nabla_\theta \mathcal{L}_\tau = -\left(\frac{\partial \Phi_\tau}{\partial \phi}\right)^{-\top}\!\frac{\partial \Phi_\tau}{\partial \theta}^\top \nabla_\phi \mathcal{L}_\tau,\)$ 其中 \(\Phi_\tau(\phi; \theta) = \nabla_\phi \mathcal{L}_\tau^{\text{inner}}\)。inner 通常 proximal 正则化保证强单调，IFT well-posed。

    事实 2：STA-RLHF（Makar-Limanov et al. 2024）/ SLHF（arXiv:2512.16626）解决的对象是 $\(\min_\theta \mathcal{L}_{\text{outer}}\left(\theta, \phi^*(\theta)\right), \quad \phi^*(\theta) = \arg\min_\phi \mathcal{L}_{\text{inner}}(\phi; \theta, \mathcal{D}_{\text{pref}}).\)$ "missing parameter-steering term" 是 $\(\frac{\partial \phi^*}{\partial \theta}^\top \nabla_\phi \mathcal{L}_{\text{outer}} = -\left(\frac{\partial \Phi_{\text{inner}}}{\partial \phi}\right)^{-\top}\!\frac{\partial \Phi_{\text{inner}}}{\partial \theta}^\top \nabla_\phi \mathcal{L}_{\text{outer}}.\)$

    事实 3：iMAML 的完整 meta-gradient 公式 = STA-RLHF 的 parameter-steering correction（即 myopic RLHF 漏掉的那一项；RLHF outer loss 直接含 \(\theta\)，所以有额外的 myopic 项 \(\partial_\theta \mathcal{L}_{\text{outer}}\)，iMAML 因 outer 不直接含 \(\theta\) 该项为零）——通过把"task \(\tau\)" 重命名为 RLHF preference-modeling 配置、把"\(\mathcal{L}_\tau^{\text{inner}}\)" 重命名为 reward-model 损失，iMAML adjoint 逐字化身 STA-RLHF parameter-steering term。这一精修反而强化了原创性：iMAML 的整个 meta-gradient 在 RLHF setting 下恰好等于 myopic RLHF 漏掉的修正项。

    事实 4：这两个文献社区彼此未引用。iMAML 在 meta-learning / few-shot 社区；STA-RLHF 在 RLHF / human-feedback / alignment 社区。Google Scholar / arXiv 反向检索均未见 STA-RLHF 或 SLHF 引用 iMAML，反之亦然。

    综合：本综述把这一桥显式建立——STA-RLHF 的 parameter-steering correction = iMAML 的 implicit-gradient adjoint 应用到 RLHF preference 双层结构。这是与 §1.3 论点陈述直接相符的最强证据：Thread C（隐式层）确实是 Thread A（算法）与 Thread B（博弈 ML 应用）之间被忽视的结构桥。

    对 Phase 2 fact-checker 与读者的预期反应：可能的反驳是"任何 bilevel 都长这个样子，没什么新意"。回应：是的，bilevel IFT 公式从 1970s Bracken–McGill 起就是经典；但两个独立运行的现代文献社区在数学相同时没有相互识别，本身是文献综述的有效贡献——这恰恰是 survey 而非 original research paper 的角色。

    Precedent hedge (deep-diver review 提示)：S-BC1 的等价并非凭空——至少有 4 条结构性先例：(a) Bracken & McGill 1973 / Dempe 2002 经典 bilevel IFT；(b) Pedregosa 2016 / Franceschi et al. 2017 hyperparameter implicit-gradient；(c) Balduzzi et al. SGA (ICML 2018, arXiv:1802.05642) 通过 IFT 计算博弈均衡梯度；(d) Brero et al. Stackelberg-POMDP 已在 leader-follower POMDP 用 implicit gradient。本综述的诚实贡献是infrastructural / clarifying——把 iMAML 已为深度模型工程化的 CG-adjoint / Neumann-series / proximal-schedule 工具显式 portable 到 RLHF——而非无前 case 的全新数学识别。

    该桥的可操作后果：识别等价后，iMAML 文献的工程经验（CG 解 inner adjoint、内层步数控制策略、proximal 系数 schedule）可以直接搬到 STA-RLHF / SLHF 实现——这构成本综述对 RLHF 工程社区的具体技术输出。反过来，STA-RLHF / SLHF 在 RLHF 实证下识别到的"alignment collapse" 现象（arXiv:2605.04266，alignment-collapse 预印本）可以反过来推动 iMAML 社区重新检视 meta-learning 在大模型 fine-tune 设定下的 bilevel 稳定性——meta-learning 社区目前主流实验仍停留在 vision few-shot benchmark，alignment 现象未被 isolate 过。

    与 §11.4 open problem (iv) 的关联：S-BC1 把 STA-RLHF 桥到 iMAML；§11.4 open problem (iv) 进一步把 DPO/IPO 桥到 Stackelberg-VI。如果 (iv) 解决，那么 DPO → Stackelberg-VI → iMAML-adjoint 的三跳桥就完成了，把 RLHF 全谱（myopic RLHF / DPO / IPO / STA-RLHF / SLHF）都统一在 iMAML implicit-gradient 框架下——这是本综述提出的最完整的统一图景。

    10.4 Stitch S-AC2 (Thread-A solvers in DEQ forward) — Thread A 算法用于 DEQ 前向求解器#

    Phase 0c-C Seam C3 指出 DEQ 实现选择 Broyden / Anderson 加速属于经验导向；现有文献未引用 Yoon–Ryu (EAG) 或 Gorbunov–Loizou–Gidel (EG last-iterate) 作为 DEQ 内的 forward solver。

    stitch 的具体形式：把 monDEQ 的强单调参数化与 EAG forward solver 配对，在 DEQ 前向单调 + Lip 设定下能给出 \(O(1/k^2)\) on \(\|F\|^2\) 的紧 last-iterate 收敛，并继承 IFT well-posed 后向。这是一个 low-effort port，应该被一个 NeurIPS workshop paper 占领；本综述识别这一 unrealized opportunity。

    EAG → DEQ forward 移植的具体形式：考虑 monDEQ 前向不动点 \(\mathbf{z}^* = T_W(\mathbf{z}^*)\)，等价 VI 形式 \(F(\mathbf{z}) = \mathbf{z} - T_W(\mathbf{z}) = 0\)。在 monDEQ 强单调参数化下 \(F\) 满足 \(m\)-strong-monotonicity（§8.3 explicit form）。把 EAG 迭代（§3.2.0 Halpern formula）应用到该 \(F\)： $\(\mathbf{z}_{k+1/2} = \mathbf{z}_k - \eta F(\mathbf{z}_k), \quad \mathbf{z}_{k+1} = \beta_k \mathbf{z}_0 + (1-\beta_k)\big[\mathbf{z}_k - \eta F(\mathbf{z}_{k+1/2})\big],\)$ 其中 \(\beta_k = 1/(k+2)\) 是经典 Halpern 权重。Forward complexity：相对 Anderson 加速（DEQ 默认 forward solver）的 \(O(1/k)\) 经验收敛，EAG 给出 \(O(1/k^2)\) on \(\|F\|^2\) 的provably tight 末次率——在前向求解需要 \(\sim 30\) 步时 EAG 应快 \(\sim 3\times\)。Backward：仍是标准 IFT \(\partial \mathbf{z}^*/\partial \theta = -(\partial \Phi/\partial \mathbf{z})^{-1}(\partial \Phi/\partial \theta)\)，monDEQ 强单调保证 well-posed。实现 cost：\(\sim 200\) 行 PyTorch 代码（在 existing deq-pytorch repo 基础上替换 forward solver）。这是 §10.5 stitch S-Cgrid 之外本综述给出的最 actionable cross-thread bridge——预测一篇 NeurIPS workshop / ICLR tiny paper 占领该 niche。

    反向 (DEQ → Thread A) 也成立的具体设定：DEQ 多年工程经验 (Anderson 加速、Broyden、heavy-ball regularization) 中关于 forward solver 在 deep network 设定下的 numerical robustness 知识，对 Thread A 把 EAG 移植到 large-scale ML 训练有反向 inform——目前 Thread A 算法 paper 几乎全部在 synthetic VI / 小 GAN 上验证，没有 deep-network 规模实证。S-AC2 这条反向 bridge 留作 §11.7 Seam A-extra。

    10.5 Stitch S-Cgrid — Thread C ↔ 外部 subagent-lab/grid_surveys/13_diff_opf §6 / §11#

    本综述的显式外部接口。13_diff_opf final §6 把 KKT-on-convex 层（cvxpylayers / OptNet）应用到 AC 最优功率流 (AC-OPF) 训练；§6.7 "the cubic wall" 指出 cvxpylayers / OptNet 后向 cost 是 \(O(n^3)\)（active KKT 线性系统求解）；§11 Seams A1 / C-α 指向同一结构事实——这正是 Thread C 的强单调假设付出的代价：只有在 well-conditioned 后向 linear solve 下，IFT 反向才能保证；而 well-conditioned 又只能来自前向算子的强单调，所以 cubic 后向成本是"算子论代价"。

    stitch 的具体形式：把 Thread C 与 13_diff_opf §6 联立，得到一篇两边都看得见但没有人写的 paper——SOCP-relaxed AC-OPF KKT 层 + EG+ / weak-Minty corrector 处理非单调 AC 残量。SOCP 松弛把 AC-OPF 的非凸性挪到 corrector，corrector 用 EG+ 在 weak-Minty 区域稳定收敛，KKT 层处理 convex 部分给 well-posed IFT。这桥既扩展了 Thread C 的应用面（突破 cubic wall 至 SOCP-monDEQ scale），又给 13_diff_opf 提供 ML 端的算法学武器（thread A 非单调前沿）。

    双 survey 互引指引：本节明确为"subagent-lab/grid_surveys/13_diff_opf §6 / §11" 的 cross-survey 锚点；Phase 2 review 应核对该桥在两份综述的对称性。

    结构更直白的说法：

    视角 来自本综述 Thread C 来自 13_diff_opf §6
    后向 IFT 良态条件 \(\partial \Phi / \partial \mathbf{z}\) 可逆 ⇔ 内层强单调 同——强单调来自 QP / SOCP Hessian
    主要 ML 代价 \(O(n^3)\) Schur complement / dense linear solve 同 §6.7"the cubic wall"
    非凸障碍 非单调前向算子 ⇒ Jacobian 奇异 ⇒ 后向 ill-posed AC-OPF 二次约束非凸 ⇒ KKT 系统不一定可解
    算法学武器 EG+ / weak-Minty corrector / BC-SEG+ DC3 corrector / unrolled fix-up

    两条 thread 互译后得到的"未写论文" 大致形态：SOCP 松弛 AC-OPF 作为可微凸内层 + 非凸残差由 EG+ stochastic corrector 处理 + IFT 后向保留 \(O(n^3)\) 但通过 conjugate gradient / Krylov 降到 \(O(n^2 \log n)\) 实际成本。该论文同时回应本综述 §11.5（非单调隐式层 well-posedness）与 13_diff_opf §11 Seam A1 / C-α。该综合性提案是本综述与 13_diff_opf 共同的明确"预测"——也是本综述操作论统一视角"具备外部预测力" 的最强证据之一。

    10.6 Cross-domain conceptual anchor pool#

    Deep-diver review 指出本综述的 cross-domain 引用过窄——除了 §10.5 与 13_diff_opf 的显式桥外，对古典博弈论 / 控制论 / 形式验证社区的 conceptual reservoir 未充分调用。本节作为未来 frontier 的概念蓄水池，给出 7 条 classical 节点的简短引入（不作为本综述独立引用名单，仅 conceptual reference）。每条 1-2 句指明其与本综述 thread 的关系，留待后续 paper 展开。

    1. Wardrop equilibrium (Beckmann, McGuire & Winsten 1956)——交通网络上每个 commuter 选择最短路径所形成的 user equilibrium，与 Nash 均衡等价但通常表述为 VI on path-flow simplex。与本综述的关系：Wardrop UE 是 VI 经典应用的"非 ML 旗舰"——Dafermos 1980 等运筹学 VI 文献的发源；本综述 §6 的 Nash-VI ⊂ 该 Wardrop 框架的特例（无 BPR cost-curve 时退化）。

    2. HJI differential games (Isaacs 1965, Differential Games)——连续时间 zero-sum differential game，Hamilton-Jacobi-Isaacs PDE 给出 saddle-point value function。与本综述的关系：连续时间 saddle-point VI 的祖先；§5 GAN 的离散 saddle-point 是 HJI 的 time-discretization 极限。Safe-RL / robust control 文献仍在用 HJI 框架处理 adversarial-disturbance 设定。

    3. Witsenhausen 1968 non-classical information——经典控制论 paper（"A Counterexample in Stochastic Optimum Control," SIAM J. Control 6:131–147）显示信息结构非经典 (non-nested information patterns) 时分布式优化的非凸性可以是结构性的，不能用 single-agent 框架处理。与本综述的关系：§6 general-sum MARL 的"general"行的算子论困难性，本质上是 Witsenhausen 非经典信息困难性的现代化身；§11.2 hidden Minty open problem 在 partial-observation MARL 设定下退化为 Witsenhausen 经典反例。

    4. Berge maximum theorem (Berge 1963, Topological Spaces)——给出 follower-best-response correspondence 的 upper-semicontinuity 与 outer-loss 的连续性条件。与本综述的关系：§7.1.1 Stackelberg 隐藏假设 (1) commitment 的形式数学基础；任何 bilevel optimization 的 well-posedness 都需 Berge 类条件。

    5. Rosen 1965 concave games (J. B. Rosen, "Existence and Uniqueness of Equilibrium Points for Concave \(N\)-Person Games," Econometrica 33:520–534)——给出 concave \(n\)-person game Nash 均衡的存在与唯一性条件（diagonally strict concavity，对应于 game-matrix 的 strong monotonicity 充分条件）。与本综述的关系：§2.2 单调性层级在 game-theoretic 一侧的祖先；Rosen 1965 的 diagonally strict concavity = \(F\) 的 strong monotonicity on product strategy space——这条等价在博弈论文献是 classical 但 ML 文献鲜被指认。

    6. α,β-CROWN (Wang et al. NeurIPS 2021, Xu et al. NeurIPS 2020 系列)——formal NN verification 工具链，通过 linear bounds + branch-and-bound 给出 NN 输出在 adversarial input ball 下的紧 certified bound。与本综述的关系：§5 / §10 AT (adversarial training) 的 outer-max 在 α,β-CROWN 设定下被精确化为 constrained VI——formal verification 社区与 VI / Stackelberg 社区目前未充分交叉，是 §11.7 Seam B-extra 的具体形态。

    7. Mechanism design (Myerson 1981, "Optimal Auction Design," Math. of Operations Research 6:58–73)——principal 在 follower (bidder) 拥有 private type 的设定下设计 mechanism (auction rule) 以最大化 expected revenue 的 hierarchical optimization。与本综述的关系：§7 Stackelberg-RLHF 在 reward model uncertainty 下退化为 mechanism design——reward model 的 follower behavior 不是固定 \(\phi^*(\theta)\) 而是依赖 unobservable preference type；STA-RLHF + private type → mechanism design with reward learning，目前没有 paper 显式做这条 reduction（属于 §11.7 Seam B-extra）。

    用法：本节 7 条 anchor 不进入本综述独立引用名单，仅作为 §11 / §10 stitch 在未来 paper 中展开时的 conceptual reservoir。读者可视为 future-work invitation：每条都对应一个"未写但可写"的 cross-survey bridge——本综述明确指出它们的存在与接口，但不在本文展开。

    §11 Open problems 与前沿#

    把 Phase 0c 中累计的开放 seam（A 8 个、B 4 个、C 5 个，加 §10 五条 stitch 中各自衍生的 5 个）归并提炼为五大顶层问题：

    11.1 (i) one-call \(O(1/k^2)\) matching the EAG bound#

    Yoon–Ryu (EAG, ICML 2021) 在单调 + Lip 设定下给出 \(O(1/k^2)\) on \(\|F\|^2\) 的紧末次率，但 EAG 每步需要两次 \(F\) 评估（Halpern anchoring + EG 内步）。open：是否存在 one-call 算法（每步仅一次 \(F\) 评估）达到同样的 \(O(1/k^2)\) 紧率？目前 OGDA 类 one-call 算法只达到 \(O(1/N)\)（Gorbunov–Taylor–Gidel 2022）。这是 Thread A 算法侧最干净的 open。

    11.2 (ii) 非单调外边界：在 weak-Minty 与 Minty 之间#

    EG+（Diakonikolas–Daskalakis–Jordan AISTATS 2021）覆盖 weak-Minty + \(\rho < 1/(2L)\)；Anagnostides–Farina–Sandholm–Zhang (2025) 覆盖 Minty。open：weak-Minty (\(\rho \in [1/(2L), \infty)\)) 与 general non-Minty 之间的可计算区域是什么？是否存在一阶或拟一阶算法可以处理一类"hidden Minty"——即存在但不可直接观察的 Minty 解？这一开放问题对应到本综述 §6 的 general-sum MARL（Seam B-2）与 §7 的非局部 RLHF outer-loss。

    11.3 (iii) heavy-tailed stochastic VI#

    §9.4 的 gap：RLHF 实践偏好梯度的 heavy-tailed 噪声分布超出 finite-variance stochastic VI 框架。Pethick et al. BC-SEG+ 在 sub-Gaussian 假设下达到 \(O(\varepsilon^{-4})\)；但 heavy-tailed 设定下没有任何算法——既不知道下界，也不知道上界。这是 thread A × thread B 的最大空白。

    11.4 (iv) DPO/IPO ↔ Stackelberg-VI 等价性#

    §7.5 的观察：\(\Psi\)-PO / IPO (Azar et al. AISTATS 2024) 把 inner reward-modeling 闭式解出来，等价于 implicit-VI solver。open：DPO 与 IPO 是否严格等价于某种 Stackelberg-Aligned RLHF 的 closed-form 简化？如果是，DPO 与 STA-RLHF / SLHF 之间应有显式的代数桥（不是简单的"两者都比 myopic RLHF 好"，而是"DPO = STA-RLHF in some limit"）。该等价性目前未在任何文献中陈述。

    11.5 (v) 非单调隐式层 well-posedness#

    §10 stitch S-AC1 的核心：DEQ / MDEQ / game-as-layer 在非单调前向算子下"经验上 works"但无证明。open：在什么算子条件下（hidden Minty? cohypomonotone with controlled \(\rho\)? structured non-monotone with stochastic regularization?）非单调隐式层有 well-posed 后向 IFT？这是 thread C 的最大未解。

    §12 结语#

    VI 词汇在本综述中是把 GAN 训练、MARL Nash、RLHF Stackelberg 三类异源训练范式装入同一坐标系的算子论语言。在该坐标系内，三轴（算法谱系、博弈 ML 应用、结构 / 隐式接口）相互可索引，单调性层级提供垂直对齐机制，Thread C 担当 Thread A 与 Thread B 之间的结构桥（§10 stitch S-BC1 是最强证据）。

    VI 词汇买给 ML 的：(1) 末次迭代理论 ready-made 移植 (GAN/MARL)；(2) 单调性层级作为 application 困难度评级机制；(3) 隐式微分 calculus 把 bilevel / Stackelberg 训练放回标准 IFT 框架；(4) 与运筹学侧 cvxpylayers / OptNet / DC3 → AC-OPF（§10 stitch S-Cgrid）的天然接口。

    ML 反向给 operator theory 的：(1) Facchinei & Pang (2003) 经典著作完全未预见的结构性非单调性——RLHF outer-loss 的非单调性来自 reward-modeling 双层结构而非噪声扰动；(2) heavy-tailed stochastic VI 作为新的算子论挑战（§11.3）；(3) DPO/IPO ↔ Stackelberg-VI 等价性作为 closed-form implicit-VI solver 的新研究客体（§11.4）。

    本综述把这五条 cross-thread stitch（S-AB1、S-AC1、S-BC1、S-AC2、S-Cgrid）作为 future-work invitation；其中 S-BC1（iMAML adjoint = Stackelberg-RLHF parameter-steering term）与 S-Cgrid（与 subagent-lab/grid_surveys/13_diff_opf 的 SOCP-relaxed AC-OPF + EG+ corrector）是最具体、最 actionable 的两条，建议作为后续论文的第一目标。

    12.1 综述的局限性#

    本综述的局限：(1) 不覆盖 game theory 的均衡精化 (refinement)，例如 Trembling-hand perfect equilibrium 或 Sequential equilibrium——这些在 RL / multi-agent 实践中常被引用但对 VI 末次率结论不构成额外约束；(2) 不深入处理 nonsmooth VI——所有引用的算法保证均假设 \(F\) 至少 Lipschitz 连续，而 RLHF 实际中的偏好-奖励映射在数据稀疏处非平滑，理论保证退化；(3) 不覆盖 distributed / federated VI——只有 Wei et al. 2021 与 Daskalakis–Foster–Golowich 2020 触及去中心化设定，更广义的 federated VI（如带通信压缩、隐私约束）目前缺乏 VI 框架处理；(4) 三类应用以外的 VI ML 应用（如 inverse problems 中的 saddle-point regularization、equilibrium-constrained learning、congestion games）不在本综述范围。

    12.3.1 Bitter Lesson 拷问：VI machinery 在 large-model 实践能否被算力抹平？#

    Deep-diver review 在第 8 节提出本综述必须正面回应的"敌意问题"：Sutton 2019 "The Bitter Lesson" 的视角下——历史上每一代有结构的 ML 方法（feature engineering、structured priors、symbolic reasoning）最终都被"更大数据 + 更大算力 + 端到端学习"挤出主流——本综述提倡的 VI machinery（operator-theoretic 单调性层级、IFT-adjoint、anchored last-iterate）会不会是又一例"漂亮但终将被抹平的结构"？

    承认的 evidence：(a) DPO 在工业 RLHF 几乎完全替代了 PPO-RLHF，把 Stackelberg 双层结构 closed-form 化简为单目标 likelihood——若 §11.4 等价性成立，工业实践事实上已经绕过 STA-RLHF machinery而达到了大致相同的对齐效果。(b) vanilla DEQ 在实践上 work 而 monDEQ 不流行——尽管 monDEQ 提供严格 well-posed 保证；vanilla DEQ 用 Anderson 加速 + 经验 stability 在 NLP 任务上 sustained 工程使用，monDEQ 的强单调参数化引入精度损失，业界放弃了"算子论保证"换"更宽容前向"。(c) 大规模 GAN 训练（StyleGAN-2/3、扩散对抗）放弃 EG/OGDA 优化器而回归 Adam + spectral normalization；EAG 等 thread A 末次最优算法在 100M+ parameters 规模没有任何成功 case study。

    回应 1：VI machinery 在 "frontier with sparse data" niche 长期 defensible。Bitter Lesson 的前提是"算力 + 数据足够多"；当数据稀缺或物理约束强（约束 ≠ 噪声扰动）时，端到端学习无法弥补结构损失。§10 stitch S-Cgrid（与 13_diff_opf 的 SOCP-relaxed AC-OPF + EG+ corrector）是本综述最 defensible 的长期 niche——电网 OPF 不会有 10× 数据增量，物理约束 (Kirchhoff 定律) 是硬约束而非 prior，KKT 层 / EG+ corrector 在 cubic wall 之外没有被算力 brute-force 抹平的可信路径。

    回应 2：bilevel structure 在 RLHF 的"显式 vs 隐式" 之争是 ongoing。DPO closed-form 在偏好数据量 \(\gtrsim 10^5\) 时 work，但在 (a) iterative RLHF 多轮（alignment-collapse arXiv:2605.04266）；(b) 多模态偏好（视觉 + 语言 + 行为偏好同时存在）；(c) 安全 / 法规约束 (constrained RLHF) 这三种 frontier 设定下，DPO 的 closed-form 假设不再 hold——需要回到 explicit bilevel + IFT-adjoint。STA-RLHF / SLHF / foresighted-PO 三条线索都是在 DPO closed-form 失效区域的恢复——这表明 VI machinery 不是被"算力抹平"，而是被推到 frontier 边界——单点工业实践用 closed-form，frontier paper 用 explicit bilevel。

    回应 3：S-BC1 的 actionable consequence 是 falsifiable。本综述最 defensible 的原创贡献——把 iMAML 的 CG-based IFT-adjoint 工程实现 portable 到 STA-RLHF（§7.9）——是一个具体可验证 prediction：如果 70B-class reward model 下 IFT-adjoint 用 Krylov / Neumann-series 工程化可行，则 STA-RLHF / SLHF 在工业 alignment-collapse 修正中可以 outperform foresighted PO；若工程化不可行，VI machinery 在 large-model 端确实被抹平。这是 survey 给出的 falsifiable claim，不是无 risk 的方法论 advocacy。

    结论：VI machinery 在本综述场景下不是 Bitter Lesson 的反例，而是 Bitter Lesson 的互补结构——大多数主流训练 setting 下结构损失可以被算力补偿（DPO 替代 PPO-RLHF 即此类），但约束强、数据稀缺、frontier 区域（grid OPF、constrained RLHF、iterative alignment、formal verification）保留 VI machinery 作为 defensible long-run niche。

    12.4 结束语#

    VI 框架并非要替换 ML 训练社区现有的 optimization / RL / alignment 词汇——而是提供一层算子论翻译，把 GAN / MARL / RLHF 三个看似独立的训练范式重新组织在同一坐标系内。在该坐标系内，算法可以跨范式复用（§10 stitch S-AB1 / S-AC2），结构性困难 (non-monotone) 可以被识别为同一算子论挑战（§10 stitch S-AC1），bilevel adjoint 在不同社区可以被识别为同一对象（§10 stitch S-BC1），与运筹学侧的 KKT 层 ↔ AC-OPF 桥可以被明确命名（§10 stitch S-Cgrid）。本综述的写作目标即：让上述四种"识别"在文献综述层面显式发生，从而为后续原创 paper 提供清晰的 launchpad。
