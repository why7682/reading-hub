    2024–2026 年的电力 AI 文献正在围绕一个争议性概念分化：所谓"电网基础模型 (foundation model for the grid)"已经裂为两个并行的研究线索——一条是面向 PMU/SCADA/AMI/拓扑 的数值自监督编码器（Hamann 等 Joule 2024 透视、PowerPM NeurIPS 2024、LF Energy GridFM、HGT-LGMP 图 Transformer 等），另一条是在电力语料上微调的语言原生大模型（GAIA Sci Reports 2025、ElecBench、GridMind、X-GridAgent、Grid-Agent 等）；研究界当前的核心赌注是这两个线索能否在跨模态适配器、层叠 PINN⊕FM⊕LLM、覆盖数值与自然语言的联合基准之上完成融合。本综述据此采取双目 (binocular) 的"电网基础模型"定义，将上述两条线索置于同一调研框架下，并将其交汇处——架构、评测、安全治理——作为组织主线。"双目"一词在此既有方法论意味（不偏废任一线索），也有实证意味（两条线索覆盖的下游任务、模态与部署语义已经在 2024–2026 年开始相互渗透）；如果未来这两条线索真的在 cross-modal adapter / layered hybrid / 联合 benchmark 上完成融合，那么"双目"将退化为"单目"——但本综述明确认为，这一融合在 2026 年仍是 研究承诺 而非 已实现状态。

    正文按三个 Block 与 11 章展开。Block I（§4–§5）覆盖数值编码器：tokenization、电气位置编码 \(\mathrm{PE}_{\text{elec}}\)、四类骨干（Transformer/TSFM、GNN、graph-transformer、masked-graph autoencoder）、自监督目标 \(\mathcal{L}_{\text{ssl}}\) 与物理残差耦合 \(\mathcal{L}_{\text{phys}}\)；并在 N-1/N-2 contingency 下评估拓扑泛化（PFΔ、PGLearn）。Block II（§6–§7）覆盖语言原生 LLM 的 fine-tune / ICL / RAG-agent / eval suite / 新兴 closed-loop with rollback 五条子线，以 GAIA 为骨干、Jia/Cui/Hug 的反馈式 multi-agent 与 Grid-Agent 的回滚机制为代表，讨论 RAG-over-document 与 RAG-over-telemetry 之间的不对称裂缝。Block III（§8–§10）覆盖 PGLearn+PFΔ+ElecBench+ProOPF 四轴基准、跨配电公司联邦 (尚无端到端 GridFM 联邦预训练范例)、以及 PINN⊕FM⊕LLM 三层混合栈（PE-GPT、PIRL、NYISO physics-informed GridFM）。§4 给出贯穿全篇的 6 轴 taxonomy（模态/架构/预训练目标/下游任务/数据开放度/operator-grade safety tier），§7 单独处理三组跨 Block 接缝：A↔B 跨模态对齐、B↔C operator-grade 安全 benchmark、A↔C 跨公司联邦预训练。

    §11 列出五个待解接缝 (universal tokenization A1; topology generalization beyond IEEE A2; 对抗性安全 benchmark B-S1; 联邦 GridFM 预训练 C-S1; 三层 hybrid artefact C-S4)，并把 "3–4 OOM speed-up"、"Zhejiang Power Grid deployment"、"operator-grade closed-loop" 这三句load-bearing论断按 hedge 形式保留。作者署名严格遵守 verified registry（Hamann/IBM、Kibaek Kim/ANL、Cheng/GAIA、Tu/PowerPM、Sarwar、Jia/Cui/Hug、Xiyuan Zhou/ElecBench、Orfanoudakis），未核实者一律以 <authors need verify> 占位。

    1. Introduction & Scope#

    1.1 Binocular 定义与"foundation model"一词的争议#

    将"foundation model"引入电力系统并非平滑迁移。Hamann 等 (IBM Research, Joule 2024) 的透视文章把电网基础模型构想为一个吃下 waveform/phasor/SCADA/AMI/拓扑/天气/文本 等多模态信号、用预训练换取下游通用性的数值骨干；与此同时 Cheng 等 (Sci Reports 15:8925, 2025) 的 GAIA 则把"为电网工作的基础模型"演示为一个在电力语料上做继续预训练 + instruction tuning 的语言原生解码器 LLM，以"Grid Artificial Intelligent Assistant"的辅助决策定位面世。两者共享 "scale + transfer" 的修辞，但在模态、tokenizer、骨干、训练目标、评测协议、部署语义上几乎没有交集。

    本综述据此采用双目定义 (binocular)：把 GridFM (数值自监督) 与 Power-LLM (语言原生) 共同纳入"foundation model for the grid"的覆盖范围；不是把后者塞进前者的脚注，也不是把前者降级为后者的工具。理由有三：

    1. 2024–2026 文献开始出现明确的交汇尝试——cross-modal adapter \(h_\psi\)、layered PINN⊕FM⊕LLM 栈、横跨数值替代与 NL 调度的联合 benchmark——而每一个交汇尝试都同时挑战两条线索的既有形式。
    2. 我们识别出的 8 部 unifying survey (Hamann Joule; Sarwar arXiv 2512.13004; Yao IET SES; LF Energy GridFM 白皮书; Argonne workshop; Cheng GAIA 介绍; Energies 2025 deep-learning review; TSFM-for-load arXiv 2410/2412) 中，没有一篇把交汇处本身写成结构性章节。本综述把这道缝补上。
    3. 从部署看，控制中心 / utility 运维侧的 EMS/DMS 不会因为论文把两条线索分开就分开采购它们；"operator-grade" 必然意味着一个数值物理子系统 + 一个语言接口 + 一个治理框架同时到位。

    为避免概念膨胀，"foundation model for the grid"在本综述中明确不包括：纯通用 LLM 上的电力问答评测 (除非作为 baseline)；非预训练范式的 small specialised GNN；以及 "AI for energy" 框架下与电网无直接关系的能源经济建模。这条界限在 §3 §4 §6 反复用到。

    为帮助首次阅读，下表把"binocular"的两眼并列展开，作为后续章节的术语锚点（\(h_\psi\) 为 cross-modal adapter，详 §8.1；PINN⊕FM⊕LLM 三层栈详 §11.1）。§5.9 给出 "GridFM" 一词在四种具体含义下的精确区分，首次阅读时可先按下表的二歧粗读：

    轴 数值 GridFM（左眼） 语言原生 Power LLM（右眼）

    1.2 Foundation-vs-specialist 张力与读者路标#

    电力 AI 实务的近代版本是 specialised GNN / 物理求解器 / 经典 OPF/SE/SCED 软件栈的复合。把基础模型引入这条流水线只在以下三种情形下经验地占优 (§C.1 综合)：

    • 预测类、跨站点异构、少样本微调预算：numerical generalist FM 倾向于胜，PowerPM、NYISO physics-informed GridFM、Moirai 类多元 TS-FM 是代表；其优势来自于跨域预训练带来的归纳偏置，在新站点上无需重新积累训练样本。
    • 约束优化形 (AC-OPF, SCOPF)、已有 physics-aware surrogate、毫秒级延迟：specialised GNN / 经典求解器仍稳；这一类任务的 正确性 不仅取决于平均误差还取决于约束满足，FM 类方法对约束没有内生承诺。
    • 真正有意思的边界是 layered hybrid：把 PINN 放内层，FM 放中层，LLM 当对话接口，按可微/不可微切分以满足 audit 要求。这条路线的关键洞察是：约束满足由 物理层 承诺，泛化由 预训练层 承诺，可解释性由 语言层 承诺；三者职责分离，每层只对自己擅长的指标做硬约束，避免单一模型同时承诺自己不擅长的指标。这也是为何本综述在 §11 把 layered hybrid 当作整篇的整合 artefact 而非"另一类方法"。

    本综述 §5 与 §10 把这个 tradeoff 在论文级别拉成表格，并在 §8 用 PGLearn + PFΔ + ElecBench + ProOPF 四轴 benchmark 给出判据。

    读者路标：仅关心数值 GridFM 的读者可读 §2–§5、§8–§10；仅关心 LLM 调度助手的读者可读 §2–§3、§6–§7、§8、§10–§11；关心跨界与治理的读者请重点读 §7、§9、§10 与 §11。

    值得明确的是，本综述并非另一篇"AI for power systems" 的通行综述。与 phase0b 列出的 8 部 bird's-eye 来源相比，本综述的差异化定位有三：第一，明确把 numerical GridFM 与 language-native LLM 共置为同一研究纲领下的两条相互依赖线索，而非两类应用；第二，把交汇处——cross-modal adapter、layered hybrid stack、统一评测谱——本身写成结构性章节（§7、§10），而不是把它们作为各自线索的余论；第三，每一处 load-bearing 论断都在引用时携带 hedge，避免传统综述中"FM speedup 3–4 OOM" / "deployed in production" / "operator-grade closed-loop" 等口号化转述。这三点差异把本综述定位为认识论严格的桥梁性综述：它不替代任何子领域的深度综述，但试图给出社区共有的座标系。

    在覆盖范围上，本综述按 phase0a 时间窗口将 2022–2026 文献分为三段：2022–2023 的早期 GNN OPF / TS-FM 探索 (作为前史)；2024 的两条线索初露端倪 (Hamann Joule perspective、GAIA、PowerPM、PowerGraph、Jia/Cui/Hug 反馈式多 agent)；2025–2026 的快速演化（HGT-LGMP、PFΔ、PGLearn、X-GridAgent、PowerDAG、ProOPF、Grid-Agent、NYISO physics-informed GridFM、Sarwar 综述）。该时间窗的关键收尾事实是：到 2026 年中，没有任何 公开论文同时跨越 numerical 与 language 两线交付端到端工件——这是本综述的核心 motivational gap。

    1.2.1 二级问题：FM-vs-specialist 的单一指标替代单一对比#

    把 FM-vs-specialist 之争简化为"FM 是否更好"是误导。本综述据 §C.1 的实证拒绝这一简化，转而提出一个 多指标分解：在每个具体任务下，分别比较 (a) 在 少量微调数据 下的相对表现 (\(\rho\) small-data)；(b) 在 标准微调数据 下的相对表现 (\(\rho\) full-data)；(c) 在 分布外 任务/拓扑下的相对表现 (\(\rho\) OOD)；(d) 在 延迟约束 下的相对表现 (\(\rho\) latency-bounded)；(e) 在 audit-trail 要求 下的相对表现 (\(\rho\) audit-bounded)。FM 与 specialist 在五个指标上的优劣并不一致——PowerPM 在 (a)(c) 上突出，HGT-LGMP 在 (c) 上突出但 (a) 未报告，经典 IPOPT 在 (b)(d) 上不可超越但在 (a) 上无意义。本综述据此明确：FM 不是 specialist 的替代品，而是工作量的重新分布——从样本生成 + 模型训练 (specialist 路径) 转移到预训练 + 微调 (FM 路径)。哪条路径更经济，取决于具体公司的数据资源、人力配比、合规约束。

    2. Background & Notation#

    2.1 电网量与 AC 潮流#

    设电网图 \(\mathcal{G}=(\mathcal{V},\mathcal{E})\)，\(\mathcal{V}\) 为母线集合，\(\mathcal{E}\) 为支路集合，\(N=\lvert\mathcal{V}\rvert\)。导纳矩阵 \(\mathbf{Y}\in\mathbb{C}^{N\times N}\)；母线 \(i\) 的复电压相量 \(\mathbf{v}_i = V_i e^{j\theta_i}\)，复功率注入 \(\mathbf{S}_i = P_i + jQ_i\)。AC 潮流方程

    \[\sum_{j\in\mathcal{V}} Y_{ij}\,\mathbf{v}_j \;=\; \frac{\mathbf{S}_i^*}{\mathbf{v}_i^*}, \qquad i\in\mathcal{V}\]

    是所有数值 GridFM 在 §5 物理残差损失 \(\mathcal{L}_{\text{phys}}\) 中所惩罚的同一个等式。AC-OPF 在该约束加上发电机、支路、电压幅值上下界与目标 \(\min \sum_i c_i(P_i^g)\) 之下闭合；SCOPF 进一步加上 \(\forall k\in\mathcal{C}\) 的 contingency 约束，是 §3 与 §8 反复涉及的 operator-grade 基准任务。

    2.2 信号模态与采样率#

    电网 AI 关心的输入信号横跨七个量级的采样率： - synchro-waveform (kHz)：故障定位、广域震荡分析； - PMU (30–60 Hz)：广域状态估计、动态稳定； - SCADA (秒–分钟)：EMS 主表、潮流监测； - AMI (15 分–1 小时)：表后侧负荷与需求响应； - 天气栅格 (小时–日)：可再生预测； - 操作员文本/日志/规章 (事件驱动)：调度问答、合规检索； - 代码/脚本/tool-call trace (事件驱动)：Daline/MATPOWER 调用。

    这一七模态梯度是 §4 Block I 讨论 universal grid tokenizer (Seam A1) 时的 rate-mismatch 根源——kHz 与 1/h 之间相差 7+ 个量级。除采样率外，七类模态在结构上也不同质：waveform 与 PMU 是密集时间向量；SCADA 与 AMI 是带 schema 的稀疏标量表；拓扑是图结构；天气是规则空间栅格；操作员文本与日志是离散符号序列；代码与 tool-call trace 是带状态的语法树。任何"统一编码器" 必须在同一表征空间内容纳这五种结构异构形态，这正是 phase0b §4 把"统一 tokenizer"列为头号架构缺口的理由。

    从工程视角看，单一公司的 EMS 历史数据通常覆盖 SCADA + AMI 加少量 PMU 与文本日志；waveform 通常由独立的录波装置离线采集，未必进入 EMS 主表；天气栅格则由第三方气象服务提供。把这五条数据管道在预训练阶段对齐——按时间戳、按地理坐标、按 CIM 拓扑节点 ID——的工程难度，与算法侧的 tokenizer 设计同等重要。本综述把这条工程困难视为 §10 跨公司联邦 (Seam C-S1) 的隐含前提：在单公司侧尚未对齐前，跨公司预训练只是把对齐问题放大到 \(|\mathcal{U}|\) 倍。

    2.3 EMS/DMS 栈与"deployable" 含义#

    读者背景速记：EMS = energy management system，输电网级、operator 实时调度的主屏；DMS = distribution management system，配电网级；RTO/ISO = 区域 / 独立电力调度机构 (如 NYISO/CAISO/MISO/ERCOT)，负责市场出清与跨网协调。本综述大部分数值 GridFM 工件以 EMS 为目标场景；部分 LLM 工件 (Intelli-Dispatch-SQL、ProOPF NL→formulation) 跨 EMS/RTO 边界。市场出清 (market clearing) = ISO/RTO 通过 SCUC + SCED 等价问题求得 locational marginal price (LMP) 与各机组出力，是每 5–15 分钟运行的核心计算 (§9.4 #2 列其为公开 benchmark 缺口)。

    部署语义按 phase0c-C 的分级延续至本综述：(i) demo / 学术演示；(ii) shadow mode logging only (输出旁路记录、不影响调度)；(iii) advisory copilot (NL 问答，operator 自决)；(iv) sandboxed tool-use (RAG-agent 调用经典求解器，结果由 operator 审阅)；(v) 仿真闭环加回滚 (Grid-Agent 类)；(vi) fielded closed-loop。在本综述涵盖范围内，tier (vi) 没有可核实的公开案例；任何"operator-grade closed-loop"语句若不加引号都按 phase0d §6 视为论断过载。注：tier (vi) 在 EMS 实务中又可细分为 setpoint advisory still operator-confirmed 与 direct setpoint write 两种 sub-tier，本综述六级 ladder 不展开这一区分；外部参照框架 (IEC 61850-90-X、NERC CIP、NIST AI RMF) 提供了更细的合规映射。

    2.4 6 轴 taxonomy 简表（详见 §4）#

    本综述以 6 个 taxonomy 轴贯穿全文：模态 (Modality)、架构 (Architecture)、预训练目标 (Pre-training objective)、下游任务 (Downstream task)、数据开放度 (Dataset openness)、安全/operator-grade 等级 (Safety tier)。这 6 个轴既是 §4 的列，也是 §8 评测时论文落位的索引。

    5. Block I — Numerical GridFM Architectures (架构与 tokenization)#

    本章把数值 GridFM 线索按 §4.2 的骨干家族纵向铺开，并把 §4.3 的预训练目标横向耦合。每节按 (Modality/Architecture/Objective/Task/Openness/Safety tier) 六元组开篇。

    5.1 PowerPM — 分层时序 Transformer + 树结构聚合 (tree-aggregator)#

    (tabular AMI + scalar TS / Transformer + tree-aggregator (user→area→city) / masked-ETS + dual-view contrastive / forecasting + classification + anomaly + imputation / semi-open: open downstream + closed pretraining over State Grid / advisory)

    Shihao Tu (Zhejiang University) 等 在 PowerPM (NeurIPS 2024, arXiv 2408.04057) 中构造两阶段编码器：第一阶段是 over electricity-time-series 窗口的时序 Transformer (with exogenous variables)；第二阶段是 hierarchical encoder，按用户 → 区 → 市的树结构聚合 (cluster → area → city tree aggregator)，并非对全连接 meter 图做谱意义上的 graph sparsification。预训练目标合并 masked ETS 与 dual-view 对比损失。论文报告 44 个下游任务上 "only slight performance decrease" 当 fine-tune 数据减少时——few-shot transfer 是其主打。

    部署语义须按 phase0d §6 #2 hedge：PowerPM 文本中的 "deployed in Zhejiang Power Grid" 是 operator-partnered deployment, 部署模式未在论文中明示 (shadow / advisory / closed-loop 不可分)；在本综述中绝不径直读作 "production closed-loop deployment"。

    PowerPM 的体系架构 tradeoff：纯 AMI/SCADA 风格的数值输入，无导纳图处理；hierarchical 维度替代了 admittance graph。这把它从 §4.2 的 "masked-graph autoencoder" 行剥离开来，并使其在 PFΔ-类拓扑泛化测试上不可直接套用。从 GridFM-vs-PowerPM 这条架构对照看，两者代表了"对哪种异构性建模"的两种不同选择：GridFM-v0 把 拓扑异构 (跨网格大小、跨拓扑变化) 作为预训练主要泛化目标；PowerPM 把 用户-区-市层级异构 (跨规模、跨消费者类型) 作为主要泛化目标。两条选择都合理，对应不同的下游需求：前者优先服务输电网层 OPF/PF 求解，后者优先服务配电与零售层负荷预测与异常检测。把它们对立起来看是误导；把它们并置在 6 轴 taxonomy 上才能看出它们覆盖的 cell 几乎不重叠——也正因如此，把两者同时纳入 "GridFM" 概念集合在分类学上是恰当的。

    PowerPM 同时也是 Block I 里少数显式报告"下游数据减少时 FM 仅轻微退化"的工件——这对实务部署的意义远超架构论文的字面意义。EMS 部署语境下，跨公司或跨区的微调预算往往受限于数据共享协议而非算力，因此 微调样本效率 是部署评估的关键非功能指标。在该指标上 PowerPM 报告的 44 任务结果是当前 Block I 内最有部署语义的证据，尽管这些任务多为预测变体而非 OPF/SE 等约束优化形任务。

    5.2 GridFM-v0 / GridFM 0.5 — masked-graph autoencoder + LF Energy 工程生态#

    (topology + 节点 \((P,Q,V,\theta)\) / GNN (MAE) / 掩码重建 / AC-PF surrogate / 半开放 LF Energy / advisory)

    IBM Research 在 Joule 2024 透视 (Hamann、Gjorgiev、Brunschwiler、Martins、Puech、Varbella、Weiss、Bernabe-Moreno、Blondin Massé 等署名 verified) 之后发布 GridFM-v0 / GridFM 0.5——LF Energy GridFM 项目下第一个 working artefact (IBM Research 与 Hydro-Québec、Southern California Edison、NRECA 机构合作)。架构是 masked-autoencoder graph encoder：母线为节点 (特征 \((P_i,Q_i,V_i,\theta_i)\) 来自已解出的潮流解)，支路为边，自监督目标是随机掩码节点特征的重建；预训练语料目标 300k+ solved (O)PF 实例，跨异构网格规模。严格地说，GridFM-v0 学到的是 AC-PF 解空间的表征 (a learned representation of PF solutions / AC-PF surrogate)，而非带有目标函数与不等式约束的 AC-OPF surrogate——后者需在 v0 编码器之上再接一个 OPF head 才能闭合；将其口径化为"AC-OPF surrogate"是常见误读。

    GridFM 0.5 文本明确标注自身为 "first working FM" 而非已 benchmarked 工件；其与 Hamann Joule perspective 的关联是 3–4 OOM speed-up over classical solvers 这一目标 (aspirational / target，并非端到端 contingency-aware 测量) 的承袭。本综述按 phase0d §6 #1 在引用此数字处一律保留 hedge 语。

    值得展开的是：GridFM-v0 的 masked-autoencoder 设计与 LF Energy 的工程生态绑定意味着，它的"foundation model"语义不仅是技术层面的 (一个预训练后可被微调到多任务的编码器)，也是制度层面的 (一个跨多家公司可被复用的工件)。后一面正是 phase0b T4 (federation / governance) 的核心议题——一个 单公司 训练的 GridFM 在严格意义上只是一个 域适配 surrogate，称为 "foundation model" 是修辞 inflation；只有当 GridFM 通过 §10 联邦预训练机制在多家公司语料上训练，并通过 §9.5 governance 框架以可验证方式发布，"foundation model" 这一术语才在制度意义上落地。LF Energy GridFM 的存在正是为给这一制度路径搭脚手架。本综述在 §10 把这一观察展开为对 "internet-of-grid" 叙述的可证伪条件。

    5.3 OPF-HGNN / PI-TGN — heterogeneous typed GNN#

    (topology + node / heterogeneous GNN / 监督 (AC-OPF supervised)，物理结构融入消息函数 / AC-OPF surrogate / 合成 IEEE+GOC / demo)

    OPF-HGNN (arXiv 2403.00892, <authors need verify>) 用 heterogeneous GNN，把发电、负荷、传输母线置于不同节点类型，把变压器/线路置于不同边消息函数，避免 one-hot 类型特征带来的退化；论文报告相对 baseline GNN 在跨拓扑 AC-OPF 上约 2 OOM 加速 (arXiv preprint, not yet peer-reviewed)。PI-TGN (Universidad de Zaragoza 仓库，<authors need verify>) 进一步把支路提升为节点 (line-as-node)，使支路潮流在消息传递图上可直接寻址，把物理结构嵌入架构而非仅嵌入损失——这是 §5.5 物理残差讨论的关键对照。

    5.4 HGT-LGMP — graph transformer + 电气距离 PE#

    (topology + node / graph transformer / 监督 AC-OPF / AC-OPF on N-1 / 合成 IEEE 14–2000 / demo)

    HGT-LGMP (arXiv 2510.06860, <authors need verify>) 是 2025-era 最干净的 topology generalization 架构示范：类型相关 local message passing → bus 节点上的 global Transformer attention，并把电气距离先验同时以两种形式注入——既作 input-side 位置编码 \(\mathrm{PE}_{\text{elec}}(i,j) = \phi(R^{\text{eff}}_{ij})\) 加到 token 嵌入，又作 attention bias \(b_{ij} = f(R^{\text{eff}}_{ij})\) 加在 softmax \((QK^\top/\sqrt{d})\) 内部。两者在工程上不等价：input-side PE 与 graph 大小耦合，bias-form 则 graph-size-agnostic，因此对未见拓扑的泛化承诺更强。论文报告在 14–2000 母线系统上，仅以 full-topology 数据训练时，unseen N-1 拓扑的 optimality gap <3% (arXiv preprint, not yet peer-reviewed)——目前公开报告中将电气距离 PE 在拓扑泛化上量化的唯一示例。

    5.5 PowerGNN — 导纳加权 GNN#

    (topology + node / weighted message passing GNN / 监督 PF surrogate / PF on IEEE / 合成 / demo)

    PowerGNN (arXiv 2503.22721, <authors need verify>) 把图 Laplacian / 导纳加权边权写入消息聚合，并首次在 PF surrogate 任务上 量化 二值邻接 GNN 与导纳加权 GNN 的差距。它落在 §4.2 的"导纳加权 GNN"行，是从 binary GNN 向 typed/electrical-PE 上移路径上的中间桩。

    5.6 TSFM 线 — TimesFM / Chronos / Moirai / Lag-Llama 在电力负荷上#

    (scalar TS only / decoder-only or encoder-decoder TS Transformer / 跨域 TS 预训练 + zero-shot/LoRA / load forecasting / 半开放 industrial blogs + arXiv / advisory)

    跨域时序基础模型 (arXiv 2410.09487, 2412.12834, 2602.10848，<authors need verify>，YYMM 编码定为 Oct/Dec 2024–Feb 2026，arXiv ID 2602.* 需 cross-check 实际 posting date) 在电力负荷上以放弃拓扑换取跨域预训练规模。代表数字 (按arXiv preprint, not yet peer-reviewed限定)：top TSFMs (Chronos-2、TimesFM、Time-MoE、Sundial) 在 ERCOT day-ahead load 2048-h context 上达到 MASE ≈ 0.31 zero-shot，较 Seasonal-Naive 优约 47%，与精调 Transformer 相当或更优。Chronos-2 grid-imbalance 评测来自 ml6.eu 工业 blog (industrial report, not peer-reviewed)，不可作为论文级证据引用。

    TSFM 线是 §4.2 的拓扑盲极端例：它换得的 transfer 来自于扩展的非电力领域语料，而非电力结构先验。这一边界恰是 §10 hybrid stack 的左侧锚点。

    5.7 PowerGraph 与 PFΔ — 架构-不可知 benchmark 对架构的反向规范#

    PowerGraph (NeurIPS 2024 D&B, arXiv 2402.02827, <authors need verify>) 是 benchmark, 但其对 IEEE-24/-39/-118 + UK grid 的 输入格式 实际上钉死了"topology-aware 骨干"的事实标准 I/O：节点特征 \((P,Q,V,\theta)\) + 支路特征 + graph-level 级联故障标签 + 真值 edge attribution。在后续工作中标 GAT/GIN/GCN baseline 在 PF/OPF 节点级任务上 competitive 但在 graph-level 级联预测上系统性差——这正是 §5.4 graph transformer 行的设计动机。

    PFΔ (MOSSLab MIT, NeurIPS 2025, arXiv 2510.22048, <authors need verify>) 是 859,800 已解 PF 实例的 N / N-1 / N-2 contingency benchmark，跨 IEEE-14/-30/-57/-118 + GOC-500 + GOC-2000，含接近 voltage-stability 边界的近不可行实例。每个实例携带 post-switching 导纳图，因此骨干必须把拓扑当输入消费，而非把拓扑烘焙进权重。这是 phase0a §6 #2 提出的拓扑泛化最干净的公开探针。论文报告传统 Newton–Raphson 与已有 GNN baselines 各有特征性失效模式——GNN 在稳定边界处骤降，经典求解器在 ill-conditioned N-2 上 stall。该 双向退化 现象在评测语义上很有意思：它意味着任何 single-shot 方法 (无论数据驱动或纯数值) 都不构成 contingency 体制下的完整解，而 layered hybrid (经典求解器作 fallback + GNN 作 warm-start + 物理 residual 校验) 才是 PFΔ 上可能稳定的设计——这一推论被 §10 hybrid 章节进一步展开。

    5.9 跨骨干家族对照与"GridFM"标签的归属#

    把 §5.1–§5.8 的工件按 §4.2 的骨干家族纵向对照，可以看到 "GridFM" 这一标签在 2024–2026 文献中实际指向的工件并不一致：在 Hamann Joule 透视的最强意义上，GridFM 指 跨多模态、跨拓扑、自监督预训练 的统一编码器，对应 §4.2 的 "hybrid Tr + SSM + GNN (proposed only)" 行——尚未 实现。在 LF Energy 工程意义上，GridFM 指 GridFM-v0 / 0.5 这一 masked-graph autoencoder 系列工件，对应 §4.2 的 "masked-graph autoencoder" 行——已实现 v0。在 PowerPM 意义上，GridFM 指对 ETS 的层级 Transformer + sparsified GNN，对应 §4.2 的 "hierarchical Transformer + sparsified GNN" 行——已实现且部署。在 NYISO 意义上，GridFM 指 物理信息约束下的 TS-FM 多任务系统，对应 §11.2.4 的 两层 hybrid——已实现于 ISO 实时数据。

    这四种"GridFM"在术语层面是同名异义。本综述按 phase0a 选择不强行收敛术语，而是按 §4 taxonomy 把每个工件落位到其骨干家族，避免读者把 Hamann perspective 的 GridFM (proposal-only) 与 PowerPM (deployed) 等量齐观。这一术语谨慎在 §12.14 的 binocular falsifier 中再次发挥作用——若四种 "GridFM" 中只有 PowerPM 与 NYISO physics-informed 在 5 年后被实际广泛使用，那么 Hamann sense 的 GridFM 即 falsified。

    附带一条建议：引用 "GridFM" 时宜遵循 最小描述 原则——指明 哪一种意义下 的 GridFM (Hamann perspective / LF Energy v0 / PowerPM hierarchical / NYISO physics-informed)，而非默认所有读者理解相同。术语精确既是写作规范，也是评审与同行讨论中快速识别误解的工具。本综述在正文与附录 A 落位表中均显式区分这四种意义，建议后续论文沿用同一区分约定。

    6. Block I — Pre-training Objectives & Physics Coupling#

    本章把 §5 列出的骨干所配备的预训练损失 \(\mathcal{L}_{\text{ssl}}\) 拉成一条独立分析线，并讨论物理残差 \(\mathcal{L}_{\text{phys}}\) 的耦合方式。

    6.1 掩码重建 (MIM / MAE on graphs)#

    GridFM-v0 (LF Energy GridFM line; IBM Research + Hydro-Québec + SCE + NRECA) 是当前最纯粹的 masked-graph autoencoder 实现：在已解 (O)PF 实例上随机掩码节点特征 \((P_i,Q_i,V_i,\theta_i)\) 子集，模型回归被掩码的部分。优点是直接吃下大量 IEEE/GOC 合成 + 部分真实数据；缺点是缺少跨时间的动态信号，不可单独用于负荷预测或动态稳定任务。PowerPM 时序段的 masked-ETS modeling 是同类目标在时序模态上的对偶。

    6.2 双视图对比 (dual-view contrastive)#

    PowerPM 在 ETS 段同时使用 masked reconstruction 与 dual-view 对比损失；后者是 PowerPM 在 anomaly detection / classification 类任务上有竞争力的关键。在 GridFM-v0 / HGT-LGMP / OPF-HGNN 行内，对比损失尚未成为主目标。Seam A4 (跨模态对齐) 的 CLIP-style 对比正是这条线索的延伸——把"对比"从单模态内部扩展到 (grid state, operator narrative) 配对，但缺少公开 paired-data corpus，详见 §7.1。

    6.3 物理残差 \(\mathcal{L}_{\text{phys}}\) 的耦合方式#

    形式上 \(\mathcal{L}_{\text{phys}}(\theta) = \mathbb{E}_{\mathbf{x}}\left[\left\lVert\sum_{j\in\mathcal{V}} Y_{ij}\,\hat{\mathbf{v}}_j(\theta) - \hat{\mathbf{S}}_i^*(\theta)/\hat{\mathbf{v}}_i^*(\theta)\right\rVert^2\right]\)。在 2024–2026 文献中，物理残差以四种方式入场：

    1. 辅助损失项：最常见。在监督 surrogate 上加 KCL/KVL 惩罚，PINN warm-start 文献 (§C.4.1) 与 NREL/NYISO physics-informed GridFM (§C.1.3, NYISO Energies 2026, <authors need verify>) 是代表。
    2. typed 架构内嵌：PI-TGN 把支路提升为节点、按物理结构定义消息函数；物理被推入架构而非损失。
    3. differentiable AC-PF layer：把若干步 Newton–Raphson 解写成 differentiable layer (要么按隐式函数定理在 AC-PF 不动点处反传，要么 unroll 固定步数的 NR 迭代再 backprop)，置于 graph transformer block 内部。注意 OptNet (Amos & Kolter 2017) 是为 convex QP 设计的 KKT 隐式微分，AC-PF 非凸，类比要谨慎；雅可比病态是该路径的共性障碍，与本节后段提到的 FP16 数值退化同根。截至 2026 该方向尚无公开端到端实现——§11 Seam A3 的关键缺口 (在 phase0c-A 与 phase0c-C 的工件清单内均未识别到对应公开实现)。
    4. 物理-RL 框架：PIRL (MDPI Energies 2025, <authors need verify>) 把物理约束作为 RL 安全过滤层，模型-数据混合驱动实时 OPF。

    物理残差并非预训练主目标的现行选择：GridFM-v0 主目标仍是 reconstruction，PowerPM 主目标是 reconstruction+contrastive；物理残差仅在 fine-tune 阶段或下游头处出现。这与 Hamann Joule 透视的"physics-aware foundation model"愿景之间存在显著阶梯，是 §11 与 §10 多次落点之一。一个工程层面的可能解释是：在 预训练 阶段把 \(\mathcal{L}_{\text{phys}}\) 放进主损失会带来三个工程困难——(1) 模型输出空间必须严格对齐物理 state，否则残差无意义；(2) 物理残差对噪声敏感，难与 reconstruction 上的 mask probability 共调；(3) 在 mixed-precision 训练下 \(Y_{ij}\) 矩阵条件数大，FP16 下的数值梯度退化。这些工程困难解释了为何物理残差通常被推到 fine-tune 阶段。但若工程困难能在新工具上 (例如 differentiable Newton–Raphson layer，Seam A3) 解决，则物理残差作为 预训练正则化 的潜力可对应 Hamann Joule 透视所主张的方向——届时 GridFM 将不仅是"在电力数据上预训练的 Transformer"，而是"内嵌物理一致性的预训练编码器"，这一区分对下游 calibration 与 audit 都有直接影响。

    6.4 Next-token / Instruction tuning（与 Block II 衔接）#

    GAIA 的 continued pretraining + instruction tuning 完全活在 next-token 目标族内。\(\mathcal{L}_{\text{ssl}}\) 这条线在 LLM 端走的是 token-level cross-entropy；其与 §6.1–§6.3 数值目标的差异——并非"loss 形式不同"那么浅，而是token 单位不同：电力数值 GridFM 的 token 是 (bus, time-window) 或 graph patch，LLM 的 token 是 BPE-style 文本 unit。Seam A4 的跨模态 adapter 要解决的是这一对 token 空间的对齐。

    6.5 In-context learning 与 RAG 作为"非梯度更新目标"#

    把 ICL / few-shot / RAG 视为预训练目标在严格意义上是借喻——这些机制不更新参数。但它们在 Block II 中起到与 fine-tuning 同位的功能 (PowerGPT 的 zero-shot OPF formulation；PowerDAG 的 exemplar retrieval；Jia/Cui/Hug 的 RAG-over-API-docs)，因此本综述按 phase0d §4 把它们列在同一 taxonomy 轴上。

    6.4.1 Token 空间错配的工程含义#

    §6.4 提到的 "token 单位不同" 在工程实施上有具体后果：数值 GridFM (PowerPM / GridFM-v0 / HGT-LGMP) 的输入嵌入维度通常 64–512 量级，每个 token 对应一个 (bus, time-window) 或 graph patch；LLM (GAIA / GridMind / X-GridAgent) 的 token 嵌入维度通常 2048–8192 量级 (Qwen / LLaMA / DeepSeek 当前主流)，每个 token 对应一个 BPE-style 文本 unit。两者嵌入维度差 1–2 个量级，且 向量空间几何 完全无可比性 (一个由 grid state 决定，另一个由文本语料决定)。\(h_\psi\) adapter 不能是简单线性投影——它需要做两件事：(a) 把 grid embedding 抬升或压缩到 LLM 嵌入维度；(b) 把 grid embedding 几何对齐到 LLM 已习得的"概念邻近性" (例如让"高电压"与 "voltage high" 在合并空间内邻近)。第 (b) 件事是 CLIP-style 对比损失存在的根本理由，也是为何 \(h_\psi\) 不能离线训练后 freeze——它必须随 LLM 在下游任务上的微调一起更新。这是 Seam A4 的 工程困难 而非 算法神秘性。

    6.5.1 ICL/RAG 与 fine-tuning 在合规视角下的对比#

    把 ICL/RAG 与 fine-tuning 放在 合规视角 下对比，会得到与算法视角不同的结论。fine-tuning 把电力知识固化到权重，推理时 没有外部检索动作，因此满足 air-gap 部署要求 (例如 EMS 主网内不可对外联网)；但训练时需要训练语料离开公司 (或在公司内部独立训练)，且每次更新都需要重训。RAG 则需要推理时调用 向量检索 + 文档存储，对 air-gap 部署不友好；但其知识库可在不重训模型的前提下更新，且 知识来源可追溯 (每次回答都可指向具体被检索的文档片段，对 audit-trail \(\tau\) 有利)。在 operator-grade 部署中这一 tradeoff 至关重要：合规约束严格的输电网 EMS 倾向 fine-tuning，但 audit-trail 与知识更新频率 要求高的应用 (如运维知识库、规章问答) 倾向 RAG。本综述把这一对比记入 §6.5 而非 §7，因为它的根源是预训练/适配 目标 选择，而非 agent 架构差异。

    6.6 3–4 OOM speed-up 目标的物理-数值阅读#

    最后回到本综述 §1.3 hedge 规则的源头：Hamann et al. Joule perspective 提出的 "3–4 orders-of-magnitude speed-up over classical solvers" 是一条 target / aspirational 论断，并非端到端 contingency-aware 测量。本综述在此明示其阅读方式：把它读作"如果未来 GridFM 能在 §6.1–§6.3 的目标基础上稳定外推至 unseen N-1/N-2 拓扑，则单次 inference 的 wall-clock cost 相对 IPOPT-class 求解器可期 3–4 OOM 改善"——但当前公开证据 (HGT-LGMP <3% optimality gap on N-1 合成 测试，OPF-HGNN ~2 OOM speedup over baseline GNN, not over classical solvers) 远未把这条目标拉成 measurement。该 hedge 必须随论断一同复制。

    7. Block II — Language-Native Power LLMs（fine-tune / ICL / RAG-agent / eval / closed-loop）#

    7.0 桥接：为什么把 LLM 与 numerical encoder 并列？#

    §4–§6 已花 30+ 页在 numerical 侧展开，进入 LLM 侧前需要再次明确"并列而非嵌套"的论证，以免读者把 §7 误读为 §5 之上的另一类应用研究。

    (i) 目标族同构：GAIA 类 LLM 的 continued pretraining + instruction tuning 走 token-level cross-entropy，PowerPM 类 GridFM 走 masked reconstruction + dual-view contrastive。两者在 \(\mathcal{L}_{\text{ssl}}\) 的 优化目标族 上同构 (均为 self-supervised pretraining + transfer)，差异在于 token 单位 (BPE-style 文本 unit vs. (bus, time-window)/graph patch) 而非目标形式 (§6.4 与 §6.4.1 已展开)。由此，两者都符合 "foundation model" 的 SSL-pretraining + 可迁移性最小判准——这是把它们置于同一 tier 而非 nesting 的认识论根据。

    (ii) 接口而非分类：将 §7 即将展开的 fine-tune / ICL / RAG-agent / eval / closed-loop 五子流，与 §5 已展开的 backbone 家族 + §6 已展开的 objective 族做 cross-cut——§4.2 的 "Decoder-only LLM (+ tool use)" 行其实是同一 taxonomy 在语言侧的延伸。读者从 §5 → §7 时需要带着这条 cross-cut 阅读，而非把 §7 视为新增维度。本综述继承上游 agentic 文献 (ReAct, Yao et al. 2023; Toolformer, Schick et al. 2023; Voyager, Wang et al. 2023; AutoGPT 等通用范式) 的整体设计点，grid 特殊性主要在 tool API (Daline / MATPOWER / OPF solver) 与 安全 tier (rollback / audit)，而非 agent 架构本身——这一观察避免把 grid LLM-agent 的原创性视高。

    (iii) 预告 §8 的 \(h_\psi\)：§6.4 提到的 token 空间错配将在 §8.1 通过 cross-modal adapter \(h_\psi:\mathcal{Z}\to\mathbb{R}^{d_{\text{LLM}}}\) 解决。\(h_\psi\) 的合理设计原语已在 vision-language 文献成熟，例如 Q-Former (BLIP-2, Li et al. 2023)、perceiver 风格 cross-attention (Flamingo, Alayrac et al. 2022)、pivot-anchor 多模态对齐 (ImageBind, Girdhar et al. 2023)、cross-modal RAG (MuRAG, Chen et al. 2022; Atlas, Izacard et al. 2022)。把 GridFM 当 "frozen image encoder"，GAIA 当 "frozen LLM"，中间训练一个 Q-Former 类 \(h_\psi\) 是当前最直接可迁移的工程路径；ImageBind 的"用 pivot anchor 把所有模态间接对齐"在 grid 域类比为 以拓扑图作 pivot 把 PMU / SCADA / AMI / 文本对齐到拓扑空间。这些设计原语提示 \(h_\psi\) 的"算法神秘性"远小于"配对数据可得性"——后者才是 Seam A4 的实质 blocker (§8.1 详)。同时也需提防 cross-modal performance ceiling (Lu et al. 2021 Pretrained Transformers as Universal Computation Engines; Tsimpoukelli et al. 2021 Frozen 的 negative result)：frozen 语言模型 + 小 adapter 在非语言任务上常显著低于 from-scratch 训练。

    (iv) §7 与 §8 的预告：§7.6 末段的"跨子流观察"将把 Thread B 内部 数值正确性承诺位置 的差异 (fine-tune 把正确性嵌权重 vs. RAG-agent 把正确性外包给 solver) 显性化，§8 将把这条差异与 Thread A 的架构选择、Thread C 的部署约束在三组接缝 (A↔B / B↔C / A↔C) 上 collapse。

    接下来按 phase0c-B §3 的四加一子流分类组织 Block II——这是迄今为止在 LLM-for-power 文献内部最稳定的内生 spine，因为它精确追踪 语言如何与电网量耦合 的机制差异，而后者直接决定安全、可靠与审计义务的差异。

    7.5.1 Grid-Agent (arXiv 2508.05702)#

    (text + 数值 solver / planning agent + validation agent + sandboxed execution + rollback / no fine-tune; LLM-orchestration / 电压/过载违规 + 网络攻击场景 / <authors need verify> / simulated closed-loop with rollback, not fielded)

    Grid-Agent (arXiv 2508.05702, <authors need verify>) 是 Thread B 在 2026 之前唯一把 rollback 内嵌闭环 的工作：planning agent 用潮流求解器生成协同动作序列，validation agent 强制稳定性/安全约束，沙箱执行附 rollback。研究目标包括 DER 集成所致电压/过载违规与网络攻击场景。phase0d §6 #3 的 operator-grade hedge 在此严格生效：closed-loop 是 simulated，rollback agent 自身的 adversarial validation 未公开演示。本综述据此把 Grid-Agent 列为 "simulated closed-loop with rollback" tier，不读作 "operator-grade closed-loop"。

    7.5.2 Grid-Agent 与 phase0d §7.2 安全 benchmark 的关系#

    把 Grid-Agent 单独成立 closed-loop with rollback 子流的真正动机不是其方法新颖性 (planning + validation + rollback 在通用 AI safety 文献中已成熟)，而是它把"rollback 是 grid agent 进入更高 safety tier 的必要机制" 这一命题在公开工作中第一次清楚地说出来。其它 RAG-agent (GridMind / X-GridAgent / PowerDAG) 即便接经典 solver 也仍停在 advisory tier，正是因为没有 rollback 这一原语——operator 必须为 LLM 的每个建议作最终决策，agent 在结构上不可能跨越 advisory/sandboxed 边界。Grid-Agent 把这一边界推到了"simulated closed-loop"，但同时也暴露 出 rollback 自身的对抗性验证问题 (Seam B-S2)：若 rollback 决策本身能被 prompt-engineered 操控，则 rollback 提供的安全感是表象而非实质。这正是 §8.2 提出的 operator-grade safety benchmark 必须同时覆盖 rollback agent 的红队 检验的根本原因。

    8.1 A ↔ B：跨模态对齐 (Seam A4 × Seam B-S4)#

    Block I §5 提出的 cross-modal adapter \(h_\psi:\mathcal{Z}\to\mathbb{R}^{d_{\text{LLM}}}\) 与 Block II §7 提出的 RAG over telemetry (vs. RAG over documents) 在结构上 collapse 为同一个研究工件：

    • 架构形：\(h_\psi\) 把数值 GridFM (GridFM-v0 / PowerPM / HGT-LGMP) 的 embedding \(\mathbf{z}=f_\theta(\mathbf{x})\) 投到 LLM (GAIA-class) 的 embedding 空间，并通过 CLIP-style 对比损失 $\(\mathcal{L}_{\text{align}} = -\log \frac{\exp(\langle h_\psi(\mathbf{z}_i), \mathbf{e}^{\text{text}}_i\rangle/T)}{\sum_j \exp(\langle h_\psi(\mathbf{z}_i), \mathbf{e}^{\text{text}}_j\rangle/T)}\)$ 在 (grid state, operator narrative) 配对上训练。
    • agentic 形：给定 LLM 调度查询，先从 GridFM embedding space 检索"operational neighbours"（相似的过去 contingency、相似的负荷形态），再把这些 neighbours 作为 RAG context 拼回 LLM 提示。

    两种视角的实现核心是同一个 (state, narrative) paired-data corpus 与 \(h_\psi\) adapter。截止 2026 该 corpus 不存在——这是 Seam A4 / B-S4 的共同 blocker。本综述把这条接缝写成结构性章节 (§11 主要 open seam 第一条) 而非脚注，理由是它同时 falsify 两条线索 (T1 binocular 收敛假设的实证试金石)。

    现成的设计原语来自 vision-language 文献 (§7.0 已展开)：CLIP 对比 (Radford et al. 2021)、BLIP-2 Q-Former 作 frozen image encoder ↔ frozen LLM bridge (Li et al. 2023)、Flamingo perceiver cross-attention (Alayrac et al. 2022)、ImageBind 以 pivot anchor 把多模态对齐 (Girdhar et al. 2023)、MuRAG / Atlas cross-modal RAG (Chen et al. 2022; Izacard et al. 2022)。在 grid 域，把 GridFM 当 "frozen image encoder"、GAIA 当 "frozen LLM"、\(h_\psi\) 当 Q-Former 是最直接的工程映射；ImageBind 的 pivot-anchor trick 在 grid 类比为 以拓扑图作 pivot 把 PMU / SCADA / AMI / 文本对齐到拓扑空间。

    但 cross-modal alignment 在科学领域有三类已知失败模式，paired-data 充足并不能自动避免：(i) modality gap (Liang et al. 2022 "Mind the Gap")——text 与 numerical embedding 在对齐后仍在 分离的锥形子空间，下游 zero-shot 性能因此被钳制；(ii) shortcut features——对齐损失被 平凡共现 而非语义内容主导 (例如 timestamp / 公司 ID 等元数据共现)；(iii) paired-data vs downstream query 的分布偏移——operator 实际查询的分布与历史日志的分布并不重合。每一项都是 方法论 而非纯 数据可得性 障碍。

    8.2 B ↔ C：operator-grade 安全 benchmark (Seam B-S1 × Seam C-S2)#

    Block II §7 标定 Thread B 没有共享的 adversarial-robustness benchmark；Block III §9 标定 benchmark governance 在 NERC / IEC 审计语义下尚未定义。两者 collapse 为同一个结构性研究工件——一个 跨成熟 prior-art 框架 的 benchmark。本综述把其轴列表锚定到三条 cross-domain 框架，避免在 grid 内"另起炉灶"：

    • OWASP LLM Application Top 10 (2025) 提供 LLM01 prompt injection / LLM02 sensitive info disclosure / LLM03 supply chain / LLM04 data & model poisoning / LLM05 improper output handling / LLM06 excessive agency / LLM07 system prompt leakage / LLM08 vector & embedding weaknesses / LLM09 misinformation / LLM10 unbounded consumption。LLM06 (excessive agency) 直接对应 Grid-Agent 的 rollback 设计 (§7.5)；LLM08 直接对应 RAG-over-telemetry 攻击面 (§8.1)；LLM04 直接对应 §10 联邦预训练的 byzantine 风险 (§10.4)。
    • NIST AI RMF 1.0 (2023) + GenAI Profile (NIST AI 600-1, 2024) 提供 Govern / Map / Measure / Manage 四 function 以及 12 项 GenAI 风险 (其中 confabulation 与 ElecBench misinformation 轴同构；human-AI configuration 直接对应 advisory / sandboxed / closed-loop tier 设计)。
    • Formal verification of NN (Reluplex, Katz et al. 2017; Marabou; α,β-CROWN, Wang et al. 2021) 与 GNN verification 文献：grid 域 typed GNN (OPF-HGNN / PI-TGN) 的 输入空间结构化 + 物理约束有界 在理论上使 formal verification 比在 NLP 上更 tractable——这是 §12 新增 Seam B-S6 的根据 (未在原 12 seam 列表内，作为本 review pass 的延伸)。

    综合上述，本综述提议的 operator-grade adversarial-safety benchmark 轴列表为：(i) 内容幻觉 (ElecBench misinformation 扩展)；(ii) OWASP LLM01–LLM10 全谱 channel-level adversarial 注入；(iii) NIST GenAI 12 项风险映射；(iv) audit-trail completeness \(\tau\)；(v) (optional, B-S6) typed-GNN formal verification 子轴。

    \(\tau\) 的形式化：设 agent 在 episode 内执行动作序列 \(\{u_1,\ldots,u_T\}\)，每个 \(u_t\) 在审计日志中对应 justification record \(j_t\) (输入提示、检索到的 context、tool-call 输入输出、validation agent 决策)。\(\tau = \mathbb{E}\left[\frac{|\{t: j_t \text{可重建}\}|}{T}\right]\)。当 \(\tau = 1\) 且 \(j_t\) 通过 cryptographic linkage chained，则 audit-trail 完整；NERC 审计 baseline 应至少要求 \(\tau \geq 0.99\) on episode-level。当前 Block II 的所有公开工作均未报告 \(\tau\)。

    \(\tau\) 与传统 EMS 软件中的事件日志完整度在精神上接近，但在 LLM-agent 语境下有两点不同：第一，LLM 的中间推理 (chain-of-thought) 是否计入 \(j_t\)，取决于该 agent 是否暴露 CoT——闭源 API (Claude / GPT) 通常隐藏 CoT，使得 \(\tau\) 在外部 NERC 第三方 audit 语义下天然小于 1；第二，RAG 检索的 context 是否随 \(j_t\) 一并存档？若不存档，则后续 \(u_t\) 的可解释性依赖一个时变 RAG index 的快照——这对索引版本管理提出额外工程要求。这两点共同说明 \(\tau \geq 0.99\) 不是单纯算法目标，而是涉及 LLM 提供商透明度政策、agent 框架日志策略、RAG 索引版本控制三方协同的系统目标——这一基础设施层障碍指向一个结构性主张：operator-grade 部署的外层 LLM 在中期内更可能落在 本地部署的开源权重模型 (LLaMA / DeepSeek / Qwen 等)上，而非闭源 API，否则 \(\tau\) 在外部 audit 下不可达。

    按 phase0d §7.2 与 phase0d §6 #3 hedge：这个 benchmark 是从 advisory / sandboxed tier 跨入 simulated-closed-loop tier 的 gating artefact——不是 fielded-closed-loop 的充分条件。本综述据此把 phase0b T5 (operator-grade safety) 从"tentative thread" 提升为结构性章节 (§9.5)。

    8.4 跨 Block：三层 hybrid stack 作为整合 artefact (T3 × all blocks)#

    最能同时检验 binocular 论断的最简单单点工件，是一个三层 PINN ⊕ FM ⊕ LLM 的 stack 在 operator-grade 任务 (例如 SCOPF advisory) 上的端到端实现：

    1. 内层 PINN：differentiable AC-PF / KCL/KVL 残差约束，提供 physics-bounded warm-start；
    2. 中层 FM：GridFM-class 编码器消费 PMU/SCADA/AMI/topology，给出 telemetry-encoded state 与 OPF surrogate；
    3. 外层 LLM：GAIA-class，对 operator 提供 NL 解释 / 调整建议 / 黑启动指南。

    评测 spine 为 PGLearn + PFΔ + ElecBench，对照对象为经典求解器 (IPOPT) 与精调 specialised baseline。NYISO physics-informed GridFM (NREL/MDPI Energies 2026, <authors need verify>) 是已知最接近的工件，但停在两层 (TS-FM + physics constraint + explainability，缺 LLM)；PE-GPT (community survey 2025, <authors need verify>) 跨 LLM + PINN 但缺 FM。三层端到端 operator-grade artefact 在 2026 仍是空白，本综述把它写成 §11 的最强 recommendation。

    9.4.1 Benchmark 与 实务部署评估 的差距#

    公开 benchmark 与 EMS 实务部署评估之间存在一条结构性差距：benchmark 通常使用 合成或半合成 拓扑、固定时间窗、清洗过的输入；实务部署面对 真实 SCADA bad data、动态 topology 切换 (合解列、变压器分接头切换)、跨多季节的 concept drift。在公开 benchmark 上的胜出不蕴含在实务部署上的胜出——这是 PFΔ 把"接近 voltage-stability 边界的近不可行实例"显式纳入数据集的真正理由：它试图把 benchmark 拉向实务边界。但 PFΔ 仍是 合成 拓扑；真正的 real TSO topology corpus (operator-confirmed switching events 系列) 在 2026 仍空缺，这是 §12 Seam A2 的来源。一个值得 community 推动的 第二阶段 benchmark 路线是：以 PFΔ / PGLearn 为基础，叠加 脏数据注入 (SCADA dropout、bad measurement)、topology drift trace (来自 operator log 的真实切换序列模式)、与 concept drift (跨季节负荷模式) 三类增强，作为 operator-grade benchmark v2。这一路线在 §12.12 Seam C-S3 中再次出现。

    这一空白的结构原因可分三层解释：(a) 制度 层面，跨公司的 EMS 数据共享通常需要双边数据共享协议、NDA 与监管审批，而 FL 机制虽然在技术上绕开了 raw data 共享，但在审计与合规层面仍需要相同的双边协议作背书；(b) 工程 层面，跨公司 schema harmonisation (CIM 版本、SCADA tag 命名、时间戳时区、采样率约定) 在 FL 启动前是必要前置，工作量通常被低估；(c) 研究 层面，"backbone 预训练" 在 FL 语境下需要 任务无关 的损失 (典型是 §6.1 的 masked reconstruction)，而 FL 文献中报告 best practice 的 mechanism (例如 per-feature DP、meta-learning 个性化) 大多依赖 任务相关 的损失形态，使得直接迁移到 backbone 预训练并不平凡。综合这三层，跨公司 FL backbone 预训练在 2026 不是因为不够吸引人而无人做，而是因为前置条件多、ROI 不确定，且没有任何单一团队能独立完成全栈。LF Energy GridFM 与 ANL Argonne workshop 共同提供制度路径与 governance scaffold，是当前唯一可见的可行渠道。

    最直接可借鉴的 cross-domain 经验是 医疗影像 FL：NVIDIA Clara / FLARE 与 Flower / Owkin 等 framework 在 2020–2024 已踩过"联邦预训练 (而非 task-specific FL)"的全套坑——跨机构、严格隐私 (HIPAA / GDPR)、schema 异构 (DICOM 元数据)、监管驱动。grid FL 与医疗 FL 在制度结构上高度同构，差别主要在于：(i) grid 监管由 NERC / IEC / FERC 而非 HIPAA / FDA；(ii) grid 数据时序密度高 (SCADA 秒级)、医疗影像低 (单次扫描)；(iii) grid 模态种类多 (PMU/SCADA/AMI/topology) 而医疗 FL 通常单模态。但 framework 层 (NVIDIA FLARE 的客户端注册 / aggregation 协议 / SecAgg 接入) 与制度层 (跨机构 PoC 治理) 几乎可直接复用。本综述把此条记入 §10 以避免 grid FL 社区"自我封闭"。

    10.2 DP 在 GridFM 预训练上的预算编排#

    形式上，单步 SGD 加 Gaussian DP noise，对总组合的 \((\varepsilon, \delta)\)-DP 保护按 Rényi DP (Mironov 2017) / moments accountant 给定——这两种 DP 会计技术在多步 SGD 复合下给出比朴素 \(\varepsilon\) 加和更紧的隐私预算；当前 best practice 是 PRV-based accounting (Gopi et al. 2021)，§12.10 Seam C-S1 的 PoC 建议沿用此口径。对 GridFM 预训练，关键工程问题是：(i) per-feature DP 预算分配应否随物理意义偏置 (例如 \(V_i\) 与 \(\theta_i\) 比天气栅格更敏感)？(ii) cross-silo (公司间) 与 cross-user (公司内 AMI 用户间) 应使用差异化 DP 配置？(iii) §10.1 表中第二行 "explainability-driven DP" 工作 (ScienceDirect 2025) 的 utility-vs-privacy 改进在 strict \((\varepsilon,\delta)\) 复合下的会计是否仍 valid——本综述 §3.4 hedge 规则在此挂条 primary-text verification before quoting any privacy guarantee。

    需要并列说明的几条 fundamental tension：(1) Composition 爆炸——backbone 预训练涉及 \(10^5\)–\(10^6\) 步、跨多家公司复合，典型 \((\varepsilon,\delta)=(1\text{–}10, 10^{-5})\) 在 PRV accountant 下复合后 \(\varepsilon\) 通常远超 50，几近 无意义 privacy；(2) utility 异质性放大 DP 噪声需求——跨公司负荷形态/拓扑差异巨大 (Hydro-Québec 与 SCE 几乎无可比性)，per-client 调参与 uniform noise scale 之间存在 强约束 tension，大公司的 utility 被小公司的隐私需求向下钳制；(3) DP 噪声等价于缩小语料——在 scaling-law 视角下，DP-SGD 在固定 \((\varepsilon,\delta)\) 下的有效样本数 \(\propto \varepsilon^2 / \sigma^2\)，scale-up 公司数若需保持同等 \(\varepsilon\) 则 noise scale 增大、有效样本反降，这与"联邦预训练 unlock 跨公司 scale"的乐观叙述在形式上对冲；(4) grid 域 函数级 隐私威胁——攻击者关心的是公司负荷形态特征 / 拓扑结构 / 运维实践是否可被反推 (类比 Carlini et al. 2021 / Nasr et al. 2021 在 LLM 训练数据提取上的攻击)，而 DP-SGD 提供的是 样本级 保证，两者语义不直接对应。

    一条务实折中是 混合预训练：大头在 公开 IEEE/GOC 合成 + 公开 PGLearn 上 (无 DP 成本)，公司侧仅对 残差表征学习 做 DP-SGD。这一路径在 §11.3 三层 artefact MVP 的数据层给出了较合理的 starting point，且把 §10 §11 串成一条可执行的工程路线。

    10.3 Schema harmonisation 与 vertical FL 跨公司#

    Phase 0c-C §C.2.3 的 industrial-load FL + meta-learning 范例对应纵向 FL (跨用户) 的有限切片；GridFM 级别的跨公司纵向 FL 需要把不同公司 EMS schema (SCADA tag 命名、 CIM/CIM-XML 模型版本、单位约定) 在预训练前 harmonise。CIM (IEC 61970/61968) 是显然的工程锚点，但其覆盖率参差，需要按 LF Energy GridFM (S4) 现有 schema 调查推进。

    10.3.1 跨公司 schema harmonisation 的具体工作量#

    把 §10.3 抽象论述具体化：典型公司 EMS 在 SCADA tag 命名上通常采用 公司内部约定 + IEC 61970 CIM 部分映射 的混合方案。跨公司联邦预训练前的 harmonisation 至少需要做以下三件事：(1) 把 业务命名 (例如 "Substation_A_Bus_1_Voltage" 或 "ABC-110kV-母线-1-电压") 翻译为 CIM standard identifier；(2) 把 单位约定 (P/Q 单位 MW vs. pu，电压单位 kV vs. pu) 统一；(3) 把 时间戳 统一到 UTC 并对齐采样周期 (不同公司 SCADA 周期可在 1–10 秒区间)。这三件事的工作量大致是: 单家公司 1–3 人月 × 公司数 + 公司间协议 1–2 人月 × 公司对数。对一个 5 家公司的联邦预训练 PoC，schema harmonisation 工作量量级约 20–30 人月——这是 §10 §12 标记 Seam C-S1 为"机构协同"工件而非"单团队可解"工件的真实原因。

    10.4 联邦 + 物理：cross-domain 物理残差作为 正则化 而非 attack surface#

    跨公司联邦预训练有一个有用 by-product：物理残差 \(\mathcal{L}_{\text{phys}}\) 在 服务端（aggregator）可作为一致性正则——任何参与方上传的梯度若导致全局模型在已知 IEEE/GOC 实例上违反 KCL/KVL 超阈值，可作为 byzantine attack 嫌疑信号。该机制把物理一致性变成 安全 而非仅是 泛化 工具，是 §6.3 物理残差 4 用法的 第五 用法 (跨公司 byzantine 检测) 的延伸思考；该机制为 猜想，目前未见公开实现，引用时须保留这一限定。

    需补一条 机制层面 约束：secure aggregation (SecAgg with masking) 通常隐藏 per-client 梯度，而 byzantine-robust aggregator (Krum、median、trimmed-mean) 直接作用于 per-client 梯度——两者不可平凡复合。因此 物理残差作为 byzantine 检测信号 在 SecAgg 启用时必须在 aggregated model state 上做 post-aggregation 评估 (例如在合成 IEEE batch 上前向)，而不是在 per-client 梯度上做——这限制了检测的 latency 与 false-positive rate。该工程约束应在任一公开实现中显式说明。

    11. Block III — Hybrid Physics-FM-LLM Stacks & Deployment#

    11.1 layered T3 architecture 的形式 spine#

    把 phase0b T3 的 layered 思想形式化：

    \[\underbrace{\text{LLM}_{\text{GAIA-class}}}_{\text{outer: NL interface}} \;\circ\; \underbrace{\text{FM}_{\text{GridFM-class}}}_{\text{middle: telemetry encoding + surrogate}} \;\circ\; \underbrace{\text{PINN/AC-PF layer}}_{\text{inner: differentiable physics}}\]

    读法：内层 PINN 保证 KCL/KVL 残差有界、提供 warm-start；中层 FM 把 (PMU + SCADA + AMI + topology) → state embedding \(\mathbf{z}\) → OPF surrogate；外层 LLM 仅承担 NL → tool-call / NL ← result 的解释。Audit-trail \(\tau\) 与 ECE 在每层独立可测——在 §11.4 四元 envelope \((\rho, \text{ECE}, \tau, \kappa)\) 下，该指标分解能力是 layered 设计相对 monolithic 工件的安全性区分。

    把每层职责分清的另一项好处是 版本演化 的解耦：内层 PINN 在物理建模标准更新 (CIM 版本、市场规则变更) 时单独升级，不需重训中层 FM；中层 FM 在新公司数据到位时单独更新，不影响外层 LLM 的 NL 协议；外层 LLM 在底层基础模型 (Claude / GPT / DeepSeek 等) 出新版时单独切换，不打扰物理与数值层。这种分层演化对 EMS 软件采购的实务有直接价值——经典 EMS 软件通常 5–10 年才大改一次，FM/LLM 半年迭代一次，单一 monolithic 工件几乎不可能在两个节奏上同时合规。layered 架构是把这两个节奏调和的工程选择。

    11.2 已有两层实例#

    11.2.1 PINN warm-start for OPF#

    PINN 训练以 KCL/KVL 残差为损失，输出作为 AC-OPF 求解器的 primal warm-start，并附 bound-tightening。报告在 AC-OPF 上 success rate 与 compute-speed 双升 (<authors need verify>, ResearchGate/arXiv 2024)。该工作是 inner + middle 双层组合：PINN 内、surrogate 中，外层 LLM 缺席。

    11.2.2 PIRL — Physics-Informed RL (MDPI Energies 2025, <authors need verify>)#

    物理约束作为 RL 的 safety filter，model-data hybrid drive 实时 OPF。Inner physics + middle policy；LLM 不在栈内。这是 phase0b T3 layered pattern 的另一独立实例。

    11.2.3 PE-GPT (community survey 2025, <authors need verify>)#

    PE-GPT 是 outer + inner 的两层组合：域适配 LLM (power-converter modulation) 以 ICL 联系 tiered PINN，对 power-electronics 参数做 conversational tuning。中层 FM 缺席——LLM 直接对话 PINN。这是 Argonne workshop (S5) 提出的 "LLM-as-interface, PINN-as-physics-core" 蓝图的最干净 demonstrator。

    11.2.4 NYISO physics-informed multi-task GridFM (NREL/MDPI Energies 2026, <authors need verify>)#

    §4.8 主表登记的 NYISO physics-informed GridFM (NREL/MDPI Energies 2026, <authors need verify>) 是 inner + middle 的最强单工件：FreqMixer adapter retarget 通用 TS-FM 到电网模式，GNN-embedded power-balance / zonal-topology 约束，multi-task head (load / LBMP / carbon / renewables)，SHAP explainability。

    在 NYISO 实时数据上报告对比 TS-FM baseline：load forecasting MAPE 减少 18.5% (至 2.14%)、price 减少 23.2% (至 7.8% MAPE)、emissions 减少 21.7%。这些改善的对照对象是 FM baseline，而非 well-tuned specialised LSTM/Transformer——head-to-head specialist baseline 非论文主对照 (本综述 hedge 规则下，引用此数字时必须显式说明对照对象)。该 hedge 与 §6.3 物理-informedness 的 4 分类需对齐：NYISO 工件的 physics-informedness 形态是 (1) 辅助损失 + (2) typed/GNN-embedded constraint，而非 (3) differentiable PF layer——后者仍是 Seam A3 空白。

    11.2.5 跨四个两层实例的对照#

    把 §11.2.1–§11.2.4 的四个两层实例放在一起对照可见：PINN warm-start 是 inner+middle (求解器)；PIRL 是 inner+middle (RL policy)；PE-GPT 是 inner+outer (跳过 FM)；NYISO physics-informed GridFM 是 inner+middle (FM)——四者中只有 NYISO 用 FM-class 中层，且只有 PE-GPT 接外层 LLM。把它们合并成"PINN ⊕ FM ⊕ LLM 三层"的最小修改不是 新方法，而是 接口工程：在 NYISO physics-informed GridFM 上加一层 LLM 解释 (类 GAIA / GridMind 的 NL 接口) 或在 PE-GPT 上插入 FM 中层，都能在不重构核心算法的情况下产出 §11.3 所需的三层工件。这个观察对 研究规划 有意义——它说明三层 artefact 不需要等待算法突破，只需要等待跨团队工程合作。LF Energy GridFM 与 NREL/MDPI 的 NYISO 工作群、以及 GAIA / GridMind 团队若能在 2026–2027 协调，三层 artefact 在原理上可在 2027 年内交付。

    11.3 缺失的三层端到端工件#

    §8.4 已说明：三层 PINN ⊕ FM ⊕ LLM 在 operator-grade SCOPF advisory 上的端到端工件 截止 2026 不存在。本综述对 可信复现路径 的建议是：

    1. 取 NYISO physics-informed GridFM 作 middle 锚点；
    2. 取 PE-GPT-style LLM-over-PINN 模式作 outer 锚点；
    3. 在两者之间插入 cross-modal adapter \(h_\psi\) (Seam A4)；
    4. 在 PGLearn + PFΔ (SCOPF expansion) + ElecBench 上联合评测，以经典 IPOPT + GAIA + GridMind 为三个独立 baseline；
    5. 报告 (\(\rho\), \(\text{ECE}\), \(\tau\), SHAP entropy) 四元组以兑现 §9.4 #5 的 measurement seam。

    该工件 ≠ 单篇论文；其 结构功能 是把 phase0b T2 (scale-vs-task) 与 T3 (physics-ML layered) 同时落到一个可比基线上。一旦该工件落地，"FM 替代 specialist"与 "FM 加层 specialist"两条对立路线的比较终于能在同一基准上以同一组指标做出可重复结论——这是当前最严重的结构空缺：在三轴 benchmark spine 上单独的 FM 工作（PowerPM、GridFM-v0）、单独的 specialist 工作（HGT-LGMP）、与单独的 LLM 工作（GAIA、GridMind）各自做评测，跨工作的数字不可直接比较，使得 "FM 是否值得"这一最根本的实务问题始终无法以经验回答。本综述把 §11.3 三层 artefact 列为最强 recommendation——不是因为它技术新颖，而是因为它是当前可见的、能让 FM-vs-specialist 的经验比较在同一基准上收敛的最小工件。

    11.4 部署 envelope：\(\rho\) (latency)、\(\text{ECE}\) (calibration)、\(\tau\) (audit)、\(\kappa\) (calibrated PI coverage)#

    §9.4 #5 列出的"latent measurement seam"在此被显式形式化为一个四元 deployment envelope：

    • \(\rho\) — wall-clock latency per inference (ms)。EMS 主表轮询 10 s 量级；advisory copilot 容忍 sub-second；closed-loop 容忍 ms。
    • \(\text{ECE}(\hat{p})\) — 校准误差 (forecasting / 多任务场景下取 回归形 PI-ECE)。Chronos-2 在工业 blog 报告 ~95% 经验覆盖率于 90% PI 上 (industrial report, not peer-reviewed)，是当前最接近 deployment-grade 的 PI 校准数字。
    • \(\tau\) — audit-trail completeness ratio (§8.2)。
    • \(\kappa\) — calibrated prediction-interval 经验覆盖率 (避免与 §8.3 的 DP 噪声方差 \(\sigma^2\) 重载)。

    无任何已知公开工作同时报告这四项。本综述把"联合报告 \((\rho, \text{ECE}, \tau, \kappa)\)"列为 §11.3 三层 artefact recommendation 的结构性评测要求。这一要求看似仅是 报告格式 的约束，但实际上构成了 layered hybrid 与 monolithic FM 路线在 §11.4 envelope 下的判别杠杆——layered hybrid 的每一层对其中一项指标有清晰承诺 (内层 PINN 负责 \(\text{ECE}\) 的物理基线、中层 FM 负责 \(\rho\)、外层 LLM 负责 \(\tau\) 的可解释性、组合负责 \(\kappa\))，而 monolithic 工件通常只能强约束其中一项 (TS-FM 强 \(\kappa\)、FM-OPF surrogate 强 \(\rho\)、纯 LLM 强 \(\tau\))。因此 四元联合报告 既是部署评测要求，也是架构选型证据。

    11.4.0 FM 优势的 boundary conditions（形式化）#

    把 FM-vs-specialist 之争升级为 boundary conditions：若以下条件成立，则 FM 路径相对 specialist 路径无优势 (或反之 disqualified)。

    1. 数据量边界：若下游样本 \(|\mathcal{D}_{\text{down}}| > N^*\) (其中 \(N^*\) 随任务内在维度与源-目标分布距离同阶，参 Hernandez et al. 2021 Scaling Laws for Transfer；Tay et al. 2022 Scale Efficiently；典型 \(N^* \propto (D_S/D_T)^\alpha\))，则 FM 迁移收益趋零。AC-OPF 类约束优化的内在维度被 KCL/KVL 严格约束，意味着 \(N^*\) 较小，这是 specialist GNN 在 PGLearn 上不易被 FM 抹平的理论上的原因。
    2. 任务异构性边界：若部署语境只关心 单一任务 (单一公司只买 load forecasting)，则 specialist 在 买方经济学 上永远更经济，与算法选择无关。PowerPM 44-task 报告之所以重要，正是因为它把任务集合多样性 \(H(\{\mathcal{T}_k\})\) 推高。
    3. 延迟边界：若 \(\rho_{\text{FM}} > \rho_{\text{closed-loop}}\) (closed-loop EMS 容忍 ms；当前 LLM-class 在主流 hardware 上 \(\rho \gg 100\) ms)，则 FM 路径直接 disqualified 进入 closed-loop tier，无论平均误差多低。
    4. Audit 边界：若 \(\tau < \tau^*\) (NERC CIP-008 / FERC Order 754 类要求 post-event 重构)，则即便 (1)–(3) 都满足，FM 也无法进入 EMS 主网部署——这不是软目标而是 合规否决。

    这四条 boundary 给 §11.3 的"为什么不是单一 FM"提供明确答复：layered hybrid 不是审美选择，而是 (3) + (4) 在 closed-loop tier 的硬约束下的必然——FM 在 outer/middle 提供泛化与解释，inner PINN 提供 ms-级数值正确性与可重建的物理 trace。

    与 Sutton (2019) Bitter Lesson 的正面交锋: Sutton 论断在 5–10 年视野上预言"塞先验进模型"长期被"算力 + 通用学习/搜索"抹平。在电力域有人据此主张：layered hybrid 的物理一致性 inductive bias 是 短期工程权宜，长期被纯 Transformer + scale 抹平。本综述不同意这一推论的强形式，理由分四层：(i) bitter-lesson 的 falsifier 在 grid 域是 可观察的——HGT-LGMP 在 PGLearn 10M-sample 体制下若仍稳定优于 plain transformer，则 explicit electrical PE 是 机理 而非 样本 优势；反之若被抹平，则 §4.10 热力图的 "拓扑显式编码" 一栏将随时间淡化，本综述对此保持开放。(ii) 算力扩张并不抹平合规约束——NERC CIP-008、IEC 62443/62351、FERC Order 754 不会因为模型规模扩大而放宽 audit-trail 要求；layered hybrid 在 §11.4.0 boundary (4) 上的优势是 制度 优势而非 算法 优势，与 Sutton 论域正交。(iii) 数据可得性 ceiling——bitter lesson 在 NLP/CV 上的胜利建立在 web-scale 语料 (\(10^{12}\) token, \(10^{10}\) image) 之上，电力域语料即便完成 §10 跨公司 FL 后乐观估计仍在 \(10^7\)–\(10^9\) 量级 (PGLearn 10M sample 是已知最大公开集合)，scaling law 的 渐近 区间在 grid 域可能不可达；这是 §1.2.1 boundary (a) 的另一面。(iv) layered 是 Bitter Lesson 的 合规约束版本——把 Sutton 论域中"算力 + 通用学习"局部部署到 middle FM + outer LLM 两层，把 inner PINN 作为不可妥协的物理一致性承诺；这一立场不是反对 Bitter Lesson，而是承认在 operator-grade 部署中存在 Sutton-外 的硬约束。综合四点，本综述在 §11.6(e) 把 layered hybrid 定位为 "Bitter Lesson 的合规约束版本"而非反例——这一定位的可证伪表述见 §12.14。

    11.4.1 layered hybrid 与 经典 EMS 工程 的衔接#

    把 §11 layered hybrid 放回经典 EMS 工程语境，再做一次 sanity check：内层 PINN 在 EMS 中已经 有对应物——经典的 Newton–Raphson 潮流、IPOPT-class SCOPF 求解器、PSAT/PSS-E 类暂稳分析——这些工具都是 显式物理一致性 的；中层 FM 在 EMS 中 没有 对应物，是新增的 跨任务表征层；外层 LLM 在 EMS 中也 没有 对应物，是新增的 自然语言接口层。这一对照说明，layered hybrid 的工程含义不是"用 FM/LLM 替代经典工具"，而是"在经典工具周围加两个新层"——内层不动，新增中层与外层。这一定位让 layered hybrid 的合规审批路径远比 "用 LLM 替代 OPF 求解器" 简单——因为关键的物理计算仍由经过认证的经典工具执行，FM/LLM 只承担辅助/接口职能。本综述把这一观察记入 §11.4 后，作为对 operator-grade 部署可行性 的乐观判断依据。

    11.5 Block III 整体小结#

    把 §8、§9、§10、§11 合起来看，Block III 的核心结论简化为三句：(1) benchmark 谱已成形 (PGLearn + PFΔ + ElecBench + ProOPF)，但缺 SCOPF-under-contingency 与 market clearing；(2) FL 机制成熟而 backbone 预训练未做，制度层 scaffolding 已就位；(3) layered hybrid 有四个两层实例而无三层端到端工件，§11.3 的 MVP 给出可执行路径。详细 what should be built 推到 §12.15，本节不重复。

    11.6 "Foundation Model" 作为话语对象 (sociology of science)#

    把 binocular 立场仅作为分类学选择是不充分的；本节追加一段元论述，给术语承诺一个 知识社会学 自觉。

    (a) 术语史：foundation model 一词由 Stanford CRFM 在 Bommasani 等 On the Opportunities and Risks of Foundation Models (2021) 中提出并推广，自诞生起即承担 修辞 + 技术分类 的双重功能。Bender 等 On the Dangers of Stochastic Parrots (FAccT 2021) 等批评指出，该术语放大了"scale + emergence"这一 未必成立 的假设，并把已存在多年的 self-supervised pretraining + transfer 范式重命名以主张话语权。

    (b) 修辞 inflation 与学术经济学：在 NLP 域取得话语势能后，"foundation model" 标签被快速借用到电力 / 医疗 / 气候等领域；论文标题中出现该词显著提高引用率，构成 学术经济 诱因。这一诱因解释了 2024–2026 同时出现四种"GridFM"的现象 (§5.9 已记)。§1.1 选择 binocular permissive 读法，是有意识接受这一 inflation 的同时通过 §5.9 / §4.8 "FM 准入声明" 在制度上对其加以约束——不把 OPF-HGNN 类纯监督 surrogate 与 SSL-pretrained FM 等量齐观。

    (c) 跨学科借用的认识论代价：NLP 域成熟的 "scale + transfer + emergence" 修辞迁移到电力域时，"emergent capabilities" 论断在 grid 数据规模 (≪ NLP web-scale) 下几乎不成立。§1.2.1 的 5 指标 (\(\rho\) small-data / full-data / OOD / latency-bounded / audit-bounded) 实际上是把 emergence 从 implicit assumption 拆为 explicit metrics——FM 的优势应在具体可测指标上落地，而非以"emergence"作为论断。

    (d) 资源分配政治学：foundation model 标签使资源 (算力、人力、政府资助、监管注意) 倾向集中于少数大团队 (IBM Research、State Grid Zhejiang、NYISO 这类有 ISO/utility 合作的团队)。这是 资源分配的政治学 而非纯技术问题，若不讨论则等同默认认可这一集中。此处仅记入事实，不作价值判断。

    (e) Bitter Lesson 的受限肯定：Sutton (2019) The Bitter Lesson 主张把人类领域知识塞进模型的方法长期看被 扩大算力 + 通用学习与搜索 抹平。在电力域，跨公司语料分布相似度高 (同样的 KCL/KVL、同样的发电拓扑类型)，transfer scaling laws 应比 NLP/CV web-scale 更陡；若数据增长可期 (PGLearn 10M、跨公司 FL)，则纯 Transformer + scale 在 2030 视野内有可能超越 typed GNN / electrical PE 这一代显式 inductive bias 架构——HGT-LGMP <3% gap 在 PGLearn 10M 体制下是否仍优于 plain transformer 是 open empirical question。但 合规与 audit 约束 (NERC CIP、IEC 62443) 使 operator-grade 部署必须保留物理一致性的显式承诺，与 Bitter Lesson 方法论不冲突但与其 部署形态 推断冲突。据此 layered hybrid 是 Bitter Lesson 的合规约束版本，而非其反例。

    合在一处：对"foundation model"一词的承诺是双层的——分类学上采 permissive 读法 (§1.1)，认识论上以 §1.2.1 的 5 指标、§4.8 的 FM 准入声明、§11.4 的 deployment envelope 把"FM 是否值得"的问题落到可测对象。术语本身不构成论证。

    12. Open Problems & Outlook#

    12.1 Seam A1 — Universal grid tokenizer (跨七模态)#

    Seam A1 (与 §4.1 modality 8 类、§4.11 log-scale 采样率梯度对齐)：跨 (waveform, phasor, SCADA, AMI, topology, weather, text) 的统一 tokenizer 在 2026 仍空白。gating 问题是 rate mismatch (kHz vs. 1/h ≥ 7 OOM)；候选 primitives 包括 Perceiver IO、multi-rate patching、mixture-of-tokenizers，但均未在 grid signal 上 validated。该 seam 与 §11.3 三层 artefact 是 upstream 关系——三层 artefact 的中层 FM 输入必须由 universal tokenizer 提供，否则 layered 假设退化为 modality-specific stack。

    12.2 Seam A2 — Topology generalization beyond IEEE cases#

    PFΔ 是当前最干净的拓扑泛化探针，但其拓扑来自 IEEE/GOC，真实 TSO 拓扑 (异构 switching state、变压器 tap、breaker-and-a-half、HVDC) 不在该 benchmark 内。所需补全：一个 operator-confirmed switching-events 的 real TSO topology corpus。HGT-LGMP 的 <3% optimality gap on N-1 (arXiv preprint, not yet peer-reviewed) 在该真实 corpus 上是否保持是关键 falsifier。

    12.3 Seam A3 — Differentiable AC-PF layer in backbone#

    物理残差作为辅助损失是当前主流；把 differentiable Newton–Raphson 作为 graph transformer block 内部一层 (类 OptNet) 是未实现的设计点。该 seam 是 §11.1 内层 PINN 与中层 FM 之间的 架构内嵌点——若实现，可减少 inner/middle 之间数据传递的 audit 表面。

    12.4 Seam A4 / B-S4 — Cross-modal alignment \(h_\psi\) + RAG over telemetry#

    §8.1 已展开。Blocker 是 paired-data corpus。LF Energy GridFM 是社区路径；任何 公司侧 paired-data release 都是 falsifying step。

    12.5 Seam A5 — SSM / Mamba 在 waveform 上#

    §4.2 "SSM on grid signals" 行 (absent) 与 §4.10 ASCII 热力图 (全 ○) 共同标记的最大架构空白。开放且可答的实证问题："在固定参数量下，Mamba 在 synchro-waveform 分类 / 故障定位上是否超过 temporal Transformer"，可基于现有 public waveform 数据集回答。该 seam 与 Block I 物理形式无 conflict，但若证实，可改写 §4.2 的"absent" 行。

    12.6 Seam B-S1 — Operator-grade adversarial-safety benchmark#

    §8.2 已展开。本综述把它列为 gating artefact：在该 benchmark 缺席的情况下，任何 LLM-agent 离开 advisory/sandboxed tier 都缺基础；按 phase0d §6 #3，没有该 benchmark 也意味着 "operator-grade closed-loop" 不可在文本中无引号断言。锚定 prior art (OWASP LLM Top 10 2025、NIST AI RMF 1.0 + GenAI Profile) 见 §8.2。主体分工：安全研究社区主导 + LF Energy GridFM / Argonne workshop 提供 venue。

    12.6.1 Seam B-S6 (新增) — Formal verification of typed GNN on AC-OPF#

    grid 域 typed GNN (OPF-HGNN / PI-TGN / HGT-LGMP) 在 输入空间结构化 + 物理约束有界 上比 NLP 模型更 tractable for formal verification (Reluplex, Katz et al. 2017；α,β-CROWN, Wang et al. 2021；GNN verification 子线索)。该 seam 是 B-S1 的 mechanism 补充——B-S1 是 benchmark, B-S6 是单一工件级别的安全保证手段。主体分工：单团队 (与 NN verification 社区合作)。

    12.7 Seam B-S2 — Rollback 的对抗性验证#

    Grid-Agent 的 rollback 自身未经 adversarial validation：planning agent 能否被构造性提示来产生 通过 validation agent 但实际不安全 的动作？通用 AI safety 文献的 self-validation failure mode 在 grid 场景下未演示。该 seam 与 B-S1 互补——B-S1 是 benchmark, B-S6 是单一工件级 verification, B-S2 是 mechanism red-team。在 OWASP 语境下，B-S2 同时命中 LLM06 (excessive agency) + LLM05 (improper output handling)，与 §8.2 的 prior-art 锚点共享论证基础。主体分工：安全研究社区主导 + Grid-Agent 团队 / 后续 closed-loop agent 工作配合。falsifier：若 2027 仍无任何 rollback red-team 的公开论文 / 数据集，则任何 simulated closed-loop with rollback 工件的安全承诺为修辞。

    12.8 Seam B-S3 — NL → SCOPF formulation 与 unit commitment#

    ProOPF 关注 OPF formulation，SCOPF / UC / 市场出清 不在公开 LLM 评测内。这是 phase0b T2 (scale-vs-task) 在 LLM 侧的实证空洞。

    12.9 Seam B-S5 — 操作员-LLM 交互协议未标准化#

    GAIA、Intelli-Dispatch-SQL、GridMind、X-GridAgent 各自定义 NL I/O 与 function-call schema。Model Context Protocol-style 在 grid EMS 上未被采用。每个公司集成仍是 bespoke。该 seam 是 工程 层面而非研究层面，但其缺失锁死了 agentic Thread B 的 demo-stage 边界。

    12.10 Seam C-S1 — 跨公司 GridFM 联邦预训练#

    §8.3 已展开。这是 internet-of-grid 叙述的 sine qua non。

    12.11 Seam C-S2 — Benchmark governance under audit regime#

    §9.5 已展开。建议路径是社区联盟 + 监管协调，而非论文创新。

    12.12 Seam C-S3 — SCOPF-under-real-time-contingency 上 bench#

    §9.4 #1 已展开。这与 Seam B-S3 互补：Seam B-S3 是 LLM 侧 NL → SCOPF formulation；Seam C-S3 是数值侧 SCOPF surrogate on contingency-conditioned data。

    12.13 Seam C-S4 — 三层 hybrid (PINN ⊕ FM ⊕ LLM) on operator-grade task#

    §8.4 与 §11.3 已展开。本综述的主结论性 recommendation。

    12.12.1 SCOPF benchmark 与 operator-grade benchmark v2 的 最小可信路径#

    把 §9.4.1 与 §12.12 Seam C-S3 合并，给出可执行路径：以 PGLearn IEEE-118 + GOC-500 子集为底盘，加三类增强 (bad data injection, topology drift, concept drift)，并人工标注一份 N-1 list (50–200 个 contingency)；评测指标延续 PGLearn 的 optimality gap 与 feasibility rate，新增 约束违反频率 与 求解时间分布尾部 两项。这一 最小可信版本 不需要真实 TSO 拓扑 (这是 Seam A2 的更高目标)，但已能区分纯 FM、纯 specialist 与 layered hybrid 在 contingency 体制下的表现差异。它对应 §12.13 三层 artefact MVP 的 评测对手 工件，二者配对即可让 §11.3 的 recommendation 进入 falsifiable 阶段。

    12.12.2 SCOPF 与 unit commitment：被结构性忽略的下游任务#

    把 §9.4 #1 与 §12.12 拉到一起明示：在 6 轴 taxonomy 的 下游任务 轴 (§4.4) 上，2026 公开文献的覆盖呈现明显倾斜——AC-PF 与 AC-OPF 被充分研究，load / renewable 预测被充分研究，NL 调度问答与 NL→formulation 被新一批 LLM 工作覆盖；但 SCOPF、unit commitment、ancillary service market clearing、real-time congestion management 这四项 operator 实际每天都要做的任务 在 FM/LLM 文献中近乎缺席。原因不复杂：(a) SCOPF 的 N-1 list 因公司而异，没有公开标准；(b) UC 的整数变量与 MILP 求解器集成度高，FM/LLM 难以提供差异化价值；(c) 市场出清涉及保密的报价信息与规则，没有公开数据；(d) congestion management 的真实工况依赖实时调度记录，公开度低。这四条共同的"非技术性"原因让 FM/LLM 研究在选择任务时系统性回避它们——但 operator-grade 部署 的真正难点恰在这些任务上。本综述把这一观察作为 §12 的强信号，认为下一阶段研究应主动闯入这些"被回避的任务"，即便代价是公开 benchmark 不齐全。

    12.13.1 三层 artefact 的 最小可信版本#

    为避免 §11.3 的 recommendation 被读作"理想型 artefact"，本综述把三层 artefact 的最小可信版本 (MVP) 单独勾画：内层使用现成 PINN warm-start (§11.2.1) 在 IEEE-118 + GOC-500 子集上训练，输出作为 AC-OPF 求解器的 primal initialization；中层使用 GridFM-v0 (公开权重) 在同一拓扑下做 telemetry-encoded embedding，并把 embedding concatenate 进 OPF surrogate head；外层使用 GAIA 或一个开源 7B–13B 量级 LLM (LLaMA-3 / Qwen / DeepSeek 当前公开权重) 加 RAG over IEEE-118 调度手册片段，提供 NL 接口。评测在 PGLearn IEEE-118 subset + PFΔ IEEE-118 N-1 split + ElecBench IEEE-related Q&A subset 上联合进行。这一 MVP 的好处是每一层都用现成组件，工程量集中在层间接口；其局限是仅覆盖小型 IEEE 系统，不直接说明 2000-bus 真实 TSO 可扩展性——但作为 proof of concept 已足够 falsify or validate "三层 hybrid 在 operator-grade 任务上有 measurable 收益" 这一基本命题。

    12.14 Binocular convergence 论断的可证伪化（双向）#

    本综述的核心论断在两条方向上都需有 falsifier：

    (单向 falsifier — 论断不成立)：若 2027–2028 在 5 个 seam (A1, A4, C-S1, C-S2, C-S4) 上全部不进展——具体地，仍无 paired-data corpus、无端到端三层 artefact、无跨公司联邦预训练 PoC——则 "binocular foundation model" 应被认定为 修辞 而非研究纲领，本综述的二歧立场 collapse 为"两条独立线索"。

    (对称 falsifier — 论断方向也可被证伪)：若 2028 时 numerical GridFM 与 LLM-agent 两条线索仍未在 任何 共享 benchmark 上同时被评测、未在 任何 公开工件中被同时部署——即工程社群以实证表明两者互不相干——则 binocular 立场是 观察者强加的统一，应退回"两套独立分类学"读法。这条 对称 承诺让本综述的认识论立场不偏向"必然收敛"的一面，而是把收敛假设挂在可观测的工程现象上。

    两条 falsifier 共同构成本综述的认识论收尾承诺。

    12.14.1 三条 "what-if" 推断#

    最后给出三条 "what-if" 推断，把本综述的论断与未来情景联系起来：

    (I) 若 paired-data corpus 在 2027 年开放：cross-modal adapter \(h_\psi\) 将成为本领域 研究热点 的第一候选；CLIP-style 对比 + KL-style 校准两条路线的对比在 2028 年应出现首批论文；下游应用 (RAG over telemetry + NL 调度问答 + 跨模态异常检测) 将快速生长。本综述 §8.1 与 §11.3 的 recommendation 将在该情景下被加速验证。

    (II) 若联邦预训练 PoC 在 2027 年由 LF Energy 落地：GridFM 这一术语在 制度 层面首次实现，"internet-of-grid" 叙述从修辞落到具体工程实例；后续争议从"FM 能否做"转向"FM 的 scaling law 是否 hold"——这是 phase0b T2 (scale-vs-task) 的下一阶段问题。本综述 §10 的论断将进入新阶段，但 §9.5 governance 缺口需在同期推进，否则 PoC 的成果无 audit 基础。

    (III) 若 adversarial-safety benchmark 在 2027 年达成社区共识：B-S1 / B-S2 / C-S2 三个 seam 同时收敛；任何 Grid-Agent 类工作进入 simulated-closed-loop tier 的 准入路径 首次形成；rollback 的 adversarial validation 成为标准评测项；NERC / IEC audit 框架可参照该 benchmark 拟定行业 baseline。这是把 LLM-agent 从 demo 推到 EMS 实际工程的最关键 unlock。

    三条 what-if 互不冲突，但其推进对主体差别巨大：(I) 需要 utility 主导、(II) 需要 utility 联盟 + 工程组织 (LF Energy) + 政府研究机构 (ANL) 协同、(III) 需要安全研究社区主导。把它们并列写出可帮助下一个调研周期 (Phase 2 +) 判断哪一条最先打通。一个相对悲观的备注是：三条 what-if 的主体差异意味着它们不是 可同时推进 的三件事——任何 utility 在同一时期通常只能主导一件大事 (paired-data release 或联邦预训练 PoC 二选一)，而安全社区与电力工程社区的语言尚未充分对话，致使 (III) 的推进对其他两件事的实现路径有显著耦合 (例如若 (III) 滞后，则 (II) 的 PoC 即便完成也无 audit 框架可对接)。综述据此把三条 what-if 视为 相互依赖 的路线图节点，而非可独立调度的工件清单。

    12.15 未来两年 (2026–2028) 应产出什么#

    按本综述判断，最有 ROI 的三件工件依优先序：

    1. paired-data (grid state, operator narrative) corpus 的开放 release (LF Energy GridFM 路径)；
    2. 跨公司 GridFM 联邦预训练 PoC (LF Energy + ANL governance)；
    3. operator-grade adversarial-safety benchmark with \(\tau\) 指标 (Argonne workshop S5 推动)。

    完成上述三件后，三层 artefact (Seam C-S4) 才有可证伪的评测基底。

    这三件工件的优先序不是按技术难度排，而是按依赖关系排：paired-data corpus 是 cross-modal adapter (Seam A4) 与 RAG-over-telemetry (Seam B-S4) 的前置；联邦预训练是 GridFM scale-up 的前置，也是 audit-trail \(\tau\) 在跨公司语境的前置；adversarial-safety benchmark 是把任何 LLM-agent 从 advisory 抬到 simulated-closed-loop tier 的 gating 工件。没有前两件，三层 artefact 只能在合成 + 单公司语料上工作，对 internet-of-grid 论断无说服力；没有第三件，三层 artefact 的外层 LLM 无 audit 基础，无法进入更高 safety tier。本综述按这一依赖图把 §12 写成一个推进路线图而非简单的"open problems list"，旨在让后续研究在 优先序 上有可参照的座标。

    另一条值得指出的方向是：以上 12 个 seam 中，A1 / A3 / A5 是 单团队可解 的研究问题 (universal tokenizer 设计、differentiable AC-PF layer、Mamba on waveform)，A2 / A4 / B-S1 / B-S2 / B-S3 / B-S5 / C-S3 / C-S4 是需要社区协同 的工件 (新 benchmark / 新协议 / 新对比基线)，C-S1 / C-S2 是需要 机构协同 的工件 (跨公司、跨监管)。按这一分层，单独的学术团队可优先攻 A1 / A3 / A5，社区联盟 (LF Energy GridFM、Argonne workshop) 可优先攻第二组，监管 + 行业则负责 C-S1 / C-S2。本综述据此把"未来两年应产出什么"具体化为一个 按主体分工 的工件清单，而不是"未来某个团队应该做某些事"的笼统建议。

    • Ansari et al., "Chronos: Learning the language of time series," arXiv 2403.07815, 2024. ★ tokenization-via-quantization 路线，对位 §4.1 中数值标量 TS 的"什么是 token"问题。
    • Gu & Dao, "Mamba: Linear-time sequence modeling with selective state spaces," 2024. ★ §4 中明确标注的"state-space backbone 在电网信号上缺席"的对位文献，理解为何 PMU 长序列尚未出现 SSM 应用。

    Safety / verification#

    • OWASP "Top 10 for LLM Applications" 2025. ★★ §7.2 adversarial-safety benchmark 的外部规范；LLM01 prompt injection、LLM06 sensitive info disclosure 是 §11 dispatch NL 安全章节的引用基线。
    • NIST AI Risk Management Framework, Generative AI Profile (NIST AI 600-1), 2024. ★★ §11 governance scaffolding 的美国侧规范；与 Argonne workshop 的 deployment-tier 框架互相强化。
    • Wang et al., "α,β-CROWN: A bound propagation-based neural network verifier," VNN-COMP 2021–2024. ★ §11 给出 formal-verification baseline，是把 advisory-tier 推到 simulated-closed-loop tier 的形式化工具——电网 NN surrogate 已开始引用其作为 OOD-safety 工具。

    Position pieces / contrarian#

    • Sutton, "The Bitter Lesson," 2019. ★★ §11 scale-vs-specialist 张力的对位经典；本综述 §5 的 "Hamann 3–4 OOM speed-up vs. measured" 论证即在与此命题对话。
    • Tay et al., "Efficient transformers: A survey," ACM Computing Surveys, 2022. ★ 把 §4 Transformer/GNN/graph-transformer 的效率讨论置于 NLP 侧已有结论之中；用以避免本综述重新发明效率分类法。
