    Summary (≤500 字)#

    条件扩散模型 (conditional diffusion) 已成为可再生能源 (wind / solar / load) 场景生成的主流方法，但当前文献在三条互相正交的轴上同时出现结构性断裂，且没有任何已发表的 survey 把这三条轴连起来读。

    轴 I — 物理约束在扩散管线中的安置位置 (constraint placement)。 DDPM / score-SDE 管线天然暴露六个插入点：P1 数据预处理、P2 score network 内的 physics-informed loss、P3 reverse-step gradient guidance、P4 inter-step projection \(\Pi_\mathcal{F}\)、P5 hard output layer \(L_\mathcal{F}\)、P6 decision-aware loss。可再生能源 diffusion 文献集中在 P1–P3，Dvorkin 组 (Hoseinpour & Dvorkin, arXiv 2506.11281, 唯一在 Phase 0 verified 的作者归属) 是 P3 的代表性工作；P5 对可再生能源完全为空；P6 仅在非扩散 cGAN (Operation-Adversarial Scenario Generation, EPSR 2022 — 修正 Phase 0b 把它误置于 Applied Energy 的错误) 和 generic ML (Diffusion-DFL, arXiv 2510.11590) 中出现，从未在 renewable-diffusion 出现。

    轴 II — Downstream-cost 评估。 调研池内所有 diffusion 论文均报告 CRPS / energy score / variogram / pinball，但没有任何一篇运行 stochastic unit commitment、DRO、或 value-of-stochastic-solution (VSS) / EVPI。Cramer et al. (Validation Methods…, IEEE T-PWRS 2022, 来自 arXiv 2110.14451 <verify-Phase-2>) 早已在 pre-diffusion 时代命名了这一缺失层。Gap 持续存在的原因有四：基础设施成本、审稿惯例、方法论文偏置、以及 gradient-transport gap (差分 UC surrogate 与 diffusion sampler 之间的梯度通道未被打通)。

    轴 III — Conditioning ladder × diffusion-vs-transformer。 Conditioning 在过去五年沿 ladder 爬升了五级 (none → scalar → time-series covariate → graph → text/LLM)；power-diffusion 占据 rung 2–3，rung 5 (text-conditioned scenario) 对可再生能源为空。比较断言"diffusion 在可再生能源 scenario 上击败 probabilistic transformer"仅靠 2021 年非可再生基准 (TimeGrad 0.0206 vs Transformer-MAF 0.0207 in electricity, 0.0001 的差距在 run-to-run variance 内) 经传递性间接支撑；2024 年 TACTiS-2 在 GluonTS 上已反超，2026 年 foundation-transformer 在 ERCOT-PERFORM 上的 benchmark (P15, arXiv 2604.22077) 没有任何 diffusion entry。

    三条轴在一个结构点上交汇：P6 (decision-aware loss) 既是 constraint placement 的最高层、也是 conditioning ladder 的终点 (cost-as-implicit-condition)、也是评估层级的 Tier 4。本 survey 将三条裂缝读为同一个结构问题——这个领域在错误的轴上、用错误的 loss、在错误的 testbed 上做优化——并把 P5 / P6 / rung-5 / matched diffusion-vs-foundation-transformer benchmark 作为 frontier (F1–F8) 明确点名。

    2.0 电力系统最小术语包 (ML reader's onboarding)#

    全文反复引用以下电力系统概念；首次出现处仅在此一次定义。

    • UC (Unit Commitment)：决定未来 24 h 每台火电机组每小时开/关 (整数 0/1 决策) 以最小化运营成本，受 capacity / ramp / reserve / network 约束。是 day-ahead market 的核心调度问题。本 survey 中 UC 是 Tier 4 评估的 default 决策模型。
    • SP-UC (Stochastic UC)：UC 在风/光/负荷不确定下，目标变为期望成本 \(\mathbb{E}[c_{\mathrm{op}}]\)，通过 scenario set \(\{\mathbf{x}^{(k)}\}_{k=1}^K\) 离散化期望。是 §7 Tier 4 与 §9 P6 训练的核心 testbed。
    • Dispatch / economic dispatch：在 commitment 决策已定后，决定每台机组每小时实时出力 (连续变量 LP 问题)，与 UC 的整数 commit 决策互补。
    • Ramp rate：机组在相邻时刻输出的最大变化 (MW/min)，例如燃煤约 2 % capacity / min。Ramp 是 UC 的关键时间耦合约束。
    • Reserve：留给 contingency / 不确定性的 spare capacity，分 spinning / non-spinning 等。Reserve adequacy 指 commit 后机组群是否有足够 ramp 能力应对偏差。
    • KCL (Kirchhoff Current Law)：每个节点 \(\sum P_{\mathrm{in}} = \sum P_{\mathrm{out}}\)，即节点功率平衡，是 power flow 的核心等式约束。
    • AC power flow / DC-OPF：AC PF 是完整非线性方程 (含 \(V \cos\theta\), \(V \sin\theta\))；DC-OPF 是线性化近似 (相角线性, 忽略无功)，tractable LP 形式。AC-feasibility 比 DC-feasibility 严格得多，也难得多——P4 在 AC manifold 上的非凸是 W6 选择 P3 (gradient guidance) 而非 P4 (projection) 的根本原因。
    • DRO (Distributionally Robust Optimization)：不信任 single distribution，在"真实分布在某个 ball 内" 的假设下做 worst-case 优化；ambiguity set 是该 ball；Wasserstein \(W_p\) 是常见 ball 度量。
    • VSS / EVPI (Value of Stochastic Solution / Expected Value of Perfect Information)：分别量化"更好的不确定性表示" 与"完美信息" 各能买到多少成本下降。在 §2.7 形式化。
    • Net load：总负荷 \(-\) 风/光出力，是火电要服务的"剩余"部分；renewable penetration 高时 net load 波动大。
    • Redispatch volume：在 real-time 时刻，day-ahead UC 的决策不符合实际 net load 时，需要紧急上下调机组的总 MWh；直接对应 ISO 的 imbalance cost。
    • Dunkelflaute (德语"阴暗无风")：多日同时风小 + 光弱的 rare regime，是 renewable-heavy 电网的最严苛 reserve 测试场景；§7.6 / §10 F6 / F8 反复使用。
    • ISO (Independent System Operator)：区域电网调度机构 (e.g. ERCOT, NYISO, CAISO)；day-ahead market 是提前一天竞价 + UC 优化的市场环节。
    • Scenario reduction：给定大样本 \(\{\mathbf{x}^{(n)}\}_{n=1}^N\)，选 \(K \ll N\) 代表 \(\mathcal{S}\) 使其在 Wasserstein 距离下逼近经验分布；是 SP / DRO 的上游必经预处理 (随机优化求解器在 \(K\) 上是线性甚至超线性复杂度)。
    • MILP / LP relaxation：UC 原本是 MILP (NP-hard)；LP relaxation 把 0/1 变量松弛到 \([0,1]\)，tractable 且可微，是 F3 (P6 decision-aware training) 的工程钥匙。
    • KKT differentiation：对优化问题 KKT 条件做隐函数定理，得到优化解对参数的梯度；是 DFL (§9.3) 的标准工具。
    • 测试系统：IEEE 14/30/39/118-bus 是经典 transmission 测试网络；RTS-GMLC (Reliability Test System–Grid Modernization Lab Consortium) 是含 wind/solar 的现代化测试集；NREL WTK (Wind Toolkit) 与 SURFRAD 是 wind / solar 历史数据集；ERCOT PERFORM 是 2026 年发布的高分辨率 renewable benchmark 数据集 (§8.2)。

    2.1 DDPM 与 score-SDE#

    符号约定 — 两个 \(T\) 必须区分：全文使用 \(T_{\text{horizon}}\) 表示场景长度 (\(\mathbf{x}_0 \in \mathbb{R}^{T_{\text{horizon}} \times D}\), 例如 day-ahead 96 步 × \(D\) 通道) 与 \(T_{\text{diff}}\) 表示扩散步数 (反向链总步数, 例如 DDPM 1000、DDIM 50)。这一区分对 §5–§9 不可省略：P3 / P4 的 \(\eta_t\) schedule、P6 的 pathwise gradient through DDIM 都 仅 在 \(T_{\text{diff}}\) 维度上展开，而 ramp / KCL 等约束沿 \(T_{\text{horizon}}\) 维度展开。

    DDPM (denoising diffusion probabilistic model) 定义在长度 \(T_{\text{horizon}}\)、\(D\) 通道的清洁场景 \(\mathbf{x}_0 \in \mathbb{R}^{T_{\text{horizon}} \times D}\) 上的 Markov 前向链：

    \[q(\mathbf{x}_t \mid \mathbf{x}_{t-1}) = \mathcal{N}(\mathbf{x}_t; \sqrt{1-\beta_t}\,\mathbf{x}_{t-1}, \beta_t \mathbf{I}), \quad t = 1, \ldots, T_{\text{diff}},\]

    其中 \(\{\beta_t\}\) 是 noise schedule，\(\alpha_t = 1 - \beta_t\)，\(\bar{\alpha}_t = \prod_{s \le t} \alpha_s\)。其闭合形式 forward marginal (直觉：从清洁数据 \(\mathbf{x}_0\) 出发，\(t\) 步后变成什么分布——闭合 Gaussian 使训练时能直接采样 \(\mathbf{x}_t\) 而不必走 \(t\) 步链)：

    \[q(\mathbf{x}_t \mid \mathbf{x}_0) = \mathcal{N}(\sqrt{\bar{\alpha}_t}\,\mathbf{x}_0,\,(1-\bar{\alpha}_t)\mathbf{I}).\]

    逆向链由参数化网络 \(p_\theta(\mathbf{x}_{t-1} \mid \mathbf{x}_t, \mathbf{c})\) 学习，其中 \(\mathbf{c}\) 是条件向量 (NWP 协变量 / 模式标签 / 文本嵌入 / 图特征)。\(\epsilon\)-参数化对应 noise prediction network \(\epsilon_\theta(\mathbf{x}_t, t, \mathbf{c})\)，训练目标为：

    \[\mathcal{L}_{\text{simple}} = \mathbb{E}_{t, \mathbf{x}_0, \epsilon}\left[\|\epsilon - \epsilon_\theta(\mathbf{x}_t, t, \mathbf{c})\|_2^2\right], \quad \epsilon \sim \mathcal{N}(\mathbf{0}, \mathbf{I}).\]

    Score-SDE 视角下，等价的 score network 是 \(\mathbf{s}_\theta(\mathbf{x}_t, t, \mathbf{c}) \approx \nabla_{\mathbf{x}_t} \log p_t(\mathbf{x}_t \mid \mathbf{c})\)，并通过 reverse-time SDE 采样。直觉：score function \(\nabla \log p\) 指向数据高密区域；沿 score 方向上升 = 朝真实数据走，沿其负方向下降 = 走向 prior。P3 (§2.8) 把"约束违反"做成一个额外的"似然"信号叠加在 score 上，正是该直觉的直接利用。

    Tweedie estimator 在反向采样中至关重要 (用于 P3 gradient guidance 和 P4 projection)：

    \[\hat{\mathbf{x}}_0(\mathbf{x}_t, t) = \frac{\mathbf{x}_t - \sqrt{1-\bar{\alpha}_t}\,\epsilon_\theta(\mathbf{x}_t, t, \mathbf{c})}{\sqrt{\bar{\alpha}_t}}.\]

    直觉：\(\hat{\mathbf{x}}_0\) 是模型在 noisy \(\mathbf{x}_t\) 处对清洁版本 \(\mathbf{x}_0\) 的当下最佳猜测。P3 在这个猜测上算约束违反梯度，而不是在 \(\mathbf{x}_t\) 本身上算——因为 noisy \(\mathbf{x}_t\) 的 capacity / ramp / KCL 没有物理意义 (它是 \(\mathbf{x}_0\) + 高斯噪声)，对它算约束违反量在数值上和物理上都是错的。Tweedie 提供"假设噪声已被去除后样本应是什么样" 的可微估计，因此构成 P3 / P4 全部技术叙事的核心钩子。

    DDPM 与 score-SDE 的等价性：Song et al. (ICLR 2021) 证明 DDPM 的离散 Markov 链可以视为连续时间 forward SDE \(\mathrm{d}\mathbf{x} = f(\mathbf{x}, t) \mathrm{d}t + g(t) \mathrm{d}\mathbf{w}\) 的离散化；score function \(\mathbf{s}_\theta \approx \nabla_{\mathbf{x}_t} \log p_t\) 与 noise prediction \(\epsilon_\theta\) 通过 \(\mathbf{s}_\theta(\mathbf{x}_t, t) = -\epsilon_\theta(\mathbf{x}_t, t) / \sqrt{1-\bar{\alpha}_t}\) 联系。两种视角各有优势：DDPM 视角更接近 ELBO 推导，便于讲解；score-SDE 视角更适合理解 P3 (gradient guidance)。Phase 0 调研池中，CLDM / CAL-DM / MS-CADM 等 power-renewable 论文几乎全部采用 DDPM 视角；Hoseinpour & Dvorkin (W6) 与 Score-based Offshore Typhoon Diffusion 采用 score-SDE 视角。本 survey 在 §5 之后默认 score-SDE 视角，因为 P3 / P4 在该视角下数学更紧凑。

    2.2 Classifier-free guidance (CFG)#

    CFG 通过同时训练条件与无条件 noise prediction (后者由随机 drop \(\mathbf{c}\) 实现) 得到：

    \[\tilde{\epsilon}(\mathbf{x}_t, t, \mathbf{c}) = (1+w)\,\epsilon_\theta(\mathbf{x}_t, t, \mathbf{c}) - w\,\epsilon_\theta(\mathbf{x}_t, t, \varnothing),\]

    其中 \(w\) 是 guidance scale。\(w\) 越大，条件对齐越强，但模式覆盖收缩 (mode coverage shrinks)——这是 §7 evaluation 章节中 coverage–consistency trade-off 的核心机制。Dynamic-CFG 在 2025 年的工作进一步表明，trade-off 在 denoising step 上是不均匀的：早期 step 高 \(w\) 会塌缩到"平均样本"，中期 step 才是 high-frequency 内容塑形的窗口。

    CFG 在图像 diffusion 中是控制可控性的标准工具 (Ho & Salimans 2022)，在 power-renewable diffusion 中通过 cluster / regime label 作为 \(\mathbf{c}\) 实现可控生成。但 \(w\) 不是一个 "tune-once 全 setting 都适用" 的超参数：相同 \(w\) 下，rare regime 的尾部覆盖与 common regime 的尾部覆盖会沿不同曲线变化。这是 §10 F6 的核心 frontier——一张 \(w\)-sweep × tail-coverage figure 是 任意 CFG-conditioned power diffusion 论文都应附带的诊断。

    2.3 Latent diffusion 与 conditional latent diffusion#

    Latent diffusion 把 diffusion 从原始空间 \(\mathbb{R}^{T_{\text{horizon}}\times D}\) 搬到 encoder \(\mathcal{E}\) 学到的压缩空间 \(\mathbf{z}_0 = \mathcal{E}(\mathbf{x}_0)\) 中，由 decoder \(\mathcal{D}\) 反向映回。这在场景生成中带来两个好处 (采样加速 + 条件耦合更易) 和一个 well-documented 失败模式：conditioning collapse (本 survey 采用此命名以与经典 VAE 的 posterior collapse 区分；这里"collapse" 的对象是条件嵌入 \(\mathbf{c}\) 而非 latent \(\mathbf{z}\) 塌缩到 prior)，即当条件嵌入相对 latent 容量较小时，逆向链会忽略 \(\mathbf{c}\)，退化为无条件生成。CAL-DM (W4 in §5 — Cross-Attention Latent Diffusion, SSRN 2025 <verify-Phase-2>) 是 Phase 0 调研池中唯一显式以 conditional mutual information (CMI) 辅助目标对抗 conditioning collapse 的论文——但 CMI 辅助本身不是 CAL-DM 的发明，而是从 VAE 时代的 InfoVAE / β-VAE / mutual-information-bound 家族 (Zhao et al. 2017, InfoVAE: Information Maximizing Variational Autoencoders；Higgins et al. 2017, β-VAE) lift 到 latent diffusion 的直接继承。这一 lineage 在 §4.4 末段 (coverage-consistency 的家族 lineage) 进一步展开。

    为什么 power-renewable 文献偏向 latent diffusion 而非 raw-space diffusion？ 两个原因：(i) 场景长度 \(T\) 在 day-ahead 用例下是 96 步 (15-min × 24h) 或 288 步 (5-min × 24h)，raw-space diffusion 在这一长度上 attention / convolution 成本可控，但 multi-channel + 多场站推上去后 raw-space 张量维度爆炸——latent diffusion 通过 encoder 把通道维度压缩 5–10 倍；(ii) NWP / pattern label 等条件天然适合在 latent 空间通过 cross-attention 注入。但 latent space 也是 posterior collapse 的舞台——CAL-DM 用 CMI 项做对抗，是目前唯一显式动作。

    2.4 Discrete-token 与 LLM-guided diffusion#

    Phase 0c-C Seam C5 强调："diffusion" 在当前文献中指向至少三个不同的对象：

    1. Continuous-noise DDPM / score-SDE — 上述 §2.1 含义，是 power-renewable 文献的主流。
    2. Discrete-token language diffusion (LEAF-class, EMNLP 2025 Findings <verify-Phase-2>) — 在 LLM token space 中做 masked-token denoising，把"扩散"层级搬到离散符号。该家族与 continuous-noise diffusion 在数学对象上不同；§8 head-to-head 比较表中必须保持家族区分。
    3. LLM-guided continuous diffusion (LTSM-DIFF, arXiv 2602.00040; T2S, IJCAI 2025 <verify-Phase-2>) — 在 continuous diffusion sampler 之上叠加 LLM 派生的 conditional guidance，是 conditioning ladder rung 5 的代表。

    家族区分对 §8 比较至关重要：discrete-token diffusion (LEAF) 在数学对象上更接近 BERT 风格的 masked language model，而非 DDPM；如果 §8 head-to-head 表把 LEAF 与 continuous-noise diffusion (TimeGrad, CSDI) 列在同一行，会导致结论混淆——"diffusion wins" 可能是 LEAF 在 LLM 强先验下的胜利，而非 score-matching 范式的胜利。Phase 0d §6.6 已专门要求 §8 比较表保持家族区分。

    2.5 Distributional metrics#

    CRPS (Continuous Ranked Probability Score):

    \[\mathrm{CRPS}(F, y) = \int_{-\infty}^{+\infty} (F(z) - \mathbb{1}\{y \le z\})^2 \, dz,\]

    其中 \(F\) 是预测的累积分布函数，\(y\) 是观测。Energy score (multivariate CRPS 的能量分析):

    \[\mathrm{ES}(F, \mathbf{y}) = \mathbb{E}_{\mathbf{X} \sim F}\|\mathbf{X} - \mathbf{y}\| - \tfrac{1}{2}\mathbb{E}_{\mathbf{X}, \mathbf{X}' \sim F}\|\mathbf{X} - \mathbf{X}'\|.\]

    Variogram score (Scheuerer & Hamill 2015 <verify-Phase-2>) 抓取空间-时间相关结构；pinball loss 抓取分位数；reliability diagram 抓取边缘标定。这些是 §7 Tier 1–2 的标准工具。

    CRPS / ES 的 proper-scoring-rule 性质：CRPS 与 ES 都是 strictly proper scoring rules——预测分布 \(F\) 等于真实分布 \(G\) 时 score 最小，且不存在使 score 更低的 \(F \neq G\)。这一性质使 CRPS / ES 成为 Tier 1–2 的"安全选项"。但 proper-scoring-rule 性质不保证 与下游决策相关——两个 score 相同的分布可以诱导完全不同的运营成本。这是 §7 Tier 4 必要性的根本理论原因。

    2.6 Projection 与 scenario reduction#

    Feasibility set \(\mathcal{F} \subset \mathbb{R}^{T \times D}\) 定义为 capacity / ramp / KCL / balance 约束的交集。Projection operator \(\Pi_\mathcal{F}: \mathbb{R}^{T\times D} \to \mathcal{F}\) 用于 P4 (§5.4)。Hard output layer \(L_\mathcal{F}\) 在 P5 (§5.5) 给出可微分映射到 \(\mathcal{F}\) (KCLNet-style)。

    Scenario reduction：给定大样本 \(\{\mathbf{x}^{(n)}\}_{n=1}^N\)，选择 \(K \ll N\) 的代表 \(\mathcal{S} = \{\mathbf{x}^{(k)}, \pi_k\}\) 使其在 \(p\)-Wasserstein 距离 \(W_p\) 下最接近原经验分布。这是 SP / DRO 上游的标准 pre-processing。

    Projection 的两类失败模式：在凸 \(\mathcal{F}\) 上 \(\Pi_\mathcal{F}\) 唯一且可微 (除了 boundary 集合)，所有理论性质良好；在非凸 \(\mathcal{F}\) 上 (例如包含 AC power flow 等式约束) projection 既不唯一也不连续——P4 在该情况下退化为 heuristic projection，理论保证消失。Phase 0c-A W9 (PGDM) 的理论保证只覆盖凸场景，这是为什么 power systems 的 AC-feasibility (本质非凸) 上 P4 一直困难、而 Hoseinpour & Dvorkin (W6) 选择 P3 而非 P4 的根本原因。

    2.7 Decision-aware 量#

    Operating cost \(c_{\mathrm{op}}(\cdot)\) 定义为给定场景下的 stochastic UC / OPF / DRO 的最优目标值。cost-CRPS (Phase 0c-B Seam 3) 定义为 CRPS 在 \(c_{\mathrm{op}}\) 分布上的取值——对每个条件 \(\mathbf{c}\)，比较由生成场景诱导的运营成本分布 vs 由 oracle 场景诱导的。Commitment Hamming distance \(d_H(u_1, u_2)\) 对两个承诺向量 \(u_1, u_2 \in \{0,1\}^{G\times T}\) 计算 0-1 不一致位数。VSS (Value of Stochastic Solution) 与 EVPI (Expected Value of Perfect Information) 是经典 SP 量：

    \[\mathrm{VSS} = \mathbb{E}[c_{\mathrm{op}}(x^*_{\mathrm{EV}})] - \mathbb{E}[c_{\mathrm{op}}(x^*_{\mathrm{SP}})], \quad \mathrm{EVPI} = \mathbb{E}[c_{\mathrm{op}}(x^*_{\mathrm{SP}})] - \mathbb{E}_\xi[c_{\mathrm{op}}(x^*(\xi))].\]

    这些是 §7 Tier 4 与 §9 decision-aware chapter 的核心工具。

    VSS / EVPI 在 renewable-heavy 系统中变大：经典 SP 文献 (Birge & Louveaux) 在火电主导的系统上报告 VSS ≈ 0.5–2 %；renewable penetration 升高后，由于风能 / 太阳能的尾部行为不能被 deterministic / EV 解充分捕获，VSS 显著上升 (现代研究报告 5–15 % 量级在高 renewable 占比的系统上 <verify-Phase-2>)。这意味着在 renewable-heavy 场景下，scenario quality 对运营成本的杠杆比火电时代更大——而这正是为什么 Tier 4 的空白在当下尤其严重的原因。

    2.8 P3 与 P4 的数学钩子#

    P3 (reverse-step gradient guidance) 把 score 用约束违反梯度修正：

    \[\tilde{\mathbf{s}}(\mathbf{x}_t, t, \mathbf{c}) = \mathbf{s}_\theta(\mathbf{x}_t, t, \mathbf{c}) - \eta_t \nabla_{\mathbf{x}_t}\, c(\hat{\mathbf{x}}_0(\mathbf{x}_t, t)),\]

    其中 \(\eta_t\) 是 constraint-guidance scale (step-dependent)，\(c(\cdot)\) 是约束违反量 (e.g. AC power balance residual)，\(\hat{\mathbf{x}}_0\) 是 Tweedie estimator。P4 (projection) 直接对 \(\mathbf{x}_{t-1}\) 或对 decoded \(\hat{\mathbf{x}}_0\) 做 \(\Pi_\mathcal{F}\)。

    实际数值范围 (供参考)：在以 IEEE 118-bus 风电场景为例的标准 SP-UC 设置下，运营成本 \(c_{\mathrm{op}}\) 量级约 \(10^6\)–\(10^7\) 美元 / day；VSS 在 5–15 % renewable penetration 下约 \(0.5–2\) % (典型值 \(5–20\)k 美元 / day)；commitment Hamming \(d_H\) 在两 cost-near-optimal 解之间常为 \(10–100\) (对应 \(1–10\) % 决策位)；redispatch volume 在重大 forecast error 后可达 \(200–500\) MWh (典型 ISO 一天 redispatch 总量 \(5\%–10\%\) 总发电)。这些量级是 §10 F1 testbed 设计的 sanity-check 起点；任何 diffusion 论文 report 的 Tier 4 数字若 远离 该量级 (例如 VSS = 50%) 应触发方法论 sanity-check。

    3. Generative-family taxonomy#

    本章的核心目的是把"diffusion" 在当前文献中所指的 至少三个不同的数学对象 显式区分，并把 diffusion 之外的对照家族 (GAN / VAE / NF / autoregressive transformer) 与 diffusion 的方法学关系梳理清楚。为什么这一区分至关重要？ §8 head-to-head 比较表如果不做家族区分，会得出错误的结论——例如把 LEAF (discrete-token language diffusion) 的胜绩归功于 score-matching 范式，但实际上 LEAF 的优势可能来自 LLM 强先验而非 diffusion 本身。Phase 0d §6.6 已把这一 hygiene 列为 fact-check register 的一项。

    3.1 三分支扩散#

    (承接 §2.4 的家族区分声明) "Diffusion" 这一标签在文献中至少指向三个数学对象。本 survey 采用以下三分支：

    (a) Continuous-noise DDPM / score-SDE. 主流。所有 power-renewable diffusion 论文都属于这一支：CLDM (W1, IEEE T-STE 15:1074–1085, 2024 <verify-Phase-2> author Dong/Mao/Sun/Xu 候选)、Multi-Resolution DDPM (W2, Energies 18:3781, 2025)、PI-DDPM (W3, arXiv 2504.17210, 2025)、net-load PI-DDPM (W4, arXiv 2406.01913, 2024)、Transient-Stability PI-Diffusion (W5, Processes 13:2344, 2025)、Hoseinpour & Dvorkin (W6, arXiv 2506.11281, 2025, 唯一 verified)、CDSG (W7, Applied Energy 377:124555, 2025)、Pattern-Guided / MS-CADM (W8, Applied Energy 398, 2025)、CAL-DM (SSRN 2025)、G-DDPM (Energy and AI 2024)、DiffSTG (arXiv 2301.13629)、Score-based Offshore Typhoon Diffusion (arXiv 2508.10705, 2025)、DiffLoad (T-PWRS 2024, arXiv 2306.01001)、Multi-Energy Building Cluster Diffusion (Energy 2025)。

    (b) Discrete-token language diffusion. LEAF (P9, EMNLP 2025 Findings <verify-Phase-2>)：把历史 tokenize 后与 masked prediction segment 串联，在 token space 做 iterative denoising。"扩散"发生在离散符号空间，与 continuous noise 是不同对象。Phase 0 显式标记的 caveat：§8 比较表中不可与 (a) 直接相加；评估其在 power 场景的可用性需要 专门 的 ablation。

    (c) LLM-guided continuous diffusion. LTSM-DIFF (P10, arXiv 2602.00040, "Enhancing Few-Shot Time Series Forecasting with LLM-Guided Diffusion", Jan 2026)、T2S (P11, IJCAI 2025 <verify-Phase-2>)。LLM 派生的 sequential representation 充当 (a) 中 \(\mathbf{c}\) 的角色，sampler 仍是 continuous diffusion。这是 conditioning ladder rung 5 的代表，但对 renewable scenario 没有任何已发表的运行。

    三分支的相对体量 (Phase 0 调研池中)：分支 (a) 占 14 篇 power-renewable diffusion 论文中的 13 篇 (约 93 %)；分支 (b) (LEAF) 与分支 (c) (LTSM-DIFF / T2S) 各占 0 篇 (无 power 实例)。对 power-renewable 来说 "diffusion" 几乎等价于 continuous-noise DDPM / score-SDE；这也是 §4.5 rung 5 空白与 §10 F5 frontier 的直接前因 (分支 b/c 未有 power-domain run)。

    3.2 比较基线 (generative families used as anchors)#

    • GAN — Operation-Adversarial Scenario Generation (OA-cGAN, EPSR 212:108451, 2022, 修正 phase0b 把它误置于 Applied Energy; arXiv 2110.02152, 2021 <verify-Phase-2> 候选作者 Liang/Mieth/Dvorkin)：唯一在调研池中实现 P6 (decision-aware loss) 的工作，§9 的核心 anchor。
    • VAE / VAE-GAN — 历史 control-handle baseline，被 GAN/diffusion 在 multivariate 指标上反超。
    • Normalizing flow — likelihood baseline，性能稳健但 mode coverage 弱。
    • Autoregressive transformer — TimeGrad (ICML 2021)、CSDI (NeurIPS 2021)、ScoreGrad (arXiv 2021)、TACTiS-2 (ICLR 2024)、foundation-model class (TimesFM, Chronos-Bolt, MOIRAI-L, MOMENT, Tiny Time Mixer, TFT, PatchTST, TimeXer, LSTM, CNN, 见 arXiv 2604.22077 benchmark)。§8 head-to-head 章节专门处理。

    为什么 GAN 在 power-renewable 上仍然重要？OA-cGAN 在 2022 年发表，比 diffusion 在 power-renewable 上的大规模 adoption (2024+) 早两年。这两年的 "head start" 加上 cGAN 框架天然容纳 saddle-point optimization (与 OA-cGAN 的 decision-aware loss 完美契合)，使 cGAN 在 P6 placement 上至今仍然是唯一有 power-renewable 实例的家族。这不是"GAN 比 diffusion 更适合 P6"，而是"diffusion 的 P6 lift 还没有人做"。F3 frontier 正是要把 OA-cGAN 的 idea 从 cGAN 框架 lift 到 diffusion 框架，把这一历史"head start" 解锁。

    3.3 三大家族的 trade-off triangle 与扩散的位置#

    S7 (Phase 0b, arXiv 2103.04922) 已定义 generative family 的 trilemma：expressiveness / tractable likelihood / sampling speed。扩散在 expressiveness 与 likelihood 两条上同时强 (score matching 是 ELBO 的良好替代)，但在 sampling speed 上弱 (反向链 1000 step 在标准 DDPM)。DDIM、DPM-Solver、consistency model 等加速方法把 step 数压到 10–50；但加速本身会改变 P3 / P4 中 step-dependent \(\eta_t\) 与 projection 的频次，这在 renewable scenario 的约束执行中是被忽视的耦合 (Phase 0c-A Seam 5 的隐含变形)。

    关于 trilemma 的一个 power-renewable 特定补充：在 image diffusion 中，sampling speed 是用户体验问题 (用户等图)；在 power-renewable scenario 中，sampling speed 不仅是 推理 问题，还是 训练时 cost 问题——F3 frontier (decision-aware training) 需要在训练每一步 sample 多次场景以估计期望 cost 的梯度，\(T_{\text{diff}}\) × 训练步数 = 关键瓶颈。这一耦合在 image 文献中不存在，是 power-renewable diffusion 特有的工程难题。Accelerated sampling (DDIM, DPM-Solver, consistency model) 在 F3 上不再是 "nice-to-have"，而是 "必备前置"。

    4. The conditioning ladder#

    Phase 0b T2 / Phase 0c-C §2 把 conditioning 在过去五年的演进抽象为 information-density ladder：每爬一级，控制粒度提高、可控性增强，但条件 bottleneck (latent diffusion 中条件嵌入相对 latent 容量) 加剧、配对数据稀缺性上升、posterior collapse 风险增加。本节沿 ladder 五级 populate；ladder 与 §5 constraint placement 的 6×5 笛卡尔积是本 survey 的核心 figure (§7.2 cross-thread)。

    把 ladder 当作"信息密度"的连续维度，而非离散类别，有助于读者理解为什么相邻两级常常被同一篇论文同时跨越：例如 CDSG (§4.4) 把 controllable label (rung 4 风格) 与 source-load 多通道 (rung 2–3 风格) 揉成一个统一的 conditional space；Score-based Offshore Typhoon Diffusion (§4.3) 把 NWP (rung 2)、场站拓扑 (rung 3)、操作 regime (rung 4) 三类条件同时挂在 score function 上。本 survey 选择沿 ladder 五级分层叙述而非沿论文叙述，是为了让读者看到每一级新增的信息维度带来的新失败模式——从 rung 1 的"完全 uncontrollable" 到 rung 5 的 "极端 posterior collapse 风险与配对数据稀缺"。

    4.1 Rung 1 — Unconditioned / scalar#

    Multi-Resolution DDPM (W2 in §5, Energies 18(14):3781, 2025, <verify-Phase-2> authors)。Hierarchical denoising at multiple temporal resolutions；conditioning 至多通过 hour-of-day / season 等标量；不引入 NWP。报告 CRPS 减少 "2.1–70.9 %"，MAE 4.4–52.2 %，RMSE 7.9–53.4 %——该范围 hedge：Phase 0b S2 / Phase 0c-B B-a2 已指出此 range 几乎肯定是 max-min across regime × baseline，Phase 2 必须 extract median 并指明每个端点的 baseline。

    Rung 1 是 coverage-favoured 的一端：不引入条件意味着没有 posterior collapse，但也没有 controllability。在 Phase 0a 提到的 5 个 open problem 中，rung 1 完全不触及 §6.2 (text/LLM 条件) 与 §6.5 (regime/tail 覆盖) 的可控性需求。

    4.2 Rung 2 — Time-series covariate (NWP, calendar embedding)#

    最密集的一级，包含 power-renewable diffusion 文献的多数：

    • CLDM (W1, IEEE T-STE 15:1074–1085, 2024 <verify-Phase-2>)。两阶段：deterministic point forecast + diffusion modelling of forecast error，NWP 协变量驱动 deterministic stage、再驱动 diffusion 的 conditioning embedding。两阶段分解把 diffusion 任务限制在残差分布上 (近似零中心)，降低 denoising 复杂度；这是 §5.1 的 P1 trick (data-space transformation 把 \(\mathbf{x}_0\) 支撑收紧到残差分布)。一个值得 reviewer 关注的风险是：残差 + 点预测不保证 \(\hat{\mathbf{x}} + \mathbf{r} \in [0, P_{\mathrm{cap}}]\)；Phase 2 必须 verify 是否报告 violation rate。
    • CAL-DM (Cross-Attention Latent Diffusion, SSRN 2025 <verify-Phase-2>)。Single-stage，直接生成 wind/PV scenarios under multimodal meteorological + equipment features；cross-attention information module + Mamba state-space denoiser for long sequences + conditional mutual information auxiliary objective。CMI 项是 Phase 0 调研池中唯一已发表的、对 posterior collapse of condition 的显式补救。Phase 0c-C Risk 6 要求 verify CMI 是否在原文中以 "posterior-collapse remedy" 框架介绍，而非通用 regularizer。
    • Short-Term Wind Scenario Generation via Conditional Diffusion (P5 in Phase 0c-C, IEEE conference 2024 <verify-Phase-2>)。NWP 协变量通过 concatenation 而非 cross-attention 注入；与 CLDM/CAL-DM 形成 upgrade path (naive concat → cross-attention with CMI)。

    Rung 2 的标准 risk 是 conditioning bottleneck：当 NWP 维度高、latent 容量小时，diffusion 可以"绕过"条件直接学到无条件边缘——这正是 CAL-DM 引入 CMI 的动机。

    4.3 Rung 3 — Graph / topology / multi-asset#

    把多场站 / 多源 (wind+solar+load) 的空间结构引入 conditioning。

    • G-DDPM (P6 in Phase 0c-C, Energy and AI 2024 <verify-Phase-2>)。Graph-DDPM with site / topology embeddings，是 Phase 0 调研池中第一个把空间结构显式注入 score function 的 power 工作 (而非把多场站当作独立 channel)。
    • DiffSTG (P7, arXiv 2301.13629 <verify-Phase-2>)。Non-power-domain 但是 G-DDPM 风格 power 论文的方法论 anchor：STGNN spatial encoder + denoising head 的耦合。
    • Score-based Offshore Wind Diffusion under Typhoon (P8, arXiv 2508.10705, 2025 <verify-Phase-2>)。Operating-regime covariate (typhoon vs benign) + 场站拓扑，介于 rung 2 与 rung 3 之间。关键意义：Phase 0 调研池中唯一显式做 regime-conditional 评估的 power-diffusion paper，直接回应 Phase 0a §6.5 (regime/tail 覆盖)。

    Rung 3 引入的新难度是 scalability vs. coverage：图越大，score function 越难学；同时 graph 引入 spatial constraint 的潜在 P2 / P3 钩子 (在某些 site 上的 KCL 必须满足)，这与 §5 constraint placement 自然耦合。

    4.4 Rung 4 — Regime / pattern label#

    Rung 4 通过 CFG 把 regime / cluster 标签作为 controllability 杠杆。

    • MS-CADM (Pattern-Guided Diffusion, Applied Energy 398, 2025 <verify-Phase-2>)。Multi-scale condition adaptive diffusion model：multi-scale embedding network 提取 hierarchical conditions + time-step adaptation Transformer 解耦 diffusion-step conditioning 与 external control conditioning。Hourly-point clustering 而非 24-h line clustering，给出 finer-granularity pattern labels。报告相对偏差减少到 0.40 / 6.14 / 0.86 % vs. conventional 11.34 / 79.89 / 10.48 %。79.89 % conventional baseline 数字 implausibly large，几乎肯定反映 poorly-tuned baseline 而非 diffusion superiority；Phase 0d §6.2 已点名，Phase 2 必须 (i) 识别 baseline、(ii) 确认 dataset 与 metric 定义、(iii) 决定是否引用 headline。
    • CDSG (W7 in §5, Applied Energy 377:124555, 2025 <verify-Phase-2>)。Conditional Diffusion-based Scenario Generation for Joint Source-Load：CSTFM (conditional spatio-temporal fusion module) + CSNEM (conditional scenario noise estimation module)；"condition" 包含 controllable label，CFG-style conditioning 是 source-load coupling 与 controllability 的共同杠杆。

    Rung 4 的核心 trade-off 是 CFG-scale × tail-coverage 曲线：\(w\) 越大，conditional alignment 越锐，但模式覆盖收缩。Phase 0c-C Seam C2 强调：没有任何已发表的 renewable-diffusion paper 报告 \(w\)-sweep 与 tail-coverage 的 quantitative 曲线。这是 §7.3 cross-thread 的核心 frontier。

    Coverage–consistency 的家族 lineage (deep-diver review §1)：CFG-scale × tail-coverage 不是 diffusion 独有的新问题——它是 GAN mode collapse (Arjovsky & Bottou; Salimans et al.; "unrolled GAN") 与 VAE posterior collapse / KL-vanishing (Bowman et al. 2016; β-VAE; InfoVAE) 这两条已经有 10+ 年理论沉淀的 trade-off 在 diffusion 时代的延续。关键映射：(i) CFG-scale \(w\) ↔ GAN discriminator 强度——更强的条件信号 sharpen sample 但缩 mode coverage；(ii) CAL-DM 的 CMI 辅助目标 (§2.3) ↔ InfoVAE / β-VAE 家族的互信息下界——CAL-DM 不是 invent CMI，而是从 VAE 文献 lift 到 latent diffusion。这一 lineage 的直接后果是：F6 frontier 的 \(w\)-sweep figure 应当沿用 GAN evaluation 的 precision/recall for generative models (Sajjadi et al. 2018) 轴向，而非自创"CRPS-vs-\(w\)" 简化轴——这样 diffusion-renewable 的 trade-off 曲线可与 GAN / VAE 文献的同类曲线直接可比。MS-CADM 的 79.89 % conventional baseline 数字 (§7.5) 也可在此 lineage 下重新解释：它很可能是一条 mode-collapsed GAN 曲线而非 "poorly-tuned baseline"。

    Circularity warning (Phase 0d §6.6, 来自 Phase 0c-B B-a1)：以 pattern-classification accuracy 作为 evaluation metric 时，label 既是 training input 也是 evaluation target——这是 circular evaluation，§7 评估章节必须 flag。

    4.5 Rung 5 — Free text / LLM prompt#

    对 power-renewable scenario 完全为空。 Phase 0a §6.2 的开放问题；Phase 0c-C C3 的核心 seam。

    调研池中给出方法论 scaffolding 的工作：

    • LEAF (P9, EMNLP 2025 Findings <verify-Phase-2>)。Masked-token diffusion in LLM token space。家族区分：§3.1 (b) discrete-token language diffusion，与 (a) continuous-noise 不可混淆。无 power-domain run。
    • LTSM-DIFF (P10, arXiv 2602.00040, "Enhancing Few-Shot Time Series Forecasting with LLM-Guided Diffusion", Jan 2026)。LTSM 提供 sequential representation 作为 diffusion 的 conditional guidance；声称在 data-rich 与 few-shot 上 SOTA。这是 ladder rung 5 的最干净实现，但 renewable 转移未做。
    • T2S (P11, IJCAI 2025 <verify-Phase-2>)。High-resolution text-conditioned time-series generation，显式 text-to-series alignment 模块。

    Phase 0c-C C3 提议的第一篇 power-domain rung-5 论文模板：把 NREL WTK regime cluster label 与简短合成文本描述 ("clear-sky summer afternoon, light westerly") 配对，在 CLDM 之上训练 T2S-style adapter，评估 regime-conditional CRPS。这是 §10 F5 frontier 的具体化。

    rung 5 的实际 blocker：方法学 scaffolding (LEAF / LTSM-DIFF / T2S) 已经存在，但 power-domain run 缺席的核心原因不是技术——而是 paired data scarcity。文本描述 ("clear-sky summer afternoon") 与对应历史场景的 paired corpus 在 power domain 几乎不存在；NWP 文本化 (把 weather forecast 自动转写为自然语言) 也是空白工具集。F5 frontier 的第一篇论文必须用 合成 text-from-cluster-label 的简化路径 ("clear-sky" = cluster 1 的合成 label) 绕过这一 corpus blocker。这是 F5 看似简单实则需要工程巧思的部分。

    5.1b 六个安置位置 (展开)#

    P1–P5 是 feasibility-oriented；P6 是 consequence-oriented，结构正交。P6 的两个变体 (P6a / P6b) 必须显式区分：P6a (per-scenario cost) 把每条 generated scenario 单独评估其 operating cost 并取期望，没有 here-and-now decision (commitment) 嵌入训练；P6b (SP-decision cost) 把生成的 scenario set 喂入完整 SP/UC solver 得到 here-and-now decision \(x^*_{\mathrm{SP}}\)，再在 held-out realization 下评估该决策的实际成本。OA-cGAN 是 P6b (DC-OPF 凸、LP 对偶让 inner SP 可折叠)；W12 Diffusion-DFL 在原 paper 中接近 P6b 但因 SP 是 generic 而非 UC 不能直接说覆盖 P6b power 实例；本 survey §10 F3 frontier 以 P6b 为目标，但允许"P6a 作为 stepping-stone"——这是为什么 §5.9 ablation grid 把 "off / per-scenario / SP-decision" 列为 P6 axis 的三档。下面 12 个代表工作按位置 populate；每个 cell 显式标注覆盖情况。

    5.2 P1 — Data / preprocessing#

    P1 是"通过数据空间变换把约束隐式化"的位置：不引入新的 loss 项、不修改 score 网络、不增加采样步骤；通过对训练数据的预处理 (rescaling, clipping, residual decomposition) 让 \(\mathbf{x}_0\) 的支撑近似落在 \(\mathcal{F}\) 内。优点是零计算开销；缺点是约束永不严格满足 —— 任何 P1 trick 都只能让"违反 feasibility" 的概率小，不能让它为零。

    W1. CLDM (IEEE T-STE 15:1074–1085, 2024, <verify-Phase-2> Dong/Mao/Sun/Xu 候选)。Headline 机制是 deterministic forecast + diffusion-modelled residual：先训练 embedding network 给出确定性预测 \(\hat{\mathbf{x}}\)，然后让 diffusion 模型只学预测残差 \(\mathbf{r} = \mathbf{x}_0 - \hat{\mathbf{x}}\) 的分布。这是 P1：data-space 变换把 \(\mathbf{x}_0\) 的支撑限制到残差分布；capacity bound 与 \(\mathbf{x}_0\) 量级隐式而非显式约束。两阶段分解把 diffusion 任务限制在一个近似零中心、低方差的目标上，显著降低 denoising 复杂度并间接提高 calibration。其潜在缺口是 P1 alone 不保证 \(\hat{\mathbf{x}} + \mathbf{r} \in [0, P_{\mathrm{cap}}]\)；尾部样本可能 violate capacity box —— 当 \(\hat{\mathbf{x}}\) 接近 capacity 上限且 \(\mathbf{r}\) 给出正向尾部噪声时，sum 超过容量在数值上完全可能。Phase 2 fact-check 必须 verify CLDM 原文是否报告 violation rate；本 survey 默认 P1 提供 soft 而非 hard feasibility。

    W2. Multi-Resolution DDPM (Energies 18:3781, 2025, <verify-Phase-2>)。多分辨率 + condition-constrained denoising via historical and trend-based priors。结构上是 P1 + P3 混合：训练阶段用 priors 条件化数据集 (P1)，采样阶段把 trend-based condition 作 soft pull (P3)。无显式 feasibility set，"physical realism" 由统计相似度替代。这是当前 P1 文献的一个典型问题——"physical realism" 与 "statistical similarity to historical data" 被默认等价，而二者在 rare regime / out-of-distribution 上完全不一致：历史数据没有的 feasibility 组合 (e.g. 极端 ramp 在历史频率为零) 可能仍然是物理可行的，反之统计相似的样本可能违反 ramp 限制。这一概念混淆是 §5.3 P2 论文的常见动机。

    5.3 P2 — Inside the score / noise-prediction network (physics-informed loss)#

    W3. PI-DDPM for Synthetic Power Flow Data (arXiv 2504.17210, IEEE SmartGridComm 2025 submission <verify-Phase-2>)。Auxiliary training + physics-informed loss 使 noise prediction network 学到 (voltage, \(P_g\), \(P_d\)) 的联合结构。IEEE 14- / 30-bus。报告满足所有不等式约束；residual power imbalance 0.013 p.u. (14-bus) / 0.017 p.u. (30-bus)，文中称 "absorbable by slight adjustments" (报告值待 Phase 2 verify)。Phase 0d §6.2 警示：(i) "equality (balance) constraint 仅近似满足"；(ii) Phase 2 必须 verify 是否在 test set 上还是 representative example。

    W4. Net-Load PI-DDPM (arXiv 2406.01913, 2024 <verify-Phase-2> candidate Zhang et al.)。Physical model function 嵌入 denoising network；transition-kernel 参数与 physics-function 参数联合训练；Pecan Street smart meter；声称 ≥ 20 % 在所有指标上提升 over GAN / VAE / NF / vanilla DDPM。这里的 "physical model" 更接近 parametric structural prior (PV/load decomposition)，而非 hard constraint；与 PINN-style soft constraint 相邻。

    W5. Transient-Stability PI-Diffusion (Processes 13(8):2344, 2025 <verify-Phase-2>)。Hierarchical conditional diffusion + transient differential equations 嵌入 + transient-energy 作 stability-boundary constraint。Modified IEEE-39-bus；reported 98.77 % unstable-scenario recognition rate, +3.92 / +2.65 pp over named alternatives；Phase 2 必须 verify alternative 身份与 test split。结构上是 P2 (DE embedding) + P1 (energy criterion 过滤数据)；energy function 作 Lyapunov-derived penalty (在原论文中是光滑能量函数, 偏 penalty 而非 barrier — barrier 在边界附近梯度爆炸, penalty 是平滑增长)，非 sampling-time projection。

    Phase 0c-A Seam 2 critique：P2 (physics-informed loss) 在文献中至少隐藏三个子机制 — PDE residual (W3)、structural prior (W4)、soft Lyapunov / barrier (W5)。这三者在数学性质 (可导性、约束饱和、训练动力学) 上差异显著，但目前文献用同一标签 "physics-informed" 笼统对待。

    具体来说：

    (i) P2-PDE-residual (W3 in §5.3 above)。把守恒律 (如 KCL: \(\sum_i P_i = 0\)) 通过 \(\|\hat{\mathbf{x}}_0\|\) 形式作为额外 loss 项加到 \(\mathcal{L}_{\mathrm{simple}}\) 上。训练动力学：梯度始终存在 (光滑可导)，但 violation 永不为零；\(\lambda\) 增大降低 violation，但与 \(\mathcal{L}_{\mathrm{simple}}\) 形成 Pareto trade-off。典型用例：power flow balance constraint, transmission-line capacity, ramp constraint。与 PINN 的关系：直接继承 Raissi et al. 2019 的 PINN 框架，把 score / noise prediction network 替代 PINN 的 forward solver。

    (ii) P2-structural-prior (W4 in §5.3 above)。把 PV / load 的结构方程嵌入 score 网络架构，约束通过 参数共享 而非 loss 项强制——更接近 inductive bias 而非 soft penalty。训练动力学：约束几乎免费 (architecture 强制)，但表达能力受限——架构外的样本无法 represent。典型用例：PV / load decomposition, generator-load balance through fixed linear map。与 hard layer (P5) 的关系：边界模糊；P2-structural-prior 是 layer 内部参数化 (e.g. fixed weight)，P5 是 layer 输出后处理 (e.g. clipping / KCL completion)；二者可叠加。

    (iii) P2-Lyapunov-penalty / barrier (W5 in §5.3 above)。把 transient-energy 函数作为 penalty (光滑二次, W5 选用的形态) 或 barrier (在 stability boundary 附近梯度爆炸) 项添加。训练动力学：penalty 平滑、barrier 在边界爆炸；具体使用何种取决于能量函数的构造。典型用例：transient stability boundary, voltage envelope, frequency containment。Caveat：barrier function 在边界附近的梯度 explosion 与 gradient clipping 互动复杂，常需要 careful \(\lambda\)-warmup schedule。

    对 P2 标签的方法学含义：把这三种机制都标为 "physics-informed" 会让读者对 (a) 收敛速度、(b) violation rate、(c) 对超参数 \(\lambda\) 的敏感性形成错误预期——三种机制在三方面都不同。Phase 2 应在 §A.6 methodological hygiene 中要求每篇 P2 论文显式说明使用的子机制。对 §5.9 ablation grid 的扩充：P2 应当被拆为 {off, PDE-residual, structural-prior, Lyapunov} 四档而非 {off, on} 二档。

    5.4 P3 — Reverse-step gradient guidance#

    P3 是当前 power-renewable diffusion 中最活跃的位置，也是 唯一 有 Phase 0 verified 作者归属 (Hoseinpour & Dvorkin) 的位置。其数学钩子 \(\tilde{\mathbf{s}} = \mathbf{s}_\theta - \eta_t \nabla_{\mathbf{x}_t} c(\hat{\mathbf{x}}_0)\) 把 score 视为 "学到的先验"，约束违反梯度视为"似然修正"——这是 score-SDE 框架下 Bayes posterior 的直接类比 (Song et al. 提出的 inverse problem 框架)。P3 相对 P1 / P2 的优势是 测试时 可控：\(\eta_t\) 可以根据 sample 的 violation 程度动态调整，而不需要重训。劣势是测试时计算成本翻倍 (每个反向 step 都要算约束梯度) 与 \(\eta_t\) schedule 的调参成本。

    W6. Hoseinpour & Dvorkin — Constrained Diffusion Models for Synthesizing Representative Power Flow Datasets (arXiv 2506.11281 v2, 2025)。Phase 0 唯一 verified author attribution：Milad Hoseinpour, Vladimir Dvorkin (U. Michigan EECS)。Headline 机制是 AC-power-flow gradient guidance 加到反向 score 上 + variable-decoupling strategy (灵感来自 fast decoupled power flow，使梯度评估 tractable)。输出在 well-tuned guidance scale 下统计忠实且 AC-feasible。位置：power systems 的 canonical P3。Caveat：v1 题为 "Domain-Constrained Diffusion Models to Synthesize Tabular Data: A Case Study in Power Systems"；Phase 2 必须 reconcile 引用版本 (preprint vs published / accepted)。

    W7. CDSG — Conditional Diffusion-based Scenario Generation for Joint Source-Load (Applied Energy 377:124555, 2025 <verify-Phase-2>)。CSTFM + CSNEM；"condition" 包含 controllable label，CFG-style conditioning 调制反向 score。位置：P3 in spirit (条件调制 score across reverse steps)，但没有物理约束——"constraint" 是 style / regime label。这是 rung 4 与 P3 的交叉单元 (§7.2 的核心例子)。

    W8. MS-CADM — Pattern-Guided Diffusion for Controllable Renewable Scenarios (Applied Energy 398, 2025 <verify-Phase-2>)。Prototype / cluster-label conditioning 驱动反向 diffusion。架构与 W7 同族；"pattern" 起到 CFG class label 的作用。位置：P3 used for regime control，not feasibility。

    Phase 0c-A Seam 5 critique：P3 (gradient guidance) 与 style conditioning (CFG) 共享同一架构钩子；"constraint" 与 "style" 之间的区分需要 prompt 设计与 evaluation 设计共同强化。

    W6 中 variable-decoupling 的重要性：纯 AC power flow 在反向采样的每一步都需要 Jacobian 求解，对 1000-bus 级别 raw cost 不可接受。Hoseinpour & Dvorkin 借鉴 fast decoupled power flow 思想——把 \(P\)–\(V\) 与 \(Q\)–\(\theta\) 解耦——把每步 Jacobian 因式分解从 full-AC sparse-Newton scaling 降到 fast-decoupled scaling (实际加速 order-of-magnitude；精确复杂度依赖求解器实现：full AC sparse-Newton 约 \(O(N^{1.4})\)–\(O(N^2)\)、fast-decoupled 大致线性到亚二次)。这一工程巧思是把 P3 从 toy 30-bus 推到 system-level 的关键，也是 Phase 0c-A 把该工作选为 P3 canonical anchor 的原因。

    5.5 P4 — Inter-step projection#

    W9. PGDM — Projected Generative Diffusion Models for Constraint Satisfaction (arXiv 2402.03559 v1/v2 <verify-Phase-2>)。非 power-domain 但是方法学上的核心：把 sampling 重新表述为 约束优化 问题，每个反向 step 做 iterative projection。在 convex \(\mathcal{F}\) 与 convex \(-\log p\) 下有理论保证；非凸约束 (materials, motion, ODE) 上有经验证据。位置：textbook P4，桥接 P3 (gradient guidance) 与 P4 (projection)。关于 P3 / P4 边界的方法学澄清：P4 不是 "P3 with large \(\eta_t\)" 的极限。P3 (DPS / reconstruction-guidance 风格) 是 一阶 soft 修正——每个反向 step 一次 \(\nabla_{\mathbf{x}_t}\) nudge，不保证 \(\hat{\mathbf{x}}_0 \in \mathcal{F}\)；P4 (projection / proximal operator) 在每个反向 step 内做 iterative projection，结构上更接近 proximal 而非 single-step gradient。增大 P3 的 \(\eta_t\) 只会让 score correction 主导但 不 强制 \(\hat{\mathbf{x}}_0 \in \mathcal{F}\)；二者只有在 \(\mathcal{F}\) 为半空间且 projection 退化为单步梯度时才重合。这一区分对应 §2.6 凸/非凸 projection 行为的具体后果。任何自称 "projected" 的 power-diffusion paper 应以 PGDM 为方法学 anchor。

    W10. Predict-Project-Renoise (arXiv 2601.21033, "Sampling Diffusion Models under Hard Constraints", 2026)。预测 \(\hat{\mathbf{x}}_0\) → 投影到 \(\mathcal{F}\) → re-noise 到 \(\mathbf{x}_{t-1}\)，是 constraint-satisfaction-diffusion 文献中正在标准化的 pattern。无 power-system instantiation；技术目前通用。

    W11. Projection-Constrained Diffusion on Manifolds (arXiv 2602.17773, "Learning Flow Distributions via Projection-Constrained Diffusion on Manifolds", 2026)。Scope sharpening：该论文的真实作用域是 2D incompressible fluid flow on manifolds (Helmholtz–Hodge projection 把 score 修正到 divergence-free 子空间)，而非通用 feasibility manifold。本 survey 把它列为 P4 anchor 是 方法学类比 (任何 "已学/已知 low-dim manifold + 反向 step projection" 模板对 AC power flow manifold 都可参考)，不是 主张该论文已覆盖 AC manifold——AC power flow 既不是 incompressible flow，也不是 fluid-mechanics 意义上的 manifold。因此 "\(\Pi_\mathcal{F}\) onto AC manifold" 在该论文中是未实现的延伸，本 survey 把它作为 P4 在 power-domain 空缺的方法学最近邻引用。

    5.6 P5 — Hard output layer (empty for renewable scenarios)#

    P5 是 engineering-cheap, empirically-empty 的典型例子。其数学钩子简单：在 latent diffusion 的 decoder 后挂一个可微分的 final layer \(L_\mathcal{F}: \mathbf{z} \to \mathcal{F}\)，把 raw decoded \(\mathbf{z}\) 显式映射到 feasibility set。常见构造包括：(i) capacity-clipping (sigmoid + scaling 到 \([0, P_{\mathrm{cap}}]\) 但保留梯度通过 straight-through estimator)、(ii) KCL-completing layer (KCLNet 风格：给 \(N - 1\) 个自由变量预测，第 \(N\) 个由 KCL 约束自动给出)、(iii) ramp-respecting projection (\(\Delta_t = \min(|\hat{\Delta}_t|, R_{\max}) \cdot \mathrm{sign}(\hat{\Delta}_t)\))。这些都是单层可微分操作，工程成本几乎为零。

    对 renewable scenario 完全为空。 Phase 0c-A Seam 3 命名了这个 cell：

    • DiffOPF (arXiv 2510.14075, 2025 <verify-Phase-2>) 是 diffusion solver for OPF 而非 scenario generator；其输出受限于 OPF KKT manifold——这是 P5 idea 的倒置 (扩散针对受约束算子的输出，而非输入分布)。
    • KCLNet / OPF-Net 风格 hard layer 在 非扩散 生成模型 (cGAN, flow) 中惯用；其在 diffusion final layer 的适配是 open seam。

    这是本 survey 命名的关键空白格之一：Phase 0c-A Seam 3 + Phase 0d F2 指出，"latent diffusion + decoder = hard-capacity layer" 在机械上是小改动，但调研池中 零 实现。这是 §10 F2 frontier 的具体化。

    5.7 P6 — Decision-aware loss (empty for renewable-diffusion)#

    对 renewable-diffusion 完全为空。

    • W12. Diffusion-DFL — Decision-Focused Diffusion Models for Stochastic Optimization (arXiv 2510.11590, 2025 <verify-Phase-2>)。Diffusion predictor 通过 differentiate through downstream stochastic optimization 训练；loss 是 decision-evaluated cost，而非 likelihood / score-matching loss。声称 diffusion-DFL "consistently delivers the best decision performance" 在 stochastic 方法中。位置：canonical P6，generic (非 power-specific)。
    • OA-cGAN — Operation-Adversarial Scenario Generation (Electric Power Systems Research 212:108451, July 2022; arXiv 2110.02152, 2021)。修正 phase0b S6 的错误：venue 不是 Applied Energy，而是 EPSR；arXiv preprint 自 Oct 2021。<verify-Phase-2> Liang/Mieth/Dvorkin 候选作者。cGAN with embedded DC-OPF cost；generator 学最大化 OPF 成本，discriminator 强制统计可信度。位置：非扩散 P6 的 canonical anchor (§9)。

    Diffusion P6 for renewable scenarios 是 Phase 0c-A Seam 4 + Phase 0c-B Seam 2 + Phase 0d F3 共同命名的 frontier：把 W12 的框架 lift 到 renewable scenarios for UC / DRO，把 OA-cGAN 的 idea 从对抗 saddle-point 提升到 non-adversarial diffusion loop。技术钥匙是 pathwise gradient through DDIM sampler × differentiable UC surrogate。

    5.8 六单元矩阵 (Phase 0d Axis 3, 与 §10 frontier 关联)#

    Placement Power-renewable 代表 (Phase 0 调研池) 状态
    P1 CLDM (residual decomposition), Multi-Res DDPM (trend prior) 已实现
    P2 PI-DDPM (2504.17210), Net-Load PI-DDPM (2406.01913), Transient-Stability Processes 13:2344 已实现，三种子机制混杂 (Seam 2)
    P3 Hoseinpour & Dvorkin 2506.11281, CDSG (style), MS-CADM (pattern) 已实现 (\(\eta_t\) 唯一 verified 工作)
    P4 PGDM (generic), Predict-Project-Renoise (generic), Manifold (fluid flow, methodological anchor) 无 power instantiation
    P5 (empty); DiffOPF 是 inverted neighbour 空白格 (frontier F2)
    P6a / P6b (empty for diffusion); OA-cGAN (GAN, P6b), Diffusion-DFL (generic ML, P6a/P6b boundary) 空白格 (frontier F3)

    P5 与 P4 的概念差异：P4 (projection \(\Pi_\mathcal{F}\)) 是采样时操作，对采样路径的每一步做修正；P5 (hard layer \(L_\mathcal{F}\)) 是架构操作，编码在 decoder 的最后一层、训练时与采样时一致。这一区别在梯度行为上有具体后果：P4 通过 \(\Pi_\mathcal{F}\) 的 sub-gradient (在 boundary 上不光滑) 把信号反传，可能在边界附近不稳定；P5 通过 sigmoid / softmax / KCL-completion 等 光滑 映射保持梯度连续，使训练动力学良好。这是为什么 P5 在 F3 (P6 decision-aware training) 中作为工程前置不可替代——P4 的不光滑梯度会污染 P6 的 cost 梯度。

    5.9b P3 vs P4 boundary-condition decision rule (per domain-expert review)#

    Domain-expert review §2.1 + deep-diver review §2 共同指出：§2.6 / §5.5 已经分别给出 P3 (gradient guidance) 与 P4 (projection) 的数学差异，但没有装配为一张决策表——读者无法直接根据自身约束类型选择 P3 还是 P4。下表把分散在 §2.6 / §5.4 / §5.5 / §5.8 中的判据汇总为 5 行决策规则：

    Condition on \(\mathcal{F}\) P3 (guidance) 行为 P4 (projection) 行为 Verdict
    Convex \(\mathcal{F}\), smooth \(c(\cdot)\) \(\eta_t\) 调好渐近 feasible；cheap；梯度光滑 \(\Pi_\mathcal{F}\) unique, differentiable, idempotent；每步 strict feasibility P4 strictly dominates (cheaper + hard)
    非凸 \(\mathcal{F}\) (AC power flow equality) \(\eta_t\) 沿局部梯度推近 \(\mathcal{F}\)；从未严格 feasible；但不会被 projection discontinuity 打飞 \(\Pi_\mathcal{F}\) non-unique, non-continuous；"projection" 退化为 heuristic；可能把样本踢出学到的流形 P3 dominates — 正是 W6 Hoseinpour & Dvorkin 的选择
    高维 \(\mathcal{F}\) + cheap residual 但 expensive projection \(\nabla c\) 是 one backward pass \(\Pi_\mathcal{F}\) 是 inner-loop QP / LP P3 dominates on compute
    \(\mathcal{F}\) 由 learned manifold 定义 (数据驱动 typical operating envelope) guidance 尊重 score 自身流形 projection 需要显式 manifold 参数化，renewable scenarios 很少有 P3 dominates unless manifold 已工程化 (PGDM setup)
    约束必须满足以使 downstream solver 启动 (e.g. capacity bound \(\le P_{\max}\) for UC) guidance 给 soft feasibility；UC 可能在 infeasible sample 上 error projection 给 hard feasibility P4 (或 P5) strictly required

    对 F2 / F3 frontier 的具体含义：第 5 行表明，如果 downstream UC solver 对 infeasibility 敏感 (典型情况)，那么 P3 alone 不够，需要 P4 或 P5 作为兜底。P5 (hard layer) 在工程上比 P4 (projection inside sampler) 更易实现且梯度光滑 (§5.8 末段已论证)，所以 F2 → F3 的依赖链准确地说是 "smooth-feasibility-layer → P6"，P5 与可微分 P4 (convex \(\mathcal{F}\) 上的 differentiable QP) 是该 precondition 的两条可互换路径。这给 F3 实施者额外的工程灵活度。

    5.9 Layered combination ablation (Seam 5)#

    Phase 0c-A Seam 5 + Phase 0d "layer don't choose" 立场：调研池中的论文几乎总是挑一个 placement报告，组合 ablation 缺失。一个自然的 grid：

    \[\{P1 \in \{\text{raw, residual}\}\} \times \{P3 \in \{\text{off, gradient guidance}\}\} \times \{P5 \in \{\text{off, capacity layer}\}\}\]

    会让领域分清哪一个 placement 实际买到 feasibility 与 哪一个买到统计忠实度。当前文献证据不允许这一分离。 §10 F2 + F3 的两篇论文同时也会自然 produce 这一 ablation。

    6. Spatial-temporal architectures#

    本章从空间-时间粒度这一相对独立的轴上重新审视 §3 (generative family) 与 §5 (constraint placement) 中已介绍的论文。Phase 0a §2 的 sub-problem tree 把 spatial-temporal 列为 sub-problem 1, 5, 6——分别对应"单点 / 残差 / 多场站"——这三类问题在数学结构上有显著差异：单点是 1D 序列分布学习；残差是低方差零中心分布学习；多场站需要联合分布与空间结构建模。本章选择按 系统级颗粒度 (单点 → 多场站 → 联合源-荷 → 区域 → 多分辨率 → 多能源) 分层叙述，使读者看到 diffusion 在每一级颗粒度上面临的具体技术挑战。

    6.1 Single asset, single horizon#

    入门级 (Phase 0a §2 Sub-problem 1)：单一场站 / 单一资产 (e.g. 单 wind farm 24h × 15-min)。代表性工作 CLDM (W1) 在 short-term wind 上、DiffLoad (T-PWRS 2024, arXiv 2306.01001) 在 building / system 级 load 上。CLDM 的两阶段分解 (§5.2 P1) 与 DiffLoad 的 separable epistemic vs aleatoric uncertainty 是同一 trade-off 的两个对面：CLDM 把不确定性压到 residual diffusion 中，DiffLoad 把它显式 decompose 为认知 / 偶然两类，aleatoric 部分用 robust additive Cauchy distribution 建模 (<verify-Phase-2>)。

    6.2 Multi-asset, same source#

    Wind farm cluster (多 turbine / 多 farm 同时生成)。CAL-DM (§4.2) 显式处理多模态 meteorological + equipment features。这一类的关键问题是 inter-asset spatial correlation：相邻场站的 ramp 事件高度相关，独立 channel 建模会低估 portfolio-level 尾部风险。

    单点 / 单 horizon 的核心难点是 calibration vs sharpness：单点边际容易标定 (CRPS 在 5–15 % 量级常见)，但 sharpness (分布的方差) 与 calibration 之间存在 trade-off——过 sharp 的分布会丢 calibration、过 wide 的分布 calibration 良好但对决策无用。CLDM 的两阶段分解通过把 sharpness 让渡给点预测、把 calibration 让渡给残差 diffusion，缓解这一 trade-off；DiffLoad 通过显式 epistemic / aleatoric 分解，把 calibration 的责任在两类不确定性间分配。这一对的相似之处是都把 calibration 责任从单一模型中拆分；区别是 CLDM 在数据层做拆分 (P1)、DiffLoad 在不确定性源头做拆分。

    6.3 Joint source-load#

    CDSG (W7, Applied Energy 377:124555, 2025 <verify-Phase-2>)：CSTFM 显式建模 source-load 联合分布。Pattern-Guided Diffusion (W8) 在更精细的 pattern 粒度上做同样事情。Multi-Energy Building Cluster Diffusion (Energy 2025 <verify-Phase-2>) 把 source-load 推广到 cooling + heating + electrical + on-site renewable 的多能源耦合。

    Joint source-load 的核心难点是 跨变量相关性建模。Wind / solar 之间在日尺度上常负相关 (日间 solar 高时 wind 平均略低)，但在多日 Dunkelflaute 期间高度正相关 (二者同时为低)；source 与 load 之间又通过 weather-driven HVAC demand 形成正相关。这些相关性在 regime-dependent 上变化巨大——这是 §7.6 regime-conditional 评估的天然 motivation。CDSG 的 CSTFM 模块通过 spatio-temporal fusion 试图捕获这种 regime-dependent 相关性；MS-CADM 通过 hourly-point cluster label 间接编码 regime。两者都没有显式报告 regime-conditional 相关性指标，这是 Phase 2 应该核查的关键点。

    6.4 Regional / topology-aware#

    G-DDPM (§4.3) 与 DiffSTG (§4.3)。把网络拓扑 (传输线、变压器) 作为图条件注入 score function。这一层与 §5 P3 (gradient guidance) 自然耦合——某些节点的 KCL 约束需要在反向采样中通过图传播执行。

    6.5 Multi-resolution / hierarchical#

    Multi-Resolution DDPM (W2, Energies 18:3781, 2025 <verify-Phase-2>)：hierarchical denoising at multiple temporal resolutions (e.g. 1h + 15-min + 5-min)。对 hierarchical UC (day-ahead + intra-day) 在概念上有明显价值——日前 UC 用粗粒度，intra-day re-dispatch 用细粒度——但 Phase 0c-B B-a2 指出，Multi-Res DDPM 论文本身没有运行 hierarchical UC 实验。这是 Tier 1–2 评估文化的典型病例。

    6.6 Multi-energy / building cluster#

    Multi-Energy Building Cluster Diffusion (Energy 2025 <verify-Phase-2>) 把生成扩展到 building cluster 的 cooling + heating + electrical + on-site renewable。这与 energy-hub dispatch 决策直接相关，但论文仍止步于 distributional metrics (CRPS / ES / autocorrelation match / cluster-level aggregation diagnostics)。

    6.6b 多能源耦合带来的特有约束#

    Multi-energy 系统在约束维度上比纯电系统多两层：(i) 能量转换约束 (chiller / boiler 的 COP、电热联产的电热比)，这些约束通过非线性方程耦合多类能流；(ii) 储能动态 (蓄热罐温度、电池 SoC) 在时序上引入 path-dependent constraint，无法用单时刻 box constraint 表达。这些约束在 P1–P6 框架内的具体安置至今没有完整调研——Multi-Energy Building Cluster Diffusion 在哪一格？没有完整 placement vector。这是 §11.2 minimum reporting standard "六位 placement vector" 的具体动机。

    多能源 evaluation 的额外维度：除 Tier 1–4 之外，multi-energy 系统应额外报告 (i) cross-carrier balance (电热联产中电能与热能的同时供需平衡误差)、(ii) storage cycling (蓄热罐 / 电池的等效循环次数，对 lifetime cost 关键)、(iii) carbon intensity (kgCO₂/kWh aggregate, 在 low-carbon building 用例中是核心指标)。Multi-Energy Building Cluster Diffusion 论文只报告 distributional metric (CRPS / ES / autocorrelation match)，三项 multi-energy-specific metric 都没有出现，这是该论文与 building energy management 实际决策需求之间的另一个 gap。

    6.7 与 §4 / §5 的交叉#

    Spatial-temporal granularity 与 §4 conditioning ladder 几乎独立 (例外：rung 3 graph 与 §6.4 regional 是同一回事)；与 §5 constraint placement 强相关 (例外：多分辨率 § 6.5 与 P1 / P3 都正交)。6 × 6 (granularity × placement) 也是稀疏占据，但这一格子的稀疏性主要由历史路径决定 (社区分割) 而非数学新颖性；本 survey 不把它作为 frontier。

    7. Evaluation hierarchy (NEW four-tier structure)#

    本章的核心立场是：评估比方法更重要，因为评估决定后续整代论文的优化方向。当 reviewing panel 把 CRPS / energy score 作为接收 / 拒稿的核心判据，那么后续所有 diffusion 论文都会针对 CRPS / energy score 优化——即使这两个指标对运营决策几乎不敏感。这是一种 evaluation-driven local optimum：领域整体被锚在 marginal 与 multivariate calibration 上，对 tail / regime / decision-coherent 行为不敏感。本章把当前评估实践层级化、把每一层的工具与代表论文 populate，并显式把 diffusion-renewable pool 整体定位在 Tier 1–2——这是本 survey 的核心方法论 claim 之一。

    7.1 四层结构#

    Cramer et al. (Validation Methods for Energy Time Series Scenarios from Deep Generative Models, IEEE T-PWRS 2022 published version of arXiv 2110.14451; <verify-Phase-2> author order Cramer/Gorjão/+others) 在 pre-diffusion 时代已经把评估组织成层级：marginal → temporal → multivariate → task-aware。本 survey 把它升格为四层结构 (Phase 0d §2 §7):

    Tier 内容 工具
    Tier 1 — marginal 每个 (time, channel) 上的边缘标定 pinball loss, CRPS, reliability diagram, marginal histogram
    Tier 2 — multivariate (cross-channel, cross-time) 联合分布的二阶 / 高阶结构 energy score ES, variogram score
    Tier 3 — temporal / regime 自相关、ramp 分布、谱、regime-conditional autocorrelation, ramp KS, MFDFA, regime-conditional CRPS
    Tier 4 — decision-aware 下游决策意义 operating-cost gap, cost-CRPS, VSS / EVPI, commitment Hamming \(d_H\), redispatch volume

    为什么需要四层？ 当前 diffusion-renewable 论文几乎都报告 Tier 1–2 指标，把 Tier 3 (regime / temporal) 当作 "additional" 加分项、Tier 4 (decision-aware) 当作 "future work"。但从决策视角看，层级反过来才正确：运营决策者只关心 Tier 4 (运营成本)；Tier 3 (regime-conditional) 是 Tier 4 的近似 (rare regime 上的 cost-CRPS 是 worst-case operating cost 的代理)；Tier 1–2 (marginal / multivariate calibration) 是 必要但不充分 的最低门槛。本 survey 把四层结构作为全文方法论 backbone，使读者能立即看到任意一篇论文的评估实际触达哪一层。

    重新框定 (deep-diver review §3)：Tier 1–3 不是 "在通往 Tier 4 路上的渐进改进"，而是 sanity gates——marginal calibration 失败的 generator 已经坏了，但 marginal calibration 通过不代表接近运营有用；Tier 4 是唯一试图回答用户实际决策问题的层。"层级" 比喻略嫌平铺，更准确的读法是 "Tier 1–3 是 sanity gates, Tier 4 is the measurement"。

    理论 anchor — Gneiting & Raftery (2007) / Savage (1971)。本 survey 在 §2.5 已经形式化指出 CRPS / ES 是 strictly proper scoring rules；这一性质决定它们必然对 downstream decision geometry 不敏感。Gneiting & Raftery (2007, Strictly Proper Scoring Rules, Prediction, and Estimation, JASA 102:359–378) 给出 proper scoring rule 的完整公理化，并明确区分 "proper" 与 "useful"：一个 scoring rule 可以对 任何 决策问题 proper，但 只对某个特定决策问题 有用——CRPS 对 quantile-style 决策 (newsvendor with linear costs) 几乎 proper-useful 重合，对 unit commitment with combinatorial switching costs 完全不重合。Savage (1971, Elicitation of Personal Probabilities and Expectations, JASA 66:783–801) 更早已证明：对一个 forecaster 而言，"正确" 的 loss 是用户 decision problem 自身 诱导的 loss——SPO+ (Elmachtoub & Grigas, §9.2) 是这一 50 年前 idea 在 ML 时代的可计算实现，而非全新洞见。

    把 §2.5 + §7.0 + §7.1 三处串起来读：CRPS / ES 对 Tier 4 决策不敏感不是 empirical 现象，而是 proper-scoring-rule 公理的理论必然。这把本 survey "the field is optimising the wrong loss" 的核心 claim 从经验观察升级为 决策理论的直接推论——Tier 4 不是 "在 Tier 1–3 之上的额外层"，而是 Savage / Gneiting-Raftery 公理意义下唯一对应用户决策问题的 loss。F3 frontier (P6 decision-aware training) 的合法性也由此被理论锚定。

    7.3 ACF cherry-pick critique#

    Cramer et al. (Phase 0c-B B-d1) 提出的关键 methodological critique：标准实践 "randomly select 3–4 historical scenarios and search for matching generated scenarios" 后读 ACF agreement 作为 temporal correctness 证据——这不是 proper test。该 critique 推广到：

    • Marginal-CRPS matches 不证明 joint-temporal 正确性
    • Joint-ES matches 不证明 regime-conditional 行为
    • 任何不分层 (stratified) 的指标都可能被全局-均值平均掉关键 tail 行为

    调研池中所有 Tier 1–2 仅靠 ACF 通过 multivariate diagnostic 的论文都应被打上这一警告。

    ACF critique 的具体替代方案：替代 "随机选 3–4 historical scenarios" 的更严格做法包括：(a) regime-stratified ACF：在每个 regime 内单独算 ACF，给出 regime-wise 的 ACF 偏差分布而非单一汇总值；(b) multi-lag KS test：对 lag 1, 4, 24 (对应 15-min, 1-h, 6-h 滞后) 分别做 KS 检验，给出 distribution-free 的统计显著性；(c) spectral density match：在频率域比较生成与历史的 power spectral density，对周期性事件 (日周期、晚高峰) 更敏感。这三种方法在调研池的 power-diffusion 论文中几乎都没有出现——这是 §11.2 minimum reporting standard 应补充的具体技术建议。

    7.4 "2% optimality gap hides decisions" 论点 (B-d2)#

    来自 SP-UC 文献的 folk-wisdom (Castle / Princeton SP-UC 群组 <verify-Phase-2>)：a 2 % optimality gap can hide large errors in decisions。一个 cost-near-optimal commitment 仍可能在 哪些机组被 commit 上差异巨大，这影响备用、ramp adequacy、下游 redispatch。

    Phase 1 推荐：diffusion paper 即使报告 X % CRPS 改进并附加 UC 实验，也不能仅靠 optimal-cost 相同就声称 decision-coherent——必须同时报告 commitment Hamming distance \(d_H\) 与 redispatch volume。这是 §10 F7 frontier 的方法论核心。

    7.5 Coverage–consistency 与 \(w\)-sweep figure#

    Phase 0c-C Seam C2 提出 本 survey 最便宜的 frontier-figure：把任何 CFG-conditioned power diffusion (MS-CADM 是 obvious target) 的 \(w\) scan 与 (i) marginal CRPS、(ii) regime-conditional CRPS on 稀有 regimes、(iii) ramp-distribution KS distance、(iv) energy score 一起画出来。

    这一 figure 同时是 MS-CADM 79.89 % 数字的方法论 cross-check：如果 conventional-baseline error 在中等 \(w\) 下崩溃到正常范围，那么 79.89 % 就是 \(w\)-mismatch artefact 而非 diffusion superiority。本 survey §11 把这条 figure 列为 minimum reporting standard。

    \(d_H\) 在 power 实践中的意义：一个 ISO operator 在 day-ahead market 中 commit 600 个机组 × 24 小时 = 14,400 个 0-1 变量。两个 cost-near-optimal commitment 在 Hamming 上可以差异 100–500 (1–3 %)，对应数十个机组的开停决策不同——这直接影响 (i) 启动成本 (一台 large gas turbine 启动成本 \(10K-\)50K)、(ii) reserve adequacy (commit 的机组 portfolio 不同则 reserve 能力不同)、(iii) ramp adequacy (response speed 不同)、(iv) maintenance schedule (反复启停加速磨损)。所以 commitment Hamming 不是抽象指标，而是直接对应数十万美元的运营差异。这是 §10 F7 推荐它作为 minimum reporting standard 的实际依据。

    7.6 Decision-aware 指标 (Tier 4) 详解#

    Operating-cost gap (B-c2) ——最便宜的 decision-aware 指标：用生成场景训练 SP / UC，在 held-out realisation 上评估，与 oracle (见到真实场景的 perfect-information solver) 的成本差。只需 (i) 一个 deterministic UC solver、(ii) 一个 held-out realisation 集。没有一篇 diffusion-renewable 论文做这件事。

    VSS (B-c1)：\(\mathrm{VSS} = \mathbb{E}[c_{\mathrm{op}}(x^*_{\mathrm{EV}})] - \mathbb{E}[c_{\mathrm{op}}(x^*_{\mathrm{SP}})]\) 量化"更好的不确定性表示"买到了多少。EVPI：\(\mathrm{EVPI} = \mathbb{E}[c_{\mathrm{op}}(x^*_{\mathrm{SP}})] - \mathbb{E}_\xi[c_{\mathrm{op}}(x^*(\xi))]\) 量化"完美信息"再能买多少。古典 SP-UC literature 报告 VSS ≈ 0.5–2 % 在 day-ahead vs intra-day <verify-Phase-2>；现代 renewable-heavy 案例下推高。0 diffusion 论文报告 VSS / EVPI。

    cost-CRPS (B-Seam 3)：本 survey 提议作为 decision-coherent calibration diagnostic。对每个 \(\mathbf{c}\)，比较 sampled scenario 诱导的 \(c_{\mathrm{op}}\) 分布 vs oracle 场景诱导的分布的 CRPS。Sample 复杂度由 UC 求解次数 (而非 scenario 维度) 主导。

    commitment Hamming \(d_H\) (B-Seam 4)：

    \[d_H(u_1, u_2) = \sum_{g, t} \mathbb{1}\{u_1^{g, t} \ne u_2^{g, t}\}\]

    是简单非成本指标——两个生成器在相同 operating cost 下可能产生 radically 不同 commitment，差异在备用 / redispatch / 可靠性上传播。

    Regime-conditional 一切 (B-Seam 5 + C-Seam C2)：tail / regime 覆盖 (Phase 0a §6.5) 是 decision-relevance 咬合的地方——多数 operating-cost variance 居住在 5–10 % rare regimes (Dunkelflaute, frontal ramp)。报告 cost-CRPS conditional on regime label 而非汇总。这是 §10 F8。

    7.7 Gap 为何持续？(B §3)#

    Phase 0c-B §3 给出四个 mutually-reinforcing 原因：

    (i) 基础设施成本。Tier 4 评估需要 (a) 开放数据的网络模型 (ramp / capacity / reserve / transmission limit)、(b) UC solver (with Lagrangian / Benders / progressive-hedging 支持)、(c) 与训练集独立的 held-out realisation 集。ML 会议的 diffusion 论文 (TimeGrad, CSDI 系) 无 UC pipeline；Applied Energy / Energies 的 diffusion 论文有零散 UC pipeline 但无标准化。OA-cGAN 在 NYISO-11 上做 DC-OPF——但不能跨 diffusion submission 重用。

    (ii) 审稿惯例。Renewables-ML 审稿主要看 CRPS / ES / \(W_2\) 表；加 UC 实验是 additional，引入 attack surface (UC 公式选择、cost coefficient、reserve product)。边际激励是不做 UC。

    (iii) 方法论文偏置。Diffusion 架构论文走 NeurIPS / ICLR / Applied Energy；UC / DRO 实验论文走 IEEE T-PWRS / INFORMS J. on Computing。两社区非重叠 reviewer 池。

    (iv) Gradient-transport gap。DFL 解决了 predictive-point loss 的梯度传输。Diffusion 的类比——对 sampled distribution 下的期望 operating cost 关于 score / noise prediction network 微分——需要 REINFORCE-style estimator 或 pathwise gradient through sampling SDE。两者在 renewable-scenario diffusion 中均非标准。OA-cGAN 的 saddle-point 解法不直接转移到 non-adversarial diffusion loop。

    7.8 Cross-thread connections — §5 / §7 / §8 在评估章节的交汇#

    Phase 0d §7 给出了三个 deep-dive thread 的 cross-thread connections。在本章 (§7 evaluation hierarchy) 上落地，可总结为四个具体交叉：

    (i) §5 P6 (constraint placement) × §7 Tier 4 (decision-aware metric) —— 同一对象的两面 (训练 loss vs 评估 metric)；F3 frontier 闭合二者。本 survey 一直主张 P6 训练应该用 与 evaluation 同源 的 cost 函数 (operating cost from same UC solver)，否则会出现"训练优化的 cost 与评估的 cost 不一致" 的隐藏 mismatch——这是 OA-cGAN 默认满足、而 diffusion P6 必须显式保证的条件。

    (ii) §4 rung 4 (CFG-conditioned regime label) × §7.5 (CFG-scale × tail-coverage curve) —— CFG 的 \(w\) 是控制 trade-off 的唯一旋钮；调研池中任何 CFG-conditioned 论文都应该附带 \(w\)-sweep figure，但目前零 篇这样做。F6 frontier 就是把这个 curve 标准化。

    (iii) §5 P3 (gradient guidance) × §7 Tier 3 (regime-conditional CRPS) —— Hoseinpour & Dvorkin (W6) 的 AC-feasibility guidance 在 typhoon-style rare regime 上是否仍保持 feasibility？没有任何文献报告。Score-based Offshore Typhoon Diffusion 报告 regime-conditional 评估但不用 AC-feasibility guidance；W6 用 guidance 但不报告 regime split。二者必须 join。

    (iv) §3.1 (b) discrete-token diffusion (LEAF) × §8 (head-to-head) —— 家族区分对 §8 比较表的可读性至关重要 (§2.4)。

    7.9 §7 的核心 takeaway#

    回到本章开头的立场：评估比方法更重要。Diffusion-renewable 子领域当前的局部最优在 Tier 1–2 的 CRPS / ES 上反复优化，但每篇论文的边际进步对运营决策几乎不可见 (因为 Tier 4 与 Tier 1–2 不对齐)。退出这一局部最优的必要条件是：(a) reviewing convention 把 Tier 3–4 升级为必报项；(b) public testbed 让 Tier 4 评估的边际成本趋零 (F1)；(c) 至少一个 high-profile diffusion 论文 (例如把 MS-CADM 在 PERFORM 上 rerun 的 F4) 把 Tier 1–4 同时报告，使 community baseline 重置。三者都需要 survey-driven advocacy —— 这是本 survey 选择把 Tier 4 空白放在头条位置的方法学动机。

    8. Diffusion vs probabilistic transformer (NEW head-to-head)#

    本章直面 Phase 0a §6.4 的开放问题与 Phase 0b T5 的 unifying thread："diffusion 在可再生能源场景上击败 probabilistic transformer" 这一断言到底有多牢？核心结论是：该断言在当前实验记录下是 underdetermined——既不能确证、也不能证伪，因为两类方法在 renewable 数据上从未做过 matched 比较。本章按时间线整理三段证据 (2021 非可再生 baseline、2024 TACTiS-2 反超、2026 PERFORM benchmark 无 diffusion entry)，并以 5 行比较表收束。

    8.1 Benchmark trail (非可再生)#

    TimeGrad (ICML 2021) + CSDI (NeurIPS 2021) + ScoreGrad (arXiv 2021)——canonical diffusion-for-TS 三件套。在 electricity dataset 上，TimeGrad 报告 CRPS-sum 0.0206，narrowly 领先 Transformer-MAF 的 0.0207 (Phase 2 fact-check 已对原 ICML 2021 paper Table 1 cross-confirm 此数值)，远超更早 baseline。CSDI 在 electricity 与 traffic 上具竞争力。Speed：TimeGrad 最慢 (autoregressive decoding)，CSDI 非 autoregressive 更快，ScoreGrad 用 continuous-time SDE 摊销 sampling。

    广为流传的 headline "diffusion beats transformer for TS" 主要建立在该 electricity-and-traffic 比较上；0.0206 vs 0.0207 的 0.0001 差距落在 run-to-run variance 内——Phase 0d §6.2 已专门标记为不能提升到 "diffusion wins"。

    TACTiS-2 (ICLR 2024)——attentional-copula transformer，参数量在变量数上线性 (此前 TACTiS-1 是 quadratic — 由 \(D \times D\) Gaussian copula correlation 矩阵驱动；TACTiS-2 通过 attentional copula 把这一二次依赖压到线性，不是 从 factorial 降到线性)。在 multivariate 数据集上报告新 SOTA，与 TimeGrad、GPVar、TempFlow、Stochastic Process Diffusion (SPD) 直接对比。TACTiS-2 在 CRPS / CRPS-Sum / Energy Score 下、在 相同 GluonTS 标准套件 (TimeGrad / CSDI / ScoreGrad 共同使用的) 上胜出。

    8.2 Benchmark trail (renewable / power)#

    DiffLoad (IEEE T-PWRS 2024, arXiv 2306.01001 <verify-Phase-2>)——Diffusion-Seq2Seq for load forecasting，separable epistemic vs aleatoric uncertainty (aleatoric 用 robust additive Cauchy)。报告系统与建筑层级的传统方法增益；baseline 是经典 TS / DL，不包括 foundation transformer。没有与 TACTiS-2 或 probabilistic transformer foundation model 的 head-to-head。

    Foundation-model Benchmark on ERCOT PERFORM (arXiv 2604.22077, "Empirical Assessment of Time-Series Foundation Models for Power System Forecasting Applications", 2026)。高分辨率 PERFORM 数据集；评估 TimesFM, Chronos-Bolt, MOIRAI-L, MOMENT, Tiny Time Mixer, TFT, PatchTST, TimeXer, LSTM, CNN 在八个能力上 (含 probabilistic forecasting 与 context-window effects)。TimesFM 在 24-h solar 上达 3.71 % normalized MAE，Moirai-L 在 wind 上 4.17 %。No diffusion model in the lineup。

    8.3b 解读表的方法学#

    读上表的正确姿态：不是"diffusion 输给 transformer"，也不是"diffusion 在 renewable 上仍然占优"，而是 "现在没有数据支持任何一个判断"。这一立场对 reviewing process 有具体含义：

    • 任何 renewable-diffusion 论文用"diffusion 优于 transformer" 作为 motivation，应该被要求直接比较 transformer baseline (TACTiS-2, TimesFM, Chronos-Bolt, MOIRAI-L 之一)；
    • 任何 transformer foundation model 论文 (TimesFM-class) 在 renewable 数据上 claim SOTA，应该被要求与 至少一个 renewable-domain diffusion baseline (CLDM / MS-CADM / DiffLoad) 比较；
    • 任何声称"diffusion 解决了 renewable scenario" 的综述文章应该 先 解决 §8.5 的 matched benchmark 才能立足。

    本 survey 的 §8 不是为了"裁决"diffusion vs transformer，而是为了让裁决可能成立 —— 即把"该问题在当前实验记录下 underdetermined"这一事实清晰呈现，使后续工作能瞄准这一空白。

    8.4 What the trail actually licenses#

    Headline "diffusion outperforms probabilistic transformer for renewable scenarios" 仅靠 2021 baseline 在非可再生数据上的传递性间接成立。Under matched 2024 evaluation, TACTiS-2 (transformer-copula) 已在 canonical TS benchmark 上反超；renewable corpus 上没有 diffusion paper rerun 比较。

    家族区分 (Phase 0d §6.6, Phase 0c-C Seam C5)：上表的 "diffusion" 全部限定为 continuous-noise DDPM / score-SDE。LEAF (discrete-token language diffusion) 与 LTSM-DIFF / T2S (LLM-guided continuous diffusion) 不能与上表内 diffusion entry 直接相加。LEAF caveat：因为 "diffusion" 发生在 LLM token space，与 transformer 的边界本身就模糊；它不应被当作 "diffusion wins" 的证据。

    8.4b The Bitter Lesson reading — F4 必须 parameterised by training-data budget#

    Deep-diver review §5 指出 §8 的最重要遗漏：把 diffusion-vs-foundation-transformer 简化为"matched benchmark 还没跑" 是 benchmark coverage 问题视角，但更强的 prior on F4 outcome 是 Sutton 的 Bitter Lesson 在时序 foundation model 上的具体化——TimesFM (训练于 ~100B 时间点)、Chronos-Bolt、MOIRAI-L 把先验知识从百万级无关序列压缩进权重；它们到 renewable 任务时自带强 inductive bias，是 score-matching 单领域模型无 pretraining scale 时无法匹配的。§8.2 的 PERFORM 数字 (TimesFM 24-h solar 3.71 % nMAE, Moirai-L wind 4.17 %) 关键不在 绝对优良，而在 near-zero-shot——foundation 模型没有在 PERFORM 上重训。

    F4 应当 parameterised by training-data budget，而非单点比较：

    Target-asset 数据规模 预测胜者 推理
    Few-shot (≤ 数月 target-asset 数据) Foundation transformer Pretraining prior 主导
    Mid-data (1–3 年) Tie 或 domain-specific 占优 Score-matching 学到的 marginal–joint coupling 是 foundation 模型留在桌上的
    Large data (5+ 年, dense asset history) Domain-specific diffusion 或 fine-tuned foundation transformer 取决于 diffusion 是否注入 foundation 缺失的物理结构 (P2 / P3 / P5)
    Out-of-distribution regime (Dunkelflaute, typhoon) Unclear；foundation 可能脆弱，但 diffusion 也没有 demonstrated 优势 F4 应专门测此 regime

    F4 框架的两层含义：(i) 用 数据预算 x 轴 + cost-CRPS y 轴 而非单数字 leaderboard 报告 F4；(ii) 准备承受最可能的 outcome——domain-specific diffusion 只在 mid-data regime 上有竞争力，意味着 diffusion-for-renewable 是 transitional technology。本 survey 把这一可能性写进 §11.5 limitations，因为即使 F4 给出这一结果，F1 / F7 / F8 这三个 model-agnostic frontier 仍然合法成立——survey 的方法学 claim 不依赖于"diffusion 必将胜利"。

    9. Decision-aware generative scenarios#

    本章把 §5 P6 的"空白格" 与 §7 Tier 4 的"空白层"放在同一画面下读。结构性观察：把 decision-aware 训练 (§5 P6) 与 decision-aware 评估 (§7 Tier 4) 视为同一问题的两面——前者把成本作为 loss 信号、后者把成本作为评估信号；二者都需要 differentiable / repeatable UC pipeline，且共享同一 gradient-transport 难题。OA-cGAN 在 2022 年通过 saddle-point 在 cGAN 框架内同时解决两面 (训练 loss = 评估 loss = 运营成本)；diffusion 至今没有 analogous 工作。本章按方法学源流 (OA-cGAN → SPO → DFL → DRO → IEEE-CIS challenge) 整理 prior art，并以 gradient-transport gap 收尾——这正是 §10 F3 frontier 的技术核。

    9.0 章节结构与方法学定位#

    本章按"由近及远"的方法学距离展开：先 (§9.1) OA-cGAN——在 diffusion 之外、但已经实现 P6 的最直接前驱，是 diffusion P6 必须 dethrone 的 baseline；再 (§9.2) SPO/SPO+——给出"正确的 loss 是下游成本" 的数学奠基，但只覆盖 point predictor，scenario-set 扩展未做；再 (§9.3) DFL——把 gradient transport 推广到通用 differentiable optimization，但 diffusion lift 未做；再 (§9.4) DRO with generative ambiguity——把 scenario-set 与 worst-case 决策耦合，但 latent-space DRO 与 cost-space DRO 不等价；再 (§9.5) IEEE-CIS challenge——community-level 标准化，但 diffusion 缺席。最后 (§9.5b + §9.6) 收束到 gradient-transport gap——把这五条线索读为一个未解决的技术问题。

    9.1 OA-cGAN — 非扩散 P6 的 canonical anchor#

    Operation-Adversarial Scenario Generation (Zhirui Liang, Robert Mieth, Yury Dvorkin; Electric Power Systems Research vol. 212 art. 108451, July 2022; arXiv 2110.02152 Oct 2021)。Venue 更正：Phase 0b S6 把它误置于 Applied Energy — 错误，正确 venue 是 EPSR。Authors are Phase-2 verified (Rutgers / NYU / Johns Hopkins lineage via OSTI + Rutgers publication page).

    Mechanism：cGAN 的 generator 训练为 最大化下游 DC-OPF 模型的运营成本，DC-OPF 消费 generator 的输出作为 net-load forecast error。Discriminator 仍执行统计可信度。Saddle-point 在 "credible and costly" 处。

    Testbed：NYISO 11-zone，day-ahead net load。

    为什么对 Thread B 关键：它是 Phase 0 调研池中唯一闭合 "generator → operational model → cost → loss signal" 的代表——任何 decision-aware diffusion paper 都必须以它为先验。Phase 0c-B 与 Phase 0d 反复强调它在 §5 P6 + §9 中的双重 anchor 地位。

    OA-cGAN 的 saddle-point 公式 (tri-level 结构)：

    \[\min_{G}\ \max_{D}\ \min_{\theta_{\mathrm{op}}}\ \mathbb{E}_{\mathbf{c}}\left[ - c_{\mathrm{op}}(G(\mathbf{z}, \mathbf{c}); \theta_{\mathrm{op}}) + \lambda \log D(\mathbf{x}^{\mathrm{real}}, \mathbf{c}) + \lambda \log (1 - D(G(\mathbf{z}, \mathbf{c}), \mathbf{c}))\right]\]

    其中 \(\theta_{\mathrm{op}}\) 是 DC-OPF 的内部变量 (dispatch, line flow)。结构是 tri-level：最内层 \(\min_{\theta_{\mathrm{op}}}\) 表示系统操作员最小化派遣成本 (这是 OPF 本身的定义)；中层 \(\max_D\) 是 discriminator 想区分真假；最外层 \(\min_G\) 是 generator 想 maximize operator 看到的 worst-case operating cost (因此外层是 \(-c_{\mathrm{op}}\) 的 minimize 等于 cost 的 maximize)。让 saddle-point 可解的关键是 DC-OPF 的 LP 凸性：通过 LP 对偶把最内层 \(\min_{\theta_{\mathrm{op}}}\) 折叠为对偶变量上的 \(\max\)，得到 standard \(\min_G \max_{D, \mu_{\mathrm{dual}}}\) 的双层 saddle-point。原 paper 用 KKT-based 反传或 LP 对偶嵌入实现这一折叠。

    关键 inferential 工具：生成器同时优化 statistical credibility 与 cost informativeness——只追求 cost 会产生不像真实数据的极端样本 (被 \(D\) 拒绝)；只追求 credibility 会产生 cost-uninformative 的中位数样本 (gradient 信号弱)。Saddle-point 是平衡点。

    diffusion P6 不能直接套用 saddle-point：因为 diffusion 没有显式 discriminator。F3 的设计 (§5.7 + §10) 用 calibration regularizer (CRPS-like) 替代 discriminator，把 saddle-point 退化为 single-objective minimization \(\mathcal{L}_{\mathrm{DA}} = \mathbb{E}[c_{\mathrm{op}}] + \lambda \mathcal{L}_{\mathrm{simple}}\)，但这一替换是否保留 OA-cGAN 的"统计可信"诱导力是 F3 的核心 unresolved 问题。

    9.2 Smart "Predict, then Optimize" (SPO / SPO+)#

    Elmachtoub & Grigas (Management Science journal version, 2022; arXiv 2017) <verify-Phase-2>：定义 SPO loss = 用预测参数 vector 替代真实 vector 时的 excess decision cost；加上 convex surrogate SPO+ with consistency 保证。非生成——是 predictive-point 而非 scenario-set。

    对本 survey 的关键：它是 "正确的 loss 是下游成本" 的数学参考。Scenario-set 扩展应为 expected SPO loss under the sampled distribution —— diffusion 上未形式化。

    9.3 Decision-Focused Learning (DFL) for power systems#

    Phase 0c-B B-b3 的 cluster：(i) economic dispatch with price-responsive demand (Electric Power Systems Research 2024), (ii) PV-battery scheduling (J. Energy Storage 2026), (iii) data-driven robust energy management (Applied Energy 2025), (iv) decision-focused retraining for smart-energy optimisation (ACM e-Energy 2024)——全部 <verify-Phase-2>，机制各异，不可联合引用 (Phase 0d §6.4 警告)。

    Mechanism：end-to-end 梯度通过优化问题 (KKT differentiation, perturbation à la Berthet et al., 或 surrogate objective)，使预测模型被下游决策质量塑形。

    对扩散的意义：DFL 解决了 deterministic / quantile predictor 的 gradient-transport 问题；把它 lift 到 diffusion 的 score / noise prediction network 是未做。技术钥匙：(a) pathwise gradient through DDIM-style 可微分 sampler，(b) differentiable UC surrogate (LP relaxation + perturbation 或 Lagrangian dual)。

    DFL 与 diffusion 的难度比较：DFL 在 deterministic predictor 上"只需"对单一点估计的 cost 取梯度；diffusion 上需要对 sampled distribution 的期望 cost 取梯度——后者引入 (i) Monte Carlo sample variance，(ii) sampler 内部 \(T\) 步链式梯度，(iii) regularization vs cost 的双 loss 权衡。这三层难度叠加是 F3 高 novelty 的根源，也是为什么调研池中没人做的实际原因。

    9.4 DRO with generative ambiguity sets#

    Phase 0c-B B-b4：建立 Wasserstein ambiguity set 在生成模型 latent space 内 (包括 diffusion)。arXiv 2602.08976 "Distributionally Robust Optimization via Generative Ambiguity Modeling" (提出 "GAS-DRO" 框架, 2026)。Mechanism：替代 raw scenario space 上的 \(W_2\) 测量，ambiguity 半径在学到的 latent 中设；ball 内 worst-case 分布驱动 DRO。

    Phase 0c-B B-d3 critique：latent-space \(W_2\) 不证明 worst-case 在 operations 意义上是 worst-case。Latent-\(W_2\) 与 cost-\(W_2\) 一般给出不同 ranking。

    直觉：latent space 中的 ball 通过 decoder 映射到 raw scenario space 后，形变可以剧烈非各向同性——所以 raw scenario space 中"等远"的两点在 latent 中可以"近"或"远"；同样地，raw scenario space 中 cost-相邻的两点 (operating cost 相同) 在 latent 中可能很远。这是 latent-DRO 的 operationally suboptimal 根因。修复路径有二：(a) 在 cost space 直接做 DRO (但 cost 不可微所以 ambiguity ball 几何复杂)；(b) 学习 cost-aware latent (joint training of encoder 与 cost predictor)。两条路径都未在 power-diffusion 上探索。

    9.5 IEEE-CIS Predict+Optimize Challenge (B-b5)#

    2022 challenge + 2023 follow-up；arXiv 2212.10723 <verify-Phase-2>。Community benchmark：forecaster + scheduler 联合按 dispatch cost 评分而非 forecast 准确度。对本 survey 的意义：少数 标准化 decision-cost benchmark 在 renewable-scheduling 交集；diffusion entrant 未参加。

    9.5b Cross-thread: 为什么这个 chapter 与 §5 P6、§7 Tier 4 是同一问题？#

    回到 §1.1 的三轴攻击：本 chapter 既是 §5 (constraint placement) 中 P6 cell 的展开，也是 §7 (evaluation hierarchy) 中 Tier 4 的展开——这不是巧合。从信息论角度看，把"运营成本"作为 loss 信号 (训练) 等价于把"运营成本"作为 evaluation 信号 (评估)，差别只是梯度方向 (训练时反向传播，评估时只前向)。这就解释了为什么本 survey 一直主张：F2 (P5 hard layer) + F3 (P6 decision-aware diffusion training) + F7 (commitment Hamming as metric) + F1 (decision-aware reusable benchmark) 应当被视为同一个 4-piece artefact，而非 4 个独立 frontier。任何 v2 survey 应该把这 4 件作为单一交付物 推荐给社区。

    9.6 The gradient-transport gap (frontier F3 的技术核)#

    Phase 0c-A Seam 4 + Phase 0c-B Seam 2 + Phase 0d F3 一致命名：pathwise gradient through DDIM sampler × differentiable UC surrogate 是 unsolved gradient-transport 问题。

    技术拆解：

    1. Pathwise sampler——DDIM (Denoising Diffusion Implicit Model, Song et al. ICLR 2021) 是 DDPM 的确定性变体：反向链改写为 ODE 求解器，整个采样过程对参数可微，是 pathwise gradient 的前提。它给出 deterministic sampler \(\mathbf{x}_0 = G_\theta(\mathbf{z}, \mathbf{c})\)，其中 \(\mathbf{z}\) 是初始 Gaussian noise。\(\partial \mathbf{x}_0 / \partial \theta\) 可计算 (chain rule through \(T_{\text{diff}}\) steps，可能因 step 多而梯度爆炸 / 消失)。
    2. Differentiable UC surrogate——纯 MILP UC 不可微，但其 LP relaxation 可微 (一阶 KKT)，或通过 perturbation (Berthet et al. 2020 <verify-Phase-2>) 得到 unbiased 梯度估计。也可用 Lagrangian dual 显式构造可微 dual。
    3. Loss——上式 \(\mathcal{L}_{\mathrm{DA}} = \mathbb{E}_{\mathbf{c}}[\mathbb{E}_{\mathbf{x}_0 \sim p_\theta(\cdot \mid \mathbf{c})}[c_{\mathrm{op}}(\mathbf{x}_0)]] + \lambda_{\mathrm{cal}} \cdot \mathcal{L}_{\mathrm{calibration}}\) 是 P6a (per-scenario expected cost) 的具体化；calibration regularizer (e.g. CRPS-like) 防止 generator 只追求 cost 而抛弃 marginal 标定。P6b 形式则需把 inner expectation 替换为 SP-decision cost：\(\mathcal{L}_{\mathrm{DA}}^{\text{P6b}} = \mathbb{E}_{\mathbf{c}}[c_{\mathrm{op}}(x^*_{\mathrm{SP}}(\{\mathbf{x}^{(k)} \sim p_\theta\}); \xi_{\mathrm{true}}\mid \mathbf{c})] + \lambda_{\mathrm{cal}} \mathcal{L}_{\mathrm{calibration}}\)——SP / UC 求解在训练 loop 内，与 OA-cGAN 同 target 但用 diffusion sampler 替代 cGAN generator。P6a 与 P6b 只在 SP 问题 不 分解 per-scenario 时 (即存在 here-and-now binding decision 如 unit commitment) 才严格不同；F3 frontier 应明示选择哪个变体。

    F2 (P5 hard layer) 是 F3 的工程前置：没有 P5 把 sampled \(\hat{\mathbf{x}}_0\) 钉在 \(\mathcal{F}\) 上，F3 的 gradient signal 会被 UC solver 对 infeasible scenario 的 clipping / penalty 污染。

    9.7 Diffusion + DRO 的两种 lift 路径#

    (a) Latent-space DRO (B-b4 风格扩展到 diffusion)：在 diffusion latent (或 \(\mathbf{x}_t\) at 某中间 \(t\)) 上设 \(W_2\) ball；通过 score function 把 ambiguity 推回 raw scenario space。Caveat: latent-\(W_2\) ≠ cost-\(W_2\) (§9.4)。

    (b) Sample-then-evaluate DRO：用 diffusion sample \(\{\mathbf{x}^{(k)}\}\) + raw scenario space 上的 \(W_2\) ambiguity ball；evaluate worst-case expected cost via Lagrangian / cutting plane。这是 B-c1 风格的扩展，但要求 sample 量大到能逼近 \(p_\theta(\cdot \mid \mathbf{c})\) 的尾。

    两条路径都 未在 diffusion-renewable 调研池中实现。

    9.8 §9 章节小结#

    回顾全章：OA-cGAN 在 2022 年以 saddle-point 在 cGAN 框架内实现了 P6，是 唯一 在 power-renewable 调研池中实现"训练 loss = 运营成本" 的工作；SPO / SPO+ 给出"用决策成本而非预测误差作为 loss" 的数学基础；DFL 把这一理念推广到通用可微分优化；DRO with generative ambiguity sets 把 scenario set 与 worst-case 决策耦合，但 latent-vs-cost mismatch 未解决；IEEE-CIS challenge 提供 community-level 标准，但 diffusion 缺席。

    整章的方法学 takeaway：把 diffusion 训练成 decision-aware 而非 likelihood-aware 是当前最高新颖性、最高 leverage 的技术问题；技术钥匙是 pathwise gradient through DDIM × differentiable UC surrogate；其工程前置是 P5 hard layer (§5.6)；其评估配套是 commitment Hamming + cost-CRPS (§7.6)；其公共基础设施是 F1 testbed (§10)。把这四块打包作为单一研究 program，是本 survey 推荐给 v2 或 Phase 3 deep dive 的具体路径。

    10. Open frontiers (NEW synthesis section)#

    本章把 Phase 0 三个 deep-dive thread 的 15 个 seam 去重、合并、按 leverage × novelty × engineering cost 排序为 F1–F8。F1–F8 不是 8 个独立子问题，而是两个核心问题 (decision-aware + regime-aware) 沿不同侧面的具体化：所有 frontier 在两个收敛点上耦合——(i) decision-aware feasibility on public testbed (A-Seam 3+4 / B-Seam 1+2 / C-Seam C1)；(ii) regime-conditional 一切 (B-Seam 5 / C-Seam C2 / Phase 0a §6.5)。把它们一起读，能看到 v2 survey 应该锚定的位置。

    每个 frontier 后附 "what would the first paper here look like" 的一段速写，给出可立即操作的实验框架。

    F1–F8 的两轴聚类：把 F1–F8 沿"是否涉及决策意义"与"是否涉及 rare regime"两个轴分类，得到一个紧凑的 2×2：

    decision-aware not decision-aware
    regime-stratified F1 (testbed)、F3 (P6 训练)、F7 (commitment Hamming)、F8 (regime-conditional) F6 (CFG × tail-coverage)

    F1 — Decision-aware reusable benchmark (B-Seam 1)#

    问题：调研池所有 diffusion-renewable 论文均无 Tier 4 评估，而 Tier 4 需要 (a) 开放数据网络模型、(b) UC solver、(c) held-out realisation 集——任何单一论文都不愿独自承担基础设施成本。

    建议工件：公共 testbed = NREL WTK (wind) + SURFRAD (solar) + IEEE 118-bus / RTS-GMLC + Egret 或 PowerSimulationsDynamics 作为开源 UC solver + 标准化 held-out realisation 拆分。任意生成器一旦适配 testbed，automatically gain (i) stochastic-UC operating cost、(ii) DRO worst-case expected cost、(iii) redispatch volume、(iv) commitment Hamming——全部为 free。

    第一篇论文形态：把上述 pipeline 打包为 GitHub repo + 数据 manifest + 评估 script + 三个 baseline generator (历史 bootstrapping, copula GMM, simple DDPM)。Survey-driven artefact paper，不需要新方法。

    为什么是 F1：jointly solves "infrastructure" 与 "coverage" side (§7.7 + §8.5)；后续所有 v2 survey 都能引用为 first matched comparison。

    Phase 0d §7.4 命名的 meta-fissure：F1 同时关闭 §7.7 (评估基础设施)、§8.5 (matched 模型覆盖)、§9.7 (decision-aware testbed)——三个看似独立的 gap 共享同一 testbed 基础设施。一篇 F1 论文等于把整个领域的 公地 (commons) 提供给社区，使后续每篇论文都能 免费 继承 matched 比较与 decision-aware 评估。这是本 survey 推荐的 highest-leverage 单篇论文目标。

    F1 的非技术风险：把 testbed 真正变成 community 公地需要解决三个非技术问题：(i) 维护——开放数据 (NREL WTK 等) 偶尔会有 schema 变更或文件 retirement，testbed 必须有 maintainer；(ii) 正典性——多个 testbed 共存会重新分裂社区，single canonical testbed 比 multiple competing testbed 更有价值，但需要 leadership；(iii) 冠名——learning challenge / leaderboard 在 ML 社区有强 incentive，但 open leaderboard 容易出现 over-fitting 行为；hidden test set 与 round-based release 是缓解工具。这些都是 F1 paper 写作时应当提前考虑的运营问题。

    F2 — P5 hard output layer for renewable scenarios (A-Seam 3)#

    问题：P5 cell 对 renewable scenario 完全空白；KCLNet-style hard 层在 非扩散 生成模型中惯例，但 diffusion decoder 上未实现。

    第一篇论文形态：在 CLDM 或 CAL-DM 上挂一个 capacity / ramp / KCL-completing 可微分 final layer \(L_\mathcal{F}\)；ablate (i) raw diffusion、(ii) + P3 gradient guidance、(iii) + P5 hard layer、(iv) P3 + P5。报告 (a) feasibility violation rate、(b) marginal CRPS、(c) ramp-distribution KS distance。

    为什么是 F2：机械上是 small change (一个 differentiable layer)，工程风险极低，实证空白；是 §10 F3 的工程前置。Phase 0d 把它称为 "最可能的第一个 publishable empirical result"。

    为什么 P5 在 power-diffusion 文献中长期空白？Phase 0c-A 提供的猜测：在图像 diffusion 中，feasibility 通常是软约束 (像素值 \(\in [0, 255]\)，clipping 不会损失信息)，所以社区从未发展出 "hard output layer" 的工程惯例；power-system 社区有 KCLNet / OPF-Net 这些工具，但社区与 diffusion 社区交集少。这是一个跨社区的工程盲点，而非技术难题——F2 的存在本身就是对"为什么过去三年没人做" 的答案，也是 phase 1 推荐它作为 F1 之后的第二篇论文的理由。

    F3 — P6 decision-aware diffusion training (A-Seam 4 + B-Seam 2)#

    问题：把 W12 (Diffusion-DFL) 的 generic 框架 + OA-cGAN 的 idea lift 到 renewable diffusion 的 non-adversarial loop；解锁 §9.6 gradient-transport gap。

    第一篇论文形态：训练 CLDM (或 CAL-DM) 的 \(\epsilon_\theta\) 以最小化 \(\mathcal{L}_{\mathrm{DA}} = \mathbb{E}_{\mathbf{c}}[\mathbb{E}_{\mathbf{x}_0 \sim p_\theta(\cdot \mid \mathbf{c})}[c_{\mathrm{op}}(\mathbf{x}_0)]] + \lambda_{\mathrm{cal}} \mathcal{L}_{\mathrm{simple}}\)；通过 pathwise gradient through DDIM sampler + LP-relaxed UC + perturbation 估计器 (Berthet et al.) 计算梯度。Pre-condition：F2 已部署 (否则 sampler-time infeasibility 污染 gradient)。

    为什么是 F3：最高新颖性；技术钥匙清晰；与 OA-cGAN (非扩散 P6) 形成自然 saddle-point-vs-direct-min 比较；是 §1.1 三轴交汇点的具体实现。

    F3 的 risk-tiering：技术风险来自三个方向：(i) DDIM sampler 的 \(T\) 步链式梯度可能爆炸 / 消失 (与训练大型 Transformer 类似)；(ii) LP-relaxed UC 与原 MILP UC 之间的 决策 gap 可能在某些 regime 上放大，使 F3 的"训练时 LP cost" 与 "测试时 MILP cost" 不一致；(iii) 训练时 calibration regularizer 的权重 \(\lambda_{\mathrm{cal}}\) 需要仔细调，过小会使 diffusion 退化为 cost minimizer (单点而非分布)、过大会使 cost loss 信号被 calibration 淹没。这三个 risk 都有标准的 ML 工具集 (gradient clipping、curriculum、grid search)，但在 power-renewable diffusion 上没有任何经验数据——所以 F3 的 novelty 极高，但工程 risk 也实在。

    F4 — Renewable diffusion-vs-foundation-transformer matched comparison (C-Seam C1)#

    问题：§8.5 已展开。Headline 比较 "diffusion beats transformer" 仅靠 2021 baseline 在非可再生数据上的传递性；2024 TACTiS-2 已反超；2026 PERFORM benchmark 无 diffusion entry。

    第一篇论文形态：两条独立路径：(a) 把 CLDM / MS-CADM / DiffLoad 跑在 PERFORM 协议上 (TimesFM / Chronos / MOIRAI / TACTiS-2 共同 leaderboard)；(b) 把 TimesFM / MOIRAI / TACTiS-2 跑在 CLDM 公开数据集上。报告 Tier 1–2 全套 + (若 F1 已部署) Tier 4。

    为什么是 F4：highest ROI / lowest novelty / highest 确定性；任何后续 survey 可以直接引用。

    F4 vs F1 的关系：F4 可以在 F1 (公共 testbed) 部署后免费完成——任何在 testbed 上注册的生成器自动产出 matched 比较数据；F4 也可以在 F1 不存在时单独完成 (作为 stand-alone benchmark paper)，但缺乏后续可扩展性。本 survey 推荐 F1 + F4 打包完成。

    F4 的两个具体路径与各自风险：路径 (a) "把 CLDM/MS-CADM/DiffLoad 跑在 PERFORM 上" 风险在于这些 diffusion 模型原本针对 Chinese regional 数据训练，迁移到 ERCOT 后性能可能崩溃——这一崩溃本身就是有信息的 (说明现 diffusion 论文对地理 / 气候迁移的鲁棒性弱)，但需要 paper 设计能区分"方法弱" 与"训练数据 distribution shift"。路径 (b) "把 TimesFM/MOIRAI 跑在 CLDM 数据集上" 风险较小但对应工作量大 (需要复现 CLDM 数据 pipeline)。推荐先做 (a) 因为信息密度更高——一个失败的迁移结果比一个 baseline 的额外验证更能推动领域思考"renewable 数据是否真的不同于 GluonTS 标准数据"。

    F5 — Text / LLM-prompt conditioning for power scenarios (C-Seam C3)#

    问题：§4.5 rung 5 对 power 完全空白；conditioning bottleneck (小 text 嵌入 ↔ 大 scenario latent) 与 paired data scarcity (天气 regime 与场景的配对文本) 是实际 blockers。

    第一篇论文形态：把 NREL WTK regime cluster label 与简短合成文本 ("clear-sky summer afternoon, light westerly", "frontal passage with afternoon ramp") 配对；在 CLDM 上挂 T2S-style adapter；评估 regime-conditional CRPS + tail coverage。简单 modest，但是 rung-5 power 的首篇。

    为什么是 F5：highest novelty / methodological 影响 (打开 rung 5)；也自然演化为 F6 (CFG × tail) 的具体 carrier。

    F5 与现有 LLM-for-power 工作的关系：LLM 在 power-system 上的应用近一年快速增长 (S4 综述纳入)，但主要在 优化决策辅助 (LLM 作为 retrieval / explanation interface) 而非 生成式条件输入。F5 推荐的方向 (LLM-as-prompt for diffusion conditioning) 在 方法学 上是新的——它把 LLM 用作 prior on weather narrative，diffusion 用作 prior on physical scenario，二者通过 cross-attention 或 adapter 耦合。这一架构在 image 领域有 Stable Diffusion 等成熟先例；在 power 领域是空白。

    F6 — CFG-scale × tail-coverage curve (C-Seam C2)#

    问题：§4.4 + §7.5。Coverage–consistency trade-off 在 abstract 中断言，但没有任何已发表 power-diffusion paper 报告 \(w\)-sweep。

    第一篇论文形态：选 MS-CADM (或任何 CFG-conditioned power diffusion)，做 \(w \in \{0, 1, 2, 5, 10, 20\}\) 的 scan，对每个 \(w\) 计算 (i) marginal CRPS、(ii) regime-conditional CRPS on 5 % rare regimes (low-output / high-ramp / multi-day Dunkelflaute)、(iii) ramp-distribution KS、(iv) ES。一张图。

    Bonus：这张图同时是 MS-CADM 79.89 % 数字的 methodological cross-check (§7.5)。

    为什么是 F6：lowest engineering cost；single figure；本 survey §11 把它列为 minimum reporting standard。

    F6 与已有 power-diffusion 论文的关系：原 paper 不需要重训——F6 只是在 推理时 对训练好的 CFG-conditioned generator 做 \(w\)-sweep，再在 held-out test 上算各项指标。整个流程在单 GPU 上 ~12 小时可完成。这意味着 F6 是任意一篇调研池论文的合作作者 (或 reviewer 提议的 revision) 都可以快速补上的 figure。它的低成本是其作为 minimum reporting standard 而非独立论文的根本原因。

    F7 — Commitment Hamming 与 cost-CRPS 作 decision-coherent diagnostic (B-Seams 3, 4)#

    问题：§7.4 + §7.6。当前 diffusion 论文即使要做 UC，也只报 optimal cost，但 cost-near-optimal commitment 可能 wildly 不同。

    第一篇论文形态：在任意 diffusion-renewable scenario set (例如 CLDM 在公开 wind 数据上) 之上，运行 deterministic UC + report (i) cost-CRPS over 生成场景诱导的 \(c_{\mathrm{op}}\) 分布、(ii) commitment Hamming \(d_H\) vs oracle、(iii) redispatch volume vs realised。Pure methodology paper。

    为什么是 F7：把 §7.6 形式化的两个指标 (\(\mathrm{cost\text{-}CRPS}, d_H\)) 第一次报告在 power-diffusion 上，与 F1 互补 (F1 是 testbed，F7 是 metric protocol)。

    Bonus 的 fact-check 价值：把 MS-CADM 在 \(w \in \{0.5, 1, 2, 5\}\) 上 rerun，如果 conventional baseline 在某个 \(w\) 下回落到 ~10 % 量级，那么原文的 79.89 % 数字就被诊断为 \(w\)-mismatch artefact 而非 diffusion superiority。这一 single-figure cross-check 比传统 venue-level fact-check (查 venue, 查 author, 查 arXiv) 更具方法学价值，因为它直接重新执行论文的实验。本 survey §A.2 + §A.6 共同推荐 F6 figure 作为 79.89 % claim 的最终判决工具。

    F8 — Regime-conditional 一切 (C-Seam C2 + B-Seam 5)#

    问题：§7.6 末尾。多数 operating-cost variance 居于 5–10 % rare regime；现有 diffusion 论文用 pool-averaged 指标，对 grid-critical 事件不敏感。在 renewable-heavy 系统中，rare regime (Dunkelflaute、frontal ramp、heatwave-induced load spike) 是 reserve sizing 与 capacity expansion 决策的核心驱动；pool-averaged 指标在这些 regime 上的性能可以与汇总性能差 2–3 个数量级，但 paper 标题数字看不出。

    第一篇论文形态：训练 regime classifier (e.g. low-output / high-ramp / multi-day Dunkelflaute / frontal ramp)；对调研池中至少 3 个 diffusion 论文重新报告 Tier 1–4 指标 分层 在 regime 上。Methodology paper，可以基于公开生成器复现。

    为什么是 F8：stratification methodology，与 F6 / F7 自然嵌套。

    • F5 → F8 通过 regime label：F5 (text/LLM conditioning) 的 first paper 用合成 regime text 作为 conditioning input，这一 regime label set 同时 enable F8 (regime-conditional 一切) 的 stratification。

    11. Conclusion & methodological recommendations#

    11.0 综述的方法论姿态 (回顾)#

    本 survey 在每个章节上都坚持两个原则：(i) 不查不写 —— author / venue / arXiv ID / 数值改进幅度都要先通过 verification gate；未通过的，要么不写名字，要么以 <verify-Phase-2> 显式暴露；(ii) taxonomy-first, fact-checked——三条轴的展开优先于具体方法的列举，使读者能在统一 notation 下读懂任意一篇 diffusion-renewable 论文位于哪一格、占据哪个 placement、做哪一层评估、爬到哪一级 conditioning ladder。这一姿态在 LLM-辅助综述时代尤为重要：流畅的 fabrication 与可信的 hedge 在文本上仅一线之差，唯一的防线是 verification discipline。

    11.1 三轴攻击 (复述)#

    三条轴 (constraint placement P1–P6、evaluation Tier 1–4、conditioning ladder rung 1–5) 各自的空白格 (P5 / P6 / Tier 4 / rung 5) 与"diffusion vs transformer underdetermined" 在一个结构点上交汇：decision-aware enforcement of feasibility on a public renewable testbed——P6 既是 placement 的最高层、又是 conditioning ladder 的终点 (cost-as-implicit-condition)、又是 evaluation 的 Tier 4。详见 §1.1 (展开)、§5.7–§5.8 (P6 单元)、§7.2 (Tier 4 census)、§4.5 (rung 5)、§8.5 (matched 比较)。

    11.2 Minimum reporting standards#

    任何后续 renewable-diffusion 论文应同时报告：

    1. 六位 placement vector：对每个工作，标注其在 P1 / P2 / P3 / P4 / P5 / P6 上的位置 (multi-hot)。Phase 0c-A Seam 5 已警告：当前文献用 single-label，导致 layered combination 不可比。
    2. 四层 evaluation reporting：Tier 1 (marginal CRPS)、Tier 2 (ES + variogram)、Tier 3 (ACF + ramp KS + regime-conditional CRPS)、Tier 4 (至少 operating-cost gap 与 commitment Hamming \(d_H\)，若有 SP 框架则加 VSS / EVPI)。
    3. Regime-stratification：所有 Tier 1–4 指标分层在 regime label 上 (low-output / high-ramp / multi-day Dunkelflaute)，而非汇总。
    4. CFG-scale sweep：CFG-conditioned 工作必须报告 \(w\)-sweep 与 tail-coverage 曲线 (§7.5 figure)；否则 headline 改进数字不可读。

    11.3 不查不写的具体形态 (recommendation)#

    任何后续 survey / 综述应：

    • 把 fact-check pass 作为单独 phase；任何 author / venue / arXiv ID / 数值 claim 必须通过 Semantic Scholar / OpenAlex / Crossref direct lookup。
    • 把 hedge 数值 ranges (e.g. "2.1–70.9 %") 拆分到 baseline-by-baseline；提供 median + 端点 baseline 说明。
    • 把可疑 arXiv ID 显式列出 (§6 fact-check register)；ID-based suspicion 不替代 verification，但是 prioritization signal。

    11.3b 对审稿与社区惯例的具体建议#

    (a) 审稿表格升级：renewables-ML 主流审稿表格 (NeurIPS / ICLR / Applied Energy) 目前在"评估完备性" 一栏只要求 CRPS / ES / variogram；建议升级为四层 reporting 表，并把缺失 Tier 3 / Tier 4 设为 "soft reject" 信号 (而非硬性拒稿，避免一次性扼杀好方法)。

    (b) 复现性数据 manifest：每篇 diffusion-renewable 论文应同时提交 (i) 训练数据切片 manifest、(ii) held-out realisation 集 manifest、(iii) baseline generator 复现脚本——使后续 v2 survey 能 直接 复现 head-to-head 比较，而不需要重训。

    (c) fact-check appendix 成为标配：综述 / survey 论文应附 Phase-0 / Phase-1 风格的 fact-check register；任何作者归属、venue、arXiv ID、数值 claim 都在该 register 中标记 verification 状态。本 survey §A 是一个具体模板。

    本 survey 与 S1–S4 的关系不是 "替代" 而是 "正交补充"：

    • S1 (Applied Energy 380:125059, 2025) 给出家族 share 分布；本 survey 不重复这一统计，但修正其 P6 venue 错误 (OA-cGAN 不在 Applied Energy)、补充 P5 / P6 空白格分析。
    • S2 (ACM CSUR 2025) 给出 ML-centric task-architecture-modality taxonomy；本 survey 在 power-renewable 子领域专门补充物理约束维度 (P1–P6) 与决策意义维度 (Tier 4)，这是 S2 不覆盖的。
    • S3 (arXiv 2401.03006, 2024) 聚焦 TimeGrad / CSDI / ScoreGrad；本 survey 在 §8 把 2024 TACTiS-2 与 2026 PERFORM benchmark 更新进时间线，并指出 S3 之后两年的关键证据空白。

    11.3d 数据与代码 reproducibility 的具体协议#

    本 survey 推荐的 reproducibility 协议有四级，按严格性递增：

    • L1 (基础)：论文附带 README 描述使用的数据集与版本；脚本 README 描述训练超参数；模型 checkpoint 不要求公开。这是当前 diffusion-renewable 论文的事实最低标准。
    • L2 (Tier 1–2 复现)：公开训练 / 验证 / 测试切片 manifest (文件 hash 或时间戳 cut-off)；公开评估脚本能在 manifest 上直接复算 CRPS / ES / variogram。这一级是 本 survey 推荐 的最低标准。
    • L3 (Tier 4 复现)：公开 UC 配置文件 (网络模型 + cost coefficients + reserve product 定义)；公开 held-out realisation 切片；公开 baseline generator 复现脚本。Tier 4 评估的公平比较只在 L3 之上才可能。
    • L4 (matched benchmark)：公开 testbed pipeline 把任意生成器映射到 Tier 1–4 评估结果 (本 survey F1 frontier 的实现)。这是 community-level 推荐。

    F1 frontier (公共 testbed) 的本质就是把整个领域从 L1 / L2 推到 L4——使 "matched 比较" 不再依赖每篇论文的 individual 努力，而是 默认免费。

    11.3e 与电力系统决策者沟通的 takeaway#

    最后给非 ML 背景的电力系统读者一个简明 takeaway：当前 diffusion-renewable scenario 文献的成绩 (CRPS 改进 5–15 %、energy score 改进相似量级) 在 统计上 是真实进步，但在 运营决策上 的传导未知。如果你是一个 ISO / utility 的 planner，决定是否把某篇 diffusion 论文的方法部署到 production UC，这篇论文的报告不足以让你做决定——你需要 (a) operating-cost gap 数字、(b) commitment Hamming vs 现有 forecaster 的差异、(c) regime-stratified 性能 (尤其是 high-ramp / low-output 等关键 regime)，三者目前都不在 paper 标准报告中。本 survey §11.2 的 minimum reporting standard 是直接为弥合"研究 paper" 与 "可部署 evidence" 之间的 gap 而设的。

    11.4 收束 — survey 的方法论 claim#

    本 survey 不报告新方法，而报告一个 re-reading：三条轴的断裂在 P6 / Tier 4 / decision-aware testbed 上汇聚为 同一个 结构问题。问题不是 "diffusion 是否优于 transformer / GAN / VAE"，而是 "整个领域是否在错误的轴上、用错误的 loss、在错误的 testbed 上做优化"——而 F1–F4 给出关闭这一问题所需的具体工件。

    更具体地说，本 survey 的核心 takeaway 可以浓缩为五句话：

    1. 物理结构有六个安置位置 (P1–P6)，不是 "physics-informed yes/no"。当前 power-renewable diffusion 论文几乎都集中在 P1–P3，P5 完全空白，P6 仅有非扩散 anchor (OA-cGAN, Diffusion-DFL)。
    2. 评估有四个层级 (Tier 1–4)，不是 "CRPS / ES 足够"。整个 diffusion-renewable pool 占据 Tier 1–2，Tier 4 (operating cost / VSS / commitment Hamming) 完全空白。
    3. Conditioning 有五级 ladder (rung 1–5)，不是 "conditional vs unconditional"。Power-renewable 占据 rung 2–4，rung 5 (text/LLM) 完全空白。
    4. "diffusion 击败 transformer for renewable" 在当前实验记录下是 underdetermined——2024 TACTiS-2 已在 GluonTS 反超，2026 PERFORM 无 diffusion entry。
    5. F1–F4 是关闭以上四条 gap 的具体可执行 artefact，建议作为单一研究 program 打包推进。

    这五句话是本 survey 希望 每一位 读者带走的最低限度结论；其余章节是把这五句话的根据、范围、操作含义详细化的支撑材料。

    11.5 限制 (Limitations) 与未来 update#

    本 survey 自身也有限制，需要诚实声明：

    (i) 调研范围：Phase 0 调研以 abstract-level 阅读 + 6/6 web query budget per thread 的方式进行；某些 方法论文 (尤其是 IEEE T-II / T-SG / T-PWRS conference paper 与 J. Modern Power Systems and Clean Energy 的 2025–2026 论文) 可能未充分覆盖。Phase 2 应做 systematic literature search (Web of Science + IEEE Xplore + ScienceDirect 完整查询) 补充。

    Foundations (diffusion / generative methodology canon)#

    1. Ho, Jain & Abbeel, "Denoising Diffusion Probabilistic Models," NeurIPS 2020 [作者待 verify] — DDPM 母论文，\(\mathcal{L}_{\text{simple}}\) 与 \(\bar{\alpha}_t\) 记号源头，§2 background 必引。它把扩散模型从理论（Sohl-Dickstein 2015）真正推进到工程可用，对 power-renewable 领域的影响是奠定一切后续 noise-prediction 训练范式。

    2. Song & Ermon, "Generative Modeling by Estimating Gradients of the Data Distribution," NeurIPS 2019 [作者待 verify] — score matching / NCSN，score-SDE 之前的关键铺垫。§2 / §3 score-parameterization 来源。理解它的退火 Langevin 采样有助于读懂为何 P3 reverse-step guidance 可以做成 score 加项，而不必从头训练受约束模型。

    3. Ho & Salimans, "Classifier-Free Diffusion Guidance," NeurIPS Workshop 2021 / 后续 arXiv 2207.12598 [作者待 verify] — CFG 公式 \(\tilde{\epsilon}=(1+w)\epsilon_\theta(\cdot,\mathbf{c})-w\,\epsilon_\theta(\cdot,\varnothing)\) 的源头。§4 conditioning ladder 与 F6 \(w\)-sweep frontier 的形式化基础。CFG 的 \(w\) 既是 controllability 旋钮也是 mode-coverage 杀手，本综述 F6 frontier 就是要把 \(w\) 对 tail-coverage 的代价量化成单图。

    4. Rombach et al., "High-Resolution Image Synthesis with Latent Diffusion Models," CVPR 2022 [作者待 verify] — latent diffusion paradigm。CLDM / CAL-DM 的隐空间训练直接继承这一思路。它的 perceptual-compression + diffusion-on-latent 解耦是把 high-resolution 时序场景做出来的工程关键，否则在 96×D 或更长 horizon 上做像素级扩散成本不可控。

    5. Song, "Denoising Diffusion Implicit Models," ICLR 2021 [作者待 verify] — DDIM 确定性采样，是 P3 / P4 / F3 路径上做 differentiable / invertible sampling 的工作母机。F3 frontier 提出的"pathwise gradient through DDIM × differentiable UC surrogate"完全依赖于 DDIM 反向链的可微性，因此该文是 decision-aware diffusion 任何尝试的方法论起点。

    6. Tweedie 估计器 [需补 Efron 2011 *JASA* "Tweedie's formula and selection bias" 作 anchor] — 公式 \(\hat{\mathbf{x}}_0(\mathbf{x}_t,t)=(\mathbf{x}_t-\sqrt{1-\bar{\alpha}_t}\epsilon_\theta)/\sqrt{\bar{\alpha}_t}\) 是 P3 / P4 把 constraint 评估在"clean-estimate 空间"的关键技巧。没有 Tweedie，constraint gradient 只能在 noisy \(\mathbf{x}_t\) 上算，物理意义模糊；有了它就能在每步把 noisy 状态映射回 clean-domain，在那里评估 capacity / ramp / KCL 等约束。

    1. Gneiting & Raftery, "Strictly Proper Scoring Rules, Prediction, and Estimation," JASA 102(477) 2007 [作者待 verify] — CRPS / energy score / log score 的统一 proper-scoring 框架。§7 Tier 1-2 metrics 必引。

    2. Savage, "Elicitation of Personal Probabilities and Expectations," JASA 1971 [作者待 verify] — proper scoring 哲学源头，定义"诚实报告概率"的奖励结构。引用为 §7 评估章节的方法论原点。
